Commands

low run
Compiles and runs a file or a module directory.
low build
Writes a native binary. -o names it and -target picks linux/amd64 or windows/amd64.
low dev
Runs the program and patches changed functions into it on save. Changing main, a type's layout or a function's signature restarts it.
low ir
Prints the optimised SSA form.
low asm
Prints the generated assembly.
low lint
Type-checks the program and prints its warnings.
low lsp
Starts the language server that the editor extensions use.

Build from source

$ git clone https://github.com/simon-curtis/lowlang
$ cd lowlang
$ go install ./cmd/low

Needs Go 1.27.3.

Projects and editors

A directory is a module. A low.mod file marks the project root, and import ui/text loads ui/text/ under it. The standard library is imported as std/..., and the editor extensions need low on PATH.
