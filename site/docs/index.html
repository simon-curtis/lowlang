Documentation

Low compiles to static native binaries with no libc dependency, has a tracing garbage collector and green threads with channels, and adds sum-type enums and typed error returns on top of a Go-sized core.

CommandDoes
low runCompiles and runs a file or a module directory.
low buildWrites a native binary. -o names it and -target picks linux/amd64 or windows/amd64 and defaults to the host.
low devRuns the program and patches changed functions into it on save. Changing main, a type's layout or a function's signature restarts it. Needs a Linux host.
low irPrints the optimised SSA form.
low asmPrints the generated assembly.
low lintType-checks the program and prints its warnings.
low docPrints the public API of every module under a directory as JSON.
low lspStarts the language server that the editor extensions use.
low versionPrints the release, or dev+ and the commit for a build from source.

A directory is a module. A low.mod file marks the project root, and import ui/text loads ui/text/ under it. The standard library is imported as std/..., and the editor extensions need low on PATH.

Build from source with Go 1.27.3:

$ git clone https://github.com/simon-curtis/lowlang
$ cd lowlang
$ go install ./cmd/low
