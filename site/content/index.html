A small language with its whole toolchain in one binary

Low is a compiled language with a garbage collector, green threads and errors the compiler makes you handle. Your programs build to small static binaries for Linux and Windows.

Free and open source under the MIT license.

The scripts install to ~/.local/bin on Linux and %USERPROFILE%\.low\bin on Windows. Set LOW_BIN to install somewhere else. A Linux binary you download yourself needs chmod +x.

Build from source

Use

low is the only tool you need. It compiles, assembles and links your program itself, so there is no C compiler or linker to install.

Pass --target to build for another system, such as a Windows program from Linux.

Every command

$ cat hello.low
fn main() {
    print("hello")
}
$ low run hello.low
hello
$ low build hello.low -o hello
$ low build hello.low --target windows/amd64

Features

Typed errors

A function that can fail says which errors it returns. The compiler won't let you ignore one: you handle it, or pass it up with ?.

Errors

Exhaustive enums

Enum variants can carry data. A match must handle every variant, so adding one shows you each place that needs updating.

Enums

Green threads and channels

spawn starts a lightweight thread. Threads talk over typed channels, and select waits on several channels at once.

Concurrency

Standard library

HTTP, TLS, gRPC, SQL, compression and a UI toolkit are built into low, so there is nothing extra to download.

Hot reload

low dev runs your program and swaps in the functions you change each time you save. Most edits apply without a restart, so the program keeps its state.

Hot reload

Tests

low test runs every test in its own process, in parallel. A test that passed is not run again until its code or the files it reads change.

Testing

Three targets

low build writes a Linux executable, a Windows executable or a WebAssembly module for the browser.

Compiler

Packages

List your dependencies in build.low with the versions you accept. build.lock records the exact commit and a hash of each, so every build uses the same code.

Projects

Inside the compiler

low splits hello.low into tokens, parses them into a tree, checks the types, optimises the code as SSA, writes amd64 assembly and links the executable. Every step runs inside low.
