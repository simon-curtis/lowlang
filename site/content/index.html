Low

A compiled, garbage-collected language with green threads, enums and typed errors. It builds small static binaries for Linux and Windows.

enum Shape {
    Circle(radius: i64)
    Rect(w: i64, h: i64)
}

fn area(s: Shape) -> i64 {
    match s {
        Circle(r) => 3 * r * r
        Rect(w, h) => w * h
    }
}

fn main() {
    print(area(Shape.Rect(3, 4)))
}

Install

Linux

$ curl -fsSL {{origin}}/install.sh | sh

Windows

> irm {{origin}}/install.ps1 | iex

The scripts install the latest release to ~/.local/bin on Linux, and on Windows to %LOCALAPPDATA%\Programs\low, which the script adds to PATH. Set LOW_INSTALL to choose another directory.

low compiles and links programs itself, including the patches of low dev, which needs a Linux host. Build from source

A program built for Windows runs the whole language and the standard library modules that only compute. Modules that call the operating system, such as files, processes and sockets, panic.

Use

$ cat hello.low
fn main() {
    print("hello")
}
$ low run hello.low
hello
$ low build hello.low -o hello
$ low build hello.low -target windows/amd64

Runtime and standard library

fn worker(jobs: chan[i64], results: chan[i64]) {
    for j in jobs { results <- j * j }
}

fn main() {
    let jobs = chan[i64](16)
    let results = chan[i64](16)
    for _ in 0..4 { spawn worker(jobs, results) }
    for i in 1..11 { jobs <- i }
    close(jobs)
    var total = 0
    for _ in 0..10 { total += (<-results) ?? 0 }
    print(total)
}
