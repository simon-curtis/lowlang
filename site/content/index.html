Low

A compiled, garbage-collected language with green threads, enums and typed errors. It builds small static binaries for Linux and Windows.

import std/slices

enum Shape {
    Circle(radius: f64)
    Rect(w: f64, h: f64)
}

enum ParseError {
    Unknown(name: str)
}

fn parse(name: str, size: f64) -> Shape ! ParseError {
    match name {
        "circle" => Shape.Circle(size)
        "square" => Shape.Rect(size, size)
        _ => fail Unknown(name)
    }
}

fn area(s: Shape) -> f64 {
    match s {
        Circle(r) => 3.14159 * r * r
        Rect(w, h) => w * h
    }
}

fn measure(name: str, areas: chan[f64]) {
    let shape = parse(name, 2.0) catch {
        Unknown(other) => {
            print("no shape called {other}")
            Shape.Rect(0.0, 0.0)
        }
    }
    areas <- shape.area()
}

fn main() {
    let names = ["circle", "square", "hexagon"]
    let areas = chan[f64](names.len)
    for name in names { spawn measure(name, areas) }
    let total = names.map(fn(_) (<-areas) ?? 0.0).sum()
    print("{names.len} shapes cover {total:f2}")
}

Inside the compiler

hello.low passes through each stage of low: lexing, parsing, type checking, SSA, amd64 assembly and linking, until the bytes of its static ELF build the mark.

Install

Linux

$ curl -fsSL {{origin}}/install.sh | sh

Windows

> irm {{origin}}/install.ps1 | iex

The scripts install the latest release to ~/.local/bin on Linux, and on Windows to %LOCALAPPDATA%\Programs\low, which the script adds to PATH. Set LOW_INSTALL to choose another directory.

low compiles, assembles and links programs itself, so it needs no other toolchain. low dev needs a Linux host. Build from source

Programs built for Windows use files, processes, sockets, DNS, terminals and the environment through Win32. Signals, file watches and pseudo-terminals fail with Unsupported.

Use

$ cat hello.low
fn main() {
    print("hello")
}
$ low run hello.low
hello
$ low build hello.low -o hello
$ low build hello.low -target windows/amd64
