A small language with its whole toolchain in one binary

A compiled, garbage-collected language with green threads, enums and typed errors. It builds small static binaries for Linux and Windows.

Free and open source under the MIT license.

The scripts install the latest release to ~/.local/bin on Linux, and on Windows to %USERPROFILE%\.low\bin, which the script adds to PATH and where low install writes. Set LOW_BIN to choose another directory.

Build from source

Use

low compiles, assembles and links programs itself, so it needs no other toolchain. low dev needs a Linux host.

Programs built for Windows use files, processes, sockets, DNS, terminals and the environment through Win32. Signals, file watches and pseudo-terminals fail with Unsupported.

Every command

$ cat hello.low
fn main() {
    print("hello")
}
$ low run hello.low
hello
$ low build hello.low -o hello
$ low build hello.low --target windows/amd64

Features

Typed errors

A function that can fail declares its error enum. ? returns the error to the caller, and a result cannot be discarded without ?, catch or or.

Errors

Exhaustive enums

Variants carry payloads, and a match has to cover every one of them.

Enums

Green threads and channels

spawn starts a green thread, a chan[T] carries values between threads and select waits on several channels at once.

Concurrency

Standard library

HTTP, TLS, gRPC, SQL, compression and a Vulkan user interface toolkit, compiled into low.

Hot reload

low dev patches the functions you changed into the running program on save. The heap, the stack and every live value are kept.

Hot reload

Tests

low test runs each test in its own process, in parallel, and replays a passing result while the test program and its inputs are unchanged.

Every command

Three targets

low build writes a native binary for linux/amd64 or windows/amd64, or a WebAssembly module for browser/wasm32.
