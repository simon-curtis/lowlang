std/base58

#encoding

import std/base58

The Bitcoin alphabet (encode, decode), the Flickr alphabet (encode_flickr, decode_flickr) and Base58Check (encode_check, decode_check), failing at the first bad character.

Imports std/crypto/hash, std/text.

Functions

decode

pub fn decode(s: str) -> []u8 ! Error

Decodes Base58 text written with the Bitcoin alphabet. Each leading 1 becomes one leading zero byte, and an empty string gives empty data. Fails with BadCharacter at the index of the first byte outside the alphabet.

decode_check

pub fn decode_check(s: str) -> []u8 ! Error

Decodes Base58Check text and returns the payload without its checksum. Fails with BadCharacter as decode does, with TooShort when fewer than four bytes decode, and with BadChecksum when the last four bytes are not the first four bytes of the double SHA-256 of the rest.

decode_flickr

pub fn decode_flickr(s: str) -> []u8 ! Error

Decodes Base58 text written with the Flickr alphabet. Failure cases and leading-character handling are those of decode.

encode

pub fn encode(data: []u8) -> str

Returns data encoded as Base58 with the Bitcoin alphabet, which omits 0, O, I and l. Each leading zero byte becomes one leading 1, and empty input gives an empty string. The cost is quadratic in the length of data.

encode_check

pub fn encode_check(data: []u8) -> str

Returns data followed by the first four bytes of its double SHA-256, encoded as Base58 with the Bitcoin alphabet (Base58Check).

encode_flickr

pub fn encode_flickr(data: []u8) -> str

Returns data encoded as Base58 with the Flickr alphabet, which is the Bitcoin alphabet with lowercase letters ordered before uppercase. Leading zero bytes become leading 1 characters, as in encode.
