#database

import std/sql/postgres

A PostgreSQL driver over protocol 3.0, plain or over TLS.

Imports std/base64, std/crypto, std/crypto/hash, std/crypto/md5, std/crypto/password, std/io, std/math, std/net, std/sql, std/sql/driver, std/text, std/time/date, std/tls.

Scram

pub struct Scram {
    ...
}

The state of one SCRAM-SHA-256 authentication exchange: the password, the client nonce, the client-first-message body and the server signature scram_final computes for scram_verify.

scram_final

pub fn scram_final(s: *Scram, server_first: str) -> str ! sql.Error

Computes the client-final-message, with the proof, from the server-first-message server_first.

Returns sql.Error.Protocol when server_first lacks the r, s or i attribute, when the server nonce does not extend the client nonce, or when the salt or iteration count is invalid, and sql.Error.Unsupported when the server demands an extension. It records the signature scram_verify expects.

scram_first

pub fn scram_first(s: *Scram) -> str

Returns the client-first-message to send to the server, n,,n=<user>,r=<nonce>.

scram_verify

pub fn scram_verify(s: *Scram, server_final: str) ! sql.Error

Checks the server-final-message server_final against the signature scram_final computed.

Returns sql.Error.Authentication when the server reports an e= error or the signature differs, and sql.Error.Protocol when the message has no v attribute or it is not valid base64.

Functions

connect

pub fn connect(o: sql.Options) -> sql.Connection ! sql.Error

Connects to a PostgreSQL server over plain TCP, using o.host and o.port (5432 by default), and authenticates as o.user to o.database.

A call that times out closes the connection and sends a cancel request to the server over a new connection. Passwords are sent in cleartext, as an MD5 hash or through SCRAM-SHA-256, as the server requests. Returns sql.Error.Connect when the connection cannot be made, sql.Error.Timeout when it exceeds o.timeout, sql.Error.Authentication when the login fails, sql.Error.Unsupported for an authentication method the driver lacks and sql.Error.Server when the server rejects the startup. Dropping the returned sql.Connection closes the socket.

connect_stream

pub fn connect_stream(s: io.Stream, o: sql.Options) -> sql.Connection ! sql.Error

Connects over a stream that is already connected, such as a Unix socket or a tunnel, and authenticates as connect does.

o.host, o.port and o.timeout are not used to dial. A timed out call closes the stream without sending the cancel request that connect sends. Fails like connect after the dial.

connect_tls

pub fn connect_tls(o: sql.Options, config: tls.Config) -> sql.Connection ! sql.Error

Connects to a PostgreSQL server and upgrades the connection to TLS with the SSLRequest exchange before authenticating. config sets the TLS options; an empty server_name is replaced with o.host.

Returns sql.Error.Unsupported when the server answers that it does not do TLS and sql.Error.Protocol for any other answer. Otherwise fails like connect.

scram

pub fn scram(user: str, password: str, nonce: str) -> *Scram

Starts a SCRAM-SHA-256 exchange for user and password with the client nonce. The , and = characters in user are escaped as =2C and =3D.
