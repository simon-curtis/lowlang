std/net

#net

import std/net

Addresses: IPv4 and IPv6 Addr, parse_ip, format_ip, parse_addr, format, in_network (tests an address against a CIDR prefix) and is_global (false for addresses the IANA special-purpose registries mark as not globally reachable, and for multicast). Types: the droppable Listener, Conn and Socket, each with a copyable ListenerHandle, ConnHandle or SocketHandle in its handle field; adopt and detach convert between a ConnHandle and a Conn. TCP: listen, accept, accept_handle (returns the connection's view for a green thread to adopt), connect, dial and their _within forms with a connect timeout, connect_through (binds the socket to a network interface first), connect_first (tries a list of addresses in order through an optional interface) and interface_index. Connection I/O: read, write, write_all, close, shutdown_write, set_nodelay, read and write timeouts and stream, with read_on, write_on, write_all_on, close_on and stream_on on the view. UDP: bind_udp, send_to, receive_from and close_socket. lookup tries an IP literal, then /etc/hosts, then A and AAAA queries to each /etc/resolv.conf nameserver. An Addr with an empty ip is a Unix address: listen_unix, connect_unix, connect_unix_within and socketpair return the same Listener and Conn, abstract names start with @ or NUL, and a listener unlinks its pathname when closed. peer_credentials returns the peer's credentials. listen_with and bind_udp_with take ListenOptions (reuse_addr, reuse_port, backlog). Socket options: set_keepalive and set_buffer_sizes. UDP multicast: join_group, leave_group, set_multicast_ttl, set_multicast_loop and set_multicast_interface. Dialer is a function value that makes a connection; direct_dialer is the plain one.

Imports std/file, std/io, std/text.

connect

pub fn connect(a: Addr) -> Conn ! io.Error

Connects to the TCP or Unix address a.

Parks the green thread while the connection is in progress, with no time limit of its own. Does the same as connect_within with no timeout.

connect_through

pub fn connect_through(a: Addr, device: str, millis: i64) -> Conn ! io.Error

Connects to a through the network interface device.

Binds the socket to device before connecting, which usually needs privileges. An empty device leaves the choice to the system. millis is the timeout as for connect_within.

connect_within

pub fn connect_within(a: Addr, millis: i64) -> Conn ! io.Error

Connects to a, failing with TimedOut if the connection takes longer than millis milliseconds.

A millis of 0 or less means no limit. Parks the green thread while the connection is in progress. Fails with Refused or Unreachable as the system reports.

read

pub fn read(c: Conn, buf: []u8) -> i64 ! io.Error

Reads up to buf.len bytes from c into buf and returns the count, or 0 at end of input.

Parks the green thread until data arrives. If the read timeout elapses first, the connection is shut down and the call fails with TimedOut. Fails with NotConnected after the connection is closed, including while the call is waiting.

set_buffer_sizes

Sets the receive and send buffer sizes of c in bytes.

A value of 0 or less leaves that buffer unchanged. The kernel can adjust the requested size, so read it back with buffer_sizes. Fails with NotConnected if c is closed.

set_keepalive

pub fn set_keepalive(c: Conn, idle: i64, interval: i64, count: i64) ! io.Error

Configures TCP keep-alive on c.

An idle of 0 or less turns keep-alive off. Otherwise it sets the idle time in seconds, sets interval and count when they are greater than 0 and leaves the system default otherwise, and turns keep-alive on. Fails with NotConnected if c is closed.

set_nodelay

write

Shuts the connection down so green threads waiting to read or write wake and fail, and releases the descriptors once the last operation in progress has finished. Later reads and writes fail with NotConnected. Later calls do nothing.

Accepts the next connection on the listener behind h and returns its view.

Parks the green thread until a connection arrives. The caller owns the connection, usually by passing the view to a green thread that binds it with adopt. Fails with NotConnected once the listener is closed, including while the call is waiting. A connection reset before it was accepted is skipped.

join_group

pub fn join_group(s: Socket, group: []u8, interface: str) ! io.Error

Joins the multicast group on the UDP socket s.

group is 4 bytes in 224.0.0.0 to 239.255.255.255 or 16 bytes starting with 0xFF, and must be the same family as the socket's bound address. interface names the network interface to join on, or is empty to let the system choose. Fails with Invalid if group is not a multicast address of the socket's family, with NotFound for an unknown interface and with NotConnected if s is closed.

connect_first

pub fn connect_first(ips: [][]u8, port: i64, device: str, millis: i64) -> Conn ! io.Error

Connects to the first of the addresses ips that accepts a connection on port.

Tries the addresses in order, each with the timeout millis and through device as for connect_through, and moves on after a failure. The error of the last address is the one returned. Fails with NotFound if ips is empty.

pub fn connect_unix(path: str) -> Conn ! io.Error

Connects to the Unix stream socket at path.

Parks the green thread while the connection is in progress. Fails as connect_unix_within does, with the default wait.

connect_unix_within

pub fn connect_unix_within(path: str, millis: i64) -> Conn ! io.Error

Connects to the Unix stream socket at path, waiting at most millis milliseconds.

When the listener's backlog is full it retries every millisecond for up to millis, or 30 seconds when millis is 0 or less, and then fails with TimedOut. Fails with Invalid for a bad path, NotFound if there is no socket and Refused if nothing listens.

pub fn format_ip(ip: []u8) -> str

Returns the text form of ip: dotted decimal for 4 bytes and lowercase hexadecimal groups for 16.

The longest run of two or more zero groups in an IPv6 address is written as ::. Returns an empty string for an empty ip.

in_network

pub fn in_network(ip: []u8, prefix: str) -> bool

Returns whether ip lies within the CIDR range prefix, written address/bits such as 10.0.0.0/8.

interface_index

pub fn interface_index(name: str) -> i64 ! io.Error

Returns the kernel index of the network interface name.

Fails with Invalid if name is empty or longer than 15 bytes, and with NotFound if there is no such interface.

is_global

pub fn is_global(ip: []u8) -> bool

Returns whether ip is a globally reachable unicast address.

Returns false for the ranges the IANA special-purpose registries mark as not globally reachable, such as loopback, private, link-local, documentation and unique-local ranges, and for multicast and reserved ranges. The registries' globally reachable exceptions inside those ranges return true. An IPv4-mapped IPv6 address is judged by its IPv4 part, and an ip that is neither 4 nor 16 bytes returns false.

listen

pub fn listen(host: str, port: i64) -> Listener ! io.Error

Listens for TCP connections on host and port.

Uses the default ListenOptions. An empty host listens on all IPv4 addresses, :: on all IPv6 addresses, and any other name is resolved with lookup and its first address is used. Port 0 chooses a free port, which handle.addr.port reports. Fails with AddrInUse if the port is taken and Denied if the caller may not bind it.

listen_unix

pub fn listen_unix(path: str) -> Listener ! io.Error

Listens for stream connections on the Unix socket path.

path is validated as unix_addr does and can name an abstract socket. The backlog is 4096. Fails with AddrInUse if a file already exists at path. Closing the listener removes the socket file, except for an abstract name.

listen_with

pub fn listen_with(host: str, port: i64, o: ListenOptions) -> Listener ! io.Error

Listens for TCP connections on host and port with the given options.

host and port are used as for listen. Fails with Invalid if the system rejects reuse_addr or reuse_port.

lookup

pub fn lookup(host: str) -> [][]u8 ! io.Error

Returns the IP addresses of host.

Tries an IP literal first, then the entries of /etc/hosts matching the name without regard to case, then localhost as 127.0.0.1 and ::1, and then DNS. For DNS it asks each nameserver of /etc/resolv.conf in turn, or 127.0.0.1 when none is listed, for A and then AAAA records over UDP port 53, with a 2 second timeout and one retry per query, and returns the addresses of the first server that has any. Search domains and TCP fallback are not used. Fails with NotFound if no address is found. Parks the green thread during the network queries and blocks the OS thread while it reads the two files.

parse_addr

pub fn parse_addr(s: str) -> Addr ! io.Error

Parses host:port into an Addr.

The text is split at its last :. The host must be an IP literal, in square brackets if desired, and the port a number from 0 to 65535. Host names are not resolved. Fails with Invalid for any other form.

parse_ip

pub fn parse_ip(s: str) -> []u8 ! io.Error

Parses an IPv4 dotted-quad or an IPv6 literal and returns its 4 or 16 bytes.

An address containing : is read as IPv6, with :: compression and an optional trailing dotted IPv4 part. Brackets, zone identifiers and host names are not accepted. Fails with Invalid if s is not an address.

socketpair

pub fn socketpair() -> ConnPair ! io.Error

Returns two connected, unnamed Unix stream sockets.

unix_addr

pub fn unix_addr(path: str) -> Addr ! io.Error

Returns the Unix address for the socket path.

A path that starts with @ or NUL names an abstract socket and is returned as @ followed by the rest of the name. Fails with Invalid if path is empty, longer than 107 bytes or, for a filesystem path, contains NUL.
