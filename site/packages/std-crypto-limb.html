std/crypto/limb

#crypto

import std/crypto/limb

Fixed-width limb arithmetic the big-integer code shares: carry and borrow out of a 64-bit step, add, sub and add_masked over limb slices, and the constant-time same, mask_of, blend, choose, gather, equal and is_zero. std/crypto/ecdsa, std/crypto/rsa and std/crypto/ed25519 build on it.

Functions

add

pub fn add(out: []u64, a: []u64, b: []u64) -> u64

Sets out to a + b over the limbs of out, least significant limb first, and returns the final carry as 0 or 1.

a and b must have at least as many limbs as out. out can be the same slice as a. The running time does not depend on the values.

add_masked

pub fn add_masked(out: []u64, x: []u64, mask: u64) -> u64

Adds x to out in place wherever mask is all ones, and returns the final carry as 0 or 1.

mask is 0 to add nothing or all ones to add x. x must have at least as many limbs as out.

blend

pub fn blend(mask: u64, a: u64, b: u64) -> u64

Returns a where mask is all ones and b where it is 0.

borrow

pub fn borrow(a: u64, b: u64, diff: u64) -> u64

Returns the borrow out of the 64-bit subtraction a - b whose wrapped result is diff, as 0 or 1.

carry

pub fn carry(a: u64, b: u64, sum: u64) -> u64

Returns the carry out of the 64-bit addition a + b whose wrapped result is sum, as 0 or 1.

choose

pub fn choose(out: []u64, a: []u64, b: []u64, mask: u64)

Sets each limb of out to the matching limb of a where mask is all ones and of b where it is 0.

a and b must have at least as many limbs as out.

clear

pub fn clear(out: []u64)

Sets out to zero.

equal

pub fn equal(a: []u64, b: []u64) -> bool

Returns whether a and b hold the same limbs, comparing all of them.

b must have at least as many limbs as a. The running time does not depend on the values.

gather

pub fn gather(out: []u64, row: []u64, mask: u64)

Ors the limbs of row into out wherever mask is all ones, for a table lookup that reads every row.

row must have at least as many limbs as out.

is_zero

pub fn is_zero(a: []u64) -> bool

Returns whether every limb of a is zero, comparing all of them.

mask_of

pub fn mask_of(bit: u64) -> u64

Returns the mask that is all ones when bit is 1 and 0 when it is 0.

same

pub fn same(a: u64, b: u64) -> u64

Returns 1 when a equals b and 0 otherwise, without a branch that depends on the values.

sub

pub fn sub(out: []u64, a: []u64, b: []u64) -> u64

Sets out to a - b over the limbs of out, least significant limb first, and returns the final borrow as 0 or 1.

a and b must have at least as many limbs as out. out can be the same slice as a. The running time does not depend on the values.
