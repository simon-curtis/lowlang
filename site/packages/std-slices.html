std/slices

#data

import std/slices

Queries and transforms: contains, index, clone, concat, reverse, map, filter, fold, scan, any, all, sum, min and max (as optionals), sorted. Sorting: sort and sort_by are unstable and in place, a quicksort with median-of-three pivots that recurses into the smaller side and finishes runs of 16 or fewer with insertion sort. sort_stable and sort_stable_by are a top-down merge sort; sort_by_key is stable. Also reduce, count, find, find_index, first, last, equal, compare, starts_with, ends_with, unique (adjacent duplicates), flat_map, flatten, repeat, lower_bound, binary_search (the first match) and binary_search_by. take, skip, chunks and windows share the source's elements. partition and zip work over Pair[A, B]. fill, swap, rotate, insert and remove are in place. They chain as calls on the slice: xs.sort(), words.map(fn(w) w.len).sum().|> slices.sort()`.

Imports std/math.

Examples

daily_sales

import std/slices

struct Day {
    name: str
    sales: i64
}

/// Summarises two weeks of daily sales with running totals, weekly chunks, moving sums, a sorted ranking and a partition by target.
fn main() {
    let sales = [120, 95, 140, 180, 210, 90, 60, 130, 150, 125, 170, 220, 80, 70]
    print("total {slices.sum(sales)}, best {slices.max(sales) ?? 0}, worst {slices.min(sales) ?? 0}")
    print("running total {slices.scan(sales, 0, fn(total, day) total + day)}")

    for i, week in slices.chunks(sales, 7) {
        print("week {i + 1}: {slices.sum(week)}")
    }

    let moving = slices.map(slices.windows(sales, 3), fn(w) slices.sum(w) / 3)
    print("3 day average {moving}")

    var days: []Day = []
    for i, amount in sales {
        push(mut days, Day { name: "d{i + 1}", sales: amount })
    }
    slices.sort_by_key(mut days, fn(d) 0 - d.sales)
    let top = slices.map(slices.take(days, 3), fn(d) "{d.name}={d.sales}")
    print("top three {top}")

    let split = slices.partition(sales, fn(s) s >= 150)
    print("at or above 150: {split.first}")
    print("below 150: {split.second}")
    print("first day under 100: day {(slices.find_index(sales, fn(s) s < 100) ?? -1) + 1}")
    print("every day above 50: {slices.all(sales, fn(s) s > 50)}, any above 200: {slices.any(sales, fn(s) s > 200)}")

    var ranked = slices.clone(sales)
    slices.sort(mut ranked)
    slices.reverse(mut ranked)
    print("ranked {slices.take(ranked, 5)}")
    var ascending = slices.clone(sales)
    slices.sort(mut ascending)
    let at = slices.binary_search(ascending, 150)
    print("150 sits at sorted position {at ?? -1}, 151 would insert at {slices.lower_bound(ascending, 151)}")
}

Functions

all

pub fn all[T](xs: []T, test: fn(T) -> bool) -> bool

Returns true when test returns true for every element of xs.

Stops at the first failure. Returns true for an empty slice.

any

pub fn any[T](xs: []T, test: fn(T) -> bool) -> bool

Returns true when test returns true for at least one element of xs.

Stops at the first match. Returns false for an empty slice.

binary_search

pub fn binary_search[T: Ord](xs: []T, x: T) -> i64?

Returns the index of the first element of the sorted slice xs equal to x, or none when there is none.

The slice must be sorted in ascending order. Takes logarithmic time.

binary_search_by

pub fn binary_search_by[T](xs: []T, order: fn(T) -> i64) -> i64?

Searches xs with a three-way comparison function and returns the index of an element for which order returns 0, or none.

order(item) returns a negative number when item is before the target, a positive number when it is after the target and 0 for the target. The slice must be partitioned in that order. When several elements match, any of their indexes can be returned. Takes logarithmic time.

chunks

pub fn chunks[T](xs: []T, size: i64) -> [][]T

Splits xs into consecutive slices of size elements.

The last slice is shorter when size does not divide xs.len, and the result is empty for an empty xs. The slices share storage with xs. Panics when size is less than 1.

clone

pub fn clone[T](xs: []T) -> []T

Returns a new slice with a copy of the elements of xs.

The result does not share storage with xs.

compare

pub fn compare[T: Ord](xs: []T, ys: []T) -> i64

Compares xs with ys element by element and returns -1, 0 or 1.

The first differing pair decides. When one slice is a prefix of the other, the shorter one is less.

concat

pub fn concat[T](xs: []T, ys: []T) -> []T

Returns a new slice holding the elements of xs followed by those of ys.

The result does not share storage with either argument.

contains

pub fn contains[T: Eq](xs: []T, x: T) -> bool

Returns true when xs has an element equal to x.

Scans xs from the start, so it takes linear time.

count

pub fn count[T](xs: []T, test: fn(T) -> bool) -> i64

Returns the number of elements of xs for which test returns true.

ends_with

pub fn ends_with[T: Eq](xs: []T, suffix: []T) -> bool

Returns true when the last elements of xs equal suffix.

An empty suffix always matches.

equal

pub fn equal[T: Eq](xs: []T, ys: []T) -> bool

Returns true when xs and ys have the same length and equal elements at every index.

fill

pub fn fill[T](mut xs: []T, value: T)

Sets every element of xs to value.

filter

pub fn filter[T](xs: []T, keep: fn(T) -> bool) -> []T

Returns a new slice of the elements of xs for which keep returns true, in their original order.

find

pub fn find[T](xs: []T, test: fn(T) -> bool) -> T?

Returns the first element of xs for which test returns true, or none when there is none.

find_index

pub fn find_index[T](xs: []T, test: fn(T) -> bool) -> i64?

Returns the index of the first element of xs for which test returns true, or none when there is none.

first

pub fn first[T](xs: []T) -> T?

Returns the first element of xs, or none when it is empty.

flat_map

pub fn flat_map[T, U](xs: []T, f: fn(T) -> []U) -> []U

Returns the concatenation of f applied to each element of xs, in order.

flatten

pub fn flatten[T](xss: [][]T) -> []T

Returns a new slice of the elements of each slice in xss, in order.

fold

pub fn fold[T, A](xs: []T, initial: A, f: fn(A, T) -> A) -> A

Combines the elements of xs from the first to the last into one value.

Starts with initial and sets the accumulator to f(accumulator, element) for each element. Returns initial when xs is empty.

index

pub fn index[T: Eq](xs: []T, x: T) -> i64?

Returns the index of the first element of xs equal to x, or none when there is none.

insert

pub fn insert[T](mut xs: []T, at: i64, value: T)

Inserts value into xs so that it ends up at index at, moving later elements one place right.

at may equal xs.len to append. Takes linear time in the number of elements moved. Panics when at is negative or greater than xs.len.

last

pub fn last[T](xs: []T) -> T?

Returns the last element of xs, or none when it is empty.

lower_bound

pub fn lower_bound[T: Ord](xs: []T, x: T) -> i64

Returns the index of the first element of the sorted slice xs that is not less than x.

Returns xs.len when every element is less than x. The slice must be sorted in ascending order. Takes logarithmic time.

map

pub fn map[T, U](xs: []T, f: fn(T) -> U) -> []U

Returns a new slice of f applied to each element of xs, in order.

max

pub fn max[T: Ord](xs: []T) -> T?

Returns the largest element of xs, or none when it is empty.

When several elements are equal and largest, the first is returned.

min

pub fn min[T: Ord](xs: []T) -> T?

Returns the smallest element of xs, or none when it is empty.

When several elements are equal and smallest, the first is returned.

partition

pub fn partition[T](xs: []T, test: fn(T) -> bool) -> Pair[[]T, []T]

Splits xs into the elements for which test returns true and the rest.

first holds the matches and second the others, each in their original order.

reduce

pub fn reduce[T](xs: []T, f: fn(T, T) -> T) -> T?

Combines the elements of xs from the first to the last with f, starting from the first element.

Returns none when xs is empty and the only element, without calling f, when it has one.

remove

pub fn remove[T](mut xs: []T, at: i64) -> T

Removes the element at index at from xs and returns it, moving later elements one place left.

Takes linear time in the number of elements moved. Panics when at is out of range.

repeat

pub fn repeat[T](xs: []T, times: i64) -> []T

Returns a new slice holding xs repeated times times.

The result is empty when times is zero or negative.

reverse

pub fn reverse[T](mut xs: []T)

Reverses the elements of xs in place.

rotate

pub fn rotate[T](mut xs: []T, by: i64)

Rotates the elements of xs left by by places in place, so the element at index by moves to index 0.

A negative by rotates right. by is taken modulo xs.len. Takes linear time and no extra storage.

scan

pub fn scan[T, A](xs: []T, initial: A, f: fn(A, T) -> A) -> []A

Returns every accumulator value fold passes through, in order, without initial.

Element i of the result is fold over the first i + 1 elements of xs, so the result is as long as xs.

skip

pub fn skip[T](xs: []T, n: i64) -> []T

Returns xs without its first n elements.

The result shares storage with xs. It is xs itself when n is zero or negative and empty when n is at least xs.len.

sort

pub fn sort[T: Ord](mut xs: []T)

Sorts xs in ascending order in place.

The sort is not stable. It is a quicksort with a median-of-three pivot that finishes small ranges with insertion sort, taking O(n log n) time on typical input and O(n^2) in the worst case, with logarithmic stack use.

sort_by

pub fn sort_by[T](mut xs: []T, less: fn(T, T) -> bool)

Sorts xs in place so that no element is preceded by one for which less returns true.

less(a, b) returns true when a must come before b and must be a strict weak ordering. The sort is not stable and has the cost of sort.

sort_by_key

pub fn sort_by_key[T, K: Ord](mut xs: []T, key: fn(T) -> K)

Sorts xs in place by the ascending value of key for each element, keeping elements with equal keys in their original order.

key runs on every comparison, not once per element, so it should be cheap.

sort_stable

pub fn sort_stable[T: Ord](mut xs: []T)

Sorts xs in ascending order in place, keeping equal elements in their original order.

A merge sort that takes O(n log n) time and a temporary buffer of half the slice.

sort_stable_by

pub fn sort_stable_by[T](mut xs: []T, less: fn(T, T) -> bool)

Sorts xs in place by less, keeping elements that compare equal in their original order.

less(a, b) returns true when a must come before b and must be a strict weak ordering. A merge sort that takes O(n log n) time and a temporary buffer of half the slice.

sorted

pub fn sorted[T: Ord](xs: []T) -> bool

Returns true when xs is in ascending order, which includes equal neighbours.

Slices with fewer than two elements are sorted.

starts_with

pub fn starts_with[T: Eq](xs: []T, prefix: []T) -> bool

Returns true when the first elements of xs equal prefix.

An empty prefix always matches.

sum

pub fn sum[T: Number](xs: []T) -> T

Returns the sum of the elements of xs, which is 0 for an empty slice.

The addition has the overflow behaviour of T.

swap

pub fn swap[T](mut xs: []T, i: i64, j: i64)

Exchanges the elements of xs at indexes i and j.

Panics when either index is out of range.

take

pub fn take[T](xs: []T, n: i64) -> []T

Returns the first n elements of xs, or all of xs when it is shorter.

The result shares storage with xs. It is empty when n is zero or negative.

unique

pub fn unique[T: Eq](xs: []T) -> []T

Returns a new slice of xs with each run of consecutive equal elements reduced to one.

Only neighbours are compared, so equal elements that are apart both stay. Sort xs first to remove all duplicates.

windows

pub fn windows[T](xs: []T, size: i64) -> [][]T

Returns every run of size consecutive elements of xs, starting at each index in turn.

The result is empty when xs has fewer than size elements. The slices share storage with xs. Panics when size is less than 1.

zip

pub fn zip[A, B](xs: []A, ys: []B) -> []Pair[A, B]

Returns a slice of pairs of the elements of xs and ys at the same index.

The result has the length of the shorter slice.
