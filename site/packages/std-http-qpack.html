std/http/qpack

#net #web

import std/http/qpack

QPACK (RFC 9204) with no I/O. Decoder (decoder takes the maximum table capacity, the blocked stream limit and the field section size limit) keeps the dynamic table: on_encoder_stream consumes encoder stream bytes split anywhere, buffers at most 64 KiB of an incomplete instruction and returns the blocked streams that can now decode; decode returns Decoded, either Fields or Blocked, and queues a Section Acknowledgment; cancel_stream queues a Stream Cancellation; take_decoder_stream returns the queued decoder stream bytes plus one Insert Count Increment. Encoder writes field sections with the static table only, so they never block and nothing goes on the encoder stream; on_decoder_stream accepts Stream Cancellations and fails Malformed on any other instruction. decompression_failed, encoder_stream_error and decoder_stream_error return the HTTP/3 codes 0x200, 0x201 and 0x202 for failures of decode, on_encoder_stream and on_decoder_stream. Every entry point fails Malformed on hostile input: integers are capped at 2^62-1, and strings, indexes, Required Insert Counts, Bases, entry sizes and capacities are checked before use. static_table, insert_count, table_size and table_entries expose the tables.

Imports std/header, std/http/huffman, std/io, std/slices, std/text.

Examples

field_section

import std/header
import std/http/qpack
import std/io
import std/text

/// Encodes a request's header fields for HTTP/3 and decodes the section the way a peer would.
fn main() ! io.Error {
    let request = [
        header.Header { name: ":method", value: "GET" }
        header.Header { name: ":scheme", value: "https" }
        header.Header { name: ":path", value: "/index.html" }
        header.Header { name: ":authority", value: "example.com" }
        header.Header { name: "User-Agent", value: "low/1" }
        header.Header { name: "x-request-id", value: "r-42" }
    ]
    let encoder = qpack.encoder()
    let block = qpack.encode(encoder, request)
    print("{block.len} bytes: {text.encode_hex(block)}")

    let decoder = qpack.decoder(0, 0, 4096)
    match qpack.decode(decoder, 0, block)? {
        Fields(fields) => {
            for f in fields {
                print("{f.name}: {f.value}")
            }
        }
        Blocked => print("blocked")
    }
}

Decoder

pub struct Decoder {
    ...
}

A QPACK decoder (RFC 9204): the dynamic table, the encoder stream parser and the decoder stream instructions owed to the peer's encoder.

A decoder does no I/O and is not safe for concurrent use. The caller owns the streams. It feeds bytes read from the peer's encoder stream to on_encoder_stream, field sections read from request or response streams to decode, and writes take_decoder_stream to its own decoder stream.

Failures map to HTTP/3 error codes by the function that failed. A failure of decode is QPACK_DECOMPRESSION_FAILED (decompression_failed), except TooLarge, which is a field section over the size limit and is handled as RFC 9114 section 4.2.2 describes. A failure of on_encoder_stream is QPACK_ENCODER_STREAM_ERROR (encoder_stream_error). After any failure the connection is to be closed with that code, so the decoder is not used again.

cancel_stream

pub fn cancel_stream(d: *Decoder, stream: i64)

Records that stream was reset or abandoned before its field sections were all decoded, and queues a Stream Cancellation for the peer's encoder.

A blocked section of the stream is forgotten and no longer counts against max_blocked. When max_capacity is 0 the encoder cannot hold references and no instruction is queued.

decode

pub fn decode(d: *Decoder, stream: i64, block: []u8) -> Decoded ! io.Error

Decodes one encoded field section read from stream, which is a non-negative QUIC stream ID.

Returns Fields with the field lines in order. When the section's Required Insert Count is above insert_count, returns Blocked and records the stream as blocked; the caller keeps the section bytes and decodes them again once on_encoder_stream lists the stream. A blocked section is parsed only as far as its prefix, so its field lines are checked on the second call.

After a section whose Required Insert Count is not zero is decoded, a Section Acknowledgment for stream is queued for take_decoder_stream.

Fails Malformed, which the caller reports as QPACK_DECOMPRESSION_FAILED, for a truncated section, an integer over 2^62-1, an invalid Required Insert Count encoding, a Base below zero, an index past the static table, a dynamic reference that is evicted, at or above the Required Insert Count or relative to a Base it underflows, a string that runs past the section, invalid Huffman data, and a block that would exceed max_blocked blocked streams. Fails TooLarge when the decoded field section would exceed max_field_section_size; the decoder stops before building more than that.

insert_count

pub fn insert_count(d: *Decoder) -> i64

Returns the number of entries the decoder has inserted into the dynamic table, counting those since evicted.

on_encoder_stream

pub fn on_encoder_stream(d: *Decoder, data: []u8) -> []i64 ! io.Error

Consumes bytes of the peer's encoder stream and returns the streams that were blocked and can now be decoded.

The instructions are Set Dynamic Table Capacity, Insert With Name Reference (static or dynamic), Insert With Literal Name and Duplicate. An instruction may be split across calls: the unparsed tail is kept and joined to the next call's data. The tail is never larger than 65536 bytes, and no string in an instruction may declare a longer length, so a peer cannot make the decoder buffer more.

The returned stream IDs are those decode reported as Blocked whose Required Insert Count the table has now reached, in the order they became blocked. Each is returned once. The caller decodes its stored section for each stream again.

Fails Malformed, which the caller reports as QPACK_ENCODER_STREAM_ERROR, for a capacity above max_capacity, an entry larger than the capacity, a static index past the table, a dynamic index that was evicted or never inserted, an integer over 2^62-1, a string longer than its limit, invalid Huffman data and a tail over the buffer limit.

table_entries

pub fn table_entries(d: *Decoder) -> []header.Header

Returns the entries still in the dynamic table, oldest first.

table_size

pub fn table_size(d: *Decoder) -> i64

Returns the size of the dynamic table in bytes: each entry counts its name length, its value length and 32.

take_decoder_stream

pub fn take_decoder_stream(d: *Decoder) -> []u8

Returns the bytes to write to the decoder stream and clears them.

They are the Section Acknowledgments and Stream Cancellations queued since the last call, in order, followed by one Insert Count Increment covering the insertions the peer has not yet been told about, either by an increment or by the Required Insert Count of an acknowledged section. The result is empty when nothing is owed. Call it after on_encoder_stream, decode and cancel_stream.

Encoder

pub struct Encoder {
    ...
}

A QPACK encoder (RFC 9204) that uses only the static table.

It never inserts into the dynamic table and writes nothing to the encoder stream, so every field section it produces has a Required Insert Count of 0 and can be decoded at once. A peer decoder needs no SETTINGS_QPACK_MAX_TABLE_CAPACITY for it. The caller feeds the bytes it reads from the peer's decoder stream to on_decoder_stream.

encode

pub fn encode(e: *Encoder, fields: []header.Header) -> []u8

Encodes fields as one field section and returns its bytes.

The name of each field is lowercased. A field that equals a static table entry is written as an indexed field line, a field whose name is in the static table as a literal with a name reference, and any other as a literal with a literal name. A string is Huffman coded when that is shorter. The section starts with a Required Insert Count of 0 and a Base of 0. An empty fields gives the two prefix bytes alone.

on_decoder_stream

pub fn on_decoder_stream(e: *Encoder, data: []u8) ! io.Error

Consumes bytes of the peer's decoder stream.

An instruction may be split across calls; the unparsed tail is kept. A Stream Cancellation is accepted and has no effect, because this encoder holds no references. Any other instruction contradicts what the encoder sent: a Section Acknowledgment names a section with no dynamic table references, and an Insert Count Increment, whatever its value, exceeds the zero insertions made.

Fails Malformed, which the caller reports as QPACK_DECODER_STREAM_ERROR, for a Section Acknowledgment, an Insert Count Increment, or an integer over 2^62-1.

Functions

decoder

pub fn decoder(max_capacity: i64, max_blocked: i64, max_field_section_size: i64) -> *Decoder

Returns a decoder with an empty dynamic table.

max_capacity is the largest dynamic table capacity the peer's encoder may set, the value advertised as SETTINGS_QPACK_MAX_TABLE_CAPACITY. max_blocked is the most streams that may be blocked at once, the value of SETTINGS_QPACK_BLOCKED_STREAMS. max_field_section_size is the most a decoded field section may measure, the value of SETTINGS_MAX_FIELD_SECTION_SIZE, where each field line counts its name length, its value length and 32. A negative argument is treated as 0.

static_table

pub fn static_table() -> []header.Header

Returns the QPACK static table of RFC 9204 appendix A: 99 field lines indexed from 0.

Field lines whose value the RFC leaves empty have an empty value. The slice is built on each call.
