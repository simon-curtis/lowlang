std/mail

#net

import std/mail

Message building: Message with text and HTML alternatives and attachments, RFC 2047 encoded words, quoted-printable, base64 wrapped at 76, RFC 5322 dates, and rejection of CR and LF in any header.

Imports std/base64, std/crypto, std/header, std/text, std/time/zone, std/time/zoned, std/uri.

Examples

invoice

import std/io
import std/mail
import std/time/offset
import std/time/timestamp
import std/time/zone
import std/time/zoned

fn sent_at() -> zoned.Zoned? {
    let ts = timestamp.from_unix(1762851000) or return none
    let shift = offset.hours(1) or return none
    zoned.of(ts, zone.fixed(shift)) or none
}

/// Renders an invoice email with a text and HTML body and a CSV attachment, then lists its recipients.
fn main() ! io.Error {
    let sender = mail.named("Billing", "billing@example.com")
    let customer = mail.parse_address("Zoë Ångström <zoe@example.org>") or return
    let message = mail.Message {
        from: sender
        to: [customer]
        bcc: [mail.address("audit@example.com")]
        reply_to: [mail.address("support@example.com")]
        subject: "Your invoice for November"
        date: sent_at()
        message_id: "invoice-2025-11@example.com"
        text: "Hello Zoë,\nyour invoice is attached.\n"
        html: "<p>Hello Zoë,</p><p>your invoice is attached.</p>"
        attachments: [mail.Attachment { filename: "invoice.csv", data: bytes("item,total\nsupport,120\n"), content_type: "text/csv" }]
        boundary: "invoice-boundary"
    }
    print(mail.render(message) or return)
    print(mail.recipients(message) or return)
    print(mail.valid_email("not an address"))
}

format_address

pub fn format_address(a: Address) -> str

Returns the address as written in a header: the bare email when there is no name, otherwise name <email>.

A name made of plain characters is written as is, one with specials such as commas or quotes is double quoted with backslash escapes, and one with non-ASCII characters becomes encoded words.

An email message.

render turns it into RFC 5322 text and std/smtp sends it. A message with both text and html becomes multipart/alternative; any attachments wrap the body in multipart/mixed.

needs_8bit

pub fn needs_8bit(m: Message) -> bool

Returns whether render would send the text or HTML body with the 8bit transfer encoding, which requires the SMTP 8BITMIME extension.

This is the case only when eight_bit is set and the body is not already 7-bit safe.

needs_utf8

pub fn needs_utf8(m: Message) -> bool

Returns whether any address of the message (from, to, cc, bcc or reply_to) contains non-ASCII characters, which requires the SMTP SMTPUTF8 extension.

recipients

pub fn recipients(m: Message) -> []str ! Error

Returns the envelope recipients of the message: the addresses of to, cc and bcc in that order, with duplicates removed ignoring case.

Fails with InvalidAddress or HeaderInjection for the first bad address and with NoRecipients when the list would be empty.

render

pub fn render(m: Message) -> str ! Error

Returns the message as RFC 5322 text with \r\n line endings, ready to send as SMTP data.

Headers are written in the order Date, From, To, Cc, Reply-To, Subject, Message-ID, MIME-Version, then headers; Bcc is never written. Header values are folded to 76 columns and non-ASCII values are encoded. Bodies use 7bit, 8bit or quoted-printable as needed, attachments base64.

Fails with InvalidAddress, HeaderInjection or InvalidHeader when a field is invalid. A message without a body or attachments renders an empty plain text body.

Functions

address

pub fn address(email: str) -> Address

Returns an Address for email with no display name. The address is not validated.

encode_words

pub fn encode_words(s: str, used: i64) -> str

Encodes s as RFC 2047 encoded words (=?utf-8?b?...?=) for use in a header value.

used is the number of columns already taken on the first line, typically the header name and its colon and space. Words are sized so that lines stay within 76 columns, and are joined with \r\n so the result folds correctly. A UTF-8 sequence is never split across words. Returns an empty string for empty input.

named

pub fn named(name: str, email: str) -> Address

Returns an Address for email with the display name name. The address is not validated.

new_message_id

pub fn new_message_id(domain: str) -> str

Returns a new Message-ID value of the form <token@domain>, where token is 24 hexadecimal digits from the system's random source.

parse_address

pub fn parse_address(s: str) -> Address ! Error

Parses s as local@domain or Name <local@domain>.

Surrounding whitespace is ignored. A display name in double quotes has the quotes removed and backslash escapes resolved. Fails with InvalidAddress(s) when the angle brackets are unbalanced or the address is not valid. Comments and groups are not supported.

quoted_printable

pub fn quoted_printable(s: str) -> str

Encodes s as quoted-printable.

Line breaks (\n or \r\n) become \r\n. Bytes outside printable ASCII, =, and a space or tab at the end of a line are written as =XX with uppercase hexadecimal digits. Lines are soft-wrapped with =\r\n so that none exceeds 76 columns. No line break is added at the end.

valid_email

pub fn valid_email(s: str) -> bool

Returns whether s is a usable email address.

The text before the last @ is the local part and must be 1 to 64 bytes; the text after it is the domain and must be 1 to 255 bytes. Neither may start or end with a . or contain .., spaces, control characters or any of ()<>[]:;@\,". Non-ASCII characters are accepted. Quoted local parts and domain literals are not.

wrap_base64

pub fn wrap_base64(data: []u8) -> str

Returns the base64 encoding of data broken into lines of 76 characters separated by \r\n.

There is no line break after the last line. Empty input gives an empty string.
