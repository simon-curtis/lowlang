std/text

#text

import std/text

Parsing and formatting: integer parsing in any base from 2 to 36; correctly rounded float parsing, which allocates only to expand a decimal when digits beyond the 19th decide the rounding; parse_bool, radix, hex and hex encoding; fixed(x, places), which rounds half to even on the exact binary value. Trimming and splitting: trim and its start, end, prefix and suffix forms; split on a byte; split_str on a string (an empty separator splits into code points); fields; lines (drops a final empty line and \r before \n); chars; join. Searching: index, last_index, contains, count, starts_with, ends_with. Rewriting: repeat, replace, ASCII upper and lower (return their argument when no byte changes), and case-insensitive equal_fold and starts_with_fold (allocate nothing). Widths: char_count, from_char, and pad_left and pad_right to a width in code points. append and append_char onto a []u8. Comma-separated token lists. cut and last_cut return a Cut of before, after and found. strip_prefix and strip_suffix return str?. Also split_n, title, quote and unquote (backslash, \x, \u and \U escapes, failing with QuoteError), edit_distance over code points, wrap to a width, is_ascii and reverse.

Imports std/simd.
