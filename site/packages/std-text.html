std/text

#text

import std/text

Parsing and formatting: integer parsing in any base from 2 to 36; correctly rounded float parsing, which allocates only to expand a decimal when digits beyond the 19th decide the rounding; parse_bool, radix, hex and hex encoding; fixed(x, places), which rounds half to even on the exact binary value. Trimming and splitting: trim and its start, end, prefix and suffix forms; split on a byte; split_str on a string (an empty separator splits into code points); fields; lines (drops a final empty line and \r before \n); chars; join. Searching: index, last_index, contains, count, starts_with, ends_with. Rewriting: repeat, replace, ASCII upper and lower (return their argument when no byte changes), and case-insensitive equal_fold and starts_with_fold (allocate nothing). Widths: char_count, from_char, and pad_left and pad_right to a width in code points. append and append_char onto a []u8. Comma-separated token lists. cut and last_cut return a Cut of before, after and found. strip_prefix and strip_suffix return str?. Also split_n, title, quote and unquote (backslash, \x, \u and \U escapes, failing with QuoteError), edit_distance over code points, wrap to a width, is_ascii and reverse.

Imports std/simd.

Functions

append

pub fn append(mut out: []u8, s: str)

Appends the bytes of s to out.

append_char

pub fn append_char(mut out: []u8, c: u32)

Appends the UTF-8 encoding of the code point c to out. The value is not validated: surrogates are encoded as they stand, and a value above 0x1FFFFF gives a malformed sequence.

char_count

pub fn char_count(s: str) -> i64

Returns the number of code points in s. A byte that is not part of a valid UTF-8 sequence counts as one.

chars

pub fn chars(s: str) -> []str

Returns the code points of s as one-character strings. A byte that is not part of a valid UTF-8 sequence becomes a piece of its own. The pieces are slices of s.

contains

pub fn contains(s: str, sub: str) -> bool

Returns whether sub occurs in s. An empty sub always occurs.

count

pub fn count(s: str, sub: str) -> i64

Returns the number of non-overlapping occurrences of sub in s. An empty sub counts the positions between code points, which is char_count(s) + 1.

cut

pub fn cut(s: str, sep: str) -> Cut

Splits s at the first occurrence of sep. When sep is not found the result has before set to s, an empty after and found set to false. An empty sep is found at index 0. Both parts are slices of s.

decode_hex

pub fn decode_hex(s: str) -> []u8 ! ParseError

Decodes a hexadecimal string into bytes, accepting upper- and lowercase digits. Fails with BadDigit at the index of the start of the first pair that holds a non-hex digit, and at s.len when the length is odd. An empty string gives empty data.

edit_distance

pub fn edit_distance(a: str, b: str) -> i64

Returns the Levenshtein distance between a and b over code points. Insertion, deletion and substitution of one code point each cost 1. Time is proportional to the product of the two lengths.

encode_hex

pub fn encode_hex(data: []u8) -> str

Returns the bytes of data as lowercase hexadecimal, two digits per byte.

ends_with

pub fn ends_with(s: str, suffix: str) -> bool

Returns whether s ends with suffix. An empty suffix always matches.

equal_fold

pub fn equal_fold(a: str, b: str) -> bool

Returns whether a and b are equal when ASCII letters are compared without regard to case. Other bytes must match exactly. Allocates nothing.

fields

pub fn fields(s: str) -> []str

Splits s around runs of ASCII whitespace, as defined by space, and returns the non-empty pieces. An empty or all-whitespace s gives an empty slice.

fixed

pub fn fixed(x: f64, places: i64) -> str

Returns x as a decimal string with exactly places digits after the decimal point. The digits come from the exact binary value of x and are rounded half to even, so fixed(0.125, 2) gives 0.12 and fixed(2.5, 0) gives 2. The result has no point when places is 0. The sign is kept when the rounded value is zero, so a small negative number gives -0.00. Returns NaN, inf or -inf for those values.

float_bits

pub fn float_bits(v: f64) -> u64

Returns the IEEE 754 binary64 bit pattern of v.

float_from_bits

pub fn float_from_bits(bits: u64) -> f64

Returns the f64 with the IEEE 754 binary64 bit pattern bits.

from_char

pub fn from_char(c: u32) -> str

Returns the UTF-8 encoding of the code point c as a string.

has_token

pub fn has_token(list: str, token: str) -> bool

Returns whether the comma-separated list contains token. Each item is trimmed of ASCII whitespace and compared without regard to ASCII case, as for the value of an HTTP header such as Connection.

hex

pub fn hex(n: i64) -> str

Returns the lowercase hexadecimal form of the 64 bits of n, without prefix or leading zeros. A negative n gives its sixteen-digit two's complement form. 0 gives 0.

index

pub fn index(s: str, sub: str) -> i64

Returns the byte index of the first occurrence of sub in s, or -1 when it is absent. An empty sub is found at index 0.

index_byte

pub fn index_byte(s: str, c: u8) -> i64

Returns the index of the first byte c in s, or -1 when it is absent.

is_ascii

pub fn is_ascii(s: str) -> bool

Returns whether every byte of s is below 0x80. An empty string is ASCII.

join

pub fn join(parts: []str, sep: str) -> str

Returns the strings in parts joined with sep between them. An empty parts gives an empty string.

last_cut

pub fn last_cut(s: str, sep: str) -> Cut

Splits s at the last occurrence of sep. When sep is not found the result has before set to s, an empty after and found set to false. An empty sep is found at the end of s. Both parts are slices of s.

last_index

pub fn last_index(s: str, sub: str) -> i64

Returns the byte index of the last occurrence of sub in s, or -1 when it is absent. An empty sub is found at index s.len.

last_index_byte

pub fn last_index_byte(s: str, c: u8) -> i64

Returns the index of the last byte c in s, or -1 when it is absent.

lines

pub fn lines(s: str) -> []str

Splits s into lines at \n and removes a \r before each \n. A final line without a newline is included, but an empty piece after a trailing newline is not, so a\n gives one line. A \r that ends the last line is also removed. Empty lines in the middle are kept.

lower

pub fn lower(s: str) -> str

Returns s with ASCII letters lowercased. Other bytes, including non-ASCII UTF-8, are unchanged. Returns s itself when no byte changes. For full Unicode case mapping use std/unicode.

lower_byte

pub fn lower_byte(c: u8) -> u8

Returns the ASCII lowercase form of c, or c when it is not A to Z.

pad_left

pub fn pad_left(s: str, width: i64, fill: u32) -> str

Returns s padded on the left with the code point fill until it is width code points wide. Widths count code points, not bytes or display columns. A string already width or wider is returned as it is.

pad_right

pub fn pad_right(s: str, width: i64, fill: u32) -> str

Returns s padded on the right with the code point fill until it is width code points wide. Widths count code points, not bytes or display columns. A string already width or wider is returned as it is.

parse_bool

pub fn parse_bool(s: str) -> bool ! ParseError

Parses true or false. Fails with Empty for an empty string and with BadDigit at index 0 for anything else, including True and 1.

parse_float

pub fn parse_float(text: str) -> f64 ! ParseError

Parses a decimal floating-point number and returns the nearest f64. The form is an optional + or -, digits with an optional ., and an optional exponent e or E with its own sign, as in -12.5e-3, .5 and 5.. inf, infinity and nan are accepted in any case after the optional sign. Underscores, whitespace, prefixes and hexadecimal forms are not.

The result is correctly rounded for any number of digits. A value beyond the f64 range gives infinity and one below it gives zero, neither is an error. Fails with Empty for an empty string and with BadDigit at the first byte that does not fit the form, or at the end of the text when digits are missing.

parse_int

pub fn parse_int(s: str) -> i64 ! ParseError

Parses a signed decimal integer. Behaves as parse_radix with base 10.

parse_radix

pub fn parse_radix(s: str, base: i64) -> i64 ! ParseError

Parses a signed integer written in base. A single leading - or + is accepted and base is 2 to 36. The smallest i64 parses. Fails with Empty for an empty string, with BadDigit at the first byte that is not a digit (a lone sign fails at index 1), and with Overflow when the value does not fit in an i64.

parse_uint

pub fn parse_uint(s: str, base: i64) -> i64 ! ParseError

Parses an unsigned integer written in base and returns it as an i64. base is 2 to 36 and letters of either case give the digits from 10. No sign, prefix, underscore or whitespace is accepted.

Fails with Empty for an empty string, BadDigit at the first byte that is not a digit of base, and Overflow when the value exceeds the largest i64.

quote

pub fn quote(s: str) -> str

Returns s as a double-quoted literal. " and \ are backslash-escaped, newline, tab and carriage return become \n, \t and \r, and other control bytes below 0x20 and 0x7F become \xNN. Valid multi-byte UTF-8 is kept as it is and a byte that is not part of a valid sequence becomes \xNN, so unquote restores the original bytes.

radix

pub fn radix(n: i64, base: i64) -> str

Returns n written in base using lowercase digits, with a leading - when negative. base is 2 to 36. 0 gives 0.

repeat

pub fn repeat(s: str, n: i64) -> str

Returns s repeated n times. n of 0 or below gives an empty string.

replace

pub fn replace(s: str, old: str, new: str) -> str

Returns s with every non-overlapping occurrence of old replaced by new. Returns s unchanged when old is empty.

reverse

pub fn reverse(s: str) -> str

Returns s with its code points in reverse order. Combining marks and other grapheme clusters are not kept together. A byte that is not part of a valid UTF-8 sequence is moved as a unit of its own.

space

pub fn space(c: u8) -> bool

Returns whether c is ASCII whitespace: space, tab, carriage return or newline. Vertical tab and form feed are not included.

split

pub fn split(s: str, sep: u8) -> []str

Splits s at every byte equal to sep and returns the pieces. Always returns at least one piece: an empty s gives one empty string, and adjacent separators give empty pieces. The separator is not included. The pieces are slices of s.

split_n

pub fn split_n(s: str, sep: str, n: i64) -> []str

Splits s around sep into at most n pieces. The last piece holds the unsplit rest of s. n of 0 gives an empty slice and a negative n splits at every occurrence. An empty sep splits into code points, with the last piece holding the rest.

split_str

pub fn split_str(s: str, sep: str) -> []str

Splits s at every non-overlapping occurrence of sep and returns the pieces. Behaves as split for a string separator. An empty sep splits s into its code points, as chars does.

starts_with

pub fn starts_with(s: str, prefix: str) -> bool

Returns whether s begins with prefix. An empty prefix always matches.

starts_with_fold

pub fn starts_with_fold(s: str, prefix: str) -> bool

Returns whether s begins with prefix, comparing ASCII letters without regard to case. Allocates nothing.

strip_prefix

pub fn strip_prefix(s: str, prefix: str) -> str?

Returns s without its leading prefix, or none when s does not begin with it.

strip_suffix

pub fn strip_suffix(s: str, suffix: str) -> str?

Returns s without its trailing suffix, or none when s does not end with it.

title

pub fn title(s: str) -> str

Returns s with the first letter of each word uppercased. A word starts after any byte that is not an ASCII letter, a digit, ' or part of a multi-byte character, so o'neil gives O'neil and a-b gives A-B. Only ASCII letters change, and the other letters of a word are left as they are, not lowercased.

trim

pub fn trim(s: str) -> str

Returns s without leading and trailing ASCII whitespace, as defined by space.

trim_end

pub fn trim_end(s: str) -> str

Returns s without trailing ASCII whitespace, as defined by space.

trim_prefix

pub fn trim_prefix(s: str, prefix: str) -> str

Returns s without a leading prefix, or s unchanged when it does not begin with it. Only one occurrence is removed.

trim_start

pub fn trim_start(s: str) -> str

Returns s without leading ASCII whitespace, as defined by space.

trim_suffix

pub fn trim_suffix(s: str, suffix: str) -> str

Returns s without a trailing suffix, or s unchanged when it does not end with it. Only one occurrence is removed.

unquote

pub fn unquote(s: str) -> str ! QuoteError

Parses a double-quoted literal and returns the string it denotes. The escapes are \n, \t, \r, \a, \b, \f, \v, \\, \", \', \xNN for one byte, \uNNNN and \UNNNNNNNN for a code point. All other bytes are copied as they stand.

Fails with NotQuoted when the quotes are missing or a bare " occurs inside, with BadEscape for an unknown or truncated escape, and with BadCodePoint for a \u or \U escape that is a surrogate or above 0x10FFFF.

upper

pub fn upper(s: str) -> str

Returns s with ASCII letters uppercased. Other bytes, including non-ASCII UTF-8, are unchanged. Returns s itself when no byte changes. For full Unicode case mapping use std/unicode.

upper_byte

pub fn upper_byte(c: u8) -> u8

Returns the ASCII uppercase form of c, or c when it is not a to z.

wrap

pub fn wrap(s: str, width: i64) -> str

Wraps s so that no line is wider than width code points where possible. Each line of s is wrapped on its own: words are separated by ASCII whitespace, runs of whitespace become a single space, and leading and trailing whitespace is dropped. A word wider than width stays whole on a line of its own. Empty lines are kept. The lines are joined with \n with no trailing newline.
