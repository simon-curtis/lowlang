Semantic Versioning 2.0.0: parse (with an optional v, failing at the offset of the first bad part), format, and compare and less with prerelease precedence, ignoring build metadata.

A semantic version (semver.org 2.0.0): a numeric core with optional pre-release and build identifiers.

compare

pub fn compare(a: Version, b: Version) -> i64

Orders two versions by semver precedence and returns -1, 0 or 1 when a is lower than, equal to or higher than b. Major, minor and patch compare numerically. A version with a pre-release is lower than the same core without one. Pre-release identifiers compare left to right: numeric identifiers numerically at any size, others by byte value, numeric lower than non-numeric, and a shorter list lower when it is a prefix of the other. Build identifiers are ignored.

format

pub fn format(v: Version) -> str

Returns v as major.minor.patch, followed by - and the pre-release identifiers and + and the build identifiers when they are not empty.

less

pub fn less(a: Version, b: Version) -> bool

Returns whether a has lower precedence than b, as ordered by compare.

Functions

parse

pub fn parse(s: str) -> Version ! ParseError

Parses a version such as 1.2.3, v1.2.3-rc.1 or 1.2.3+build.5. A single leading v is accepted. The text after the first + is the build metadata and the text after the first - in the rest is the pre-release. The core must be exactly three dot-separated decimal numbers without leading zeros that fit in an i64. Pre-release and build identifiers must be non-empty and made of 0-9, a-z, A-Z and -, and a numeric pre-release identifier has no leading zero.

Fails with Empty for an empty string and with Malformed for any other violation.
