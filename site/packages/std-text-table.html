std/text/table

#text

import std/text/table

Table with per-column Align, width limits, truncation and wrapping, and Border styles None, Ascii, Unicode, Markdown and Tabs. Widths use unicode.text_width and ignore ANSI sequences. align and align_tabbed align tab-separated cells like Go's tabwriter.

Imports std/text, std/unicode.

Examples

borders

import std/text/table

fn build(border: table.Border) -> table.Table {
    var t = table.Table { header: ["package", "files", "notes"], border: border, wrap: true }
    table.add_row(mut t, ["std/path", "1", "Slash separated paths."])
    table.add_row(mut t, ["std/text/table", "3", "Lays out tables with Unicode widths: 日本語 stays aligned."])
    table.add_row(mut t, ["std/flag", "1", "Parses | and \\ safely"])
    table.set_align(mut t, 1, table.Align.Right)
    table.set_limits(mut t, 2, 0, 24)
    t
}

/// Renders one table as a terminal grid, Markdown and plain columns, truncates a cell instead of wrapping it, then aligns plain rows into columns with a gap.
fn main() {
    print(table.render(build(table.Border.Unicode)))
    print(table.render(build(table.Border.Markdown)))
    print(table.render(build(table.Border.None)))

    var truncated = build(table.Border.Ascii)
    truncated.wrap = false
    print(table.render(truncated))

    let rows = [["name", "size", "path"], ["main.low", "12", "src"], ["strings.low", "1204", "src/util"]]
    print(table.align(rows, 2))
    print(table.align_tabbed("id\tstatus\n7\tok\n1042\tfailed", 3))
    print("{table.width("日本語")} {table.width("abc")}")
}

A table of text cells that render lays out as a string. Fill header and rows and optionally columns, then call render. Widths are measured in display columns as cell.width does.

add_row

pub fn add_row(mut t: Table, row: []str)

Appends row to the body rows of t.

render

pub fn render(t: Table) -> str

Returns t laid out as text in the style of t.border. Every column is as wide as its widest cell, limited by its Column settings. Cells longer than their column are wrapped or truncated according to wrap and ellipsis, and a wrapped cell makes its row several lines tall. A Border of Ascii or Unicode puts a rule below the header only when header is not empty. The lines are joined with \n with no trailing newline, and a table with no header and no rows gives an empty string.

set_align

pub fn set_align(mut t: Table, index: i64, a: Align)

Sets the alignment of column index to a and leaves its limits as they are, adding default columns up to it as needed.

set_column

pub fn set_column(mut t: Table, index: i64, c: Column)

Replaces the settings of column index with c, adding default columns up to it as needed.

set_limits

pub fn set_limits(mut t: Table, index: i64, min_width: i64, max_width: i64)

Sets the minimum and maximum width of column index and leaves its alignment as it is, adding default columns up to it as needed. A max_width of 0 means no maximum.

Functions

align

pub fn align(rows: [][]str, gap: i64) -> str

Pads the cells of rows into columns and returns the lines joined with \n. gap is the number of blank columns between a column and the next. A cell is padded to the width of the widest cell above or below it in the same column, measured by cell.width, so wide characters and ANSI escape sequences align. A block of consecutive rows share a column width only while each has another cell after it, and the last cell of a row is not padded, so lines carry no trailing blanks. Rows may have different numbers of cells.

align_tabbed

pub fn align_tabbed(s: str, gap: i64) -> str

Splits each line of s into cells at tabs and aligns them as align does with gap.

blanks

pub fn blanks(n: i64) -> str

Returns n spaces.

fit

pub fn fit(cell: str, limit: i64, wrap: bool, ellipsis: str) -> []str

Fits cell to a column limit columns wide and returns its lines. cell is split at \n, carriage returns are removed and tabs become four spaces. A line within limit is returned unchanged. A longer line is wrapped at spaces and tabs when wrap is true, with each run of them becoming one space and breaking inside a word only when the word alone is wider than limit, and is cut and ended with ellipsis when wrap is false. The ellipsis is left out when it is itself wider than limit. ANSI colour and style sequences take no width, are carried onto each following line and are closed with a reset at the end of every line they are active on.

natural

pub fn natural(cell: str) -> i64

Returns the width in columns of the widest line of cell once tabs are expanded to four spaces and carriage returns removed. This is the width at which fit leaves cell unchanged.

pad

pub fn pad(s: str, limit: i64, a: Align) -> str

Returns s padded with spaces to limit columns, positioned by a. The width is measured by width. A string already limit columns or wider is returned unchanged.

width

pub fn width(s: str) -> i64

Returns the display width of s in terminal columns. Printable ASCII counts one column per byte. Otherwise each grapheme cluster counts its unicode.text_width, at most 2, and ANSI escape sequences count 0.
