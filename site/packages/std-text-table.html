std/text/table

#text

import std/text/table

Table with per-column Align, width limits, truncation and wrapping, and Border styles None, Ascii, Unicode, Markdown and Tabs. Widths use unicode.text_width and ignore ANSI sequences. align and align_tabbed align tab-separated cells like Go's tabwriter.

Imports std/text, std/unicode.
