std/crypto/cipher

#crypto

import std/crypto/cipher

AES in CBC, raw (cbc_encrypt, cbc_decrypt) or with PKCS#7 padding (cbc_seal, cbc_open, pkcs7_pad, pkcs7_unpad); in CTR with a 128-bit big-endian counter (ctr); and in XTS with ciphertext stealing (xts, xts_encrypt, xts_decrypt). There is no ECB, and CBC provides no integrity: use an Aead.

Imports std/crypto/aead.

Types

Block

pub struct Block {
    ...
}

An AES key prepared for encrypting and decrypting 16-byte blocks, used by the CBC and CTR modes.

cbc_decrypt

pub fn cbc_decrypt(b: *Block, iv: []u8, data: []u8) -> []u8 ! Error

Decrypts data in CBC mode with the 16-byte iv (NIST SP 800-38A).

No padding is removed, so data must be a multiple of 16 bytes; empty input returns an empty slice. The result is as long as data. Fails with Error.InvalidIv when iv is not 16 bytes and Error.InvalidLength when data is not a multiple of 16 bytes. CBC does not authenticate the data.

cbc_encrypt

pub fn cbc_encrypt(b: *Block, iv: []u8, data: []u8) -> []u8 ! Error

Encrypts data in CBC mode with the 16-byte iv (NIST SP 800-38A).

No padding is applied, so data must be a multiple of 16 bytes; empty input returns an empty slice. The result is as long as data. Fails with Error.InvalidIv when iv is not 16 bytes and Error.InvalidLength when data is not a multiple of 16 bytes.

cbc_open

pub fn cbc_open(b: *Block, iv: []u8, ciphertext: []u8) -> []u8 ! Error

Decrypts ciphertext in CBC mode with the 16-byte iv and removes the PKCS#7 padding.

Fails with Error.InvalidLength when ciphertext is empty or not a multiple of 16 bytes, Error.InvalidIv when iv is not 16 bytes, and Error.InvalidPadding when the padding is malformed. CBC does not authenticate the data.

cbc_seal

pub fn cbc_seal(b: *Block, iv: []u8, plaintext: []u8) -> []u8 ! Error

Pads plaintext with PKCS#7 and encrypts it in CBC mode with the 16-byte iv.

The result is plaintext.len rounded up to the next multiple of 16, so empty input returns 16 bytes. Fails with Error.InvalidIv when iv is not 16 bytes.

ctr

pub fn ctr(b: *Block, iv: []u8, data: []u8) -> []u8 ! Error

Returns data XORed with the AES-CTR keystream (NIST SP 800-38A).

iv is the 16-byte initial counter block. The block is incremented as a 128-bit big-endian integer after each 16 bytes of keystream. Encryption and decryption are the same operation, and the result is as long as data. Fails with Error.InvalidIv when iv is not 16 bytes. CTR does not authenticate the data.

Xts

pub struct Xts {
    ...
}

A pair of AES keys, one for the data and one for the tweak, used by XTS mode.

xts_decrypt

pub fn xts_decrypt(x: *Xts, tweak: []u8, data: []u8) -> []u8 ! Error

Decrypts data in XTS mode under the 16-byte tweak, usually the sector number.

data must be at least 16 bytes. A length that is not a multiple of 16 uses ciphertext stealing. The result is as long as data. Fails with Error.InvalidIv when tweak is not 16 bytes and Error.InvalidLength when data is shorter than 16 bytes.

xts_encrypt

pub fn xts_encrypt(x: *Xts, tweak: []u8, data: []u8) -> []u8 ! Error

Encrypts data in XTS mode under the 16-byte tweak, usually the sector number.

data must be at least 16 bytes. A length that is not a multiple of 16 uses ciphertext stealing. The result is as long as data. Fails with Error.InvalidIv when tweak is not 16 bytes and Error.InvalidLength when data is shorter than 16 bytes.

Functions

aes

pub fn aes(key: []u8) -> *Block ! Error

Returns a Block for key.

key is 16, 24 or 32 bytes (AES-128, AES-192 or AES-256, FIPS 197). Fails with Error.InvalidKey for any other length.

pkcs7_pad

pub fn pkcs7_pad(data: []u8, block_size: i64) -> []u8

Returns data extended with PKCS#7 padding to a multiple of block_size (RFC 5652 section 6.1).

Appends between 1 and block_size bytes, each holding the pad length, so input that already fills whole blocks gains a full block of padding. block_size must be between 1 and 255; this is not checked.

pkcs7_unpad

pub fn pkcs7_unpad(data: []u8, block_size: i64) -> []u8 ! Error

Returns data without its PKCS#7 padding.

The result shares memory with data. Fails with Error.InvalidPadding when block_size is outside 1 to 255, data is empty, its length is not a multiple of block_size, or the pad length or pad bytes are invalid.

xts

pub fn xts(key: []u8) -> *Xts ! Error

Returns an Xts for key (IEEE 1619).

key is the data key followed by the tweak key, 32 bytes for AES-128 or 64 bytes for AES-256. Fails with Error.InvalidKey for any other length.
