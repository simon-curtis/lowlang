std/msgpack

#formats

import std/msgpack

MessagePack: the Value model with timestamps and extensions, a decoder with depth and length limits that reports the offset of an error, the smallest-form encode, and serialize[T] and deserialize[T].

Imports std/io, std/serde, std/slices, std/text, std/unicode.

as_integer

pub fn as_integer(v: Value) -> i64?

Returns the value of an Int, or of a Uint that fits an i64, and none for any other value.

diagnostic

pub fn diagnostic(v: Value) -> str

Returns a one-line text description of v, in a notation like JSON that also shows the types JSON lacks.

Maps print as {key: value} with keys of any type, arrays as [...]. Strings are quoted, with \" and \\ escaped and every character outside printable ASCII written as \uXXXX, using a surrogate pair above U+FFFF. Floats print as NaN, Infinity, -Infinity or a decimal that always contains a .; a Single has an f suffix. Other values print as nil, true, false, plain integers, h'hex' for Bin, ext(kind, h'hex') and timestamp(seconds, nanoseconds).

encode

pub fn encode(v: Value) -> []u8

Encodes v as MessagePack.

Every integer, length and container uses its smallest format: fixint and the shortest signed or unsigned width for integers, fixstr below 32 bytes, fixarray and fixmap below 16 entries, and fixext for 1, 2, 4, 8 and 16 byte payloads. Binary data always uses a bin format. Single is written as float 32 and Double as float 64; NaN keeps its bit pattern. Entries are written in the order given. It cannot fail.

from_value

pub fn from_value[T](v: Value) -> T ! serde.Error

Converts the Value v into a T through std/serde.

Struct fields are read from Str map keys, and Int, Uint and Bool keys are accepted as text for maps with integer or boolean keys. A float may be read from Single, Double, Int or Uint. An unsigned type may be read from a non-negative Int, while a Uint fails with Range when read as signed. A []u8 is read from Bin and a str from Str. An enum variant is a Str for a variant without fields, or a map with one entry that names the variant. Fails with serde.Error.Mismatch when a value has another type, with Range, Missing and UnknownVariant as serde.read describes, and with Syntax when the value has nothing to read. Timestamp and Ext values cannot be read into a type and fail with Mismatch. In errors, at counts the values consumed so far.

get

pub fn get(v: Value, key: str) -> Value?

Returns the value of the entry whose key is the string key, or none when v is not a Map or has no such entry.

Only string keys are compared. When a key repeats, the last entry wins.

Functions

decode

pub fn decode(data: []u8) -> Value ! Error

Decodes data, which must hold exactly one value, with default Options.

Fails with Trailing when bytes follow the value. See decode_with.

decode_first

pub fn decode_first(data: []u8, options: Options) -> Item ! Error

Decodes the value at the start of data and reports its size, ignoring any bytes after it.

Use it to read a stream of back-to-back values by advancing data by Item.length. Fails like decode_with except that it never returns Trailing.

decode_with

pub fn decode_with(data: []u8, options: Options) -> Value ! Error

Decodes data, which must hold exactly one MessagePack value.

Fails with Truncated, Invalid, BadUtf8, BadTimestamp, TooDeep or TooLong for malformed or over-limit input, and with Trailing when bytes follow the value. Strings and binary data are copied, so the result does not alias data. A timestamp extension becomes Timestamp, other extensions become Ext.

deserialize

pub fn deserialize[T](data: []u8) -> T ! serde.Error

Decodes MessagePack data into a T.

Equivalent to decode followed by from_value, with the default Options. A decoding error becomes serde.Error.Syntax carrying the byte offset and message of the decoding error, except that TooDeep becomes serde.Error.TooDeep. Fails like from_value when the value does not fit T.

serialize

pub fn serialize[T](v: T) -> []u8

Encodes v as MessagePack bytes.

Equivalent to encode(to_value(v)).

to_value

pub fn to_value[T](v: T) -> Value

Converts v into a Value through std/serde.

Structs and maps become Map with Str keys, slices become Array, []u8 becomes Bin, optionals become Nil or the value, and floats become Double. Integers become Int, except that a u64 above 9223372036854775807 becomes Uint. An enum variant without fields becomes a Str and a variant with fields a one-entry Map from its name to a Map of its labelled fields or an Array of its positional ones.
