std/quic

#net

import std/quic

QUIC version 1 (RFC 9000, 9001 and 9002) over UDP. Config holds the tls.Config (ALPN required), idle and handshake timeouts, keep-alive, the flow control and stream limits advertised to the peer, and retry. Server: listen returns a droppable Listener with a copyable ListenerHandle, and accept and accept_handle wait for an established connection; close_listener and close_listener_on. Client: dial, dial_handle, connect and connect_handle complete the handshake before returning. The droppable Connection closes with code 0 when released; its *ConnectionHandle holds the negotiated protocol, the addresses, group, suite, peer_certificates and, once ended, close_code, close_reason, closed_by_peer and application_close. adopt, detach, close_connection, close_on, stats and stats_on (a Stats snapshot), and update_keys and update_keys_on. Streams: open_stream, open_uni_stream, accept_stream and accept_uni_stream with _on forms return a copyable Stream; read, write, finish, reset, stop and stream, which adapts it to an io.Stream.

Imports std/atomic, std/crypto, std/crypto/hash, std/crypto/x509, std/io, std/net, std/quic/recovery, std/quic/wire, std/sync, std/time, std/tls.

fn server_config() -> quic.Config ! io.Error {
    let pem = server_pem()
    let secure = tls.Config { certificates: x509.pem_certificates(pem), key: x509.pem_private_key(pem)?, alpn: ["echo"] }
    quic.Config { tls: secure }
}

fn client_config() -> quic.Config {
    var roots: []x509.Certificate = []
    for der in x509.pem_certificates(ca_pem()) {
        let cert = x509.parse(der) or continue
        push(mut roots, cert)
    }
    quic.Config { tls: tls.Config { roots, alpn: ["echo"] } }
}

fn echo(s: quic.Stream) {
    let channel = quic.stream(s)
    let data = io.read_all(channel) or return
    io.write_all(channel, bytes("echo: {str(data)}")) or return
    channel.close()
}

fn serve(h: *quic.ConnectionHandle) {
    for {
        let s = quic.accept_stream_on(h) or return
        spawn echo(s)
    }
}

/// Opens a QUIC connection to a loopback server and sends one message on each of two streams.
fn main() ! io.Error {
    using l = quic.listen("127.0.0.1", 0, server_config()?)?
    using client = quic.dial("127.0.0.1", l.handle.addr.port, client_config())?
    let peer = quic.accept_handle(l.handle)?
    spawn serve(peer)

    for message in ["first", "second"] {
        let s = quic.open_stream(client)?
        let channel = quic.stream(s)
        io.write_str(channel, message)?
        channel.close()
        print("stream {s.id}: {str(io.read_all(channel)?)}")
    }
    quic.close_connection(client, 0, "done")
}

accept_stream_on

pub fn accept_stream_on(h: *ConnectionHandle) -> Stream ! io.Error

Accepts the next bidirectional stream the peer opened on the connection behind h.

Streams are returned in ID order, including ones the peer opened implicitly by using a higher ID, so a stream can be returned before any of its data has arrived. Parks the green thread until the peer opens one. Fails with the error that ended the connection, including while parked.

close_on

pub fn close_on(h: *ConnectionHandle, code: i64, reason: str)

Closes the connection behind h with the application error code and reason.

Sends a CONNECTION_CLOSE, records code and reason on the handle and parks the green thread until the frame has been sent. While a stream still holds data the peer has not acknowledged, the close is held back until the streams settle, for at most 5 seconds and never past the idle timeout, so a peer cannot keep the call parked longer. The connection then stays in the closing state for three times the probe timeout, answering datagrams from the peer with the same frame, and stats_on fails with NotConnected from the moment of the call. Before the handshake completes the frame is a transport error with code 0x0c and no reason. A code outside 0 to 2^62 - 1 is clamped into that range and a reason longer than 1024 bytes is truncated. Does nothing when the connection has already ended or is closing.

open_stream_on

pub fn open_stream_on(h: *ConnectionHandle) -> Stream ! io.Error

Opens a new bidirectional stream on the connection behind h.

Stream IDs count up in steps of 4 from 0 for a client and from 1 for a server. Parks the green thread while the peer's limit on bidirectional streams is reached, which the peer raises with MAX_STREAMS as it finishes streams, and sends STREAMS_BLOCKED once per limit value. Fails with the error that ended the connection, as stats_on does, including while parked.

open_uni_stream_on

pub fn open_uni_stream_on(h: *ConnectionHandle) -> Stream ! io.Error

Opens a new unidirectional stream on the connection behind h, which this end can only write.

Stream IDs count up in steps of 4 from 2 for a client and from 3 for a server. Parks and fails as open_stream_on does, with the limit on unidirectional streams.

stats_on

pub fn stats_on(h: *ConnectionHandle) -> Stats ! io.Error

Returns a snapshot of the transport counters of the connection behind h.

Parks the green thread until the connection answers. Once the connection is closing, draining or ended it fails with the error that explains the end: NotConnected after this end closed it, Aborted after the peer closed it, Malformed after this end closed it for a protocol error, TimedOut after the idle or handshake timeout, Reset after a stateless reset and Unsupported after a Version Negotiation packet.

update_keys_on

pub fn update_keys_on(h: *ConnectionHandle) ! io.Error

Starts a key update on the connection behind h (RFC 9001 section 6).

Derives the next sending keys, flips the key phase bit of the packets sent from now on, and returns without waiting for the peer; the peer answers by updating its own sending keys, which this end follows when the first packet of the new phase arrives. A connection also updates by itself after 2^23 packets sent with one key. Fails Invalid before the handshake is confirmed and while the first packet sent with the current keys after the previous update is unacknowledged, which includes a second call without traffic in between, and with the error that ended the connection, as stats_on does.

close_listener_on

pub fn close_listener_on(h: *ListenerHandle)

Closes the listener behind h.

Closes every connection of the listener with application error code 0 and an empty reason, including the ones that are queued for accept, then closes the socket, which ends the endpoint's reader, and wakes every green thread waiting in accept or accept_handle, which fail with NotConnected. Asks every connection to close before it waits for any, then parks the green thread until each has sent its CONNECTION_CLOSE, so the wait is that of the slowest connection, at most 5 seconds as for close_on, and not the sum. New connections are refused from the first call on, and later calls do nothing.

Stream

    ...

A copyable view of one stream of a QUIC connection.

Every copy refers to the same stream. Streams are not closed when dropped: finish ends the sending side and reset and stop abandon the sending and receiving sides.

finish

pub fn finish(s: Stream) ! io.Error

Ends the sending side of the stream s after the bytes already written.

Sends FIN with the last data. Calling it again does nothing. Fails BrokenPipe after reset or STOP_SENDING, Invalid for a stream this end only reads, and with the error that ended the connection.

read

pub fn read(s: Stream, buf: []u8) -> i64 ! io.Error

Reads up to buf.len bytes from the stream s into buf and returns the count.

Parks the green thread until at least one byte is available. Returns 0 at the end of a finished stream, for an empty buf and for a stream whose state has been released after it was read to the end. Fails Reset when the peer reset the stream, Aborted after this end called stop, Invalid for a stream this end only writes, and with the error that ended the connection, including while parked.

reset

pub fn reset(s: Stream, code: i64)

Abandons the sending side of the stream s with the application error code.

Sends RESET_STREAM carrying the highest offset sent and drops the unacknowledged bytes. Parked and later writes fail BrokenPipe. A code outside 0 to 2^62 - 1 is clamped into that range. Does nothing on a finished stream, a stream this end only reads or an ended connection.

stop

pub fn stop(s: Stream, code: i64)

Abandons the receiving side of the stream s with the application error code.

Sends STOP_SENDING, discards the unread bytes and every byte that arrives later, and fails parked and later reads Aborted. The peer's writer sees BrokenPipe once it receives the frame. A code outside 0 to 2^62 - 1 is clamped into that range. Does nothing on a stream that is already finished or reset, a stream this end only writes or an ended connection.

stream

pub fn stream(s: Stream) -> io.Stream

Returns an io.Stream over the stream s.

Its read and write call read and write, and its close calls finish and ignores its error.

write

pub fn write(s: Stream, data: []u8) -> i64 ! io.Error

Writes data to the stream s and returns data.len.

Copies the bytes into the stream's send buffer, which holds at most 1 MiB of bytes the peer has not acknowledged, and parks the green thread while it is full, so a write of any length completes once the peer has acknowledged enough. Returns before the bytes are delivered. Fails BrokenPipe after finish or reset, after the peer sent STOP_SENDING and for a stream whose state has been released, Invalid for a stream this end only reads, and with the error that ended the connection, including while parked.

connect_handle

pub fn connect_handle(a: net.Addr, config: Config) -> *ConnectionHandle ! io.Error

Opens a QUIC connection to the address a, completes the handshake and returns the view of the connection.

Binds a UDP socket of the family of a on a free port that belongs to the connection and is closed when it ends. config.tls.server_name defaults to the text of a.ip when empty. Parks the green thread until the handshake finishes. Fails Invalid when config.tls.alpn is empty and with the error net.bind_udp returns when no socket can be bound. A handshake that fails fails with the error the TLS handshake returned, Refused when the server closed the connection during the handshake and Malformed when this end closed it for a protocol violation, such as invalid transport parameters.

dial_handle

pub fn dial_handle(host: str, port: i64, config: Config) -> *ConnectionHandle ! io.Error

Resolves host, opens a QUIC connection to its first address on port, completes the handshake and returns the view of the connection.

config.tls.server_name defaults to host when empty. Otherwise behaves as connect_handle, and also fails with NotFound when host cannot be resolved.

listen

pub fn listen(host: str, port: i64, config: Config) -> Listener ! io.Error

Binds a UDP socket to host and port and starts a QUIC server endpoint on it.

Port 0 chooses a free port, which handle.addr.port reports. Fails Invalid when config.tls.alpn is empty or config.tls has no certificates or no key, and with the error net.bind_udp returns when the socket cannot be bound. Dropping the listener closes the socket.
