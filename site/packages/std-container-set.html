std/container/set

#data

import std/container/set

Set[T] over a map, in insertion order: set, from_slice, add and remove (both return whether the set changed), has, size, items, union, intersection, difference and is_subset.

Imports std/maps.

Types

Set

pub struct Set[T: Hash] {
    ...
}

A set of values kept in a hash map, so items must be hashable.

Create one with set or from_slice. Membership, insertion and removal take constant time on average. Mutating functions take the set as mut.

add

pub fn add[T: Hash](mut s: Set[T], item: T) -> bool

Adds item to s.

Returns true when the item was new and false when it was already present.

difference

pub fn difference[T: Hash](a: Set[T], b: Set[T]) -> Set[T]

Returns a new set of the items of a that are not in b.

Neither argument changes.

has

pub fn has[T: Hash](s: Set[T], item: T) -> bool

Returns true when item is in s.

intersection

pub fn intersection[T: Hash](a: Set[T], b: Set[T]) -> Set[T]

Returns a new set of the items that are in both a and b.

Neither argument changes.

is_subset

pub fn is_subset[T: Hash](a: Set[T], b: Set[T]) -> bool

Returns true when every item of a is also in b.

An empty set is a subset of every set.

items

pub fn items[T: Hash](s: Set[T]) -> []T

Returns the items of s as a slice in insertion order.

remove

pub fn remove[T: Hash](mut s: Set[T], item: T) -> bool

Removes item from s.

Returns true when the item was present and false when s did not change.

size

pub fn size[T: Hash](s: Set[T]) -> i64

Returns the number of items in s.

union

pub fn union[T: Hash](a: Set[T], b: Set[T]) -> Set[T]

Returns a new set of the items that are in a or b.

Neither argument changes.
