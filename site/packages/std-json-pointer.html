std/json/pointer

#formats

import std/json/pointer

RFC 6901 pointers: escape, unescape, parse, format, get, has, set, add, replace, remove and relative pointers. Edits return a new document.

Imports std/json, std/slices, std/text.

Examples

edit

import std/json
import std/json/pointer
import std/text

fn parse(source: str) -> json.Value {
    json.parse(bytes(text.replace(source, "'", "\""))) or json.Value.Null
}

fn problem(e: pointer.Error) -> str {
    match e {
        Syntax(at, message) => "{message} at {at}"
        NotFound(location) => "{location} does not exist"
        Mismatch(location) => "{location} has the wrong type"
        CannotRemoveRoot => "the root cannot be removed"
    }
}

fn read(doc: json.Value, location: str) {
    let value = pointer.get(doc, location) catch {
        e => {
            print("{location}: {problem(e)}")
            return
        }
    }
    print("{location}: {json.stringify(value, 0)}")
}

/// Reads and edits a document by JSON Pointer, escaping member names that hold `/` and `~`.
fn main() {
    let doc = parse("{{'server': {{'host': 'a.example', 'ports': [80, 443]}}, 'routes': {{'/health': 'ok', 'a~b': 'tilde'}}}}")

    read(doc, "/server/host")
    read(doc, "/server/ports/1")
    read(doc, "/server/ports/2")
    read(doc, "/server/host/name")
    read(doc, "server")
    read(doc, "/routes/~1health")
    read(doc, "/routes/a~0b")

    let route = "/routes/{pointer.escape("/health")}"
    print("{route} exists: {pointer.has(doc, route)}")

    let edited = pointer.set(doc, "/server/host", json.Value.Str("b.example")) or doc
    let appended = pointer.add(edited, "/server/ports/-", json.Value.Int(8080)) or edited
    let trimmed = pointer.remove(appended, "/routes") or appended
    print(json.stringify(trimmed, 0))
    print(json.stringify(doc, 0))

    let missing = pointer.remove(doc, "/server/user") catch {
        e => {
            print("remove: {problem(e)}")
            return
        }
    }
    print(json.stringify(missing, 0))
}

Error

Syntax(i64, str)The pointer is well formed but the value it names does not exist: an object has no such member or an array no such index. pointer is the prefix of the pointer up to and including the token that failed.    NotFound(str)A token does not suit the value it is applied to: the value is a string, number, boolean or null, or an array and the token is not an array index. pointer is the prefix up to and including the token.    Mismatch(str)A removal named the whole document with the empty pointer.    CannotRemoveRoot

The error returned by the pointer functions (RFC 6901).

Functions

add

pub fn add(doc: json.Value, pointer: str, value: json.Value) -> json.Value ! Error

Returns a copy of doc with value added at pointer, as the RFC 6902 add operation does.

On an object the member is replaced when it exists and added at the end otherwise. On an array the value is inserted before the element at the index, which shifts the later elements, and an index equal to the length or - appends. The empty pointer returns value. The parent of the target must exist. doc is not changed. Fails with Syntax, NotFound or Mismatch as get does, and with NotFound for an array index past the length.

escape

pub fn escape(token: str) -> str

Returns token escaped for use in a pointer: ~ becomes ~0 and / becomes ~1.

format

pub fn format(tokens: []str) -> str

Returns the pointer for tokens, each escaped and preceded by /; no tokens give the empty string.

get

pub fn get(doc: json.Value, pointer: str) -> json.Value ! Error

Returns the value in doc that pointer names.

The empty pointer returns doc. An object member is found by name, using the first member of that name, and an array element by index: decimal digits with no leading zero, at most 18 of them. The - token never names an element when reading. Fails with Syntax for a malformed pointer, NotFound when a member or index does not exist and Mismatch when a token does not suit the value it is applied to.

has

pub fn has(doc: json.Value, pointer: str) -> bool

Returns whether pointer names a value in doc. It is false for a malformed pointer.

parse

pub fn parse(pointer: str) -> []str ! Error

Splits pointer into its unescaped reference tokens.

The empty string is the whole document and has no tokens. Any other pointer starts with /, and each /-separated part is a token, so / is one empty token and /a//b has three. Fails with Syntax when the pointer does not start with / or a token has a bad escape.

relative

pub fn relative(doc: json.Value, current: str, reference: str) -> json.Value ! Error

Returns the value that the relative pointer reference names, evaluated from the location current in doc (Relative JSON Pointer).

reference is a non-negative integer with no leading zero and at most nine digits, which says how many levels to go up from current, followed either by # or by a JSON pointer to follow from the level reached. With # the result is the key of that level as a Str, or its index as an Int when its parent is an array. Index offsets such as 1+1 are not supported. Fails with Syntax when the integer is missing or malformed, NotFound when it goes up past the root, and otherwise with the errors of get.

remove

pub fn remove(doc: json.Value, pointer: str) -> json.Value ! Error

Returns a copy of doc without the value at pointer.

On an array the later elements move down. The target must exist and - never names an element. doc is not changed. Fails with CannotRemoveRoot for the empty pointer, and with Syntax, NotFound or Mismatch as get does.

replace

pub fn replace(doc: json.Value, pointer: str, value: json.Value) -> json.Value ! Error

Returns a copy of doc with the value at pointer replaced by value.

The target must exist and - never names an element. The empty pointer returns value. doc is not changed. Fails with Syntax, NotFound or Mismatch as get does.

set

pub fn set(doc: json.Value, pointer: str, value: json.Value) -> json.Value ! Error

Returns a copy of doc in which pointer names value.

On an object the member is replaced, or added at the end when it is missing. On an array an index below the length replaces that element, and an index equal to the length or - appends. The empty pointer returns value. The parent of the target must exist. doc is not changed, and the copy shares the parts that were not edited. Fails with Syntax, NotFound or Mismatch as get does.

unescape

pub fn unescape(token: str) -> str ! Error

Returns token with its ~0 and ~1 escapes decoded.

Fails with Syntax when a ~ is not followed by 0 or 1.
