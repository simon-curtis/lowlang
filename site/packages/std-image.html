std/image

#media

import std/image

Bitmaps, pixel operations and resizing, with PNG, JPEG, GIF, BMP, QOI and lossless WebP codecs.

Imports std/compress/deflate, std/hash, std/io.

Format

pub enum Format {One 8-bit gray channel.    Gray88-bit gray followed by 8-bit alpha.    GrayAlpha88-bit red, green and blue.    Rgb88-bit red, green, blue and alpha.    Rgba8One 16-bit gray channel.    Gray1616-bit red, green, blue and alpha.    Rgba16

The layout of one pixel in an Image.

Samples are interleaved. Eight-bit formats use one byte per channel; 16-bit formats store each sample big-endian.

bytes_per_pixel

pub fn bytes_per_pixel(f: Format) -> i64

Returns the number of bytes one pixel of f takes: the channel count, doubled for the 16-bit formats.

channels

pub fn channels(f: Format) -> i64

Returns the number of channels in f: 1 for gray, 2 for gray with alpha, 3 for Rgb8 and 4 for Rgba8 and Rgba16.

has_alpha

pub fn has_alpha(f: Format) -> bool

Returns true when f has an alpha channel: GrayAlpha8, Rgba8 and Rgba16.

Image

pub struct Image {The width in pixels.    pub width: i64The height in pixels.    pub height: i64The pixel layout of pixels.    pub format: FormatThe number of bytes from the start of one row to the start of the next.    pub stride: i64The pixel bytes, stride * height of them.    pub pixels: []u8
}

A raster of pixels in row-major order from the top-left.

Operations return new images and leave their argument unchanged, except set, fill_rect and blend, which write into the pixels they are given.

blend

pub fn blend(dst: Image, src: Image, x: i64, y: i64)

Composites src over dst with its top-left corner at x, y, in place.

Alpha is straight, not premultiplied. The part of src outside dst is ignored, and src and dst can have different formats. Where src is opaque it replaces the pixel, and where it is transparent dst is unchanged.

convert

pub fn convert(img: Image, format: Format) -> Image

Returns a copy of img in format.

Gray is expanded to equal red, green and blue, color to gray takes the luma, a missing alpha becomes fully opaque and alpha is dropped when the target has none (it is not composited). Converting to the same format returns a plain copy.

crop

pub fn crop(img: Image, x: i64, y: i64, width: i64, height: i64) -> Image

Returns the width by height region of img whose top-left corner is x, y.

The region is clipped to the image, so the result can be smaller than requested, and is empty when nothing remains.

encode_bmp

pub fn encode_bmp(img: Image) -> []u8

Encodes img as an uncompressed bottom-up BMP.

An image with an alpha channel is written as 32 bits per pixel with a 108-byte header and bit fields; any other image is written as 24 bits per pixel with a 40-byte header. Images are converted to Rgba8 or Rgb8 first, so 16-bit samples are reduced to 8 bits and gray becomes equal red, green and blue.

encode_gif

pub fn encode_gif(img: Image, palette: []Rgba) -> []u8

Encodes img as a single-frame GIF89a.

palette is the color table; an empty palette is replaced by median_cut of the image, and a palette longer than 256 colors (255 when the image has an alpha channel) is truncated. Each pixel maps to its nearest palette color. When the image has an alpha channel, pixels with alpha below 128 become a transparent index and the rest are opaque.

encode_jpeg

pub fn encode_jpeg(img: Image, quality: i64) -> []u8

Encodes img as a baseline JPEG.

quality is clamped to 1 to 100 and scales the standard quantisation tables. Gray formats produce a single-component file and all others 4:2:0 YCbCr. Alpha is discarded and 16-bit samples are reduced to 8 bits.

encode_png

pub fn encode_png(img: Image) -> []u8

Encodes img as a non-interlaced PNG.

Every row picks whichever of the five filters has the lowest score, and the data is zlib compressed at level 6. 8-bit and 16-bit images keep their depth; Gray8, GrayAlpha8, Rgb8 and Rgba8 and the 16-bit formats map to the matching PNG color type.

encode_qoi

pub fn encode_qoi(img: Image) -> []u8

Encodes img as QOI, with 4 channels when the image has an alpha channel and 3 otherwise.

The image is converted to Rgba8 or Rgb8 first, so 16-bit samples are reduced to 8 bits. The color space byte is 0.

fill_rect

pub fn fill_rect(img: Image, x: i64, y: i64, width: i64, height: i64, c: Rgba)

Sets every pixel in the width by height rectangle at x, y to c, in place.

The rectangle is clipped to the image. Alpha is written, not blended.

flip_horizontal

pub fn flip_horizontal(img: Image) -> Image

Returns img mirrored left to right.

flip_vertical

pub fn flip_vertical(img: Image) -> Image

Returns img mirrored top to bottom.

get

pub fn get(img: Image, x: i64, y: i64) -> Rgba

Returns the pixel at x, y as an 8-bit Rgba.

Gray formats give equal red, green and blue, and formats without alpha give alpha 255. 16-bit samples are rounded to 8 bits. A position outside the image gives transparent black.

median_cut

pub fn median_cut(img: Image, count: i64) -> []Rgba

Returns a palette of at most count colors for img, chosen by median cut.

Pixels with alpha below 128 are ignored. When the image has no more than count distinct colors, those colors are returned as they are. All returned colors are opaque.

orient

pub fn orient(img: Image, orientation: i64) -> Image

Returns img transformed so that it displays upright for the EXIF orientation value 1 to 8.

exif_orientation reads that value from a JPEG. 1 and any value outside 1 to 8 return img itself.

premultiply

pub fn premultiply(img: Image) -> Image

Returns a copy of img with the color channels multiplied by alpha.

An image without an alpha channel is returned as a plain copy.

resize

pub fn resize(img: Image, width: i64, height: i64, filter: Filter) -> Image

Returns img scaled to width by height pixels using filter.

Non-nearest filters resample each axis separately on premultiplied values, so transparent pixels do not bleed color. The format is kept. When width or height is not positive, or img is empty, the result is a zeroed image of the requested size.

rotate180

pub fn rotate180(img: Image) -> Image

Returns img rotated 180 degrees.

rotate270

pub fn rotate270(img: Image) -> Image

Returns img rotated 270 degrees clockwise (90 degrees counterclockwise), with width and height swapped.

rotate90

pub fn rotate90(img: Image) -> Image

Returns img rotated 90 degrees clockwise, with width and height swapped.

set

pub fn set(img: Image, x: i64, y: i64, c: Rgba)

Writes c at x, y, converting it to the image's format.

Formats without alpha drop it, and gray formats store the luma of the color. A position outside the image is ignored.

transpose

pub fn transpose(img: Image) -> Image

Returns img reflected across its main diagonal, so pixel x, y moves to y, x, with width and height swapped.

unpremultiply

pub fn unpremultiply(img: Image) -> Image

Returns a copy of img with the color channels divided by alpha, the inverse of premultiply.

Pixels with alpha 0 or full alpha are left as they are. An image without an alpha channel is returned as a plain copy.

Functions

create

pub fn create(width: i64, height: i64, format: Format) -> Image

Returns a zeroed image of width by height pixels in format, with stride equal to width times bytes_per_pixel(format).

A negative size is treated as 0. A zeroed pixel is black, and transparent when the format has alpha.

decode

pub fn decode(data: []u8) -> Image ! io.Error

Decodes data as PNG, GIF, JPEG, WebP, BMP or QOI, chosen by its signature.

A GIF yields its first frame. Images over 2^26 pixels are rejected; decode_limited takes another limit.

Fails with Unsupported when no signature matches, and otherwise with the error of the chosen codec, such as Malformed or TooLarge.

decode_bmp

pub fn decode_bmp(data: []u8) -> Image ! io.Error

Decodes a BMP file into an Image.

Handles 1 to 32 bits per pixel, RLE4 and RLE8 compression, bit fields and every header version, and bottom-up and top-down rows. The result is Rgba8 when the file has an alpha mask (or a 32-bit file whose alpha bytes are not all zero) and Rgb8 otherwise.

Fails with Malformed when the signature or headers are invalid or the data is truncated, Unsupported for a bit depth or compression method it does not read. Fails with TooLarge when the image has more than 2^26 pixels or a side above 2^24.

decode_gif

pub fn decode_gif(data: []u8) -> Image ! io.Error

Decodes the first frame of a GIF into an Rgba8 Image the size of the logical screen.

Pixels no frame has painted have alpha 0. Fails with Malformed when the signature or data is invalid or there is no frame, and TooLarge past 2^26 pixels.

decode_gif_frames

pub fn decode_gif_frames(data: []u8) -> []Frame ! io.Error

Decodes every frame of a GIF.

Each Frame holds the whole canvas after the frame is composited onto the result of applying the previous frame's disposal method (leave, restore to background, restore to previous). Fails with Malformed when the data is invalid or there is no frame, and TooLarge when the canvas size times the frame count, or any frame, exceeds 2^26 pixels.

decode_jpeg

pub fn decode_jpeg(data: []u8) -> Image ! io.Error

Decodes a baseline or progressive JPEG into an Image.

Supports restart markers, any sampling factors, grayscale, YCbCr and Adobe CMYK and YCCK. The result is Gray8 for one component and Rgb8 otherwise. EXIF orientation is not applied; use exif_orientation with orient.

Fails with Malformed when the data is invalid or truncated, Unsupported for a feature it does not read, and TooLarge past 2^26 pixels.

decode_limited

pub fn decode_limited(data: []u8, max_pixels: i64) -> Image ! io.Error

Decodes data like decode, rejecting images with more than max_pixels pixels.

Fails with TooLarge when the image, or the total of all GIF frames, exceeds max_pixels, or a side exceeds 2^24.

decode_png

pub fn decode_png(data: []u8) -> Image ! io.Error

Decodes a PNG into an Image.

Reads every color type and bit depth, Adam7 interlacing, palettes and tRNS transparency, and checks every chunk CRC. The format is Gray16 for 16-bit gray without transparency, Rgba16 for other 16-bit images, Gray8 or GrayAlpha8 for gray, Rgba8 for color with alpha or tRNS, and Rgb8 otherwise.

Fails with Malformed when the signature, chunks, checksums or data are invalid, Unsupported for an unknown critical chunk, and TooLarge past 2^26 pixels.

decode_qoi

pub fn decode_qoi(data: []u8) -> Image ! io.Error

Decodes a QOI image into an Rgb8 or Rgba8 Image, according to its channel count.

Fails with Malformed when the header, channel count or data is invalid or truncated, and TooLarge past 2^26 pixels.

decode_webp

pub fn decode_webp(data: []u8) -> Image ! io.Error

Decodes a lossless (VP8L) WebP into an Rgb8 or Rgba8 Image, according to the alpha flag in its header.

Fails with Unsupported for lossy VP8, ALPH and animated files, Malformed when the data is invalid or truncated, and TooLarge past 2^26 pixels.

exif_orientation

pub fn exif_orientation(data: []u8) -> i64

Returns the EXIF orientation of a JPEG, 1 to 8.

Returns 1 (upright) when data is not a JPEG, has no EXIF segment or orientation tag, the tag is out of range, or the data is malformed. Pass the result to orient.

from_pixels

pub fn from_pixels(width: i64, height: i64, format: Format, pixels: []u8) -> Image ! io.Error

Returns an image that uses pixels directly, without copying.

Fails with Invalid when a size is negative or pixels.len is not width * bytes_per_pixel(format) * height.
