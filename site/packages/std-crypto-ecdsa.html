ecdh

pub fn ecdh(curve: Curve, private: []u8, peer: []u8) -> []u8 ! io.Error

Computes ECDH (the shared secret Z of SEC 1 and NIST SP 800-56A) between private and the peer point peer.

Returns the affine x coordinate of the shared point as big-endian bytes, 32 for P-256 or 48 for P-384. The bytes are not hashed.

peer must be an uncompressed SEC1 point, 0x04 || X || Y, on the curve with both coordinates below the field prime. Fails with Invalid when peer does not meet that, when private is the wrong size or outside [1, n - 1], or when the shared point is the point at infinity.

generate

pub fn generate(curve: Curve) -> []u8

Returns a new private scalar for curve as big-endian bytes, 32 for P-256 or 48 for P-384.

The scalar is drawn from crypto.random and redrawn until it lies in [1, n - 1], where n is the group order.

public_key

pub fn public_key(curve: Curve, private: []u8) -> []u8 ! io.Error

Returns the public point for private in uncompressed SEC1 form, 0x04 || X || Y, 65 bytes for P-256 or 97 for P-384.

Fails with Invalid when private is not exactly the curve's scalar size or is not in [1, n - 1].

sign

pub fn sign(curve: Curve, private: []u8, digest: []u8) -> []u8 ! io.Error

Signs digest like sign_raw and returns the signature as an ASN.1 DER Ecdsa-Sig-Value, SEQUENCE { r INTEGER, s INTEGER }.

The length of the sequence is encoded in one byte, which holds for both curves. Fails with Invalid under the same conditions as sign_raw.

sign_raw

pub fn sign_raw(curve: Curve, private: []u8, digest: []u8) -> []u8 ! io.Error

Signs digest with ECDSA (FIPS 186-4) and returns the raw signature r || s, each half big-endian and padded to the scalar size, 64 bytes for P-256 or 96 for P-384.

The nonce is deterministic (RFC 6979), with HMAC over SHA-512, SHA-384 or SHA-256 chosen by digest.len (64, 48, otherwise 32), so signing the same digest with the same key gives the same signature. digest is the hash of the message, not the message. A digest longer than the scalar size is truncated to its leftmost bytes.

Fails with Invalid when private is the wrong size or outside [1, n - 1].

verify

pub fn verify(curve: Curve, public: []u8, digest: []u8, signature: []u8) -> bool

Reports whether the DER-encoded signature is a valid ECDSA signature of digest under the public point public.

signature is a SEQUENCE of two minimally encoded, non-negative INTEGERs with no trailing bytes; any other encoding returns false. public is an uncompressed SEC1 point. Returns false, never an error, for an invalid point or a mismatch.

verify_raw

pub fn verify_raw(curve: Curve, public: []u8, digest: []u8, signature: []u8) -> bool

Reports whether signature is a valid ECDSA signature of digest under the public point public.

signature is the raw form r || s produced by sign_raw and must be exactly twice the scalar size. public is an uncompressed SEC1 point. Returns false, never an error, for a wrong-sized or out-of-range signature, an invalid point, or a mismatch. A digest longer than the scalar size is truncated to its leftmost bytes.

parse_private

pub fn parse_private(der: []u8) -> Key ! io.Error

Parses a DER SEC1 ECPrivateKey (RFC 5915) into a Key.

The key must have version 1. The curve comes from the optional [0] named-curve OID, prime256v1 or secp384r1; when the OID is absent it is inferred from the private key length, 32 or 48 bytes. The optional [1] public key must be an uncompressed point and is checked against the point computed from the private scalar. public in the result is always the computed point.

Fails with Malformed for DER that does not follow this layout or has trailing bytes. Fails with Invalid for an unsupported curve, a private key that is not a valid scalar for the curve, or a public key that does not match.
