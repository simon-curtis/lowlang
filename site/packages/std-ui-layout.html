The layout properties of one node.

Sizes, minimums, maximums and basis are border-box lengths. Percentages refer to the parent's inner size on the same axis, or to the padding box for an absolute node. A box is never smaller than its padding and border.

Tree

pub struct Tree {
    ...
}

A set of styled nodes and the rectangles compute gives them.

Nodes are named by the index node and leaf return. A tree is built for a frame, laid out once and read through rect and content.

compute

pub fn compute(mut t: Tree, root: i64, available: geometry.Size)

Places root and everything under it in a window of available logical pixels.

A root with an Auto size fills available less its margin. Every node's rectangle is replaced, so a tree may be computed again for a new size.

content

pub fn content(t: Tree, node: i64) -> geometry.Rect

Returns the content box of node: its border box less its border and padding.

leaf

pub fn leaf(mut t: Tree, style: Style, measure: fn(f32) -> geometry.Size) -> i64

Adds a leaf and returns its index.

measure takes the width available to the leaf's content, unbounded when there is no limit, and returns the content size. Its height may depend on the width, as wrapped text does.

node

pub fn node(mut t: Tree, style: Style, children: []i64) -> i64

Adds a container with the given children, which are indices returned by earlier calls, and returns its index.

A container with no children has no content and is as large as its padding and border.

rect

pub fn rect(t: Tree, node: i64) -> geometry.Rect

Returns the border box of node in logical pixels from the top left of the window.
