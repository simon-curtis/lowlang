parse

pub fn parse(source: str) -> Icon ! Error

Parses source, the text of an SVG document, into an Icon.

Reads path, rect, circle, ellipse, line, polyline and polygon, inside any number of g and nested svg elements. Every other element, with what is inside it, is skipped, so defs, use, title, style and the gradients draw nothing.

Presentation attributes and the declarations of a style attribute set fill, stroke, stroke-width, opacity, fill-opacity, stroke-opacity, fill-rule and display, and every other property is ignored. A declaration in style wins over an attribute of the same name, and a child takes what its parent has set except for opacity, which multiplies down the tree, and transform, which composes. Colours are #rgb, #rgba, #rrggbb, #rrggbbaa, rgb() and rgba() with numbers or percentages, the sixteen CSS basic colour names with grey, orange and transparent, none and currentColor; a url(...) paint server paints nothing. The default fill is black, as SVG specifies, and the default stroke is none. A stroke is always traced with a round pen, whatever stroke-linecap, stroke-linejoin and stroke-dasharray say.

transform takes translate, scale, rotate, skewX, skewY and matrix. An arc becomes cubic curves of at most a quarter turn each. A shape that has no outline, or whose fill and stroke are both none, is left out, and so is an element with display of none.

Fails with Syntax when source is not XML, with NotSvg when the root is not svg, with BadNumber or BadPath at the byte offset in the attribute's value that could not be read, and with BadValue naming an attribute whose value is not understood.
