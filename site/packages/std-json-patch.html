std/json/patch

#formats

import std/json/patch

RFC 6902 apply (atomic, failing with the operation's index) and diff; RFC 7396 merge_patch and merge_diff.

Imports std/json, std/json/pointer, std/slices, std/text.

Examples

sync

import std/json
import std/json/patch
import std/json/pointer

fn parse(source: str) -> json.Value {
    json.parse(bytes(source)) or json.Value.Null
}

fn problem(e: patch.Error) -> str {
    match e {
        Malformed(index, message) => "operation {index} is malformed: {message}"
        Pointer(index, cause) => "operation {index} does not fit the document: {reason(cause)}"
        TestFailed(index, path) => "operation {index} expected a different value at {path}"
    }
}

fn reason(e: pointer.Error) -> str {
    match e {
        Syntax(at, message) => "{message} at {at}"
        NotFound(path) => "{path} does not exist"
        Mismatch(path) => "{path} has the wrong type"
        CannotRemoveRoot => "the root cannot be removed"
    }
}

fn attempt(label: str, doc: json.Value, operations: str) {
    let result = patch.apply(doc, parse(operations)) catch {
        e => {
            print("{label}: {problem(e)}")
            return
        }
    }
    print("{label}: {json.stringify(result, 0)}")
}

/// Computes the patch between two versions of a document, replays it on a copy and applies hand written patches, including one that fails.
fn main() {
    let before = parse("{{\"name\": \"api\", \"replicas\": 2, \"ports\": [80, 443], \"labels\": {{\"tier\": \"web\"}}}}")
    let after = parse("{{\"name\": \"api\", \"replicas\": 3, \"ports\": [80, 8443, 9000], \"labels\": {{\"tier\": \"web\", \"team\": \"core\"}}}}")

    let changes = patch.diff(before, after)
    print(json.stringify(changes, 0))

    let replayed = patch.apply(before, changes) or json.Value.Null
    print("replay matches: {json.equal(replayed, after)}")

    attempt("hand written", before, "[{{\"op\": \"test\", \"path\": \"/name\", \"value\": \"api\"}}, {{\"op\": \"move\", \"from\": \"/labels/tier\", \"path\": \"/tier\"}}, {{\"op\": \"add\", \"path\": \"/ports/-\", \"value\": 8080}}]")
    attempt("failed test", before, "[{{\"op\": \"replace\", \"path\": \"/replicas\", \"value\": 5}}, {{\"op\": \"test\", \"path\": \"/name\", \"value\": \"web\"}}]")
    attempt("missing target", before, "[{{\"op\": \"remove\", \"path\": \"/ports/7\"}}]")
    attempt("unknown operation", before, "[{{\"op\": \"swap\", \"path\": \"/name\"}}]")

    let merge = parse("{{\"replicas\": 4, \"labels\": {{\"tier\": null, \"env\": \"prod\"}}}}")
    print(json.stringify(patch.merge_patch(before, merge), 0))
    print(json.stringify(patch.merge_diff(before, after), 0))
}

The error returned by apply.

Each variant carries the zero-based index of the operation that failed.

Functions

apply

pub fn apply(doc: json.Value, patch: json.Value) -> json.Value ! Error

Applies the RFC 6902 patch to doc and returns the new document.

patch is an array of operations, applied in order, each an object with op and path. add, replace and test also take value; move and copy take from. remove, replace, move and copy need an existing source or target; test compares with json.equal. Extra members are ignored. Moving a value onto its own location changes nothing. The patch is atomic: doc is never changed, and a failure reports the first operation that failed. Fails with Malformed, Pointer or TestFailed.

diff

pub fn diff(a: json.Value, b: json.Value) -> json.Value

Returns an RFC 6902 patch that turns a into b, so that apply(a, diff(a, b)) equals b.

Equal values give an empty patch. Objects are compared member by member, with remove operations and nested changes in the order of a's members followed by add operations for new members. Arrays are compared element by element: shared positions are diffed, extra elements of a are removed from the end backwards and extra elements of b are added at the end. Values of different kinds, and scalars that differ, become a replace. Only add, remove and replace are produced.

merge_diff

pub fn merge_diff(a: json.Value, b: json.Value) -> json.Value

Returns an RFC 7396 merge patch that turns a into b, so that merge_patch(a, diff) equals b.

When a and b are both objects the result is an object of the changes: a member that b lacks becomes null, new members are copied and changed ones are diffed recursively; otherwise it is b. Equal objects give an empty object. A merge patch cannot set a member to null, so the result is only exact when b has no null members.

merge_patch

pub fn merge_patch(target: json.Value, patch: json.Value) -> json.Value

Applies the RFC 7396 merge patch to target and returns the result.

When patch is not an object it replaces target. Otherwise each member of patch is merged into target, which is treated as an empty object when it is not an object: a null member removes that member of the target, and any other value is merged recursively. Arrays are replaced as a whole. Neither argument is changed.
