std/archive/tar

#compression

import std/archive/tar

ustar, GNU and pax archives. A streaming Reader (next, read_body, read_entry, list) with limits on header, entry and total size. A Writer (add_file, add_dir, add_symlink, add_hardlink, finish) that uses pax records for long or non-ASCII names. gzip through read_gzip and write_gzip. extract, extract_gzip, create and create_gzip over the filesystem strip setuid, setgid and sticky bits.

Imports std/archive, std/compress/deflate, std/file, std/io, std/text.

Examples

roundtrip

import std/archive/tar
import std/io

/// Builds an archive in memory, compresses it, then reads every entry back.
fn main() ! io.Error {
    let w = tar.writer()
    w.add_dir("notes", 0o755)?
    w.add_file("notes/todo.txt", bytes("water the plants"), 0o644)?
    w.add_symlink("notes/latest", "todo.txt")?
    let compressed = w.write_gzip(6)?

    let r = tar.read_gzip(compressed)?
    for {
        let entry = r.next()? ?? break
        match entry.kind {
            Dir => print("{entry.name} directory")
            Symlink => print("{entry.name} -> {entry.link}")
            _ => {
                let data = r.read_entry()?
                print("{entry.name} {entry.size} bytes: {str(data)}")
            }
        }
    }
}

Output

notes/ directory
notes/todo.txt 16 bytes: water the plants
notes/latest -> todo.txt

A tar archive member: its name, metadata and, for a link, its target.

The defaults describe an empty regular file with mode 0o644 owned by id 0. A writer stores values that do not fit a ustar header field, such as a long name or a large size, in a pax extended header.

Reader

pub struct Reader {
    ...
}

A streaming tar reader made by reader, reader_with, bytes_reader or read_gzip.

Call next for each entry and read its data with read_body or read_entry before calling next again.

extract_from

pub fn extract_from(r: *Reader, dir: str) ! io.Error

Extracts the entries of r below dir, creating dir and its missing parents.

Each name goes through archive.resolve, so an absolute name, a .. segment, a NUL byte or a path through a symbolic link below dir fails with Denied. Files are created exclusively and without following links, and an existing file or link at the target is replaced. Permission bits are masked to 0o777, so setuid, setgid and sticky bits are dropped, and the process umask applies. Modification times are applied to files as they are written and to directories once all entries are placed. Symbolic links are created with their stored target, which is not validated. A hard link is created to the path its target resolves to below dir, so the target must already exist. Entries of kind Other are skipped.

Fails with the errors of next and of the filesystem.

next

pub fn next(r: *Reader) -> Entry? ! io.Error

Returns the next entry, or none at the end of the archive.

The end is a zero block or the end of the input at a block boundary, and every later call returns none. Data of the previous entry that was not read is skipped. Pax extended headers (path, linkpath, size, mtime, uid, gid) and GNU long name and link records apply to the entry that follows; pax global headers are skipped. Numbers are read as octal or base-256.

Fails with Malformed for a bad checksum, a bad number or an entry with an empty name, with Eof when the input ends inside a block or an entry, with TooLarge when a limit is exceeded, and with Unsupported for a sparse file.

read_body

pub fn read_body(r: *Reader, dst: []u8) -> i64 ! io.Error

Reads up to dst.len bytes of the current entry's data into dst and returns the count, or 0 once the data is exhausted.

Fails with Eof when the source ends first.

read_entry

pub fn read_entry(r: *Reader) -> []u8 ! io.Error

Returns the rest of the current entry's data in a new slice.

Errors are those of read_body. The slice is empty for a directory, symbolic link and hard link.

Writer

pub struct Writer {
    ...
}

A tar writer made by writer or stream_writer.

Add entries in order and call finish to end the archive. Headers are ustar. A name over 100 bytes that cannot be split at a / into a name and a prefix of up to 155 bytes, a non-ASCII name or link target, a link target over 100 bytes, and a size, id or modification time that does not fit its header field are written in a pax extended header.

add

pub fn add(w: *Writer, e: Entry, data: []u8) ! io.Error

Writes the entry e with data as its contents.

data is used for a File only; every other kind stores nothing. The size recorded is data.len for a File and 0 otherwise. A directory name gets a trailing / when it lacks one. Only the low 12 bits of e.mode are stored.

Fails with Invalid after finish, for an empty name and for a name with a NUL byte, with Unsupported for Other, and with the error of the sink.

add_dir

pub fn add_dir(w: *Writer, name: str, mode: i64) ! io.Error

Writes a directory name with the permission bits mode, owned by id 0 with a modification time of 0.

add_file

pub fn add_file(w: *Writer, name: str, data: []u8, mode: i64) ! io.Error

Writes a regular file name with data and the permission bits mode, owned by id 0 with a modification time of 0.

add_hardlink

pub fn add_hardlink(w: *Writer, name: str, target: str) ! io.Error

Writes name as a hard link to the entry target that was added earlier, with mode 0o644, owned by id 0 with a modification time of 0.

target is not checked against the entries already written.

add_symlink

pub fn add_symlink(w: *Writer, name: str, target: str) ! io.Error

Writes a symbolic link name that points to target, with mode 0o777, owned by id 0 with a modification time of 0.

finish

pub fn finish(w: *Writer) ! io.Error

Ends the archive with two zero blocks of 512 bytes.

A second call does nothing. After finish, add fails with Invalid.

output

pub fn output(w: *Writer) -> []u8

Returns the bytes collected by a Writer made with writer.

Call it after finish for a complete archive. It is empty for a stream writer.

write_gzip

pub fn write_gzip(w: *Writer, level: i64) -> []u8 ! io.Error

Finishes the archive and returns it compressed as gzip at deflate level.

Fails with Unsupported for a stream writer. The compressed bytes are only returned; output still returns the plain tar.

bytes_reader

create

pub fn create(dir: str) -> []u8 ! io.Error

Returns a tar archive of the tree below dir.

Names are relative to dir, which is not an entry itself, and come in sorted depth-first order. Directories, symbolic links, which are not followed, and regular files are archived with the mode, owner and modification time that lstat reports. Other objects are skipped, and hard-linked files are stored as separate copies. Each file is read fully into memory.

Fails with the error of the filesystem call that failed.

Fails as create and write_gzip do.

read_gzip

pub fn read_gzip(data: []u8) -> *Reader ! io.Error

Decompresses the gzip data and returns a Reader over the tar archive in it, with the default Limits.

The whole archive is decompressed in memory before this returns. Fails when the data is not valid gzip or decompresses to more than Limits.total bytes.

Decompresses the gzip data and returns a Reader over the tar archive in it that applies limits.

Fails as read_gzip does, with limits.total as the decompressed size limit.
