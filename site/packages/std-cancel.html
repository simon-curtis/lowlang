std/cancel

#concurrency

import std/cancel

Token with token, child, cancel, cancelled, check and done (a channel that closes on cancellation, for select). on_cancel returns a droppable Registration that releases its callback; release, on_cancel_handle and release_on work on the copyable RegistrationHandle. pause is a sleep that ends early on cancellation.

Imports std/io.

The owner of a callback registered with on_cancel.

Dropping it removes the callback if the token has not been cancelled yet.

release

pub fn release(r: Registration)

Removes the callback registered by on_cancel without running it.

Does nothing if the callback has already run or been removed.

RegistrationHandle

pub struct RegistrationHandle {
    ...
}

A copyable reference to one callback registered on a token, which release_on removes.

Dropping or copying a handle does not remove the callback.

release_on

pub fn release_on(h: RegistrationHandle)

Removes the callback behind h without running it.

Does nothing if the callback has already run or been removed.

Token

pub struct Token {
    ...
}

A cancellation signal shared by pointer between the code that cancels and the code that watches.

Cancelling a token once closes its done channel and runs the callbacks registered with on_cancel and on_cancel_handle. A token never becomes uncancelled.

cancel

pub fn cancel(t: *Token)

Cancels t.

Closes the done channel and runs the registered callbacks on the calling green thread, in no particular order, after releasing the token's lock. Later calls do nothing.

cancelled

pub fn cancelled(t: *Token) -> bool

Returns whether t has been cancelled.

check

pub fn check(t: *Token) ! io.Error

Fails with Aborted if t has been cancelled, and returns otherwise.

child

pub fn child(parent: *Token) -> *Token

Returns a token that is cancelled when parent is cancelled.

Cancelling the child does not cancel parent, and it removes the child's link to the parent. If parent is already cancelled, the returned token is cancelled.

done

pub fn done(t: *Token) -> chan[bool]

Returns a channel that is closed when t is cancelled and never carries a value.

Receiving from it parks until cancellation, so it works as an arm of select, for example <-cancel.done(t).

on_cancel

pub fn on_cancel(t: *Token, f: fn()) -> Registration

Registers f to run when t is cancelled, and returns the Registration that removes it when dropped.

If t is already cancelled, f runs immediately on the calling green thread and the returned registration does nothing. Otherwise f runs on the green thread that calls cancel, so it should not block.

on_cancel_handle

pub fn on_cancel_handle(t: *Token, f: fn()) -> RegistrationHandle

Registers f to run when t is cancelled, and returns a copyable handle to the registration.

The callback stays registered until t is cancelled or release_on is called with the handle. If t is already cancelled, f runs immediately on the calling green thread and the handle does nothing.

pause

pub fn pause(t: *Token, millis: i64) -> bool

Sleeps for millis milliseconds and returns true, or returns false as soon as t is cancelled.

Parks the green thread while it waits.
