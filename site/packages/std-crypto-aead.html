std/crypto/aead

#crypto

import std/crypto/aead

Aead values for AES-128-GCM, AES-256-GCM, ChaCha20-Poly1305 and XChaCha20-Poly1305 (xchacha20_poly1305, 24-byte nonce). The AES block functions for 128-, 192- and 256-bit keys (aes_key, encrypt_block_into, decrypt_block, decrypt_block_into). The ChaCha20 functions chacha20_xor (takes the RFC 8439 block counter) and hchacha20.

Imports std/bits, std/crypto/hash, std/io.

An authenticated cipher bound to a key, which seals and opens messages.

Built by aes_gcm, chacha20_poly1305 or xchacha20_poly1305. A nonce must not be reused with the same key.

Functions

aes

pub fn aes(key: []u8) -> *Aes ! io.Error

Builds an AES encryption key from key.

key is 16 bytes (AES-128) or 32 bytes (AES-256). Fails with io.Error.Invalid for any other length, including 24; aes_key accepts 24.

aes_gcm

pub fn aes_gcm(key: []u8) -> Aead ! io.Error

Returns an AES-GCM Aead keyed with key (NIST SP 800-38D).

key is 16 bytes (AES-128) or 32 bytes (AES-256); fails with io.Error.Invalid for any other length. The tag is 16 bytes and nonce_size is 12. A 12-byte nonce is used directly; seal and open also accept other nonce lengths, which are hashed with GHASH as the standard defines. open fails with io.Error.Invalid when the sealed input is shorter than 16 bytes or the tag does not match.

aes_key

pub fn aes_key(key: []u8) -> *Aes ! io.Error

Builds an AES encryption key from key.

key is 16, 24 or 32 bytes (AES-128, AES-192 or AES-256). Fails with io.Error.Invalid for any other length.

chacha20_block

pub fn chacha20_block(key: []u8, counter: u32, nonce: []u8) -> []u8

Returns the 64-byte ChaCha20 block function output for block counter (RFC 8439 section 2.3).

key is 32 bytes and nonce is 12 bytes. The lengths are not validated.

chacha20_poly1305

pub fn chacha20_poly1305(key: []u8) -> Aead ! io.Error

Returns a ChaCha20-Poly1305 Aead keyed with the 32-byte key (RFC 8439 section 2.8).

The nonce is 12 bytes and the tag is 16 bytes. Fails with io.Error.Invalid when key is not 32 bytes. seal requires a 12-byte nonce. open fails with io.Error.Invalid when the nonce is not 12 bytes, the sealed input is shorter than 16 bytes or the tag does not match.

chacha20_xor

pub fn chacha20_xor(key: []u8, counter: u32, nonce: []u8, data: []u8) -> []u8 ! io.Error

Returns data XORed with the ChaCha20 keystream that starts at block counter (RFC 8439 section 2.4).

key is 32 bytes and nonce is 12 bytes. Encryption and decryption are the same operation, and the result is as long as data. Fails with io.Error.Invalid when key or nonce has the wrong length. No authentication is applied.

hchacha20

pub fn hchacha20(key: []u8, nonce: []u8) -> []u8 ! io.Error

Returns the 32-byte HChaCha20 subkey derived from key and nonce (draft-irtf-cfrg-xchacha section 2.2).

key is 32 bytes and nonce is 16 bytes. Fails with io.Error.Invalid when either has the wrong length.

poly1305

pub fn poly1305(key: []u8, message: []u8) -> []u8 ! io.Error

Computes the Poly1305 one-time authenticator of message (RFC 8439 section 2.5).

key is 32 bytes and must authenticate one message only. Returns the 16-byte tag. Fails with io.Error.Invalid when key is not 32 bytes. An empty message is accepted.

xchacha20_poly1305

pub fn xchacha20_poly1305(key: []u8) -> Aead ! io.Error

Returns an XChaCha20-Poly1305 Aead keyed with the 32-byte key (draft-irtf-cfrg-xchacha).

The nonce is 24 bytes and the tag is 16 bytes. The first 16 nonce bytes derive a subkey with hchacha20; the last 8 bytes, preceded by four zero bytes, form the ChaCha20-Poly1305 nonce. Fails with io.Error.Invalid when key is not 32 bytes. seal requires a 24-byte nonce. open fails with io.Error.Invalid when the nonce is not 24 bytes, the sealed input is shorter than 16 bytes or the tag does not match.
