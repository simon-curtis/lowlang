connect

pub fn connect(o: sql.Options) -> sql.Connection ! sql.Error

Connects to a SQL Server over plain TCP, using o.host and o.port (1433 by default), and logs in as o.user to o.database.

Returns sql.Error.Connect when the connection cannot be made, sql.Error.Timeout when it exceeds o.timeout, sql.Error.Authentication when the login fails and sql.Error.Unsupported when the server requires encryption, which needs connect_tls. Dropping the returned sql.Connection closes the socket.

import std/sql

using c = sqlserver.connect(sql.Options { host: "db.internal", user: "app", database: "shop" }) or return

connect_stream

pub fn connect_stream(s: io.Stream, o: sql.Options) -> sql.Connection ! sql.Error

Connects over a stream that is already connected, without TLS, and logs in as connect does.

Fails like connect after the dial.

connect_tls

pub fn connect_tls(o: sql.Options, config: tls.Config) -> sql.Connection ! sql.Error

Connects to a SQL Server and negotiates TLS during the TDS pre-login exchange using config, then logs in.

Returns sql.Error.Unsupported when the server does not offer encryption. Otherwise fails like connect.
