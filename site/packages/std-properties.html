std/properties

#formats

import std/properties

Java .properties: parse, get, set, format, with \u escapes and surrogate pairs.

Imports std/text, std/unicode/utf16.

Examples

messages

import std/properties
import std/text

/// Reads a Java style message bundle, adds a translation and writes the bundle back with escapes.
fn main() {
    let source = "# greetings\ngreeting = Hello, %s!\nfarewell: Goodbye\nlist.items = one, \\\n    two, \\\n    three\ncurrency = \\u20ac\n"
    var bundle = properties.parse(source) catch {
        Syntax(line, message) => {
            print("line {line}: {message}")
            return
        }
    }

    for key in bundle.keys {
        print("{key} => {bundle.get(key) ?? ""}")
    }
    print("missing => {bundle.get("title") ?? "unset"}")

    bundle.set("farewell", "See you")
    bundle.set("title", "caf{text.from_char(0xE9)}: tea=cold")
    print(properties.format(bundle))

    let bad = properties.parse("ok = 1\nbroken = \\u12zz\n") catch {
        Syntax(line, message) => {
            print("line {line}: {message}")
            return
        }
    }
    print("{bad.keys.len} keys")
}

The entries of a Java .properties file: a map of keys to values plus the order in which the keys were first set.

format

pub fn format(p: Properties) -> str

Formats p as .properties text, one key=value line per entry in keys order, each ending in \n.

Backslash, tab, newline, carriage return and form feed are written as \\, \t, \n, \r and \f, and =, :, # and ! are backslash-escaped. Every space in a key and a leading space in a value is written as \ . Control characters and non-ASCII characters are written as \uXXXX, using a surrogate pair above U+FFFF. The output parses back to the same entries.

get

pub fn get(p: Properties, key: str) -> str?

Returns the value of key, or none when it is not set.

set

pub fn set(mut p: Properties, key: str, value: str)

Sets key to value.

A new key is appended to keys; an existing key keeps its position and takes the new value.

parse

pub fn parse(source: str) -> Properties ! Error

Parses .properties text into a Properties.

Lines end at \n, \r\n or \r. A line whose first non-blank character is # or ! is a comment, and blank lines are skipped; blank means space, tab or form feed. The key ends at the first unescaped =, : or blank, and a single = or : with surrounding blanks separates it from the value, which runs to the end of the logical line and is not trimmed at the end. A line ending in an odd number of backslashes continues on the next line, whose leading blanks are dropped; a comment marker on a continuation line is part of the value. In keys and values \t, \n, \r and \f are control characters, \uXXXX is a UTF-16 code unit with a high and low surrogate escape combining into one character, and \ before any other character yields that character. A trailing lone backslash at the end of the input is dropped. A key set twice keeps its first position and last value.

Fails with Syntax, which carries the line, for a malformed \u escape.
