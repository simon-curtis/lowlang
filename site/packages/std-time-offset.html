std/time/offset

#time

import std/time/offset

Offset, a UTC offset in whole seconds within ±25:59:59, with utc, hours, hm, to_string, to_string_z, parse, and read, which reads an offset out of the middle of a string and reports where it ended.

Imports std/text, std/time/fault, std/time/scan.

Examples

normalise_logs

import std/time/datetime
import std/time/fault
import std/time/offset
import std/time/timestamp

fn to_utc(line: str) -> str ! fault.Fault {
    let wall = datetime.parse(line[0..19])?
    let reading = offset.read(line, 20)?
    let utc_seconds = datetime.civil_seconds(wall) - offset.seconds_of(reading.offset)
    let ts = timestamp.from_parts(utc_seconds, datetime.nanosecond(wall))?
    let message = line[reading.end + 1..]
    "{timestamp.to_string(ts)} [{offset.to_string(reading.offset)}] {message}"
}

/// Rewrites log lines that carry their own UTC offsets onto one timeline.
fn main() ! fault.Fault {
    let lines = [
        "2026-11-13T10:00:00 +0530 queue drained",
        "2026-11-13T04:30:00 Z worker started",
        "2026-11-12T23:30:00 -05:00 backup finished",
        "2026-11-13T05:30:00 +01:00:30 clock skew corrected",
        "2026-11-13T05:30:00 +26:00 impossible",
        "2026-11-13T05:30:00 +5:30 malformed"
    ]
    for line in lines {
        let normalised = to_utc(line) catch {
            OutOfRange(what) => "{what} out of range: {line}"
            Syntax(at) => "bad offset near byte {at}: {line}"
            _ => "unreadable: {line}"
        }
        print(normalised)
    }

    let east = offset.hm(5, 30)?
    let west = offset.hours(-8)?
    print("{offset.to_string(east)} {offset.to_string(west)} {offset.to_string_z(offset.utc())} {offset.to_string_z(east)}")
    print("east is after west: {offset.after(east, west)}")
    print("opposite of east: {offset.to_string(offset.negate(east))}")
    print("seconds from utc: {offset.seconds_of(east)}")
    print("furthest east: {offset.to_string(offset.max(east, west))}")
    print("utc: {offset.is_utc(offset.parse("+00:00")?)}")
}

Returns the offset as +hh:mm, or +hh:mm:ss when it has a seconds part.

Functions

hm

pub fn hm(h: i64, m: i64) -> Offset ! fault.Fault

Returns the offset of h hours and m minutes.

The sign of h applies to the minutes as well, so hm(-3, 30) is -03:30. Fails with OutOfRange when the result is beyond 25:59:59 and with Invalid when m is not from 0 to 59.

hours

pub fn hours(h: i64) -> Offset ! fault.Fault

Returns the offset of h whole hours.

Fails with OutOfRange when h is below -25 or above 25.

of_seconds

pub fn of_seconds(n: i64) -> Offset ! fault.Fault

Returns the offset of n seconds from UTC.

Fails with OutOfRange when n is beyond 25:59:59 in either direction.

parse

pub fn parse(s: str) -> Offset ! fault.Fault

Parses an offset written as Z, z, +hh, +hhmm, +hh:mm, +hhmmss or +hh:mm:ss, with - accepted for the sign.

Z must stand alone. Fails with Syntax at the offset of the first byte that does not fit, and with OutOfRange when an hour is above 25, a minute or second is above 59 or the result is out of range.

read

pub fn read(s: str, from: i64) -> Reading ! fault.Fault

Reads an offset written as Z, z, +hh, +hhmm, +hh:mm, +hhmmss or +hh:mm:ss, with - accepted for the sign, starting at byte from of s.

Reading stops at the first byte that is not part of the offset. Fails with Syntax at the offset of the first byte that does not fit, and with OutOfRange when an hour is above 25, a minute or second is above 59 or the result is out of range.
