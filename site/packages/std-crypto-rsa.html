#crypto

import std/crypto/rsa

RSA PKCS#1 v1.5 and PSS signing and verification, and PKCS#1 keys. integer strips the leading zeros that key integers from JWK and COSE carry.

Imports std/crypto, std/crypto/der, std/crypto/hash, std/crypto/limb, std/io.

sign_pkcs1v15

pub fn sign_pkcs1v15(key: PrivateKey, a: hash.Algorithm, digest: []u8) -> []u8 ! io.Error

Signs the hash digest with RSASSA-PKCS1-v1_5 (RFC 8017) and returns a signature as long as the modulus.

a must be sha256, sha384 or sha512 and digest must be exactly a.size bytes, the hash of the message. The result is checked with the public key before it is returned.

Fails with Invalid when a is another algorithm, when digest has the wrong length, when the modulus is too short for the encoded digest, or when the signature fails that check.

sign_pss

pub fn sign_pss(key: PrivateKey, a: hash.Algorithm, digest: []u8) -> []u8 ! io.Error

Signs the hash digest with RSASSA-PSS (RFC 8017) and returns a signature as long as the modulus.

MGF1 uses the same hash as a, and the salt is a.size random bytes from crypto.random, so signing the same digest twice gives different signatures. digest must be exactly a.size bytes, the hash of the message. The result is checked with the public key before it is returned.

Fails with Invalid when digest has the wrong length, when the modulus is too short for the hash and salt, or when the signature fails that check.

verify_pkcs1v15

pub fn verify_pkcs1v15(key: PublicKey, a: hash.Algorithm, digest: []u8, signature: []u8) -> bool

Reports whether signature is a valid RSASSA-PKCS1-v1_5 signature (RFC 8017) of the hash digest under key.

a must be sha256, sha384 or sha512. Returns false, never an error, for an unusable key, an unsupported algorithm, a digest of the wrong length, a signature that is not exactly as long as the modulus or is not below it, and a mismatch. The padding comparison does not exit early.

verify_pss

pub fn verify_pss(key: PublicKey, a: hash.Algorithm, digest: []u8, signature: []u8) -> bool

Reports whether signature is a valid RSASSA-PSS signature (RFC 8017) of the hash digest under key.

MGF1 uses the same hash as a, and the salt length is taken from the signature. Returns false, never an error, for an unusable key, a digest that is not a.size bytes, a signature that is not exactly as long as the modulus or is not below it, and any padding or hash mismatch.

Returns the big-endian integer magnitude without its leading zero bytes, the form every integer of PublicKey and PrivateKey takes.

Returns an empty slice when magnitude is empty or all zero. The result shares the memory of magnitude.

parse_private

pub fn parse_private(encoded: []u8) -> PrivateKey ! io.Error

Parses a DER PKCS#1 RSAPrivateKey (RFC 8017) with eight integers after the version.

The version must be 0 (two-prime); otherwise the call fails with Unsupported, as it does when the modulus or exponent fails the limits of parse_public. Fails with Malformed for DER that is not minimal or has trailing bytes, and when the key is inconsistent: p or q is even, qinv is not below p, p * q is not n, or a test signature does not verify under the public key.

parse_public

pub fn parse_public(encoded: []u8) -> PublicKey ! io.Error

Parses a DER PKCS#1 RSAPublicKey (RFC 8017), SEQUENCE { n INTEGER, e INTEGER }.

The DER must be minimal, with no trailing bytes; otherwise the call fails with Malformed. Fails with Unsupported when the modulus is not 2048 to 8192 bits and odd, when the exponent is even, 1 or longer than the modulus.
