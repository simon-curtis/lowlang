import std/container/sorted

Sorted[T], an ordered set over ordered.Tree: sorted, from_slice, add, remove, has, size, items, first, last, floor_item, ceiling_item and range.

Imports std/container/ordered, std/slices.

Sorted

pub struct Sorted[T: Ord] {
    ...
}

A set of ordered values kept in ascending order, backed by an ordered.Tree.

Create one with sorted or from_slice. Membership, insertion, removal and the nearest-item queries take O(log n) time. Mutating functions take the set as mut. Nodes are shared between copies, so keep a single copy.
