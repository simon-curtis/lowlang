check_signature

pub fn check_signature(issuer: Certificate, subject: Certificate) -> bool

Returns whether subject carries a valid signature by the key of issuer.

The scheme comes from the signature algorithm of subject: RSA PKCS#1 v1.5 with SHA-256, SHA-384 or SHA-512, RSASSA-PSS with SHA-256, SHA-384 or SHA-512 (MGF1 with the same hash and a salt as long as the hash), ECDSA with SHA-256, SHA-384 or SHA-512, or Ed25519. Returns false for any other scheme, when the type of the issuer key does not fit, or when verification fails. Names and validity are not checked.

verify_chain

pub fn verify_chain(leaf: Certificate, intermediates: []Certificate, roots: []Certificate, host: str, now: i64) -> []Certificate ! io.Error

Builds and verifies a certification path from leaf to one of roots and returns it, leaf first and root last.

now is Unix seconds and host is a DNS name or IP address literal the leaf must be valid for; an empty host skips that check. A DNS name is matched case-insensitively against the dns_names of the leaf only, never its common name. A wildcard such as *.example.com stands for exactly one label in the leftmost position. An IP address is matched against ip_addresses.

Every certificate must be within its validity period and carry no unhandled critical extension. The leaf must allow digitalSignature (when it has key usage) and server authentication (when it has extended key usage; anyExtendedKeyUsage also counts). Each issuer must be a certificate authority (basic constraints, or a v1 root), allow keyCertSign, respect its path_length, allow server authentication, have a subject equal to the issuer of the certificate below it and verify that certificate's signature. At most 8 intermediates are used and none appears twice. Signature algorithms are those of check_signature. A leaf that is itself in roots returns a path of one certificate.

Fails with Denied when host does not match the leaf and with Invalid when the leaf is unusable or no path exists. Revocation is not checked.

time

pub fn time(e: Element) -> i64 ! io.Error

Returns the Unix time in seconds of a UTCTime or GeneralizedTime element.

Only the forms RFC 5280 section 4.1.2.5 allows are accepted: YYMMDDHHMMSSZ with two-digit years 50 to 99 meaning 1950 to 1999 and 00 to 49 meaning 2000 to 2049, and YYYYMMDDHHMMSSZ. Fails with Malformed for any other form or an invalid date or time.

sign

pub fn sign(key: PrivateKey, scheme: i64, message: []u8) -> []u8 ! io.Error

Returns the signature of message under key for the TLS SignatureScheme code scheme.

The supported codes are those of verify_signature. An ECDSA signature is DER encoded. Fails with Unsupported when scheme is not supported or the key type or curve does not fit it, and with the error of the signing function otherwise.

verify_signature

pub fn verify_signature(key: PublicKeyInfo, scheme: i64, message: []u8, signature: []u8) -> bool

Returns whether signature is a valid signature of message under key, for the TLS SignatureScheme code scheme.

The supported codes are 0x0401, 0x0501 and 0x0601 (RSA PKCS#1 v1.5 with SHA-256, SHA-384 and SHA-512), 0x0804, 0x0805 and 0x0806 (RSASSA-PSS with SHA-256, SHA-384 and SHA-512), 0x0403 and 0x0503 (ECDSA P-256 with SHA-256 and P-384 with SHA-384) and 0x0807 (Ed25519). An ECDSA signature is DER encoded. Returns false for any other code or when the key does not fit the scheme.

parse

pub fn parse(der: []u8) -> Certificate ! io.Error

Parses a DER encoded X.509 certificate.

Parsing is strict DER. Fails with Malformed for bad encodings, trailing bytes, an empty serial number, a signature algorithm that differs between the outer and the signed part, a repeated extension, or extensions or unique identifiers in a version that does not allow them. Fails with Unsupported for a version above v3. The signature is not verified; see check_signature and verify_chain.

parse_private_key

pub fn parse_private_key(der: []u8) -> PrivateKey ! io.Error

Parses a DER encoded private key.

Accepts PKCS#8 PrivateKeyInfo (RFC 5208) holding an RSA, a P-256 or P-384 ECDSA or an Ed25519 key (RFC 8410), a PKCS#1 RSAPrivateKey (RFC 8017) and a SEC 1 ECPrivateKey (RFC 5915). Use pem_blocks to extract the DER from a PEM file. Fails with Malformed for bad encodings and with Unsupported for an unknown algorithm, curve or PKCS#8 version.

pem_blocks

pub fn pem_blocks(pem: str, label: str) -> [][]u8

Returns the decoded bodies of every PEM block (RFC 7468) in pem whose label is label, in order.

Text outside the -----BEGIN label----- and -----END label----- lines is ignored. A block whose body is not valid Base64, or that has header lines (contains a :), is skipped. An unterminated block ends the search. Returns an empty list when there is no match.

system_roots

pub fn system_roots() -> []Certificate

Returns the trusted root certificates of the system.

Reads the first file that exists among /etc/ssl/certs/ca-certificates.crt, /etc/pki/tls/certs/ca-bundle.crt and /etc/ssl/cert.pem as PEM. Entries that do not parse are skipped. Returns an empty list when none of the files exists or the file cannot be read.
