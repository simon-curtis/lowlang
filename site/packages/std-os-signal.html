std/os/signal

#os

import std/os/signal

Signal (Hangup, Interrupt, Quit, Abort, Kill, User1, User2, Pipe, Alarm, Terminate, Child, Continue, Stop, TerminalStop, WindowChange) with number, name, from_number and catchable. notify returns a droppable Watch (copyable WatchHandle) whose signals channel delivers the caught signals, with wait_for, wait_timeout, wait_any and stop. Also ignore, reset, send and raise. Kill and Stop cannot be caught and fail with Invalid.

Imports std/io.

catchable

pub fn catchable(s: Signal) -> bool

Returns whether s can be caught or ignored, which is false for Kill and Stop.

name

pub fn name(s: Signal) -> str

Returns the conventional name of s, such as SIGINT.

number

pub fn number(s: Signal) -> i64

Returns the Linux signal number of s.

raise

pub fn raise(s: Signal) ! io.Error

Sends the signal s to the calling thread.

A handler installed in this process has run by the time raise returns.

The owner of a signal watch.

Dropping it stops the watch.

stop

pub fn stop(w: Watch)

Stops the watch owned by w. Does the same as stop_on on its handle.

wait_for

pub fn wait_for(w: Watch) -> Signal ! io.Error

Parks the green thread until w delivers a signal and returns it.

Fails with NotConnected once the watch has stopped.

wait_timeout

pub fn wait_timeout(w: Watch, millis: i64) -> Signal?

Waits up to millis milliseconds for w to deliver a signal, and returns it, or none on timeout or when the watch has stopped.

Parks the green thread while it waits.

A copyable view of a signal watch, used to receive signals and to stop the watch from another green thread.

Dropping a handle does not stop the watch; stop_on or the owning Watch does.

adopt

pub fn adopt(h: WatchHandle) -> Watch

Returns the Watch that owns the watch behind h, which stops it when dropped.

stop_on

pub fn stop_on(h: WatchHandle)

Stops the watch behind h.

Restores the dispositions that were in place before the watch, except for signals whose handler another notify has replaced since. Closes the signals channel, which wakes any green thread waiting on it, and parks the calling green thread until the forwarding green thread has finished. Later calls do nothing.

wait_for_on

pub fn wait_for_on(h: WatchHandle) -> Signal ! io.Error

Parks the green thread until the watch behind h delivers a signal and returns it.

Fails with NotConnected once the watch has stopped.

wait_timeout_on

pub fn wait_timeout_on(h: WatchHandle, millis: i64) -> Signal?

Waits up to millis milliseconds for the watch behind h to deliver a signal, and returns it, or none on timeout or when the watch has stopped.

Parks the green thread while it waits.

Functions

from_number

pub fn from_number(n: i64) -> Signal?

Returns the signal with Linux number n, or none if n is not one of the signals in Signal.

ignore

pub fn ignore(signals: []Signal) ! io.Error

Sets the disposition of each signal in signals to ignored, for the whole process.

Fails with Invalid, without changing any signal, if the list contains Kill or Stop. Fails with the system error if a disposition cannot be set.

notify

pub fn notify(signals: []Signal) -> Watch ! io.Error

Starts delivering signals to the signals channel of the returned Watch.

The watch ends when the Watch is dropped or passed to stop. Fails as notify_handle does.

notify_handle

pub fn notify_handle(signals: []Signal) -> WatchHandle ! io.Error

Starts delivering signals to a channel and returns the view of the watch.

Installs a handler for each signal, replacing the current disposition, and starts a green thread that forwards them. The caller must stop the watch with stop_on, or bind it with adopt so that dropping it does. Fails with Invalid if signals is empty or contains Kill or Stop, and with the system error if a pipe, page or handler cannot be set up, in which case nothing stays installed.

reset

pub fn reset(signals: []Signal) ! io.Error

Sets the disposition of each signal in signals back to the system default, for the whole process.

Fails with Invalid, without changing any signal, if the list contains Kill or Stop.

send

pub fn send(pid: i64, s: Signal) ! io.Error

Sends the signal s to the process pid.

The signal is directed at the process and is delivered to any of its threads. Fails with NotFound if the process does not exist and Denied if the caller may not signal it.

wait_any

pub fn wait_any(signals: []Signal) -> Signal ! io.Error

Parks the green thread until one of signals arrives and returns it.

Watches the signals only for the duration of the call and restores their dispositions before returning. Fails as notify does.
