std/serde

#formats

import std/serde

The Writer and Reader protocols, write[T], read[T] and schema[T] (which the compiler derives for every type), and Field[T, F].

Types

Error

pub enum Error {
    /// The input is not well formed for the format, or a reader was used out of sequence; `message` describes the problem.
    Syntax(i64, str)
    /// The next value has a different type than the one being read; `expected` names the expected type.
    Mismatch(str, i64)
    /// A struct field or labelled variant field is absent from the input, has no default and is not optional; `field` is its name.
    Missing(str)
    /// The input names a variant, `name`, that the enum does not have.
    UnknownVariant(str)
    /// A number does not fit the integer type it is being read into.
    Range(i64)
    /// The input nests deeper than the reader allows.
    TooDeep
}

The error returned when reading a value through a Reader fails.

at in a variant is the Reader.position of the offending value, so its unit depends on the format: a byte offset, a line or a count of values.

Field

pub struct Field[T, F] {
    /// The field's name as written in the struct.
    pub name: str
    /// The zero-based position of the field in the struct's declaration order.
    pub index: i64
}

A reference to the field name of struct T, whose type is F, written T.field.

It carries the name and position of the field so a function can take a field of a given struct with a given type. It needs std/serde to be imported.

Kind

pub enum Kind {
    /// A boolean.
    Bool
    /// A signed integer; `Schema.bits` is its width.
    Int
    /// An unsigned integer; `Schema.bits` is its width.
    Uint
    /// A floating point number; `Schema.bits` is its width.
    Float
    /// A string.
    Text
    /// A byte slice (`[]u8`).
    Binary
    /// A sequence; `Schema.items` holds the element schema.
    Seq
    /// A map; `Schema.items` holds the key schema followed by the value schema.
    Map

    Optional
    /// A struct; `Schema.name` is its name and `Schema.fields` its fields.
    Struct
    /// An enum; `Schema.name` is its name and `Schema.variants` its variants.
    Enum
    /// A struct or enum met again while it is still being described, which makes the type recursive. `Schema.name` names the struct or enum it refers to.
    Ref
}

The kind of type a Schema describes.

Reader

pub struct Reader {
    /// Returns whether the next value is null, consuming it when it is. Otherwise nothing is consumed. Optionals use it.
    pub null: fn() -> bool ! Error
    /// Reads a boolean.
    pub boolean: fn() -> bool ! Error
    /// Reads a signed integer. Narrower integer types read it and then check the range.
    pub integer: fn() -> i64 ! Error
    /// Reads an unsigned integer for the `u64` type.
    pub unsigned: fn() -> u64 ! Error
    /// Reads a floating point number. `f32` values are narrowed from it.
    pub float: fn() -> f64 ! Error
    /// Reads a string.
    pub text: fn() -> str ! Error
    /// Reads a byte slice (`[]u8`).
    pub binary: fn() -> []u8 ! Error
    /// Opens the next value as a sequence. `next_element` then steps through its elements.
    pub begin_seq: fn() ! Error
    /// Moves to the next element of the open sequence and returns `true`, leaving the element to be read next, or returns `false` and closes the sequence once there are no more.
    pub next_element: fn() -> bool ! Error
    /// Opens the next value as a map, or a struct, which is read as a map. `next_key` then steps through its entries.
    pub begin_map: fn() ! Error
    /// Returns the key of the next entry of the open map, leaving its value to be read next, or `none` and closes the map once there are no more entries.
    pub next_key: fn() -> str? ! Error
    /// Opens the next value as an enum variant and returns the variant's name.
    ///
    /// A variant without fields is a name; one with fields carries them as a map when they are labelled or as a sequence otherwise, which is read next.
    pub begin_variant: fn() -> str ! Error
    /// Closes the variant opened by `begin_variant`.
    pub end_variant: fn() ! Error
    /// Skips the next value, including everything nested in it. Reading a struct uses it for keys it does not know.
    pub skip: fn() ! Error
    /// Returns the current position in the input, which is reported as `at` in errors. Its unit is up to the format: a byte offset, a line or a count of values.
    pub position: fn() -> i64
}

The source that a value is read from, made of closures that a format implements.

read calls the closures in document order and each reading closure consumes one value. Reading closures fail with Mismatch when the next value has another type, Range when a number does not fit, and Syntax when the input has no value to read.

read

pub fn read[T](r: Reader) -> T ! Error

Reads a T from r.

A struct is read as a map: unknown keys are skipped, a missing key takes the field's default or none for an optional field, and any other missing key fails with Missing. Integer types narrower than i64 are range checked and fail with Range. A slice is read as a sequence and a map's keys are parsed from the key text, failing with Mismatch when an integer or boolean key is not one. An enum is read from the variant name that begin_variant returns, failing with UnknownVariant for an unknown name, and a positional variant fails with Mismatch when the number of values is wrong. Other failures come from r.

Writer

pub struct Writer {
    /// Writes a null value, which is what a `none` optional becomes.
    pub null: fn()
    /// Writes a boolean.
    pub boolean: fn(bool)
    /// Writes a signed integer. Every integer type except `u64` is widened to `i64` and written here.
    pub integer: fn(i64)
    /// Writes an unsigned integer of type `u64`.
    pub unsigned: fn(u64)
    /// Writes a floating point number. `f32` values are widened to `f64`.
    pub float: fn(f64)
    /// Writes a string.
    pub text: fn(str)
    /// Writes a byte slice (`[]u8`).
    pub binary: fn([]u8)
    /// Opens a sequence of the given number of elements, which follow.
    pub begin_seq: fn(i64)
    /// Closes the sequence opened by `begin_seq`.
    pub end_seq: fn()
    /// Opens a map of the given number of entries. Each entry is written as `key` followed by its value.
    pub begin_map: fn(i64)
    /// Writes the key of the next map entry, as text; integer and boolean keys arrive as their decimal digits or `true` and `false`.
    pub key: fn(str)
    /// Closes the map opened by `begin_map`.
    pub end_map: fn()
    /// Opens a struct, given its type name and its field count. Each field is written as `field` followed by its value, and every field is written, private and optional ones included.
    pub begin_struct: fn(str, i64)
    /// Names the struct field whose value follows.
    pub field: fn(str)
    /// Closes the struct opened by `begin_struct`.
    pub end_struct: fn()
    /// Writes an enum variant that has no fields, given the enum's name and the variant's name.
    pub unit_variant: fn(str, str)
    /// Opens an enum variant that has fields, given the enum's name, the variant's name and its field count. The fields follow as a struct when they are labelled and as a sequence otherwise, and `end_variant` closes the variant.
    pub begin_variant: fn(str, str, i64)
    /// Closes the variant opened by `begin_variant`.
    pub end_variant: fn()
}

The sink that a value is written to, made of closures that a format implements.

write calls the closures in document order. A sequence, map, struct or variant is opened by a begin_ closure and closed by the matching end_ closure, with its elements written between them by the closures for their own types.

Functions

schema

pub fn schema[T]() -> Schema

Returns the Schema of T.

A struct or enum reached again while it is being described becomes a Ref to its name. A pointer is described as its target.

write

pub fn write[T](v: T, w: Writer)

Writes v to w.

The compiler derives the code for the concrete type T: booleans, integers, floats and strings map to the Writer primitives, []u8 to binary, slices to sequences, maps to maps with keys written as text (keys must be strings, integers or booleans), optionals to null or the value, and pointers to their target. A struct is written with every field, in declaration order. An enum variant without fields is written with unit_variant; one with fields with begin_variant, followed by a struct of its fields when they are labelled and a sequence otherwise. A type that cannot be derived is a compile error.
