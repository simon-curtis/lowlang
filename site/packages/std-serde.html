import std/serde

The Writer and Reader protocols, write[T], read[T] and schema[T] (which the compiler derives for every type), and Field[T, F].

The source that a value is read from, made of closures that a format implements.

read calls the closures in document order and each reading closure consumes one value. Reading closures fail with Mismatch when the next value has another type, Range when a number does not fit, and Syntax when the input has no value to read.

read

pub fn read[T](r: Reader) -> T ! Error

Reads a T from r.

A struct is read as a map: unknown keys are skipped, a missing key takes the field's default or none for an optional field, and any other missing key fails with Missing. Integer types narrower than i64 are range checked and fail with Range. A slice is read as a sequence and a map's keys are parsed from the key text, failing with Mismatch when an integer or boolean key is not one. An enum is read from the variant name that begin_variant returns, failing with UnknownVariant for an unknown name, and a positional variant fails with Mismatch when the number of values is wrong. Other failures come from r.

The sink that a value is written to, made of closures that a format implements.

write calls the closures in document order. A sequence, map, struct or variant is opened by a begin_ closure and closed by the matching end_ closure, with its elements written between them by the closures for their own types.

Functions

schema

pub fn schema[T]() -> Schema

Returns the Schema of T.

A struct or enum reached again while it is being described becomes a Ref to its name. A pointer is described as its target.

write

pub fn write[T](v: T, w: Writer)

Writes v to w.

The compiler derives the code for the concrete type T: booleans, integers, floats and strings map to the Writer primitives, []u8 to binary, slices to sequences, maps to maps with keys written as text (keys must be strings, integers or booleans), optionals to null or the value, and pointers to their target, a shared pointer in full each time. A pointer reached again while its target is being written is a cycle and panics with serde: cycle through *T. A struct is written with every field, in declaration order. An enum variant without fields is written with unit_variant; one with fields with begin_variant, followed by a struct of its fields when they are labelled and a sequence otherwise. A type that cannot be derived is a compile error.
