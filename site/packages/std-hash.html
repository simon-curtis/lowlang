std/hash

#crypto

import std/hash

One-shot and incremental forms of CRC-32, CRC-32C, Adler-32, CRC-64 and xxHash32/64. Also FNV-1 and FNV-1a in 32 and 64 bits; SipHash-2-4 and SipHash-1-3 with a 16-byte key in 64- and 128-bit forms; MurmurHash3 (murmur3_32, murmur3_128); wyhash final 4.2; jump consistent hashing; and rendezvous hashing.

Imports std/bits, std/io.

Examples

checksums

import std/hash
import std/slices

/// Prints the standard check values of six checksums over `123456789`, then hashes a payload in pieces and compares it with a single call.
fn main() {
    let check = bytes("123456789")
    print("crc32   {hash.crc32(check):x8}")
    print("crc64   {hash.crc64(check):x16}")
    print("adler32 {hash.adler32(check):x8}")
    print("fnv1a64 {hash.fnv1a_64(check):x16}")
    print("xxh64   {hash.xxh64(check, 0):x16}")

    let castagnoli = hash.crc32c_new()
    hash.crc32_update(castagnoli, check)
    print("crc32c  {hash.crc32_sum(castagnoli):x8}")

    let payload = bytes("a payload that arrives in three pieces")
    let pieces = slices.chunks(payload, 16)
    let running = hash.xxh64_new(7)
    for piece in pieces {
        hash.xxh64_update(running, piece)
    }
    let streamed = hash.xxh64_sum(running)
    print("pieces: {pieces.len}, streamed equals one call: {streamed == hash.xxh64(payload, 7)}")
}

sharding

import std/hash

fn owners(keys: []str, nodes: []str) -> []i64 {
    var result: []i64 = []
    for key in keys {
        push(mut result, hash.rendezvous_str(key, nodes) ?? -1)
    }
    result
}

/// Assigns cache keys to nodes by rendezvous hashing and by jump hashing, then removes a node and grows a bucket count to show how few keys move.
fn main() {
    var keys: []str = []
    for i in 0..1000 {
        push(mut keys, "user:{i}")
    }

    let before = ["cache-a", "cache-b", "cache-c", "cache-d"]
    let after = ["cache-a", "cache-b", "cache-d"]
    let was = owners(keys, before)
    let now = owners(keys, after)

    var moved = 0
    var orphaned = 0
    for i in 0..keys.len {
        if was[i] == 2 {
            orphaned += 1
        } else if before[was[i]] != after[now[i]] {
            moved += 1
        }
    }
    print("keys owned by cache-c: {orphaned}")
    print("keys that moved off a surviving node: {moved}")

    var to_new = 0
    var elsewhere = 0
    for i in 0..keys.len {
        let key = hash.xxh64(bytes(keys[i]), 0)
        let small = hash.jump(key, 4)
        let large = hash.jump(key, 5)
        if small != large {
            if large == 4 {
                to_new += 1
            } else {
                elsewhere += 1
            }
        }
    }
    print("growing from 4 to 5 buckets moved {to_new} keys, all to bucket 4: {elsewhere == 0}")
    print("no nodes: {hash.rendezvous_str("user:1", []) == none}")
}

pub struct Crc32 {

An incremental CRC-32 checksum state.

Made by crc32_new or crc32c_new. The state is mutated in place by crc32_update.

crc32_sum

pub fn crc32_sum(c: *Crc32) -> u32

Returns the CRC-32 of everything fed to c so far.

The state is not consumed; more data can be fed afterwards.

crc32_update

pub fn crc32_update(c: *Crc32, data: []u8)

Feeds data into the CRC-32 state c.

Updating with several slices in turn gives the same sum as updating with their concatenation. An empty slice leaves the state unchanged.

jump

pub fn jump(key: u64, buckets: i64) -> i64

Returns the bucket in 0..buckets that key maps to under jump consistent hashing (Lamping and Veach, 2014).

When buckets grows from n to n + 1, only about 1 / (n + 1) of the keys move, and each moves to the new bucket. Buckets can only be added or removed at the end; the function carries no per-bucket state.

Returns -1 when buckets is not positive.

rendezvous

pub fn rendezvous(key: u64, nodes: []u64) -> i64?

Returns the index in nodes that key maps to under rendezvous (highest random weight) hashing, or none when nodes is empty.

Each node id is scored by mixing it with key through the 64-bit murmur finaliser, and the highest score wins; ties go to the lowest index. Removing a node moves only the keys it owned. Node ids are not required to be sorted, and the result depends on the ids, not on their positions.

rendezvous_str

pub fn rendezvous_str(key: str, nodes: []str) -> i64?

Returns the index in nodes that key maps to under rendezvous hashing, or none when nodes is empty.

The bytes of each node name are hashed with xxh64, seeded by the xxh64 of key, and the highest hash wins; ties go to the lowest index.
