public_key

pub fn public_key(private: []u8) -> []u8

Returns the 32-byte X25519 public key for the 32-byte private key (RFC 7748).

Multiplies the base point with u of 9 by the clamped private key. The length of private is not validated.

shared

pub fn shared(private: []u8, peer: []u8) -> []u8 ! io.Error

Returns the 32-byte X25519 shared secret of private and the peer's public key peer (RFC 7748).

Fails with io.Error.Invalid when either argument is not 32 bytes or when the result is all zeros, which a low-order peer point produces. The secret is not uniformly random; derive keys from it with a KDF such as hkdf_extract.
