std/bits

#data

import std/bits

Word operations (popcount, trailing_zeros on the processor bit scan, leading_zeros, bit_length, select_in_word and the 32 and 64-bit rotations rotl32, rotr32, rotl64 and rotr64) and dense bitsets. std/hash, std/rand, std/text, the JSON, XML and YAML readers and the compressors use these for rotations, bit counts and bit lengths.

Imports std/math.

Examples

sieve

import std/bits

fn show(label: str, s: *bits.Set) {
    print("{label} ({bits.count(s)}): {bits.members(s)}")
}

/// Sieves the primes below 60 into a bit set, then combines it with another set, walks it with `next_set`, and asks for a prime by rank.
fn main() {
    let limit = 60
    let composite = bits.set(limit)
    for n in 2..limit {
        if bits.contains(composite, n) {
            continue
        }
        var multiple = n * n
        for multiple < limit {
            bits.add(composite, multiple)
            multiple += n
        }
    }

    let everything = bits.set(limit)
    for n in 2..limit {
        bits.add(everything, n)
    }
    let primes = bits.difference(everything, composite)
    show("primes", primes)

    let one_mod_four = bits.set(limit)
    for n in 0..limit {
        if n % 4 == 1 {
            bits.add(one_mod_four, n)
        }
    }
    show("primes that are 1 mod 4", bits.intersect(primes, one_mod_four))

    var gaps: []i64 = []
    var at = bits.next_set(primes, 0)
    for {
        let current = at ?? break
        let following = bits.next_set(primes, current + 1) ?? break
        push(mut gaps, following - current)
        at = following
    }
    print("gaps between primes: {gaps}")

    print("10th prime: {bits.select_at(primes, 9) ?? -1}")
    print("primes up to 30: {bits.rank(primes, 30)}")
    print("largest prime: {bits.max(primes) ?? -1}")
}

Set

pub struct Set {
    ...
}

A growable set of non-negative integers stored as one bit per member in u64 words.

Create one with set. A Set is used through a pointer and grows when a member beyond its capacity is added. Membership operations take constant time; whole-set operations, count and the scans take time proportional to the number of words, and scans skip empty words 64 members at a time. Members must not be negative.

add

pub fn add(s: *Set, x: i64)

Adds x to s, growing the set when x is beyond its capacity.

Adding a member that is present changes nothing.

clear

pub fn clear(s: *Set)

Removes every member from s, keeping its capacity.

clone

pub fn clone(s: *Set) -> *Set

Returns a new set with the same members as s.

pub fn contains(s: *Set, x: i64) -> bool

Returns true when x is a member of s.

Returns false for a negative x and for one beyond the capacity.

count

pub fn count(s: *Set) -> i64

Returns the number of members of s.

difference

pub fn difference(a: *Set, b: *Set) -> *Set

Returns a new set of the members of a that are not in b.

Neither argument changes.

difference_with

pub fn difference_with(a: *Set, b: *Set)

Removes from a every member that is in b.

equal

pub fn equal(a: *Set, b: *Set) -> bool

Returns true when a and b have the same members.

Capacity is not compared, so sets of different capacity can be equal.

for_each

pub fn for_each(s: *Set, f: fn(i64) -> bool)

Calls f with each member of s in increasing order.

Stops early when f returns false.

intersect

pub fn intersect(a: *Set, b: *Set) -> *Set

Returns a new set of the members that are in both a and b.

Neither argument changes.

intersect_with

pub fn intersect_with(a: *Set, b: *Set)

Removes from a every member that is not in b.

max

pub fn max(s: *Set) -> i64?

Returns the largest member of s, or none when it is empty.

members

pub fn members(s: *Set) -> []i64

Returns the members of s in increasing order.

min

pub fn min(s: *Set) -> i64?

Returns the smallest member of s, or none when it is empty.

next_clear

pub fn next_clear(s: *Set, from: i64) -> i64

Returns the smallest non-member of s that is at least from.

A negative from starts at zero. Every value beyond the capacity is a non-member, so the result is never none and is at most the capacity rounded up to a multiple of 64.

next_set

pub fn next_set(s: *Set, from: i64) -> i64?

Returns the smallest member of s that is at least from, or none when there is none.

A negative from starts at zero.

rank

pub fn rank(s: *Set, x: i64) -> i64

Returns the number of members of s that are at most x.

Returns 0 for a negative x and the total count for an x beyond the capacity.

remove

pub fn remove(s: *Set, x: i64)

Removes x from s.

Does nothing when x is not a member, including when it is negative or beyond the capacity.

select_at

pub fn select_at(s: *Set, k: i64) -> i64?

Returns the member of s with zero-based position k in increasing order, or none when k is negative or at least count(s).

This is the inverse of rank: rank(s, x) - 1 is the position of the member x.

subset

pub fn subset(a: *Set, b: *Set) -> bool

Returns true when every member of a is also in b.

An empty set is a subset of every set.

toggle

pub fn toggle(s: *Set, x: i64)

Adds x to s when it is absent and removes it when it is present.

Grows the set when x is beyond its capacity.

union

pub fn union(a: *Set, b: *Set) -> *Set

Returns a new set of the members that are in a or b.

Neither argument changes.

union_with

pub fn union_with(a: *Set, b: *Set)

Adds every member of b to a, growing a when b is larger.

xor

pub fn xor(a: *Set, b: *Set) -> *Set

Returns a new set of the members that are in exactly one of a and b.

Neither argument changes.

xor_with

pub fn xor_with(a: *Set, b: *Set)

Makes a the symmetric difference of a and b: members in exactly one of the two.

Grows a when b is larger.
