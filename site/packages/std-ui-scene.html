#ui

import std/ui/scene

Quads with solid or gradient fills, shadows, sprites and pictures with their clip rectangles and draw order, and batching.

Imports std/ui/geometry.

Atlas

}

Two square images the GPU samples: glyph and shape coverage for sprites, and colours for pictures.

clean

pub fn clean(mut a: Atlas)

Marks every row of both planes as copied.

dirty

pub fn dirty(a: Atlas) -> bool

Returns true when rows of either plane have changed since the last clean.

tile

Returns the fractions of a plane that a width by height pixel tile at x, y covers, for Sprite.tile and Picture.tile.

write

pub fn write(mut a: Atlas, x: i64, y: i64, width: i64, height: i64, coverage: []u8)

Copies coverage, width by height bytes in rows, into the coverage plane with its top-left pixel at x, y, and marks those rows changed.

write_colors

pub fn write_colors(mut a: Atlas, x: i64, y: i64, width: i64, height: i64, rgba: []u8)

Copies rgba, width by height pixels of four bytes in rows, into the colour plane with its top-left pixel at x, y, and marks those rows changed.

Gradient

extern pub struct Gradient {How far along the line one device pixel to the right moves, as a fraction of the line. With dy zero, the fill is solid.    pub dx: f32How far along the line one device pixel down moves.    pub dy: f32Where on the line the fill starts to change.    pub from: f32Where on the line the fill reaches background_end.    pub to: f32
}

A linear change across a quad's fill, as the quad shader reads it.

A pixel's place on the gradient line is 0.5 plus its offset from the quad's centre dotted with (dx, dy). The fill is background up to from, background_end from to, and blended between.

The primitives of one frame in device pixels, in the order they were pushed.

batches

pub fn batches(s: Scene) -> []Batch

Returns the runs to draw, in order, so that primitives of every kind draw in the order they were pushed.

Consecutive primitives of one kind share a run, so a scene of quads under text is two batches however many of each it holds.

clip

pub fn clip(s: Scene) -> geometry.Rect

Returns the rectangle primitives are currently clipped to: the intersection of every clip pushed and not popped, and the target.

pop_clip

pub fn pop_clip(mut s: Scene)

Restores the clip in force before the last push_clip. The target's own clip is never removed.

push_clip

pub fn push_clip(mut s: Scene, r: geometry.Rect)

Narrows the clip to its intersection with r until the matching pop_clip.

push_picture

pub fn push_picture(mut s: Scene, p: Picture)

Adds p above everything pushed so far, clipped to the current clip.

push_quad

push_shadow

linear

pub fn linear(bounds: geometry.Rect, degrees: f32, from: f32, to: f32) -> Gradient

Returns the gradient across bounds in the direction degrees clockwise from straight up, changing between from and to along a line as CSS draws it: through the centre, just long enough that the corners it starts and ends at sit on its ends.
