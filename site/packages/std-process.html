std/process

#os

import std/process

Command with arguments, an optional replacement environment, a working directory, Inherit, Piped or Null for each standard stream, and an optional new process group. start returns a droppable Child that kills and reaps an unwaited process and closes its pipes when released. start_handle, adopt, wait, kill, and wait_on, wait_exit_on (waits without reaping, so the process group can still be signalled) and kill_on on the shared ChildHandle. run feeds input and collects both outputs. find searches PATH. success.

Imports std/file, std/io, std/os, std/text.

Types

Child

pub struct Child {
    /// The shared view of the child.
    pub handle: *ChildHandle
}

The owner of a started child process.

Dropping a child that has not been waited for kills it with signal 9, reaps it and closes its streams.

kill

pub fn kill(c: Child, signal: i64) ! io.Error

Sends the signal number signal to the child owned by c.

Does the same as kill_on on its handle.

wait

pub fn wait(c: Child) -> Exit ! io.Error

Waits for the child owned by c to end and returns how it ended.

Does the same as wait_on on its handle.

ChildHandle

pub struct ChildHandle {
    /// The process id of the child.
    pub pid: i64
    /// A stream that writes to the child's standard input, or `none` unless it was `Piped`.
    ///
    /// Closing it closes the pipe, which the child sees as end of input.
    pub stdin: io.Stream?
    /// A stream that reads the child's standard output, or `none` unless it was `Piped`.
    ///
    /// Reads return `0` at end of output.
    pub stdout: io.Stream?
    /// A stream that reads the child's standard error, or `none` unless it was `Piped`.
    ///
    /// Reads return `0` at end of output.
    pub stderr: io.Stream?
    ...
}

A copyable view of a started child process.

The view holds the process id and the parent's ends of the pipes. It does not kill or reap the child when released; wait_on reaps it and Child does both when dropped.

adopt

pub fn adopt(h: *ChildHandle) -> Child

Returns the Child that owns the process behind h, which kills and reaps it when dropped.

kill_on

pub fn kill_on(c: *ChildHandle, signal: i64) ! io.Error

Sends the signal number signal to the child behind c.

Does nothing once the child has been waited for. Signals the whole process group for a command started with group. Does not wait for the child to end.

wait_exit_on

pub fn wait_exit_on(c: *ChildHandle) ! io.Error

Waits for the child behind c to end without reaping it.

Parks the green thread until the process ends. kill_on still signals the child's process group afterwards, and wait_on then reaps the child and returns at once. Returns at once when the child has been waited for. When no process descriptor could be obtained for the child, the wait blocks the OS thread instead. Fails with NotConnected when a concurrent wait_on reaps the child first.

wait_on

pub fn wait_on(c: *ChildHandle) -> Exit ! io.Error

Waits for the child behind c to end, reaps it and returns how it ended.

Parks the green thread until the process ends. The result is remembered, so later calls return it at once. When no process descriptor could be obtained for the child, the wait blocks the OS thread instead. Fails with the system error if the child cannot be reaped, and can fail with NotConnected when a concurrent call reaps it first.

Command

pub struct Command {
    /// The program to run. A name without `/` is searched for in `PATH` as `find` does.
    pub program: str
    /// The arguments after the program name. The program name itself is passed as `argv[0]`.
    pub args: []str
    /// The complete environment of the child, or `none` to give it the current environment from `os.environment`.
    pub env: [str: str]?
    /// The working directory of the child. An empty string keeps the parent's.
    pub dir: str
    /// How the child's standard input is connected.
    pub stdin: Stdio
    /// How the child's standard output is connected.
    pub stdout: Stdio
    /// How the child's standard error is connected.
    pub stderr: Stdio
    /// Whether the child starts in a new process group. `kill` then signals the whole group.
    pub group: bool
}

A program to run, with its arguments, environment, working directory and standard stream setup.

Made with command and adjusted by setting fields. Starting it with start, start_handle or run does not modify the command.

run

pub fn run(c: Command, input: []u8) -> Output ! io.Error

Runs c to completion with all three standard streams piped, and returns its output.

Overrides the stdin, stdout and stderr modes of c. Writes input to the child's standard input in the background and then closes it, collects standard output and standard error completely in memory, and waits for the child to end. Parks the green thread while it waits. A non-zero exit is not an error: it is reported in Output.status. Fails only if the child cannot be started or waited for. Errors from writing input, such as a child that exits without reading it, are ignored.

start

pub fn start(c: Command) -> Child ! io.Error

Starts the command and returns the Child that owns the process.

Fails as start_handle does.

start_handle

pub fn start_handle(c: Command) -> *ChildHandle ! io.Error

Starts the command and returns a view of the process.

Resolves the program with find, creates the requested pipes and forks. Returns after the child has executed the program, parking the green thread while it waits for that. Fails with NotFound if the program is not found, with the system error if a pipe or the fork fails, and with the error of a failing chdir or execve in the child, such as Denied, NotDir or NotFound, in which case the child has been reaped. The caller must wait for the child with wait_on or hand the view to adopt.

find

pub fn find(name: str) -> str?

Returns the path of the executable that name refers to, or none.

A name containing / is checked as given. Any other name is looked for in each directory of PATH, taken from os.env so os.set_env applies, or /usr/local/bin:/usr/bin:/bin when it is unset; an empty entry stands for the current directory. A match must be executable and not a directory. Blocks the OS thread while it checks the candidates.
