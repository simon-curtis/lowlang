std/process

#os

import std/process

Command with arguments, an optional replacement environment, a working directory, Inherit, Piped or Null for each standard stream, and an optional new process group. start returns a droppable Child that kills and reaps an unwaited process and closes its pipes when released. start_handle, adopt, wait, kill (which takes a std/os/signal Signal; an Exit is Exited(code) or Signaled(signal) with the same type), and wait_on, wait_exit_on (waits without reaping, so the process group can still be signalled) and kill_on on the shared ChildHandle. run feeds input and collects both outputs. find searches PATH. success.

Imports std/io, std/os, std/os/signal, std/sys, std/text.

Examples

capture

import std/io
import std/os
import std/process
import std/sys
import std/text

fn worker() ! io.Error {
    let input = io.read_all(sys.stream(0))?
    let greeting = os.env("GREETING") ?? "none"
    print("{greeting}: {text.upper(text.trim(str(input)))}")
    sys.write_all(2, bytes("worker finished\n"))?
    os.exit(3)
}

fn describe(e: process.Exit) -> str {
    match e {
        Exited(code) => "exited with {code}"
        Signaled(_) => "killed by a signal"
    }
}

/// Runs this program again as a worker, feeds it standard input and a private environment, and reports its output and exit status.
fn main() ! io.Error {
    if os.args().len > 1 {
        worker()?
        return
    }

    var job = process.command(os.executable()?, ["worker"])
    job.env = some(["GREETING": "hello"])
    let result = process.run(job, bytes("low standard library\n"))?
    print("stdout: {text.trim(str(result.stdout))}")
    print("stderr: {text.trim(str(result.stderr))}")
    print("status: {describe(result.status)}")
    print("success: {process.success(result.status)}")

    process.start(process.command("no-such-program-for-low", [])) catch {
        NotFound => {
            print("missing program: NotFound")
            return
        }
        e => fail e
    }
}

stderr: worker finished
status: exited with 3
success: false

conversation

import std/io
import std/os
import std/process
import std/sys
import std/text

fn echo_server() ! io.Error {
    let input = io.reader(sys.stream(0))
    var count = 0
    for {
        let line = io.read_line(input) catch {
            Eof => break
            e => fail e
        }
        count += 1
        let reply = "#{count} {text.upper(line)}\n"
        sys.write_all(1, bytes(reply))?
    }
}

fn ask(to: io.Stream, from: *io.Reader, question: str) -> str ! io.Error {
    io.write_all(to, bytes("{question}\n"))?
    io.read_line(from)?
}

/// Starts this program as a line-oriented server, exchanges messages over its piped standard streams, and waits for it to exit once its input closes.
fn main() ! io.Error {
    if os.args().len > 1 {
        echo_server()?
        return
    }

    var server = process.command(os.executable()?, ["serve"])
    server.stdin = process.Stdio.Piped
    server.stdout = process.Stdio.Piped
    using child = process.start(server)?
    let to = child.handle.stdin ?? fail Invalid
    let from = io.reader(child.handle.stdout ?? fail Invalid)

    for question in ["ping", "status", "quit"] {
        let answer = ask(to, from, question)?
        print("{question} -> {answer}")
    }

    to.close()
    let end = process.wait(child)?
    print("server ended: {process.success(end)}")
}

Output

ping -> #1 PING
status -> #2 STATUS
quit -> #3 QUIT
server ended: true

The owner of a started child process.

Dropping a child that has not been waited for kills it with Kill, reaps it and closes its streams.

Does the same as kill_on on its handle.

A copyable view of a started child process.

The view holds the process id and the parent's ends of the pipes. It does not kill or reap the child when released; wait_on reaps it and Child does both when dropped.

adopt

pub fn adopt(h: *ChildHandle) -> Child

Returns the Child that owns the process behind h, which kills and reaps it when dropped.

kill_on

pub fn kill_on(c: *ChildHandle, signal: signals.Signal) ! io.Error

Sends signal to the child behind c.

Does nothing once the child has been waited for. Signals the whole process group for a command started with group. Does not wait for the child to end.

wait_exit_on

pub fn wait_exit_on(c: *ChildHandle) ! io.Error

Waits for the child behind c to end without reaping it.

Parks the green thread until the process ends. kill_on still signals the child's process group afterwards, and wait_on then reaps the child and returns at once. Returns at once when the child has been waited for. Fails with NotConnected when a concurrent wait_on reaps the child first.

wait_on

pub fn wait_on(c: *ChildHandle) -> Exit ! io.Error

Waits for the child behind c to end, reaps it and returns how it ended.

Parks the green thread until the process ends. The result is remembered, so later calls return it at once. Fails with the system error if the child cannot be reaped, and can fail with NotConnected when a concurrent call reaps it first.

A program to run, with its arguments, environment, working directory and standard stream setup.

Made with command and adjusted by setting fields. Starting it with start, start_handle or run does not modify the command.

run

pub fn run(c: Command, input: []u8) -> Output ! io.Error

Runs c to completion with all three standard streams piped, and returns its output.

Overrides the stdin, stdout and stderr modes of c. Writes input to the child's standard input in the background and then closes it, collects standard output and standard error completely in memory, and waits for the child to end. Parks the green thread while it waits. A non-zero exit is not an error: it is reported in Output.status. Fails if the child cannot be started or waited for, and with the error of a read of standard output or standard error that fails before the end of the output, in which case the child is killed and reaped. Errors from writing input, such as a child that exits without reading it, are ignored.

start

pub fn start(c: Command) -> Child ! io.Error

Starts the command and returns the Child that owns the process.

Fails as start_handle does.

start_handle

pub fn start_handle(c: Command) -> *ChildHandle ! io.Error

Starts the command and returns a view of the process.

Resolves the program with find, creates the requested pipes and forks. Returns after the child has executed the program, parking the green thread while it waits for that. Fails with NotFound if the program is not found, with the system error if a pipe or the fork fails or the child's report cannot be read, and with the error of a failing chdir or execve in the child, such as Denied, NotDir or NotFound, in which case the child has been reaped. The caller must wait for the child with wait_on or hand the view to adopt.

find

pub fn find(name: str) -> str?

Returns the path of the executable that name refers to, or none.

A name containing / is checked as given. Any other name is looked for in each directory of PATH, taken from os.env so os.set_env applies, or /usr/local/bin:/usr/bin:/bin when it is unset; an empty entry stands for the current directory. A match must be executable and not a directory. On Windows a name containing \ or / is checked as given, PATH entries are separated by ;, and a name without an extension also matches with each extension in PATHEXT. Blocks the OS thread while it checks the candidates.
