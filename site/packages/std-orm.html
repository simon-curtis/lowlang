std/orm

#database

import std/orm

Typed queries over field references, row mapping, inserts, updates and deletes, tables created from types, and raw queries mapped onto structs, over an sql.ConnectionHandle.

Imports std/json, std/otel, std/serde, std/slices, std/sql, std/text.

Types

Condition

pub enum Condition[T] {The column compared with a value by op.    Compare(str, Op, sql.Value)The column is NULL.    IsNull(str)The column is not NULL.    NotNull(str)The column equals one of the values. An empty list matches no row.    OneOf(str, []sql.Value)Every part holds. An empty list matches every row.    All([]Condition[T])At least one part holds. An empty list matches no row.    Any([]Condition[T])The inner condition does not hold.    Not(*Condition[T])A SQL fragment in which each ? is replaced by the next value as a parameter.A ? with no value left stays in the text as written. The text itself is not checked or quoted.    Raw(str, []sql.Value)
}

A condition on the rows of a table T, rendered into a WHERE clause with every value passed as a statement parameter.

Build conditions with eq, lt, not, the All and Any variants and the other functions of this module.

Returns the condition that c does not hold.

How a column is compared with a value.

Query

pub struct Query[T] {
    ...
}

A select over a Table[T], built from from by adding conditions, ordering and paging.

A Query is a copyable value; each function returns a changed copy and leaves its argument alone.

filter

pub fn filter[T](q: Query[T], c: Condition[T]) -> Query[T]

Returns q with c added.

All conditions of a query must hold.

order_by

pub fn order_by[T, F](q: Query[T], f: serde.Field[T, F]) -> Query[T]

Returns q ordered by field f ascending, after any earlier ordering.

order_by_desc

pub fn order_by_desc[T, F](q: Query[T], f: serde.Field[T, F]) -> Query[T]

Returns q ordered by field f descending, after any earlier ordering.

skip

pub fn skip[T](q: Query[T], n: i64) -> Query[T]

Returns q that skips the first n rows of the result.

A value of zero or less skips nothing.

take

pub fn take[T](q: Query[T], n: i64) -> Query[T]

Returns q limited to n rows.

A negative n removes the limit. Without an ordering, which rows come first is up to the database.

Table

pub struct Table[T] {The table name, quoted for the dialect when it is used.    pub name: strThe column that holds the primary key. Defaults to id.    pub key: str
}

A database table that stores values of type T, one column per field of T.

Fields of T map to columns of the same name. Scalars, strings, byte slices and unit enums are stored natively; other values, such as structs, sequences, maps and enum variants with data, are stored as JSON text.

from

pub fn from[T](t: Table[T]) -> Query[T]

Returns the query that selects every row of t, in database order and without limit.

Functions

count

pub fn count[T](db: sql.ConnectionHandle, q: Query[T]) -> i64 ! sql.Error

Returns the number of rows that match q.

Ordering and paging of q are ignored. Fails with Protocol if the database returns no result row and Conversion if the count is not an integer.

create_table

pub fn create_table[T](db: sql.ConnectionHandle, t: Table[T]) ! sql.Error

Creates the table for t on db.

Fails with the database error, including when the table already exists.

create_table_sql

pub fn create_table_sql[T](d: sql.Dialect, t: Table[T]) -> str

Returns the CREATE TABLE statement for t in dialect d.

Columns follow the fields of T and are NOT NULL unless the field is optional. The column types come from d.types. An integer key becomes an identity primary key; any other key becomes a plain PRIMARY KEY column, with the short text type for a string key. Booleans, integers, floats, strings and byte slices get native types, a 64-bit unsigned integer gets the unsigned type and an enum of unit variants the enumeration type. Every other field gets the document type: jsonb on Postgres, nvarchar(max) on SQL Server and TEXT on SQLite.

delete_matching

pub fn delete_matching[T](db: sql.ConnectionHandle, q: Query[T]) -> i64 ! sql.Error

Deletes every row that matches q and returns the number deleted.

Ordering and paging of q are ignored. A query without conditions deletes every row of the table.

drop_table

pub fn drop_table[T](db: sql.ConnectionHandle, t: Table[T]) ! sql.Error

Drops the table of t on db if it exists.

eq

pub fn eq[T, F: Eq](f: serde.Field[T, F], v: F) -> Condition[T]

Returns the condition that field f equals v.

The value is converted as value_of does. A none value compares with NULL and matches no row; use is_null to test for it.

execute

pub fn execute(db: sql.ConnectionHandle, text: str, values: []sql.Value) -> i64 ! sql.Error

Runs the SQL text with values as parameters and returns the number of affected rows.

find

pub fn find[T, K](db: sql.ConnectionHandle, t: Table[T], key: K) -> T? ! sql.Error

Returns the row of t whose key equals key, or none if there is none.

key is converted as value_of does.

first

pub fn first[T](db: sql.ConnectionHandle, q: Query[T]) -> T? ! sql.Error

Returns the first row that matches q, or none if no row matches.

Limits the query to one row; the row that comes first is up to the query's ordering.

ge

pub fn ge[T, F: Ord](f: serde.Field[T, F], v: F) -> Condition[T]

Returns the condition that field f is greater than or equal to v.

gt

pub fn gt[T, F: Ord](f: serde.Field[T, F], v: F) -> Condition[T]

Returns the condition that field f is greater than v.

insert

pub fn insert[T](db: sql.ConnectionHandle, t: Table[T], v: T) -> sql.Value ! sql.Error

Inserts v into t and returns the key of the new row.

Every field of v becomes a column. When the key field is 0 or none, it is left out so the database generates it. Postgres and SQL Server report the key through RETURNING and OUTPUT; SQLite has no such clause here, so the result is Null.

is_null

pub fn is_null[T, F](f: serde.Field[T, F?]) -> Condition[T]

Returns the condition that the optional field f is NULL.

le

pub fn le[T, F: Ord](f: serde.Field[T, F], v: F) -> Condition[T]

Returns the condition that field f is less than or equal to v.

like

pub fn like[T](f: serde.Field[T, str], pattern: str) -> Condition[T]

Returns the condition that string field f matches the SQL LIKE pattern pattern.

% matches any run of characters and _ one character. Case sensitivity follows the database.

list

pub fn list[T](db: sql.ConnectionHandle, q: Query[T]) -> []T ! sql.Error

Returns every row that matches q, mapped onto T.

Fails with Conversion when a row does not fit T, and otherwise with the database error.

lt

pub fn lt[T, F: Ord](f: serde.Field[T, F], v: F) -> Condition[T]

Returns the condition that field f is less than v.

ne

pub fn ne[T, F: Eq](f: serde.Field[T, F], v: F) -> Condition[T]

Returns the condition that field f differs from v.

Rows where the field is NULL do not match.

not_null

pub fn not_null[T, F](f: serde.Field[T, F?]) -> Condition[T]

Returns the condition that the optional field f is not NULL.

one_of

pub fn one_of[T, F](f: serde.Field[T, F], values: []F) -> Condition[T]

Returns the condition that field f equals one of values.

An empty values matches no row.

query

pub fn query[T](db: sql.ConnectionHandle, text: str, values: []sql.Value) -> []T ! sql.Error

Runs the SQL text with values as parameters and maps each result row onto T.

Use it for statements Query cannot express. Fails with Conversion when a row does not fit T, and otherwise with the database error.

raw

pub fn raw[T](text: str, values: []sql.Value) -> Condition[T]

Returns a condition from the SQL fragment text, replacing each ? with the next of values as a parameter.

The text is sent as written, so never build it from untrusted input; pass such input as values.

remove

pub fn remove[T](db: sql.ConnectionHandle, t: Table[T], v: T) -> i64 ! sql.Error

Deletes the row of t whose key equals the key of v and returns the number of rows deleted.

Returns 0 when no row has that key.

table

pub fn table[T](name: str) -> Table[T]

Returns the table name for T, with id as its key column.

to_sql

pub fn to_sql[T](d: sql.Dialect, q: Query[T]) -> str

Returns the SELECT statement for q in dialect d, with placeholders in place of its values.

The values are not returned, so the text is for inspection. Paging is written as LIMIT and OFFSET on Postgres and SQLite, and as OFFSET ... FETCH NEXT on SQL Server, which gets ORDER BY (SELECT NULL) when the query has no ordering.

transaction

pub fn transaction(db: sql.ConnectionHandle, body: fn() ! sql.Error) ! sql.Error

Runs body between a begin and a commit on db.

If body fails, the transaction is rolled back and transaction fails with the same error, or with the rollback's error when the rollback fails too. A failed begin or commit returns its error; a failed commit does not roll back. body should use db for its statements. The transaction does not nest.

update

pub fn update[T](db: sql.ConnectionHandle, t: Table[T], v: T) -> i64 ! sql.Error

Updates the row of t whose key equals the key of v, setting every other field from v, and returns the number of rows updated.

Returns 0 when no row has that key.

value_of

pub fn value_of[F](v: F) -> sql.Value

Returns the sql.Value that stores v in a column.

Booleans, integers, floats, strings and byte slices become the matching Value variants. A u64 above the i64 maximum becomes Decimal, a unit enum variant becomes Text holding its name, and none becomes Null. Structs, sequences, maps and enum variants with data become Text holding their JSON.
