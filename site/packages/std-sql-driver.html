std/sql/driver

#database

import std/sql/driver

What the drivers share. A Session holds the busy and closed state, and guarded fails a call with Busy or Closed and abandons the connection on an error the driver calls fatal. guard applies that to every operation of a ConnectionHandle, establish runs the login under it, collect, ignore_columns and ignore_row are the row callbacks, dial and port_of resolve the dialect's default port, and traced wraps a handle with otel.instrument_sql. connection guards, traces and adopts a driver's handle, so std/sql/postgres, std/sql/sqlserver and std/sql/sqlite do not import std/otel.

Imports std/net, std/otel, std/sql.

The state of one driver connection that every call checks: whether a call is running and whether the connection is closed.

connection

Returns the owning sql.Connection for a driver's raw handle: guarded by the session, traced under scope and closed when dropped.

establish

pub fn establish(s: *Session, fatal: fn(sql.Error) -> bool, abandon: fn(), terminate: fn(), handshake: fn() ! sql.Error) ! sql.Error

Runs the login exchange handshake as a call on the session and, when it fails, calls terminate before returning the error.

guard

pub fn guard(s: *Session, fatal: fn(sql.Error) -> bool, abandon: fn(), raw: sql.ConnectionHandle) -> sql.ConnectionHandle

Returns raw with every operation run as a call on the session, as guarded does.

guarded

pub fn guarded[T](s: *Session, fatal: fn(sql.Error) -> bool, abandon: fn(), work: fn() -> T ! sql.Error) -> T ! sql.Error

Runs work as a call on the session.

Fails with sql.Error.Closed when the session is closed and sql.Error.Busy when another call is running. An error for which fatal is true calls abandon before it is returned.

Functions

collect

pub fn collect(run: fn(fn([]sql.Column), fn([]sql.Column, []sql.Value) -> bool) ! sql.Error) -> sql.Rows ! sql.Error

Runs run with a column callback and a row callback that buffer the result, and returns it.

A second column callback call, as for a later result set, discards the rows buffered so far.

dial

pub fn dial(o: sql.Options, d: sql.Dialect) -> net.Conn ! sql.Error

Opens a TCP connection to o.host at the dialect's port within o.timeout.

Fails with sql.Error.Timeout when the dial times out and sql.Error.Connect otherwise.

port_of

pub fn port_of(o: sql.Options, d: sql.Dialect) -> i64

Returns o.port, or the dialect's default port when o.port is 0.

session

Returns a session for a connection that is open and idle.

traced

pub fn traced(raw: sql.ConnectionHandle, scope: str, o: sql.Options) -> sql.ConnectionHandle

Returns raw with every query, each and execute recorded as an OpenTelemetry database call under scope, tagged with the database o.database, the server o.host and the server's port, which port_of resolves.

Every driver applies it once to the handle it returns, so a connection from any driver is traced the same way.
