std/rand

#crypto

import std/rand

A seedable, non-cryptographic xoshiro256** generator: seeded, rng (all 256 bits of state from std/crypto), next, unbiased below and between, float, chance, shuffle and pick. pcg32, pcg64 and chacha (seeded from 32 bytes; chacha_rng seeds from entropy) produce an Rng that every function accepts, and next32 draws 32 bits. Distributions: normal, exponential, gamma, beta, poisson, binomial, geometric, zipf, weighted_pick, cumulative with pick_cumulative, sample and permutation. Use std/crypto for secrets.

Imports std/bits, std/crypto, std/math.

Rng

pub struct Rng {
    ...
}

A pseudo-random number generator.

Made by rng and seeded (xoshiro256**), pcg32 and pcg64 (PCG), or chacha and chacha_rng (ChaCha20). Every function that draws numbers takes it as mut, so the state advances in place. A copy of an Rng continues the same sequence independently of the original.

Only the ChaCha generators are suitable for secrets; the others are statistical generators whose output can be predicted from a few values.

below

pub fn below(mut r: Rng, n: i64) -> i64

Returns a uniformly distributed integer in 0..n, that is 0 up to and including n - 1.

Panics when n is not positive.

beta

pub fn beta(mut r: Rng, a: f64, b: f64) -> f64

Returns a beta distributed f64 in [0, 1] with shape parameters a and b.

Computed as x / (x + y) for two gamma draws. Panics when a or b is not positive.

between

pub fn between(mut r: Rng, lo: i64, hi: i64) -> i64

Returns a uniformly distributed integer from lo to hi, both inclusive.

Panics when hi is less than lo.

binomial

pub fn binomial(mut r: Rng, n: i64, p: f64) -> i64

Returns the number of successes in n independent trials that each succeed with probability p.

The result is in 0..=n. Uses sequential inversion when n times the smaller of p and 1 - p is below 10.0, and the BTRS transformed rejection method (Hormann) otherwise. Panics when n is negative or p is outside [0, 1].

chance

pub fn chance(mut r: Rng, p: f64) -> bool

Returns true with probability p.

A p of 0.0 or less is never true and a p of 1.0 or more is always true.

exponential

pub fn exponential(mut r: Rng, rate: f64) -> f64

Returns an exponentially distributed f64 with the given rate, so the mean is 1 / rate.

Uses inversion. Panics when rate is not positive.

float

pub fn float(mut r: Rng) -> f64

Returns a uniformly distributed f64 in [0, 1).

The value has 53 bits of precision: it is next shifted right by 11 and divided by 2^53.

gamma

pub fn gamma(mut r: Rng, shape: f64, scale: f64) -> f64

Returns a gamma distributed f64 with the given shape and scale.

Uses the Marsaglia and Tsang method; a shape below 1.0 is boosted by one and corrected with a power of a uniform draw. The mean is shape * scale. Panics when shape or scale is not positive.

geometric

pub fn geometric(mut r: Rng, p: f64) -> i64

Returns the number of trials up to and including the first success when each trial succeeds with probability p.

The result is at least 1, and is always 1 when p is 1.0. Panics when p is not in (0, 1].

next

pub fn next(mut r: Rng) -> u64

Returns the next 64 random bits from r.

All other draws are derived from this function, except that a pcg32 generator builds each value from two 32-bit outputs.

next32

pub fn next32(mut r: Rng) -> u32

Returns the next 32 random bits from r.

A pcg32 generator returns one native output; the other generators return the high 32 bits of next.

normal

pub fn normal(mut r: Rng, mean: f64, sd: f64) -> f64

Returns a normally distributed f64 with the given mean and standard deviation sd.

Uses the Marsaglia polar method, which produces values in pairs; the second value is kept in the generator for the next call.

permutation

pub fn permutation(mut r: Rng, n: i64) -> []i64

Returns the integers 0 up to n - 1 in a random order.

Every permutation is equally likely. Returns an empty slice for n of 0. Panics when n is negative.

pick

pub fn pick[T](mut r: Rng, xs: []T) -> T?

Returns a uniformly chosen element of xs, or none when xs is empty.

The slice is not modified.

pick_cumulative

pub fn pick_cumulative(mut r: Rng, cumulative_weights: []f64) -> i64?

Returns the index drawn with probability proportional to its weight, given the running sums from cumulative, or none when the slice is empty or its total is not positive.

Finds the index by binary search, so each draw takes O(log n) time. An index whose weight is 0 is never returned.

poisson

pub fn poisson(mut r: Rng, lambda: f64) -> i64

Returns a Poisson distributed count with mean lambda.

Returns 0 for a lambda of 0.0. Uses Knuth's multiplication method below 10.0 and the PTRS transformed rejection method (Hormann) from there. Panics when lambda is negative.

sample

pub fn sample(mut r: Rng, n: i64, k: i64) -> []i64

Returns k distinct integers from 0..n in a random order.

Uses Floyd's algorithm, so it does not allocate an n-sized slice. Panics unless 0 <= k <= n.

shuffle

pub fn shuffle[T](mut r: Rng, mut xs: []T)

Shuffles xs in place with the Fisher-Yates algorithm, so that every permutation is equally likely.

An empty or one-element slice is left unchanged.

weighted_pick

pub fn weighted_pick(mut r: Rng, weights: []f64) -> i64?

Returns an index drawn with probability proportional to its entry in weights, or none when weights is empty or sums to zero or less.

Builds the running sums on every call; use cumulative and pick_cumulative for repeated draws.

zipf

pub fn zipf(mut r: Rng, n: i64, s: f64) -> i64

Returns a Zipf distributed rank in 1..=n where rank k has probability proportional to k raised to the power -s.

Uses rejection-inversion sampling (Hormann and Derflinger), so it takes constant time for any n. Returns 1 when n is 1. Panics when n is less than 1 or s is not positive.

Functions

chacha

pub fn chacha(seed: []u8) -> Rng ! Error

Returns a ChaCha20 generator (RFC 8439 block function, 20 rounds) keyed by the 32-byte seed.

The output is the keystream of the key with an all-zero nonce and a 64-bit block counter starting at 0, consumed as little-endian 64-bit words. Fails with BadSeed when seed is not exactly 32 bytes. The same seed always produces the same sequence.

chacha_rng

pub fn chacha_rng() -> Rng

Returns a ChaCha20 generator keyed with 32 bytes from crypto.random.

The sequence differs on every call. This is the generator to use when the output must be unpredictable.

cumulative

pub fn cumulative(weights: []f64) -> []f64

Returns the running sums of weights.

The result has the same length as weights. Pass it to pick_cumulative to draw many times from the same weights without recomputing it. An empty input gives an empty result.

pcg32

pub fn pcg32(seed: u64, stream: u64) -> Rng

Returns a PCG-XSH-RR 32-bit generator with a 64-bit state, started from seed on the sequence selected by stream.

Generators with different stream values produce independent sequences from the same seed. next32 returns one native 32-bit output and next joins two of them.

pcg64

pub fn pcg64(seed: u64, stream: u64) -> Rng

Returns a PCG-XSL-RR 128-bit generator (pcg64) with a 128-bit state, started from seed on the sequence selected by stream.

Generators with different stream values produce independent sequences from the same seed. The seed is added to the low 64 bits of the 128-bit state and the stream selects the odd 128-bit increment stream << 1 | 1. next returns one native 64-bit output.

rng

pub fn rng() -> Rng

Returns a xoshiro256** generator seeded with 32 bytes from crypto.random.

The sequence differs on every call. The generator itself is not cryptographically secure; use chacha_rng for that. When the entropy is an all-zero state, which xoshiro cannot leave, the state comes from seeded instead.

seeded

pub fn seeded(seed: u64) -> Rng

Returns a xoshiro256** generator whose 256-bit state is expanded from seed with SplitMix64.

The same seed always produces the same sequence, on every platform. Every u64 is a valid seed, including 0.
