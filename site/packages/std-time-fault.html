Types

Fault

pub enum Fault {
    /// A value for `what` is outside the range the type can hold, such as month 13 or a timestamp after year 9999.
    OutOfRange(str)
    /// A value for `what` is in range but not valid in context, such as day 30 of February or a rounding unit that is not positive.
    Invalid(str)
    /// The text does not match the expected format. `at` is the byte offset where it stopped matching.
    Syntax(i64)
    /// The result cannot be represented.
    Overflow
    /// No time zone is named `name`.
    UnknownZone(str)
    /// Zone data or a zone file is corrupt or unreadable. `what` names the part that is bad.
    Malformed(str)
    /// The input is well formed but names a feature that is not supported, such as a calendar other than ISO 8601 or a locale format verb. `what` names it.
    Unsupported(str)
    /// The local time falls in a gap that a zone transition skips, so it does not exist in the zone, and the disambiguation asked for a failure.
    Skipped
    /// The local time occurs twice in the zone because a transition repeats it, and the disambiguation asked for a failure.
    Ambiguous
    /// The offset given with a local time does not match any offset the zone has at that time.
    OffsetConflict
}

The error type returned by every fallible function in the time modules.

to_string renders a fault as a message.

to_string

pub fn to_string(f: Fault) -> str

Returns the message for f, such as syntax error at byte 5 or unknown time zone Mars/Base.
