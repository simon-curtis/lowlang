std/ui/islands

#ui

import std/ui/islands

The Islands design language over std/ui: schemes, a Theme, colour and size tokens, stroke icons, controls, a context menu, a search picker, a confirm dialog, slides, avatars, a glow and grain backdrop, scrollbar geometry, code typefaces and a whole tool window. It computes, so it runs on both targets with no library.

Imports std/bits, std/image, std/text, std/ui, std/ui/font, std/ui/geometry, std/ui/platform, std/ui/scene, std/ui/svg, std/unicode.

context_menu

pub fn context_menu(m: Menu) -> ui.Element

Returns the layer that draws m: a popover anchored at the point the menu was shown at, above everything else and taking the pointer from what is under it, or nothing while the menu is hidden.

Up and Down move the selection, wrapping at the ends, Enter chooses the selected line, and any other key dismisses the menu. So does a press outside it. Choosing a line dismisses the menu and then runs its action.

A vertical and a horizontal scrollbar, which are laid out from their tracks, the scroll offset and how far the content can scroll, and answer where the pointer is and where a drag scrolls to. Everything is in logical pixels.

Returns scroll with the offset along the dragged bar set to where the pointer at position puts the thumb, between 0 and the most the content can scroll. The other direction is left as it was.

grab

pub fn grab(s: Scrollbars, position: geometry.Point) -> Grab?

Returns the grab a press at position makes on the bar that is near it, or none. Pressing the thumb keeps the pointer where it is on the thumb; pressing the track beside it takes the thumb's middle.

Returns the bar whose track, or the six pixels of reach beside it, holds position, if any and it has something to scroll. The vertical bar is tried first.

Returns the quads that draw the thumbs of the bars that have something to scroll, the one along hot drawn brighter and wider.

Slide

    ...
}

A value that eases toward a target, such as how far a panel is open from 0.0 to 1.0.

A slide takes 500 milliseconds to open from 0 to 1, 300 to close from 1 to 0, and a share of that for a shorter way.

set_slide

pub fn set_slide(mut s: Slide, target: f32, now_ms: i64)

Starts s toward target at now_ms milliseconds on the caller's clock. A slide already headed there is left as it is.

tick

pub fn tick(mut s: Slide, still: bool, now_ms: i64) -> bool

Moves s to where it is at now_ms, or to its target when still is true, and returns whether it is still moving.

confirm_dialog

pub fn confirm_dialog(th: Theme, title: str, detail: str, verb: str, confirmed: fn(), dismissed: fn()) -> ui.Element

Returns a dialog centred over a scrim that covers its parent, which should be relative.

The dialog shows title, detail in the code font of th in a box that holds at most 240 pixels of it, and a Cancel button beside a button labelled verb. Escape and Cancel call dismissed; Enter and the verb button call confirmed. The keys go on to the elements outside the dialog as well, so a program that binds them there should check that the dialog is closed.

picker

pub fn picker(th: Theme, p: Picker, chosen: fn(str), dismissed: fn()) -> ui.Element

Returns the search box and the choices that match it, in a popover for the caller to place.

Typing narrows the choices, and the selection goes to the current choice if it still shows, else the first. Up and Down move it, wrapping at the ends, and keep it in view. Enter or a click calls chosen with the key of a choice, Escape calls dismissed, and so does a press outside the popover. The accent of th marks the current choice.

tool_window

pub fn tool_window(th: Theme, cx: ui.Context, b: Backdrop, title: str, mark: ui.Element, content: ui.Element) -> ui.Element

Returns a whole window: the glow of th's scheme behind a title bar and a card that holds content, with the grain over all of it.

The title bar is title_height tall. It holds mark, normally made by brand, then an area that moves the window and, when the program draws the window's decorations, the caption buttons. title is centred in the bar in muted text, kept clear of the buttons. The card sits 8 pixels in from the window's edges below the bar, and content grows to fill it.

Returns the theme of the scheme named scheme_name, the code face named code_face and the code size code_size. A name or size that is not one of schemes, code_faces or code_sizes takes pink, jetbrains or 13.

title_height

pub fn title_height() -> f32

Returns the height of a window's title bar: 40 pixels.

tool_button

pub fn tool_button(name: str, icon: svg.Icon, icon_colour: geometry.Color, label: str, tip: str, clicked: fn(ui.ClickEvent)) -> ui.Element

Returns a button of icon in icon_colour and label, with the tooltip tip.

tool_icon

pub fn tool_icon(name: str, icon: svg.Icon, colour: geometry.Color, tip: str, clicked: fn(ui.ClickEvent)) -> ui.Element

Returns a square button of icon in colour with the tooltip tip.

ui_font

pub fn ui_font() -> str

Returns the families of interface text: Segoe UI Variable Text, then the system's sans-serif.

unavailable

pub fn unavailable(b: ui.Element) -> ui.Element

Returns b, a button, drawn as one that cannot be used.

warn

pub fn warn() -> geometry.Color

Returns the colour of warnings.

whitespace

pub fn whitespace() -> geometry.Color

Returns the colour of drawn whitespace.

window_close_icon

pub fn window_close_icon() -> svg.Icon

Returns a cross, for the button that closes a window.

window_maximize_icon

pub fn window_maximize_icon() -> svg.Icon

Returns a square, for the button that maximizes a window.

window_minimize_icon

pub fn window_minimize_icon() -> svg.Icon

Returns a line along the bottom of a window, for the button that minimizes it.

window_restore_icon

pub fn window_restore_icon() -> svg.Icon

Returns a square in front of the corner of another, for the button that restores a maximized window.
