std/uri

#net #web

import std/uri

RFC 3986 percent coding and references. escape leaves the unreserved bytes, escape_form writes a space as +, escape_target encodes only the bytes a request target cannot hold and keeps existing escapes, and escape_where takes the set to keep. unescape returns str? and is none on a bad escape; unescape_lossy leaves a bad escape in place and unescape_form_lossy also reads + as a space. encode_form writes a list of Fields as application/x-www-form-urlencoded, and parse_query reads one into a [str: str] where the last value of a name wins. scheme_end, without_fragment, remove_dots and resolve follow RFC 3986 section 5, working on strings.

Imports std/text.

links

import std/uri

/// Resolves the links found on a page against the page's address, the way a crawler normalises them.
fn main() {
    let page = "https://example.com/docs/guide/intro.html?lang=en#top"
    let links = [
        "chapter2.html",
        "../api/index.html",
        "./images/../logo.png",
        "/about",
        "//cdn.example.org/lib.js",
        "?lang=fr",
        "#faq",
        "",
        "mailto:team@example.com",
        "../../../../outside",
    ]
    for link in links {
        print("{link,-26}{uri.resolve(page, link)}")
    }

    print(uri.resolve("/a/b?c=1", "d"))
    print(uri.remove_dots("/a/./b/../c/."))
    print(uri.without_fragment(page))
    for target in ["https://example.com", "mailto:a@b", "/relative/path", "1http://x", "://x"] {
        print("{target,-22}scheme ends at {uri.scheme_end(target)}")
    }
}

query

import std/uri

/// Builds a search request from user input, then decodes a query string and percent-encoded text.
fn main() {
    let term = "café & bar/grill"
    let page = "2"
    let target = "/search/{uri.escape(term)}?q={uri.escape_form(term)}&page={page}"
    print(target)

    let body = uri.encode_form([
        uri.Field { name: "user name", value: "ada lovelace" },
        uri.Field { name: "note", value: "a=b&c=d" },
        uri.Field { name: "empty", value: "" },
    ])
    print(body)

    let query = uri.parse_query("q=low+lang&tag=a&tag=b&flag&&name=%E2%82%AC5")
    for key in ["q", "tag", "flag", "name", "missing"] {
        print("{key} = [{query[key] ?? "<none>"}]")
    }

    print(uri.unescape("a%20b%2Fc") ?? "invalid")
    print(uri.unescape("100%") ?? "invalid")
    print(uri.unescape_lossy("100%+a%41"))
    print(uri.unescape_form_lossy("100%+a%41"))
    print(uri.escape_target("/files/my report.pdf?v=1&x=\"q\""))
}

Types

Field

pub struct Field {The name, before encoding.    pub name: strThe value, before encoding.    pub value: str
}

A name and value pair of a query string or of an application/x-www-form-urlencoded body.

Functions

encode_form

pub fn encode_form(fields: []Field) -> str

Returns fields as an application/x-www-form-urlencoded body: name=value pairs joined by &.

Names and values are encoded with escape_form. Returns an empty string for no fields.

escape

pub fn escape(s: str) -> str

Returns s percent-encoded, keeping only the unreserved bytes A-Z, a-z, 0-9, -, ., _ and ~.

Every other byte becomes % and two uppercase hexadecimal digits, so a space is %20. Use it for one path segment, one query name or one query value.

escape_form

pub fn escape_form(s: str) -> str

Returns s encoded as one name or value of an application/x-www-form-urlencoded body.

As escape, except that a space becomes +.

escape_target

pub fn escape_target(s: str) -> str

Returns s with the bytes that are not allowed in a request target percent-encoded, as decided by target_byte.

Existing % escapes and reserved delimiters are left as they are.

escape_where

pub fn escape_where(s: str, keep: fn(u8) -> bool) -> str

Returns s with every byte for which keep returns false replaced by % and two uppercase hexadecimal digits.

Returns s itself when every byte is kept.

parse_query

pub fn parse_query(query: str) -> [str: str]

Parses a query string, or an application/x-www-form-urlencoded body, into a map of names to values.

Names and values are decoded with unescape_form_lossy. Empty pairs are skipped, a name without = maps to an empty string, and a repeated name keeps its last value.

remove_dots

pub fn remove_dots(path: str) -> str

Returns path with its . and .. segments resolved, as in RFC 3986 section 5.2.4.

A .. above the root is dropped. A path that ends in a dot segment ends in /.

resolve

pub fn resolve(base: str, reference: str) -> str

Resolves the URI reference reference against base and returns the target URI, following RFC 3986 section 5.2.

The fragment of base is dropped and the fragment of reference is kept. A reference with a scheme is returned as it is, and one starting with // takes the scheme of base. An empty reference gives base, one starting with ? replaces the query, one starting with / replaces the path, and any other is joined to the directory of the base path. Dot segments are resolved in the path of the result. base may be only a path and query, such as /a/b?c.

scheme_end

pub fn scheme_end(s: str) -> i64

Returns the index of the : that ends the scheme of s, or -1 when s does not start with a scheme.

A scheme is a letter followed by letters, digits, +, - or ..

target_byte

pub fn target_byte(c: u8) -> bool

Returns whether c may appear unescaped in the path and query of a request target.

Controls, space, DEL and non-ASCII bytes are not allowed, nor are ", <, >, \, ^, `, {, | and }. Reserved delimiters such as /, ?, &, = and % are allowed.

unescape

pub fn unescape(s: str) -> str?

Returns s with each %XX sequence replaced by its byte, or none when a % is not followed by two hexadecimal digits.

A + is left as it is.

unescape_form_lossy

pub fn unescape_form_lossy(s: str) -> str

Returns s with each %XX sequence replaced by its byte and each + by a space.

A % that is not followed by two hexadecimal digits is kept as written. Use it for query names and values and form bodies.

unescape_lossy

pub fn unescape_lossy(s: str) -> str

Returns s with each %XX sequence replaced by its byte.

A % that is not followed by two hexadecimal digits and a + are kept as written. Use it for path segments.

unreserved

pub fn unreserved(c: u8) -> bool

Returns whether c is an unreserved byte of RFC 3986: A-Z, a-z, 0-9, -, ., _ or ~.

without_fragment

pub fn without_fragment(s: str) -> str

Returns s without its fragment: everything from the first #.
