std/crypto/hash

#crypto

import std/crypto/hash

Algorithm and cloneable Digest, SHA-1, SHA-256, SHA-384 and SHA-512, HMAC (hmac, and hmac_keyed for the keyed inner and outer digests that PBKDF2 clones), HKDF and constant-time equal.

Imports std/bits, std/io.

Examples

mac_and_kdf

import std/crypto/hash
import std/text

/// Streams and forks a SHA-256 digest, authenticates a message with HMAC and compares tags in constant time, then derives two keys with HKDF (RFC 4231 and RFC 5869 vectors).
fn main() {
    let sha256 = hash.sha256()

    let d = sha256.digest()
    d.update(bytes("a"))
    let fork = d.clone()
    d.update(bytes("bc"))
    fork.update(bytes("bd"))
    print("abc  {text.encode_hex(d.finish())}")
    print("abd  {text.encode_hex(fork.finish())}")
    print("one shot matches: {hash.equal(d.finish(), hash.sum(sha256, bytes("abc")))}")

    let tag = hash.hmac(sha256, bytes("Jefe"), bytes("what do ya want for nothing?"))
    print("hmac {text.encode_hex(tag)}")
    let forged = hash.hmac(sha256, bytes("Jefe"), bytes("what do ya want for something?"))
    print("tag accepted: {hash.equal(tag, hash.hmac(sha256, bytes("Jefe"), bytes("what do ya want for nothing?")))}")
    print("forged accepted: {hash.equal(tag, forged)}")

    let ikm: []u8 = [0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b, 0x0b]
    let salt: []u8 = [0x00, 0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08, 0x09, 0x0a, 0x0b, 0x0c]
    let info: []u8 = [0xf0, 0xf1, 0xf2, 0xf3, 0xf4, 0xf5, 0xf6, 0xf7, 0xf8, 0xf9]
    let prk = hash.hkdf_extract(sha256, salt, ikm)
    let okm = hash.hkdf_expand(sha256, prk, info, 42)
    print("prk  {text.encode_hex(prk)}")
    print("okm  {text.encode_hex(okm)}")
    let client_key = hash.hkdf_expand(sha256, prk, bytes("client"), 16)
    let server_key = hash.hkdf_expand(sha256, prk, bytes("server"), 16)
    print("keys differ: {!hash.equal(client_key, server_key)}")
}

A hash function: its name, sizes and a constructor for running computations.

hkdf_expand

pub fn hkdf_expand(a: Algorithm, prk: []u8, info: []u8, length: i64) -> []u8

Computes HKDF-Expand (RFC 5869 section 2.3) from the pseudorandom key prk and context info.

Returns length bytes. length must not exceed 255 * a.size because the block counter is one byte; this is not checked. A length of 0 or less returns an empty slice.

hkdf_extract

pub fn hkdf_extract(a: Algorithm, salt: []u8, ikm: []u8) -> []u8

Computes HKDF-Extract (RFC 5869 section 2.2) over the input keying material ikm.

Returns the a.size-byte pseudorandom key. An empty salt is replaced by a.size zero bytes.

hmac

pub fn hmac(a: Algorithm, key: []u8, message: []u8) -> []u8

Computes the HMAC of message under key with the hash a (RFC 2104, FIPS 198-1).

Returns a.size bytes. A key longer than a.block is hashed first and a shorter one is padded with zeros. Any key length is accepted, including empty.

hmac_keyed

pub fn hmac_keyed(a: Algorithm, key: []u8) -> Keyed

Returns the keyed inner and outer digests of the HMAC of key with the hash a.

A key longer than a.block is hashed first and a shorter one is padded with zeros. Any key length is accepted, including empty. Clone the digests to compute several MACs under one key.

sum

pub fn sum(a: Algorithm, data: []u8) -> []u8

Returns the digest of data under the algorithm a, a.size bytes long.

Functions

equal

pub fn equal(a: []u8, b: []u8) -> bool

Returns whether a and b hold the same bytes.

Slices of different lengths are unequal and return at once. For equal lengths the running time does not depend on the contents, so the call is suitable for comparing MACs and tags.

sha1

pub fn sha1() -> Algorithm

Returns the Algorithm for SHA-1 (FIPS 180-4).

The name is sha1, the digest is 20 bytes and the block size is 64 bytes. SHA-1 is not collision resistant; use it only where a protocol requires it, such as HMAC-SHA-1 or the WebSocket handshake.

sha256

pub fn sha256() -> Algorithm

Returns the Algorithm for SHA-256 (FIPS 180-4). The name is sha256, the digest is 32 bytes and the block size is 64 bytes.

sha384

pub fn sha384() -> Algorithm

Returns the Algorithm for SHA-384 (FIPS 180-4). The name is sha384, the digest is 48 bytes and the block size is 128 bytes.
