hkdf_expand

pub fn hkdf_expand(a: Algorithm, prk: []u8, info: []u8, length: i64) -> []u8

Computes HKDF-Expand (RFC 5869 section 2.3) from the pseudorandom key prk and context info.

Returns length bytes. length must not exceed 255 * a.size because the block counter is one byte; this is not checked. A length of 0 or less returns an empty slice.

hkdf_extract

pub fn hkdf_extract(a: Algorithm, salt: []u8, ikm: []u8) -> []u8

Computes HKDF-Extract (RFC 5869 section 2.2) over the input keying material ikm.

Returns the a.size-byte pseudorandom key. An empty salt is replaced by a.size zero bytes.

hmac

pub fn hmac(a: Algorithm, key: []u8, message: []u8) -> []u8

Computes the HMAC of message under key with the hash a (RFC 2104, FIPS 198-1).

Returns a.size bytes. A key longer than a.block is hashed first and a shorter one is padded with zeros. Any key length is accepted, including empty.

sum

pub fn sum(a: Algorithm, data: []u8) -> []u8

Returns the digest of data under the algorithm a, a.size bytes long.

equal

pub fn equal(a: []u8, b: []u8) -> bool

Returns whether a and b hold the same bytes.

Slices of different lengths are unequal and return at once. For equal lengths the running time does not depend on the contents, so the call is suitable for comparing MACs and tags.

sha256

pub fn sha256() -> Algorithm

Returns the Algorithm for SHA-256 (FIPS 180-4). The name is sha256, the digest is 32 bytes and the block size is 64 bytes.

sha384

pub fn sha384() -> Algorithm

Returns the Algorithm for SHA-384 (FIPS 180-4). The name is sha384, the digest is 48 bytes and the block size is 128 bytes.

sha512

pub fn sha512() -> Algorithm

Returns the Algorithm for SHA-512 (FIPS 180-4). The name is sha512, the digest is 64 bytes and the block size is 128 bytes.
