std/time/humanize

#time

import std/time/humanize

ago, relative, in_words, compact and round_to over a Words value; English by default.

Imports std/text, std/time/duration, std/time/fault, std/time/rounding, std/time/timestamp.

Examples

activity_feed

import std/time/duration
import std/time/fault
import std/time/humanize
import std/time/timestamp

struct Event {
    who: str
    what: str
    at: str
}

fn spanish() -> humanize.Words {
    humanize.Words {
        just_now: "ahora mismo",
        under_second: "menos de un segundo",
        past: "hace %s",
        future: "en %s",
        about: "unos %s",
        quantity: "%d %s",
        singular: ["segundo", "minuto", "hora", "día", "mes", "año"],
        plural: ["segundos", "minutos", "horas", "días", "meses", "años"],
        short: ["s", "min", "h", "d", "m", "a"]
    }
}

/// Prints an activity feed with relative times, a compact column, an approximate length and a Spanish rendering.
fn main() ! fault.Fault {
    let now = timestamp.parse("2026-11-13T12:00:00Z")?
    let events = [
        Event { who: "ada", what: "pushed 3 commits", at: "2026-11-13T11:59:58Z" },
        Event { who: "grace", what: "opened a review", at: "2026-11-13T11:41:00Z" },
        Event { who: "linus", what: "merged a branch", at: "2026-11-13T07:15:00Z" },
        Event { who: "ken", what: "tagged a release", at: "2026-11-06T12:00:00Z" },
        Event { who: "dennis", what: "closed an issue", at: "2025-11-01T12:00:00Z" },
        Event { who: "rob", what: "scheduled a deploy", at: "2026-11-15T14:00:00Z" }
    ]
    for event in events {
        let at = timestamp.parse(event.at)?
        let age = timestamp.since(now, at)
        print("{humanize.relative(at, now)} | {humanize.compact(age)} | {event.who} {event.what}")
    }

    let build = duration.parse("PT1H29M")?
    print("build took {humanize.in_words(build)}")
    print("build took {humanize.in_words(duration.minutes(90))}")
    print("a blink took {humanize.in_words(duration.milliseconds(40))}")
    print("rounded to two units: {duration.friendly(humanize.round_to(duration.parse("PT3H29M41S")?, 2)?)}")

    let grace = timestamp.parse("2026-11-13T11:41:00Z")?
    print("en español: {humanize.relative_with(grace, now, spanish())?}, {humanize.in_words_with(duration.minutes(149), spanish())?}")
    print("compact: {humanize.compact_with(duration.hours(72), spanish())?}")
}

4 hours ago | 4h | linus merged a branch
7 days ago | 7d | ken tagged a release
1 year ago | 1y | dennis closed an issue
in 2 days | -2d | rob scheduled a deploy

build took about 2 hours

Types

Words

pub struct Words {The text for an elapsed time under five seconds.    pub just_now: strThe text for in_words of a nonzero duration under one second.    pub under_second: strThe template for a time in the past, with the quantity at %s.    pub past: strThe template for a time in the future, with the quantity at %s.    pub future: strThe template that marks a quantity as approximate, with the quantity at %s.    pub about: strThe template that joins a count and a unit name, with the count at %d and the name at %s.    pub quantity: strThe unit names used for a count of exactly one, from second to year.    pub singular: []strThe unit names used for any other count, from second to year.    pub plural: []strThe abbreviated unit names that compact uses, from second to year.    pub short: []str
}

The wording that ago, in_words and compact use, so that a program can print another language.

A template marks where its text goes with %s, and quantity also uses %d for the count. The unit lists have six entries in order: second, minute, hour, day, month and year. A month counts as 30 days and a year as 365 days. The _with functions fail with Invalid when a unit list does not have six entries.

Functions

ago

pub fn ago(d: duration.Duration) -> str

Returns how long ago d was in English, such as 3 hours ago.

d is the time elapsed since the event. It is counted in its largest whole unit, rounded down, so 90 minutes reads 1 hour ago. Under five seconds the result is just now. A negative d reads as a future time, such as in 2 days.

ago_with

pub fn ago_with(d: duration.Duration, w: Words) -> str ! fault.Fault

Returns how long ago d was, worded by w.

Fails with Invalid when w does not have six names in each unit list. Otherwise it is ago with different words.

compact

pub fn compact(d: duration.Duration) -> str

Returns d as a single count in its largest whole unit, such as 5m or -3d.

The count is rounded down, a negative duration has a leading -, and a duration under one second is 0s.

compact_with

pub fn compact_with(d: duration.Duration, w: Words) -> str ! fault.Fault

Returns d as a single count in its largest whole unit, using the short names of w.

Fails as ago_with does.

english

pub fn english() -> Words

Returns the English Words: just now, less than a second, %s ago, in %s, about %s, %d %s, and the names second to year, with s, m, h, d, mo and y as the short forms.

in_words

pub fn in_words(d: duration.Duration) -> str

Returns an approximate English description of the length of d, such as about 2 hours or 3 days.

The sign is ignored. The duration is rounded to the nearest whole unit of the largest unit that fits, and the result is prefixed about unless it is exact. A nonzero duration under one second is less than a second and zero is 0 seconds.

in_words_with

pub fn in_words_with(d: duration.Duration, w: Words) -> str ! fault.Fault

Returns an approximate description of the length of d, worded by w.

Fails as ago_with does.

relative

pub fn relative(ts: timestamp.Timestamp, now: timestamp.Timestamp) -> str

Returns when ts is compared with now in English, such as 2 days ago or in 3 hours.

It is ago of the time from ts to now, so a ts before now reads as the past.

relative_with

pub fn relative_with(ts: timestamp.Timestamp, now: timestamp.Timestamp, w: Words) -> str ! fault.Fault

Returns when ts is compared with now, worded by w.

Fails as ago_with does.

round_to

pub fn round_to(d: duration.Duration, units: i64) -> duration.Duration ! fault.Fault

Returns d rounded to its units most significant units.

The units are years, 30-day months, days, hours, minutes, seconds, milliseconds, microseconds and nanoseconds, so 1h 30m 20s rounded to two units is 1h 30m and to one unit is 2h. A half rounds away from zero. Fails with Invalid when units is below 1 and with OutOfRange or Overflow where duration.round does. More units than the ladder has keep full precision.
