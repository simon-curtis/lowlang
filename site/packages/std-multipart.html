std/multipart

#web

import std/multipart

multipart parsing and writing (RFC 7578, RFC 2046): a streaming Reader with limits and a spill sink for large parts, RFC 2231 and 5987 parameters, Writer (write_field, write_file and write_form_part) and Form; std/http reads and writes them with multipart_reader, multipart_form, set_multipart and with_multipart.

Imports std/crypto, std/header, std/io, std/text.

Examples

upload

import std/header
import std/http
import std/io
import std/multipart
import std/net
import std/text

fn upload(req: http.Request) -> http.Response {
    let content_type = header.get(req.headers, "content-type") ?? ""
    let boundary = multipart.boundary_from_content_type(content_type) or return http.response(400, "not multipart")
    let r = multipart.bytes_reader(req.body, boundary, multipart.Limits { max_memory: 1024 }) or return http.response(400, "bad boundary")
    let form = multipart.read_form(r, none) or return http.response(422, "unreadable form")
    var lines: []str = ["title: {multipart.value(form, "title") ?? "-"}"]
    for tag in multipart.values(form, "tag") {
        push(mut lines, "tag: {tag}")
    }
    for f in form.files {
        push(mut lines, "file {f.name}: {f.filename} {f.content_type} {f.size} bytes")
    }
    http.response(200, text.join(lines, "\n"))
}

/// Uploads a form with fields and a file to a loopback server that reads it with a multipart reader.
fn main() ! io.Error {
    using l = net.listen("127.0.0.1", 0)?
    let listening = l.handle
    spawn fn() { http.serve_on(listening, upload) or {} }()

    let form = multipart.writer()
    multipart.write_field(form, "title", "Quarterly report") or return
    multipart.write_field(form, "tag", "finance") or return
    multipart.write_field(form, "tag", "2025") or return
    multipart.write_file(form, "attachment", "report.csv", "text/csv", bytes("quarter,total\nQ3,120\n")) or return
    let body = multipart.finish(form)

    let client = http.client().with_base_url("http://127.0.0.1:{l.handle.addr.port}").with_timeout(5000).build()
    let resp = client.post("/upload", multipart.content_type(form), body) or return
    print("{resp.status}")
    print(http.text(resp))

    let wrong = client.post("/upload", "text/plain", bytes("plain")) or return
    print("{wrong.status} {http.text(wrong)}")
    net.close_listener(l)
}

Reader

pub struct Reader {
    ...
}

Reads a multipart body one part at a time.

Made by reader or bytes_reader. Call next_part to reach a part, then read or a helper for its content. It does not read from the source until it is used.

next_part

pub fn next_part(r: *Reader) -> Part? ! Error

Moves to the next part and returns its headers, or none after the closing boundary.

Content of the current part that was not read is skipped. Fails with Malformed, Truncated, TooManyParts, HeaderTooLarge, TooLarge or Io. Once it has returned none it keeps doing so.

read

pub fn read(r: *Reader, dst: []u8) -> i64 ! Error

Reads content of the current part into dst and returns the number of bytes.

Returns 0 at the end of the part, when no part is open, or when dst is empty. Fails with Truncated when the body ends inside the part, with TooLarge when it exceeds Limits.max_total_bytes, and with Io when the source fails.

read_bytes

pub fn read_bytes(r: *Reader) -> []u8 ! Error

Reads the rest of the current part into memory.

Fails with TooLarge when it is longer than Limits.max_memory, and with the errors of read.

read_form

pub fn read_form(r: *Reader, spill: Spill?) -> Form ! Error

Reads the remaining parts of the body into a Form.

Parts that are not form-data or have no name are skipped. A part with a filename is a file, and any other part is a field. Without spill, a file or field larger than Limits.max_memory fails with TooLarge. With spill, a file larger than that is passed to it. Fails with the errors of next_part and read, and with Io when a Spill function fails.

read_spill

pub fn read_spill(r: *Reader, sink: fn([]u8) ! io.Error) -> Body ! Error

Reads the rest of the current part, passing it to sink once it is longer than Limits.max_memory.

Shorter content is returned in Body.data. Longer content is passed to sink in chunks starting with everything read so far, and the body returns empty with spilled set. Fails with Io when sink fails, and with the errors of read.

read_text

pub fn read_text(r: *Reader) -> str ! Error

Reads the rest of the current part as text.

The bytes are not checked for UTF-8. Fails like read_bytes.

finish

pub fn finish(w: *Writer) -> []u8

Ends the body with the closing boundary and returns it.

It is safe to call again, and returns the same bytes. Adding a part afterwards fails with Finished.

write_field

write_file

Adds a form-data file field with a filename and content_type, which defaults to application/octet-stream when empty.

Fails like write_part.

write_form_part

pub fn write_form_part(w: *Writer, name: str, filename: str?, content_type: str, data: []u8) ! Error

Adds a form-data part called name with data, as write_field and write_file do.

A filename of none makes a plain field, which has a Content-Type only when content_type is not empty. A file name makes a file field, whose content_type defaults to application/octet-stream when empty. Fails like write_part.

write_part

pub fn write_part(w: *Writer, headers: []header.Header, data: []u8) ! Error

Adds a part with headers and data.

Fails with Finished after finish, with InvalidHeader for a header that is not valid, and with BoundaryInData when the boundary was chosen and the data contains it. Nothing is added when it fails.

Functions

boundary_from_content_type

pub fn boundary_from_content_type(content_type: str) -> str ! Error

Returns the boundary of a multipart/* content type.

Fails with BadContentType for any other type, and with BadBoundary when the parameter is missing or invalid.

bytes_reader

pub fn bytes_reader(data: []u8, boundary: str, limits: Limits) -> *Reader ! Error

Returns a reader for the multipart body in data. See reader.

check_boundary

pub fn check_boundary(boundary: str) ! Error

Fails with BadBoundary unless boundary is 1 to 70 bytes of letters, digits and '()+_,-./:=? , and does not end in a space.

reader

pub fn reader(source: *io.Reader, boundary: str, limits: Limits) -> *Reader ! Error

Returns a reader for a multipart body read from source and delimited by boundary.

Fails with BadBoundary when the boundary is invalid. Reads from source block until data arrives.

writer

pub fn writer() -> *Writer

Returns a writer with a random 48-character boundary.

The boundary is random, so the data of a part is not searched for it.

writer_with

pub fn writer_with(boundary: str) -> *Writer ! Error

Returns a writer that uses boundary.

Fails with BadBoundary when it is invalid. write_part then fails with BoundaryInData for data that contains the boundary.
