std/sql/pool

#database

import std/sql/pool

A pool of connections made by an opener. open takes a Config (max, max_idle, idle_timeout, max_lifetime, wait_timeout, ping_after, ping, clock). acquire and acquire_until (with a cancel token) park in first-in first-out order while every connection is in use. A droppable Lease returns its connection on release. Also with, discard, prune, stats and shutdown.

Imports std/cancel, std/sql, std/sync, std/text, std/time/clock, std/time/duration.

Examples

shared

import std/sql
import std/sql/pool
import std/sql/sqlite

fn open_connection() -> sql.Connection ! sql.Error {
    sqlite.connect(sql.Options { database: "file:visits?mode=memory&cache=shared" })
}

fn count(h: sql.ConnectionHandle) -> i64 ! sql.Error {
    let rows = h.query("SELECT count(*) FROM visits", [])?
    match rows.rows[0][0] {
        Int(n) => n
        _ => fail sql.Error.Conversion
    }
}

fn show_stats(label: str, p: pool.Pool) {
    let s = pool.stats(p)
    print("{label}: open={s.open} idle={s.idle} in_use={s.in_use} opened={s.opened} acquires={s.acquires}")
}

/// Shares one in-memory database between pooled connections, reuses an idle connection and rolls back a lease dropped inside a transaction.
fn main() ! pool.Error {
    let p = pool.open(open_connection, pool.Config { max: 2 })

    pool.with(p, fn(h: sql.ConnectionHandle) ! sql.Error {
        h.execute("CREATE TABLE visits (page TEXT NOT NULL)", [])?
        h.execute("INSERT INTO visits (page) VALUES (?)", [Text("/")])?
    })?
    show_stats("after setup", p)

    {
        using lease = pool.acquire(p)?
        let h = pool.conn(lease)
        h.begin() catch Sql
        h.execute("INSERT INTO visits (page) VALUES (?)", [Text("/draft")]) catch Sql
        print("inside the transaction: {count(h) catch Sql}")
    }
    pool.with(p, fn(h: sql.ConnectionHandle) ! sql.Error {
        print("after the lease was dropped: {count(h)?}")
    })?
    show_stats("after rollback", p)

    {
        using first = pool.acquire(p)?
        using second = pool.acquire(p)?
        show_stats("two leases", p)
        let seen = count(pool.conn(first)) catch Sql
        let also = count(pool.conn(second)) catch Sql
        print("rows seen by each lease: {seen} {also}")
    }
    show_stats("both returned", p)

    pool.shutdown(p)
    pool.with(p, fn(h: sql.ConnectionHandle) ! sql.Error {}) catch {
        Closed => print("pool is closed")
        e => fail e
    }
}

Lease

pub struct Lease {The copyable LeaseHandle for the lease.    pub handle: *LeaseHandle
}

A connection leased from a pool, returned to the pool when dropped.

Use conn or connection to run statements on it. Dropping the lease rolls back an open transaction and returns the connection, or closes it when the lease was discarded or a call failed with a connection-level error.

conn

pub fn conn(l: Lease) -> sql.ConnectionHandle

Returns the leased connection as an sql.ConnectionHandle.

Its calls fail with sql.Error.Closed once the lease is released or broken, and calling its close discards the lease instead of closing the connection directly. A call that fails with Connect, Authentication, Closed, Timeout or Protocol, or with a Server error whose code starts with 08 or 57P, marks the connection broken so that the pool closes it on release.

connection

pub fn connection(l: Lease) -> sql.Connection

Returns the leased connection as an sql.Connection whose close does nothing, so that dropping it leaves the connection with the lease.

Its calls behave as those of conn.

discard

pub fn discard(l: Lease)

Marks the connection broken so that the pool closes it instead of reusing it when the lease is released. Statements on the lease then fail with sql.Error.Closed.

release

pub fn release(l: Lease)

Returns the connection to the pool. Releasing a released lease has no effect.

An open transaction is rolled back first, and the connection is closed instead of reused when the rollback fails or the lease was discarded. Dropping the Lease calls it.

Pool

pub struct Pool {
    ...
}

A pool of connections made on demand by an opener.

A Pool is a copyable handle; copies share one pool. It opens a connection when none is idle and max is not reached, and otherwise queues the caller in first-in first-out order. It is safe to use from several green threads.

acquire

pub fn acquire(p: Pool) -> Lease ! Error

Leases a connection, waiting up to Config.wait_timeout when every connection is in use. It is acquire_until with a token that is never cancelled.

acquire_until

pub fn acquire_until(p: Pool, t: *cancel.Token, wait: duration.Duration) -> Lease ! Error

Leases a connection, waiting at most wait for one; a zero wait waits without a time limit.

An idle connection is reused first, failing that a new one is opened while fewer than max are open, and failing that the call queues in first-in first-out order. Idle connections past their limits are closed first, and one idle longer than ping_after is pinged and replaced when the ping fails.

Returns Error.Closed when the pool is shut down, Error.Cancelled when t is cancelled, Error.Timeout when wait runs out and Error.Sql when the opener fails. Dropping the returned Lease returns the connection.

prune

pub fn prune(p: Pool) -> i64

Closes the idle connections that are past max_lifetime or idle_timeout and returns how many it closed. Leased connections are not touched.

shutdown

pub fn shutdown(p: Pool)

Shuts the pool down: closes every idle connection, fails the queued callers with Error.Closed and refuses later calls to acquire.

Blocks the calling green thread until every outstanding lease is returned; each connection returned after the shutdown is closed.

stats

pub fn stats(p: Pool) -> Stats

Returns a snapshot of the pool's sizes and counters.

with

pub fn with(p: Pool, work: fn(sql.ConnectionHandle) ! sql.Error) ! Error

Leases a connection, passes it to work and returns it to the pool when work finishes.

Fails like acquire; an error from work is returned as Error.Sql.

Functions

detach

pub fn detach(mut c: sql.Connection) -> sql.ConnectionHandle

Returns the copyable view of an owned connection and turns the connection's own close into a no-op, so that dropping c no longer closes it. An opener uses it to give a connection to the pool.

open

pub fn open(opener: fn() -> sql.Connection ! sql.Error, config: Config) -> Pool

Returns a pool that calls opener to make connections as callers need them. No connection is opened until the first acquire.

The config is normalized: max below 1 becomes 1 and max_idle below 0 or above max becomes max.
