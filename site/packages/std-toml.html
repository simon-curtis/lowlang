std/toml

#formats

import std/toml

TOML 1.0.0: a table tree, an encoder, and serde binding.

Imports std/base64, std/math, std/serde, std/text, std/time/date, std/unicode.

A TOML date, a time, or both, as the fields of a calendar date and a clock time.

Which fields hold data depends on the Value variant that carries it: LocalDate uses year, month and day, LocalTime uses hour, minute, second and nanosecond, and LocalDateTime and OffsetDateTime use all of them. The other fields are 0. datetime_text formats it as RFC 3339 text.

encode

pub fn encode(t: *Table) -> str

Returns the TOML text for the table t.

Keys that hold plain values are written first, as key = value, then each sub-table as a [table] section and each non-empty array whose elements are all tables as repeated [[array]] sections, all in key order and separated by blank lines. Other arrays are written inline as [1, 2], and tables inside them as { a = 1 }. Keys are bare when they hold only letters, digits, _ and -, and quoted otherwise. Strings are written as basic strings with the escapes \", \\, \n, \t and \r, and other control characters as \u00XX; other characters are written as they are. A float always shows a . or exponent, so it reads back as a float, and NaN is written as nan. Dates and times use datetime_text.

float

pub fn float(t: *Table, path: str) -> f64?

Returns the float at path, or none when the path does not exist or the value is not a float; an integer is not converted. See get for path.

from_table

pub fn from_table[T](t: *Table) -> T ! serde.Error

Converts the table t into a T through std/serde.

A struct is read from the table's keys: unknown keys are skipped, a missing key takes the field's default or none for an optional, and any other missing key fails with Missing. Integers are read from Int, floats from Float or Int, a []u8 from a base64 string, and a str from a string or from a date or time, which becomes its RFC 3339 text. An enum variant is a string, or a table with one key that names the variant. Fails with serde.Error.Mismatch when a value has another type and with Range for a negative integer read as unsigned. In errors, at counts the values consumed so far.

get

pub fn get(t: *Table, path: str) -> Value?

Returns the value at path in t, or none when there is none.

path is a TOML key, with dots for nesting and quotes for a part that contains a dot or other characters outside letters, digits, _ and -, for example server.http or a."b.c". Only tables are entered, never arrays. It returns none for a path that is not a valid key, a missing part, or a part that is not a table.

datetime_text

pub fn datetime_text(v: Value) -> str?

Returns the RFC 3339 text of a date or time value, or none for any other value.

An OffsetDateTime is YYYY-MM-DDTHH:MM:SS followed by Z for a zero offset or +HH:MM or -HH:MM; a LocalDateTime is the same without the offset, a LocalDate is YYYY-MM-DD and a LocalTime is HH:MM:SS. A fraction of a second is written after a . with trailing zeros removed, and left out when it is zero.

parse

pub fn parse(source: str) -> *Table ! Error

Parses the TOML document source into its root table.

The text must be valid UTF-8 and follow TOML 1.0.0, including every restriction on redefining tables and keys through headers, dotted keys, inline tables and arrays of tables. A leading byte order mark is skipped, and \r\n is read as a newline. Keys keep their document order. Values nested deeper than 128 levels are rejected. Fails with Syntax, which carries the line and column of the problem.

serialize

pub fn serialize[T](v: T) -> str ! serde.Error

Returns v as TOML text.

Equivalent to to_table followed by encode; fails like to_table.

to_table

pub fn to_table[T](v: T) -> *Table ! serde.Error

Converts v into a table through std/serde.

v must be a struct or a map, which becomes the table, since TOML documents are tables. A none field is left out. A []u8 becomes a base64 string and a u64 above 9223372036854775807 fails with serde.Error.Range. Fails with Mismatch when v is not a table, or an array holds none. An enum variant without fields is a string and a variant with fields a table with one key, the variant's name.
