std/time/clock

#time

import std/time/clock

Clock, closures for the wall reading, the monotonic reading and a cancellable sleep, with system, fixed and manual. A Manual clock moves with advance and set, and its sleep records the wait in sleeps and advances the clock without waiting, so code that asks for the time and waits is tested without sleeping.

Imports std/cancel, std/time, std/time/duration, std/time/timestamp.

Examples

backoff

import std/time/clock
import std/time/duration
import std/time/timestamp

fn flaky(attempt: i64) -> bool {
    attempt >= 4
}

fn retry(c: clock.Clock, limit: i64) -> i64 {
    var delay = duration.milliseconds(250)
    for attempt in 1..limit + 1 {
        if flaky(attempt) {
            return attempt
        }
        c.sleep(none, delay)
        delay = duration.times(delay, 2)
    }
    0
}

/// Tests a retry loop on a manual clock: the loop never waits, and the clock records what it asked for.
fn main() {
    let start = timestamp.parse("2026-11-13T09:00:00Z") or timestamp.epoch()
    let manual = clock.manual(start)
    let c = clock.clock(manual)
    let began = c.monotonic()

    let attempt = retry(c, 6)
    print("succeeded on attempt {attempt}")

    for pause in clock.sleeps(manual) {
        print("slept {duration.friendly(pause)}")
    }
    print("monotonic elapsed {duration.friendly(clock.elapsed_since(c, began))}")
    print("now {timestamp.to_string(clock.now(c))}")

    clock.set(manual, start)
    print("reset to {timestamp.to_string(clock.now(c))}")

    let frozen = clock.fixed(start)
    print("fixed clock reads {timestamp.to_string(frozen.read())}")
}

A source of the current time made of a wall reading, a monotonic reading and a sleep, which lets code that asks for the time and waits be tested without sleeping.

system reads the operating system, fixed never moves and manual is moved by the caller.

elapsed_since

pub fn elapsed_since(c: Clock, start: duration.Duration) -> duration.Duration

Returns the monotonic time that has passed on c since start.

start is an earlier reading of c.monotonic.

now

pub fn now(c: Clock) -> timestamp.Timestamp

Returns the wall-clock time of c.

Manual

pub struct Manual {
    ...
}

A clock under the caller's control, made by manual and turned into a Clock by clock.

Copies of a Manual and the clocks made from it share one state, so advance and set are seen by all of them.

advance

pub fn advance(m: Manual, d: duration.Duration)

Moves the wall and monotonic readings of m forward by d.

A negative d moves both backwards. Panics with clock: advance overflows when either reading would leave its range, and leaves the clock unchanged.

clock

pub fn clock(m: Manual) -> Clock

Returns a Clock that reads the current state of m.

Its sleep records the duration, then moves m forward by it without waiting. A sleep whose token is already cancelled is recorded and does not move m.

set

pub fn set(m: Manual, ts: timestamp.Timestamp)

Replaces the wall reading of m with ts.

The monotonic reading is unchanged.

sleeps

pub fn sleeps(m: Manual) -> []duration.Duration

Returns the durations passed to the sleeps of the clocks made from m, in the order they were requested.

Zero and negative sleeps are not recorded.

Functions

fixed

pub fn fixed(ts: timestamp.Timestamp) -> Clock

Returns a clock whose wall reading is always ts and whose monotonic reading is always zero.

Its sleep waits in real time and moves neither reading.

manual

pub fn manual(start: timestamp.Timestamp) -> Manual

Returns a Manual clock whose wall reading starts at start and whose monotonic reading starts at zero.

system

pub fn system() -> Clock

Returns a clock that reads the operating system's wall and monotonic clocks.
