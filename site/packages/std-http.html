std/http

#net #web

import std/http

Server types: Request, Response, Header, header helpers and parse_url. Request.token is cancelled when the client goes away and when the handler returns. Request.remote is the client's IP address for connections served by serve, serve_tls and serve_conn. Serving: serve, serve_tls, serve_conn and serve_stream; the _on forms (serve_on, serve_tls_on, serve_conn_on) take the listener's or connection's view. Client: a pooled client configured through client() and with_* builders, per-request builders, send, stream_to and download. with_interface binds every connection to a network interface. with_resolver substitutes for net.lookup on host names; TLS keeps the host name for SNI and certificate checks. with_cancel makes a request fail with Cancelled once its token is cancelled. URLs: parsing, resolution and encoding. connect returns a droppable Connection that closes its stream when released; detach hands the stream on. Proxies: with_proxy, with_http_proxy, with_https_proxy, with_no_proxy, with_proxy_from_environment and with_dialer send requests through an http:// proxy (absolute-form for http targets, CONNECT for https targets) or a socks5://, socks5h://, socks4:// or socks4a:// proxy. no_proxy follows Go's matching rules. CookieJar is a shared RFC 6265 jar (cookie_jar, with_cookie_jar, jar_set, jar_header, jar_cookies, jar_clear) that enforces the Secure rules and the __Secure- and __Host- prefixes and has no public-suffix check. A Response whose stream is a chan[[]u8] is written as it is produced, chunked on HTTP/1.1 and as DATA frames on HTTP/2, until the handler closes the channel.

Imports std/base64, std/cancel, std/compress/brotli, std/compress/deflate, std/compress/zstd, std/crypto, std/crypto/x509, std/file, std/io, std/json, std/net, std/os, std/serde, std/socks, std/sync, std/text, std/time, std/time/date, std/tls.
