std/sql/sqlite

#database

import std/sql/sqlite

SQLite through libsqlite3, linked only when a program calls it. open and open_with (read-only, create, busy timeout). exec runs scripts. query, each and execute take ? or ?N parameters over cached prepared statements. Also last_insert_id, begin, begin_immediate, commit and rollback, and backup to a file through the online backup API. close and close_on are idempotent; a closed Database fails with sql.Error.Closed. connection and connect present a database as an sql.Connection: the one connection returns leaves closing to the Database, the one connect returns closes it. Calls block their OS thread.

Imports std/sql, std/sql/driver.

Database

pub struct Database {The copyable DatabaseHandle for the database.    pub handle: *DatabaseHandle
}

An open SQLite database that closes itself when dropped.

Calls block the calling OS thread. Statements are prepared once per distinct text and cached until the database is closed.

backup

pub fn backup(d: Database, path: str) ! sql.Error

Copies the whole database into the file at path with the online backup API, creating the file when needed.

The copy runs in one step and retries every 10 milliseconds while the source or the target is locked. Returns sql.Error.Closed when the database is closed and sql.Error.Server or sql.Error.Busy when the target cannot be opened or the copy fails.

begin

pub fn begin(d: Database) ! sql.Error

Starts a deferred transaction with BEGIN.

begin_immediate

pub fn begin_immediate(d: Database) ! sql.Error

Starts a transaction with BEGIN IMMEDIATE, which takes the write lock at once instead of at the first write.

close

pub fn close(d: Database)

Closes the database. Closing a closed database has no effect.

commit

pub fn commit(d: Database) ! sql.Error

Commits the current transaction.

connection

pub fn connection(d: Database) -> sql.Connection

Returns the database as an sql.Connection whose close does nothing, so the Database stays responsible for closing it.

each

pub fn each(d: Database, text: str, values: []sql.Value, visit: fn([]sql.Column, []sql.Value) -> bool) ! sql.Error

Runs one statement with values bound to its ? or ?N parameters and calls visit with the columns and the row for each row it returns. visit returns false to stop early.

Returns sql.Error.Conversion when values does not match the statement's parameter count, sql.Error.Closed when the database is closed, sql.Error.Busy when it is locked and sql.Error.Server for any other failure. Rows hold Null, Int, Float, Text or Bytes values.

exec

pub fn exec(d: Database, script: str) ! sql.Error

Runs the SQL script, which may hold several statements separated by ;, without parameters and discards any rows.

Returns sql.Error.Closed when the database is closed, sql.Error.Busy when it is locked and sql.Error.Server for any other failure.

execute

pub fn execute(d: Database, text: str, values: []sql.Value) -> i64 ! sql.Error

Runs one statement with values bound to its parameters and returns the number of rows changed by the database's most recent INSERT, UPDATE or DELETE. Any rows the statement returns are discarded.

Fails like each.

last_insert_id

pub fn last_insert_id(d: Database) -> i64

Returns the row id of the most recent successful INSERT on this database, or 0 when the database is closed.

query

pub fn query(d: Database, text: str, values: []sql.Value) -> sql.Rows ! sql.Error

Runs one statement with values bound to its parameters and returns all rows. A statement that returns no rows still reports its columns, with each column's declared type as kind.

Fails like each.

rollback

pub fn rollback(d: Database) ! sql.Error

Rolls back the current transaction.

DatabaseHandle

pub struct DatabaseHandle {
    ...
}

The copyable state of an open database: the native handle, the file path and the cache of prepared statements.

close_on closes it. Every copy refers to the same database, so a closed handle makes calls through any copy fail with sql.Error.Closed.

close_on

pub fn close_on(h: *DatabaseHandle)

Finalizes the cached statements and closes the database behind the handle. Closing a closed database has no effect.

Functions

connect

pub fn connect(o: sql.Options) -> sql.Connection ! sql.Error

Opens the file named by o.database with the default Config and returns it as an sql.Connection whose close closes the database. The other fields of o are ignored.

Fails like open.

open

pub fn open(path: str) -> Database ! sql.Error

Opens the database file at path for reading and writing, creating it when it does not exist, with a busy timeout of 5000 milliseconds.

open_with

pub fn open_with(path: str, c: Config) -> Database ! sql.Error

Opens the database file at path using the settings in c.

Returns sql.Error.Server when SQLite cannot open it and sql.Error.Busy when it is locked. path is passed to SQLite unchanged, so ":memory:" opens a private in-memory database.
