std/sys

#io #os

import std/sys

The Linux system call layer, and the only standard library module besides the prelude that calls __syscall. It owns every syscall number, flag, errno and structure layout and exposes typed wrappers that repeat an interrupted call and fail with an io.Error, so callers match io.Error variants. Descriptors: FdHandle, a copyable view whose closing is coordinated by an io.Guard, and the droppable Fd that owns one; read, write, write_all, stream and the _on forms on a view park the green thread while a non-blocking descriptor is not ready; pipe, duplicate, set_nonblocking, try_read and try_write. Files: open with an Open mode, stat, fstat, access, chmod, chown, set_times, unlink, rmdir, mkdir, rename, symlink, link, readlink, statfs, lock, seek, fsync, ftruncate, list_dir and random_bytes. Processes: fork_exec, reap, wait_exit, kill, pidfd_open, signal dispositions and handlers, identity, working directory, memory mapping and exit_process. Sockets: socket, socketpair, bind, listen, accept, connect, finish_connect, recv, send, set_option, get_option, interface_index and multicast membership. Terminals: termios, raw_mode, window size and open_pty. inotify_init, inotify_add and inotify_remove.

Imports std/io.

FdHandle

pub struct FdHandle {The operating system file descriptor.    pub fd: i64
    ...
}

A copyable view of an open descriptor and the guard that coordinates its closing.

Copies of an FdHandle refer to the same descriptor. Once any copy is closed, every operation on the view fails with NotConnected, so a closed descriptor is never reached after the kernel reuses its number. Reads and writes park the green thread while the descriptor is non-blocking and not ready.

adopt

Returns the Fd that owns the descriptor behind h, which closes it when dropped.

close_on

pub fn close_on(h: FdHandle)

Closes the descriptor that h views.

Later operations on h or its copies fail with NotConnected. The descriptor is released immediately, or when the last operation in flight returns. Closing twice does nothing.

enter

pub fn enter(h: FdHandle) -> io.Lease ! io.Error

Registers a use of the descriptor behind h and returns the lease that ends it when dropped.

Fails with NotConnected once the descriptor has been closed, so a closed descriptor is never reached. Operations on the descriptor number h.fd that other sys functions perform hold a lease for their duration.

fork_exec

pub fn fork_exec(path: str, argv: []str, envp: []str, dir: str, group: bool, stdin: i64, stdout: i64, stderr: i64) -> Spawned ! io.Error

Starts the program at path in a new process and returns once the program has been executed.

argv is the whole argument vector, program name first, and envp is the complete environment as name=value entries. A dir that is not empty becomes the working directory of the child. With group the child starts its own process group. stdin, stdout and stderr are descriptors the child receives as standard streams, and a negative one leaves that stream as the parent's. The parent waits for the child to report on a pipe that closes when the program is executed, so the call parks the green thread until then.

Fails with the system error when the pipe or the fork fails. An error of chdir or execve in the child comes back in Spawned.failure.

termios

pub fn termios(fd: i64) -> Termios ! io.Error

Returns the settings of the terminal on fd.

Fails with Unsupported if fd is not a terminal.

try_read

pub fn try_read(fd: i64, buf: []u8) -> i64 ! io.Error

Reads once from the descriptor number fd without waiting.

Fails with WouldBlock when fd is non-blocking and has no data. An interrupted read is repeated.

try_write

pub fn try_write(fd: i64, data: []u8) -> i64 ! io.Error

Writes once to the descriptor number fd without waiting.

Fails with WouldBlock when fd is non-blocking and cannot take output. An interrupted write is repeated.

uid

pub fn uid() -> i64

Returns the real user id.

umask

pub fn umask(mask: i64) -> i64

Sets the file creation mask to mask & 0o777 and returns the previous mask.

unlink

pub fn unlink(path: str) ! io.Error

Removes the file or symbolic link at path.

unmap

pub fn unmap(address: i64, size: i64)

Unmaps size bytes at address.

uptime

pub fn uptime() -> i64 ! io.Error

Returns the number of seconds the machine has been running.

wait_exit

pub fn wait_exit(pid: i64) ! io.Error

Waits for the child pid to end without reaping it.

Blocks the OS thread until the child has ended.

window_size

pub fn window_size(fd: i64) -> WindowSize ! io.Error

Returns the size of the terminal on fd.

Fails with Unsupported if fd is not a terminal.

wrap

pub fn wrap(fd: i64) -> FdHandle

Returns a view of the open descriptor fd, which the view's owner closes.

A negative fd makes a view whose closing does nothing.

wrap_with

pub fn wrap_with(fd: i64, wake: fn()) -> FdHandle

Returns a view of the open descriptor fd whose closing first runs wake.

wake unblocks operations that are waiting on the descriptor, for example by shutting a socket down.

write

pub fn write(fd: i64, data: []u8) -> i64 ! io.Error

Writes a prefix of data to the descriptor number fd and returns how many bytes were written, which can be fewer than data.len.

Parks the green thread while fd is non-blocking and cannot take more output. An interrupted write is repeated.

write_all

pub fn write_all(fd: i64, data: []u8) ! io.Error

Writes all of data to the descriptor number fd, repeating write until nothing remains.

Fails with the first error a write returns, after which part of data may have been written.

yield_thread

pub fn yield_thread()

Lets another thread run.
