std/mime

#web

import std/mime

Media types by file extension and back (by_extension, extension) for web, image, font, archive, audio, video and subtitle formats. sniff recognises content by its magic bytes or its leading text and falls back to plain text or application/octet-stream.

Imports std/text.

Examples

uploads

import std/mime
import std/path
import std/text

struct Upload {
    name: str
    data: []u8
}

fn essence(content_type: str) -> str {
    text.cut(content_type, ";").before
}

fn check(upload: Upload) {
    let declared = mime.by_extension(path.ext(upload.name)) ?? "unknown"
    let actual = mime.sniff(upload.data)
    let verdict = if essence(declared) == essence(actual) {
        "ok"
    } else if declared == "unknown" {
        "unknown extension"
    } else {
        "mismatch"
    }
    print("{upload.name,-12} declared {declared}, content {actual}: {verdict}")
}

/// Compares the type an upload's file name claims with the type its leading bytes show, and maps a type back to an extension for storage.
fn main() {
    let png = [u8(0x89), 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A, 0, 0, 0, 13]
    let jpeg = [u8(0xFF), 0xD8, 0xFF, 0xE0, 0, 16]
    let uploads = [
        Upload { name: "logo.png", data: png },
        Upload { name: "photo.JPG", data: jpeg },
        Upload { name: "avatar.png", data: bytes("  <!DOCTYPE html><script>alert(1)</script>") },
        Upload { name: "scan.jpg", data: png },
        Upload { name: "data.json", data: bytes("{{\"ok\": true}}") },
        Upload { name: "notes.txt", data: bytes("plain words\n") },
        Upload { name: "blob.bin", data: [u8(1), 2, 3] },
        Upload { name: "bundle.zip", data: [u8(0x50), 0x4B, 0x03, 0x04, 20, 0] },
        Upload { name: "empty.txt", data: [] },
    ]
    for upload in uploads {
        check(upload)
    }

    for content_type in ["image/jpeg", "Text/HTML; charset=utf-8", "application/pdf", "application/x-unknown"] {
        match mime.extension(content_type) {
            some(ext) => print("{content_type} is stored as .{ext}")
            none => print("{content_type} has no known extension")
        }
    }
}

Functions

by_extension

pub fn by_extension(ext: str) -> str?

Returns the content type for a file extension, or none when it is not known.

The extension may start with a dot and is matched without regard to case. Text types carry charset=utf-8.

extension

pub fn extension(content_type: str) -> str?

Returns the file extension, without a dot, for a content type, or none when it is not known.

Parameters such as charset are ignored and the type is matched without regard to case. When several extensions share a type, such as jpg and jpeg, the first is returned.

sniff

pub fn sniff(data: []u8) -> str

Returns the content type that the leading bytes of data suggest.

Images, audio, video, archives, PDF and WebAssembly are recognised by their signatures. After leading whitespace, <!doctype html and <html give text/html; charset=utf-8, <?xml gives application/xml, and a first byte of { or [ gives application/json without checking that the rest is valid. Anything else is text/plain; charset=utf-8 unless it contains control bytes, which give application/octet-stream. Empty data is plain text.
