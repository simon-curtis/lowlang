paint

pub fn paint(mut sys: System, mut sc: scene.Scene, l: Layout, origin: geometry.Point, color: geometry.Color, highlights: []Highlight, scale: f32)

Pushes the glyphs of l onto sc tinted color, with the layout's top left at origin and everything multiplied by scale, styled by highlights.

Each glyph takes, field by field, the last highlight that covers its code point and sets that field. Backgrounds go first, as one quad per run of glyphs on a line with the same background, from the first glyph's pen position to the last one's advance and from the top of the line to its bottom. One sprite per visible glyph follows, then the underlines and strikethroughs, one per run of glyphs with the same decoration. Runs stop at the line's width, so spaces hanging past it are not marked.

Glyphs are rasterised at l.size * scale pixels, rounded to 1/64 pixel, the first time they are drawn, and packed into the atlas with a one-pixel empty border. Each glyph's pen position and each run's ends are rounded to whole device pixels. A glyph that does not fit in the atlas is left out, and so is every glyph packed after it until end_frame.

paint_image

pub fn paint_image(mut sys: System, mut sc: scene.Scene, key: str, img: image.Image, source: geometry.Rect, p: scene.Picture)

Pushes p onto sc showing the source rectangle of img, in image pixels, resampled to p.bounds snapped to whole device pixels.

The resampled pixels are packed into the atlas's colour plane, with a one-pixel empty border, the first time key is drawn with that source and size, so key must name one image's pixels. An image too large for the plane is left out, and so is every image that does not fit until end_frame clears the plane.

paint_polygons

pub fn paint_polygons(mut sys: System, mut sc: scene.Scene, polygons: [][]geometry.Point, rule: geometry.FillRule, color: geometry.Color)

Pushes a sprite onto sc covering polygons, in device pixels and filled by rule, tinted color.

The coverage is rasterised the first time a shape is drawn at its offset within a pixel, and packed into the atlas like a glyph, so a shape moved by whole pixels is drawn from the same tile.

wrap

pub fn wrap(mut sys: System, s: str, f: Format, width: f32) -> Layout

Returns s laid out with format f in lines no wider than width pixels, or in lines that end only where the text breaks them when width is infinite or f does not wrap.

The typeface chooses a font. Each code point is drawn by that font, or when it lacks the code point by a fallback, else by its glyph 0, and advances the pen by the glyph's advance plus the kern adjustment to the glyph before it when both come from one font. Consecutive code points drawn by one font, with no line break opportunity between them, are substituted by font.substitute, so a ligature is one glyph whose at and end span its code points; a mark that the font anchors to its base or to the mark before it has no advance and is placed by Placed.x and Placed.y. A line may break after a space; spaces at the end of a line hang past its width, and a word wider than width breaks between extended grapheme clusters. \n, \r, \r\n, vertical tab, form feed, U+0085, U+2028 and U+2029 end a line, and a layout always has at least one line.

With max_lines the lines past it are dropped. With an ellipsis, the last line kept after dropping, and without wrapping each line wider than width, loses its glyphs from the first that does not fit beside the ellipsis, and its trailing spaces, and ends with the ellipsis. Each line is then placed by align within width, or within the widest line when width is infinite.

The result is kept until end_frame, so laying out the same s, format and width again returns it.

system

pub fn system(fonts: []font.Font) -> System

Returns a system that draws with fonts, or with font.fallback() when fonts is empty, and an atlas whose planes are 1024 pixels square. A typeface chooses among fonts by family, weight and slant, an empty family chooses the first, and a code point the chosen font lacks is drawn by the first of fonts that has it.

system_of

pub fn system_of(faces: []font.Face) -> System

Returns a system that chooses among the fonts faces describes, loading each the first time it is chosen, with font.fallback() for text when none of them can be loaded. A code point the chosen font lacks is drawn by a font already loaded that has it, else by the first regular face that has it, trying the system's usual fallback families first.
