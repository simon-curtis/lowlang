std/sql/migrate

#database

import std/sql/migrate

Ordered migrations recorded in a schema_migrations table with a SHA-256 checksum: plan, with_table, status, up, up_to and down, each migration in its own transaction under a lock. from_text and load_dir read -- +up and -- +down files named NNN_name.sql.

Imports std/crypto/hash, std/file, std/io, std/slices, std/sql, std/text, std/time/clock, std/time/timestamp.
