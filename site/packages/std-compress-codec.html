std/compress/codec

#compression

import std/compress/codec

The parts the compressors share: a growable Buffer that packs bits, a BitReader, two-level Huffman decode Tables, a length-limited Huffman Builder, hash-chain Chain and walk, a shared LZ77 History window (history, append, index_to, extend_back), the one-shot decompress scaffold with output_for, deliver and each_chunk, the streaming Encoder shell (encoder, encode, flush, finish), copy_match, and LEB128 varints.

Imports std/io, std/math.

Types

BitReader

pub struct BitReader {Called before the source is read.    pub before_read: fn() ! io.Error
    ...
}

A reader that hands out bits from the least significant end of each byte, from a slice or an io.Reader.

Every read that runs past the end of the input fails with Malformed. A reader made by stream_reader calls before_read each time it is about to ask its source for more bytes, so a decoder can pass its pending output to a sink first.

Returns the number of bits buffered in the accumulator, which modulo eight is the position within the current byte.

discard

pub fn discard(r: *BitReader, n: i64) ! io.Error

Discards the next n bits, which must already be buffered by a peek or a take.

Fails with Malformed when fewer than n bits remain.

has_more

Returns true when at least one more whole byte can be read, asking the source when the buffer is empty.

peek

pub fn peek(r: *BitReader, n: i64) -> i64 ! io.Error

Returns the next n bits without consuming them, for an n from 0 to 56, loading more input when fewer are buffered.

Near the end of the input fewer than n bits can remain, and the missing high bits read as zero.

read_bytes

pub fn read_bytes(r: *BitReader, dst: []u8) ! io.Error

Fills dst with the next whole bytes, which must start on a byte boundary.

Fails with Malformed when the input ends first. Call align_input first when a partial byte is pending.

refill

pub fn refill(r: *BitReader, need: i64) ! io.Error

Loads bytes into the accumulator until it holds more than 56 bits or the input ends.

Stops early, without asking the source for more, once the accumulator holds need bits and the buffered input is used up.

Reads one symbol from r with the table at base in pool, built with the same root.

Fails with Malformed when the bits read are a pattern no code uses or the input ends first.

take

pub fn take(r: *BitReader, n: i64) -> i64 ! io.Error

Reads n bits as a number with the first bit read in the lowest position, for an n from 0 to 56.

Fails with Malformed when fewer than n bits remain.

Buffer

pub struct Buffer {The backing storage. The first len bytes are written.    pub data: []u8The number of bytes written to data.    pub len: i64
    ...
}

A growable byte buffer that also packs bits from the least significant end of each byte.

Every write is infallible, so an encoder core builds its output here and the caller decides when to hand it to a sink. Whole bytes land in data as bits are packed, and a partial byte waits in the accumulator until align or more bits complete it. Use the byte writes with no bits pending, or after align.

align

pub fn align(b: *Buffer)

Pads with zero bits to the next byte boundary and writes everything pending.

collector

pub fn collector(b: *Buffer) -> fn([]u8) ! io.Error

Returns a sink function that appends each chunk to b, for the one-shot decoders.

contents

pub fn contents(b: *Buffer) -> []u8

Returns the bytes written so far, not counting bits still pending.

The slice views the buffer's storage, so a later write or reset can change it.

deliver

pub fn deliver(b: *Buffer, sink: fn([]u8) ! io.Error) ! io.Error

Passes the whole bytes ready in b to sink and empties b of them, calling sink only when there are some.

Fails with any error sink returns.

drain

pub fn drain(b: *Buffer) -> []u8

Returns the whole bytes ready to send and empties the buffer of them, keeping a partial byte pending.

The slice is valid until the next write.

encoder

pub fn encoder(out: *Buffer, chunk: i64, sink: fn([]u8) ! io.Error, feed: fn([]u8), sync: fn(), close: fn()) -> *Encoder

Returns an encoder that delivers out to sink.

feed takes at most chunk bytes of input, sync ends the data written so far on a boundary a decoder can read, and close writes the end of the stream. All three write into out.

flush_bits

pub fn flush_bits(b: *Buffer)

Writes the whole bytes pending in the bit accumulator to data, leaving fewer than eight bits.

mark

pending_bits

pub fn pending_bits(b: *Buffer) -> i64

Returns the number of bits waiting in the accumulator, including whole bytes not yet written to data.

The result modulo eight is the position within the current byte.

put_bits

Appends the low n bits of v, least significant bit first, for an n from 0 to 32.

Bits of v above n must be zero.

The scratch space build and lengths need, sized for an alphabet.

assign_codes

pub fn assign_codes(b: *Builder, lens: []u8, codes: []u32)

Fills codes with the bit-reversed canonical codes for the lengths lens, shorter codes first and equal lengths in symbol order.

Lengths run from 0, which skips the symbol, to 15.

build

pub fn build(b: *Builder, freq: []i64, c: *Code, limit: i64)

Builds the code for freq into c, with no code longer than limit bits.

Sets c.used and c.first. With fewer than two symbols present no lengths are assigned, and the code of c.first is 0.

lengths

pub fn lengths(b: *Builder, freq: []i64, lens: []u8, limit: i64) -> i64

Fills lens with the lengths of a Huffman code for the symbol frequencies freq, none longer than limit bits, and returns the number of symbols with a nonzero frequency.

The code is complete when two or more symbols occur. With fewer than two the lengths stay zero and the caller picks the format's form for a one-symbol code. limit is at most 15.

Chain

pub struct Chain {
    ...
}

A hash chain over a byte history: a table of the latest position for each hash of a few bytes and a ring of the position before each one with the same hash.

Made by chain. Positions are stored one above their value, so zero marks the end of a chain.

link

pub fn link(c: *Chain, hist: []u8, i: i64)

Adds position i of hist to the chain.

Reads 8 bytes from i, so i + 8 must not pass the end of hist.

slide

pub fn slide(c: *Chain, delta: i64)

Moves every remembered position back by delta, for a history that has slid forward by that much, and forgets those that fall off the front.

walk

pub fn walk(c: *Chain, hist: []u8, p: i64, end: i64, window: i64, nice: i64, tries: i64, found: *Match)

Walks the chain for position p of hist and records in found any match longer than found.len, nearest candidates first.

At most tries candidates are checked, none more than window bytes back or older than the chain remembers, and a match may not reach past end. The walk stops once a match of nice bytes is found.

A streaming encoder over a format's core, made by encoder.

Fails with Invalid when the encoder is already finished, and with any error the sink returns.

The input window of an LZ77 encoder: the bytes seen so far, the position up to which they have been written out, and a short-match and a long-match hash chain over them.

Made by history. append fills it and slides it forward when it is full, index_to adds positions to the chains, and the chains answer searches through walk.

Copies the start of input after the bytes already held and returns the number copied.

A history that is full first slides forward so that only window bytes before pos stay, which moves fill, pos and every position in the chains back by the same amount.

Tables

pub struct Tables {The entries of every table built since the last reset_tables.    pub pool: []u32
    ...
}

Space for the two-level lookup tables that decode canonical Huffman codes read least significant bit first.

Made by tables. Each table built into pool starts at the base build_table returns: 1 << root entries indexed by the next root bits, followed by second-level blocks for codes longer than root. An entry holds the symbol in bits 8 and up and the code length in the low four bits. An entry that links to a second-level block holds its offset from the base in bits 8 and up, 0x80, and the number of index bits in the low four. A single-symbol table has length zero and 0x40 set. An entry of 0 is a bit pattern no code uses.

build_single

pub fn build_single(t: *Tables, sym: i64, root: i64) -> i64

Builds a table of 1 << root entries in which every bit pattern decodes to sym with no bits consumed, and returns its base.

build_table

pub fn build_table(t: *Tables, lens: []u8, root: i64) -> i64 ! io.Error

Builds the decoding table for the canonical code with the lengths lens and returns its base in pool.

Lengths run from 0, which marks an unused symbol, to 15, and root is the number of bits the first level indexes. Fails with Malformed when the lengths over-subscribe the code. An incomplete code is accepted, and the bit patterns it leaves unused decode to the entry 0.

reset_tables

pub fn reset_tables(t: *Tables)

Forgets every table built so far so the pool can be reused.
