std/quic/wire

#net

import std/quic/wire

QUIC encoding with no I/O: a bounds-checked Cursor with varints and packet numbers, parse_header for long and short headers, version_negotiation, packet protection (keys, initial_keys, next_keys, seal, open, peek_key_phase) with header protection, Retry packets and their integrity tag (retry_packet, retry_tag, retry_valid), the frames as one Frame enum (parse_frames, put_frame, frame_size, put_stream_frame, ack_eliciting, ack_delay_ns), transport parameters (encode_parameters, decode_parameters) and the transport error codes. Every parser fails Malformed on hostile input and never panics.

Imports std/bits, std/crypto, std/crypto/aead, std/crypto/hash, std/io, std/tls.

ack_delay_ns

pub fn ack_delay_ns(ack: AckFrame, exponent: i64) -> i64

Returns the acknowledgment delay of ack in nanoseconds, given the peer's ack_delay_exponent.

The delay is ack.delay * 2^exponent microseconds. The result saturates at the largest i64 instead of overflowing, so a hostile delay such as 2^62 - 1 is safe to use. An exponent outside 0 to 20 is clamped into that range, and a negative delay gives 0.

next_keys

pub fn next_keys(k: Keys) -> Keys ! io.Error

Derives the keys of the next key phase from k (RFC 9001 section 6).

The secret is advanced with the label quic ku, which gives a new key and IV. The header protection key is kept.

open

pub fn open(k: Keys, packet: []u8, h: Header, largest: i64) -> Opened ! io.Error

Removes header protection and decrypts the packet packet, which is exactly h.size bytes of the datagram.

h comes from parse_header. The packet number is decoded against largest, the largest packet number received in that space, or -1 when none has arrived. The input is not modified, so a packet that fails can be opened again with other keys. Fails with Malformed when the packet is not h.size bytes or is too short to sample, Invalid when authentication fails, the packet number decodes above 2^62-1 or h is a kind without a packet number. The reserved bits and key phase of the first byte are reported in the result.

peek_key_phase

pub fn peek_key_phase(k: Keys, packet: []u8, h: Header) -> bool ! io.Error

Returns the key phase bit of the short header packet packet, found by removing header protection.

Header protection keys do not change with the key phase, so a receiver reads the bit with the current keys to learn whether the packet needs the next keys. Returns false for a long header packet. Fails with Malformed when the packet is too short to sample and Invalid for a kind without a packet number.

seal

pub fn seal(k: Keys, header: []u8, pn: i64, payload: []u8) -> []u8

Returns the protected packet for payload.

header is the unprotected header up to and including the packet number field, which the caller has written with the chosen length; for a long header the Length field covers the packet number, the payload and the 16-byte tag. pn is the full packet number, which forms the nonce. The header is the associated data. Header protection is applied over the packet number and the low bits of the first byte, sampling the ciphertext from 4 bytes past the start of the packet number field. The payload must be at least 4 - packet number length bytes so the sample exists; a shorter one panics, and a sender pads it with PADDING frames.

decode_parameters

pub fn decode_parameters(raw: []u8) -> Parameters ! io.Error

Parses the body of a quic_transport_parameters extension.

Parameters with unknown identifiers, including the reserved 31 * N + 27 ones, are ignored. Fails with Malformed for a truncated parameter, a duplicate identifier, an integer whose length does not match its encoding, max_udp_payload_size below 1200, ack_delay_exponent above 20, max_ack_delay of 2^14 or more, active_connection_id_limit below 2, either initial_max_streams above 2^60, a stateless_reset_token that is not 16 bytes, a connection ID above 20 bytes, a disable_active_migration with a value or a preferred_address that is not laid out as RFC 9000 section 18.2 gives. encode_packet_number

pub fn encode_packet_number(full: i64, largest_acked: i64) -> i64

pub fn parse_frames(payload: []u8) -> []Frame ! io.Error

Parses the frames of a decrypted packet payload.

Consecutive PADDING bytes become one Padding. Fails with Malformed for an empty payload, a truncated frame, an unknown frame type, a frame type encoded in more bytes than necessary, a STREAM or CRYPTO frame whose offset plus length exceeds 2^62 - 1, a MAX_STREAMS or STREAMS_BLOCKED limit above 2^60, a NEW_TOKEN with an empty token, a NEW_CONNECTION_ID whose ID is not 1 to 20 bytes or whose retire_prior_to exceeds sequence, and ACK ranges that reach below packet number 0. parse_header

pub fn parse_header(datagram: []u8, at: i64, short_dcid_len: i64) -> Header ! io.Error

Parses the packet header that starts at offset at of datagram, with header protection still applied.

short_dcid_len is the length of the connection IDs this endpoint issues, which a short header does not carry. The connection IDs and token are copies. For version 1, long header connection IDs above 20 bytes, a clear fixed bit, a length field running past the datagram and a Retry packet shorter than its tag are Malformed, as is a Version Negotiation packet whose version list is empty or not a multiple of 4 bytes. Version Negotiation packets and long header packets of other versions are parsed by their invariant fields only: the kind is VersionNegotiation or Unknown and the packet extends to the end of the datagram.

put_frame

pub fn put_frame(mut out: []u8, f: Frame)

Appends the frame f.

A STREAM frame is written with an explicit length, so other frames can follow it; use put_stream_frame to omit the length of the last one. Padding appends count zero bytes. An Ack with no ranges acknowledges only largest. The id and reset_token of NewConnectionId and the data of PathChallenge and PathResponse are written as given and must have the lengths their variants document. Panics when an integer is negative or above 2^62 - 1.
