std/html

#web #formats

import std/html

An HTML tokenizer: a pull Tokenizer returning StartTag, EndTag, Text, Comment, Doctype and End tokens, attribute lookup and unescape for character references.

Imports std/simd, std/text.

Token

pub enum Token {
    /// An opening tag. `name` is lowercased. `attributes` lists the attributes in source order; when a name repeats, the first occurrence is kept. `self_closing` is `true` when the tag ends in `/>`.
    ///
    /// After `script`, `style`, `xmp`, `iframe`, `noembed` and `noframes` the content up to the matching end tag is one raw `Text` token. After `title` and `textarea` it is one `Text` token with character references decoded. After `plaintext` the rest of the input is one `Text` token.
    StartTag(str, []Attribute, bool)
    /// A closing tag. `name` is lowercased and any attributes are discarded.
    EndTag(str)
    /// Character data. In ordinary content and in `title` and `textarea`, `content` has character references decoded; inside raw text elements it is verbatim.
    ///
    /// A `<` that does not begin a tag, comment, declaration or processing instruction is part of the text.
    Text(str)
    /// A comment. `content` excludes the delimiters. Processing instructions (`<?...>`), unknown declarations (`<!...>`) and malformed end tags (`</ ...>`) are reported as comments holding the text up to the next `>`.
    Comment(str)
    /// A document type declaration. `name` is lowercased. `public_id` and `system_id` are `none` when absent.
    Doctype(str, str?, str?)
    /// The end of the input. Every call to `next` after the last token returns it again.
    End
}

One lexical unit of an HTML document.

The tokenizer does not build a tree and does not repair markup: it reports tags, text, comments and doctypes in source order.

next

pub fn next(t: *Tokenizer) -> Token

Returns the next token.

Returns End once the input is exhausted, and on every later call. A tag that is not closed before the end of the input is dropped, as is an empty end tag </>.

unescape

pub fn unescape(s: str) -> str

Decodes the HTML character references in s: named references, decimal references such as &#65; and hexadecimal references such as &#x41;.

Named references without a closing ; are decoded when they are one of the historic names. Numeric references to zero, surrogates and values above U+10FFFF become U+FFFD, and values from 0x80 to 0x9F are read as Windows-1252. An unknown reference is left as written.
