std/regex

#text

import std/regex

Linear-time regular expressions in the RE2 style: compile and compile_with with Flags, generated (a pattern compiled into specialised code at build time), is_match, find, full_match, find_all, replace_all (with a closure receiving each Match), split and split_n. A match offers start, end, text, group and span, with byte offsets.

Imports std/slices.

Match

pub struct Match {
    ...
}

The outcome of one successful match: the matched text and the byte spans of its capture groups. Read it with start, end, text, span and group. It stays valid after further searches.

end

pub fn end(m: Match) -> i64

Returns the byte offset one past the end of m.

group

pub fn group(m: Match, index: i64) -> str?

Returns the text of capture group index in m, where 0 is the whole match. Returns none in the cases where span does.

span

pub fn span(m: Match, group: i64) -> Span?

Returns the byte span of capture group group in m, where 0 is the whole match. Returns none when group is negative or beyond group_count, and when the group did not take part in the match.

start

pub fn start(m: Match) -> i64

Returns the byte offset where m begins.

text

pub fn text(m: Match) -> str

Returns the text m matched, as a slice of the searched input.

Regex

pub struct Regex {
    ...
}

A compiled regular expression. Matching runs in time linear in the input and uses no backtracking, in the RE2 style, and the leftmost match is chosen with greedy and lazy repeats taking priority as in Perl. Patterns match code points of UTF-8 text, and all offsets are byte offsets. The syntax covers literals, ., classes [a-z] and [^a-z], \d \w \s and their negations, \x, \u and \U escapes, groups (...) and (?:...), alternation |, repeats * + ? {n} {n,} {n,m} with a lazy ? suffix, and the anchors ^ $ \A \z \b \B. A Regex may be used from several threads at once.

find

pub fn find(re: Regex, input: str) -> Match?

Returns the leftmost match in input, or none when there is none. Group 0 of the result spans the match.

find_all

pub fn find_all(re: Regex, input: str) -> []Match

Returns every non-overlapping match in input, from left to right. After an empty match the next match may not be empty at the same offset, so the search always advances. Returns an empty slice when nothing matches.

full_match

pub fn full_match(re: Regex, input: str) -> Match?

Returns a match only when the pattern matches the whole of input, from its first byte to its last, and none otherwise.

group_count

pub fn group_count(re: Regex) -> i64

Returns the number of capture groups in re, not counting group 0 for the whole match.

is_match

pub fn is_match(re: Regex, input: str) -> bool

Returns whether input contains a match anywhere. It does not record capture groups and is the cheapest query.

replace_all

pub fn replace_all(re: Regex, input: str, replacement: fn(Match) -> str) -> str

Returns input with every non-overlapping match replaced by the string replacement returns for it. The closure's result is inserted as it stands, with no $1 expansion. Input between matches is copied unchanged.

split

pub fn split(re: Regex, input: str) -> []str

Splits input around each non-overlapping match of re and returns the pieces between them. Returns a single piece, input, when nothing matches. Adjacent matches and matches at either end produce empty pieces.

split_n

pub fn split_n(re: Regex, input: str, max: i64) -> []str

Splits input as split does, using at most max matches. The result has at most max + 1 pieces and the last holds the unsplit rest. 0 returns input as the only piece, and a negative max splits at every match.
