Examples

messages

import std/compress/lz4
import std/io

/// Sends two messages through one LZ4 frame, flushing after the first, and decodes the bytes available at that point to show what a flush makes readable.
fn main() ! io.Error {
    var wire: []u8 = []
    let enc = lz4.encoder(1, fn(chunk) {
        io.append(mut wire, chunk)
    })

    enc.encode(bytes("temp=21;temp=21;temp=21;"))?
    enc.flush()?
    let after_first = wire.len

    enc.encode(bytes("temp=35;temp=35;"))?
    enc.finish()?

    var partial: []u8 = []
    let early = io.bytes_reader(wire[..after_first])
    lz4.decode(early, fn(chunk) {
        io.append(mut partial, chunk)
    }, 1 << 20) or {}
    print("before the second message: {str(partial)}")

    let full = lz4.decompress(wire, 1 << 20)?
    print("whole frame: {str(full)}")
}

Output

before the second message: temp=21;temp=21;temp=21;
whole frame: temp=21;temp=21;temp=21;temp=35;temp=35;

Types

Encoder

pub struct Encoder {
    ...
}

A streaming LZ4 frame encoder made by encoder.

encode takes input in any chunking, flush writes the buffered input as blocks, and finish writes the end mark and the content checksum. After finish, encode, flush and finish fail with Invalid. The frame uses linked blocks of up to 64 KiB. A chunk is valid only during the call to sink.

encode

pub fn encode(e: *Encoder, data: []u8) ! io.Error

Compresses data and passes each completed 64 KiB block to the encoder's sink.

Input is buffered until a block is full, so a call can produce no output. Fails with Invalid after finish, and with any error sink returns.

finish

pub fn finish(e: *Encoder) ! io.Error

Writes the buffered input, the end mark and the content checksum.

An encoder that received no input still writes a complete empty frame. Fails with Invalid when the stream is already finished, and with any error sink returns.

flush

pub fn flush(e: *Encoder) ! io.Error

Writes the buffered input as blocks, so a decoder can read everything encoded so far.

Fails with Invalid after finish, and with any error sink returns.

Functions

compress

pub fn compress(data: []u8, level: i64) -> []u8

Returns data compressed as one LZ4 frame.

level is clamped to 1..12. The frame header records the content size.

decode

pub fn decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes LZ4 frames from r and passes the decoded bytes to sink in chunks until the input ends.

Concatenated frames are decoded in turn and skippable frames are ignored. Content and block checksums are verified. Input with no frame is Malformed; the legacy frame format and frames that need a dictionary are Unsupported. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

decompress

pub fn decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from LZ4 frames in data.

Concatenated frames are decoded in turn and skippable frames are ignored. Input with no frame is Malformed; the legacy frame format and frames that need a dictionary are Unsupported. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.

encoder

pub fn encoder(level: i64, sink: fn([]u8) ! io.Error) -> *Encoder

Returns an encoder that writes one LZ4 frame to sink.

level is clamped to 1..12; higher levels search more candidates and, from 3, parse lazily. The frame header carries no content size.
