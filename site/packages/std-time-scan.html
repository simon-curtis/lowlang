#time

import std/time/scan

Scan, the read position the time parsers share, with more, at_digit, at_byte, accept, expect, digits, take_whole and take_fraction, and the fraction text the formatters share.

Imports std/text, std/time/fault.

Examples

lap_times

import std/time/duration
import std/time/fault
import std/time/scan

fn parse_lap(line: str) -> duration.Duration ! fault.Fault {
    var p = scan.Scan { s: line, at: 0 }
    scan.expect_text(mut p, "lap")?
    scan.skip_spaces(mut p)
    let number = scan.take_whole(mut p, fault.Fault.Overflow)?
    scan.expect(mut p, ':')?
    scan.skip_spaces(mut p)
    let minutes = scan.digits_between(mut p, 1, 2)?
    scan.expect(mut p, ':')?
    let seconds = scan.digits(mut p, 2)?
    var nanos = 0
    if scan.at_byte(p, '.') {
        nanos = scan.take_fraction(mut p, 1000000000)?
    }
    if scan.more(p) {
        fail fault.Fault.Syntax(p.at)
    }
    if number == 0 {
        fail fault.Fault.Invalid("lap number")
    }
    let whole = duration.seconds(minutes * 60 + seconds)
    duration.plus(whole, duration.nanoseconds(nanos))
}

/// Reads lap times with a small parser built on the shared scanner, and reports the position of the first bad byte.
fn main() {
    let laps = [
        "lap 1: 1:02.350",
        "lap 2:   0:59.9",
        "lap 3: 1:01",
        "lap 4: 1:2.5",
        "lap 5: 1:02.3504",
        "lap 6: 1:02.5 s",
        "lap 0: 1:00",
        "pit stop"
    ]
    var best = duration.hours(1)
    for line in laps {
        let lap = parse_lap(line) catch {
            f => {
                print("{line}: {fault.to_string(f)}")
                continue
            }
        }
        best = duration.min(best, lap)
        print("{line}: {duration.friendly(lap)}")
    }
    print("best lap {duration.friendly(best)}")
    print("fraction text {scan.fraction_text(350, 3)} and {scan.sub_second_text(1500000)}, {scan.sub_second_text(42)}")
}

A read position in a string, shared by the time parsers.

The take_ and expect functions advance at as they read and fail with Syntax at the position of the first byte that does not fit.

take_fraction

pub fn take_fraction(mut p: Scan, unit_nanos: i64) -> i64 ! fault.Fault

Reads a . and the fraction digits after it, and returns the fraction as a count of nanoseconds when the whole number before it was counted in units of unit_nanos nanoseconds.

At most nine digits are read, and the fraction must be exactly representable in nanoseconds. Fails with Syntax when no digit follows the dot, when a tenth digit follows, or when a digit that cannot be represented is not zero.

take_whole

pub fn take_whole(mut p: Scan, overflow: fault.Fault) -> i64 ! fault.Fault

Reads a run of digits as one number. Fails with Syntax when there is none and with overflow when the number does not fit in an i64.
