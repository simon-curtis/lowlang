std/time/pattern

#time

import std/time/pattern

Compiled strftime and strptime patterns shared by the types above: compile, Names for other languages, render and scan. Verbs: %Y %y %C %m %d %e %j %b %B %a %A %u %w %U %W %V %G %H %I %M %S %f %N %p %P %z %:z %::z %Z %s %F %T %R %D %% %n %t. Flags: -, _, 0 and ^. Parsing is strict, and every error carries a byte offset.

Imports std/builder, std/text, std/time/fault.

The calendar and clock values a pattern reads or writes, each optional so that a pattern can fill in only the parts it names.

render takes the values to print from it and scan returns the values it found in it. The date and time types convert to and from Fields with to_fields and from_fields.

check_date

pub fn check_date(parsed: Fields, actual: Fields) ! fault.Fault

Checks that the fields in parsed agree with actual, the fields of the date they resolved to.

A field missing from either side is not compared. Fails with Invalid when a weekday, week, century or other field differs.

date_plan

pub fn date_plan(f: Fields) -> Plan ! fault.Fault

Returns how f names a date, trying year with month and day first, then year with day of year, then ISO year with week and weekday.

A year of century without a century becomes 19xx for 69 to 99 and 20xx otherwise. Fails with Invalid when none of the three is complete.

wall

pub fn wall(f: Fields) -> Wall ! fault.Fault

Returns the time of day in f.

The hour comes from hour, or from hour12 with period. Minute, second and nanosecond default to 0. Fails with Invalid when there is no hour, when hour12 has no period, or when hour, hour12 and period disagree.

The words a pattern prints and recognises for months, weekdays and the halves of the day.

Month lists have twelve entries from January and weekday lists have seven entries from Monday. A list of any other length is rejected with Invalid by render, scan and check_names.

render

pub fn render(p: Pattern, f: Fields, names: Names) -> str ! fault.Fault

Returns f printed through p using names.

Fails with Invalid when names has the wrong number of entries, when a value that p needs is missing from f and when a two-digit year is asked of a negative year.

restrict

pub fn restrict(p: Pattern, date: bool, time: bool) ! fault.Fault

Checks that p uses only the kinds of value the caller supplies, where date and time say whether date and time-of-day values are available.

Fails with Invalid when p needs a date or a time of day that is not available, and always when it needs an offset, a zone name or Unix time.

scan

pub fn scan(p: Pattern, input: str, names: Names) -> Fields ! fault.Fault

Reads input through p using names and returns the values it found.

Names are matched without regard to case, taking the longest match. A field that appears twice must have the same value both times. A zone abbreviation is a run of letters. Fails with Syntax at the offset where the input stops matching or where input is left over, with OutOfRange naming a field whose value is outside its range, and with Invalid when two fields conflict or names has the wrong number of entries.

compile

pub fn compile(text: str) -> Pattern ! fault.Fault

Compiles a layout into a Pattern.

Text is copied as written and a % starts a verb. The verbs are:

  • Date: %Y year, %y year of century, %C century, %m month, %d day, %e day padded with a space, %j day of year, %u weekday from 1 for Monday, %w weekday from 0 for Sunday, %U and %W week of the year from Sunday or Monday, %V ISO week and %G ISO year.
  • Names: %a and %A short and full weekday, %b and %B short and full month, %p AM or PM and %P the same in lower case, %Z the zone abbreviation.
  • Time: %H hour, %I hour on the 12-hour clock, %M minute, %S second and %s Unix seconds.
  • Fraction: %f six digits when formatting and one to nine when parsing, %3f, %6f and %9f an exact digit count, and %N nine digits.
  • Offset: %z as +hhmm, %:z as +hh:mm and %::z as +hh:mm:ss.
  • Shorthand: %F for %Y-%m-%d, %T for %H:%M:%S, %R for %H:%M and %D for %m/%d/%y.
  • Literal: %%, %n for a newline and %t for a tab.

Numeric verbs take a padding flag after the %: - for none, _ for spaces and 0 for zeros. Name verbs take ^ to print in upper case. Numbers are zero padded by default, except %e. A run of spaces in the layout prints that many spaces and matches that many or more when scanning. Fails with Syntax at the offset of an unknown verb, a flag the verb does not accept or an incomplete verb, and with Unsupported for the locale verbs %c, %x and %X.
