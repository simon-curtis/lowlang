Fe

pub struct Fe {
    ...
}

An element of the prime field GF(2^255 - 19) in five 51-bit limbs, least significant limb first.

Operations return limbs below 2^52 and the type has no canonical form until to_bytes, so compare values with equal rather than field by field.

choose

pub fn choose(a: Fe, b: Fe, choice: u64) -> Fe

Returns b when choice is 1 and a when it is 0, without branching on choice.

choice must be 0 or 1; any other value mixes the limbs of both inputs.

equal

pub fn equal(a: Fe, b: Fe) -> bool

Reports whether a and b encode the same field element.

Both are reduced to canonical bytes and compared without an early exit.

invert

pub fn invert(z: Fe) -> Fe

Returns the multiplicative inverse z^(p - 2) modulo p = 2^255 - 19.

The inverse of zero is zero. The exponentiation is a fixed sequence of squarings and multiplications, independent of the value.

clamp

pub fn clamp(k: []u8) -> []u8

Returns k cut or padded to 32 bytes and clamped as a Curve25519 scalar (RFC 7748 section 5): the low three bits and the top bit cleared and the second-highest bit set.

A shorter k is padded with zero bytes before clamping.

from_bytes

pub fn from_bytes(b: []u8) -> Fe

Decodes 32 little-endian bytes into an element.

Bit 255 is ignored, so the top bit of the last byte never contributes. A value in [2^255 - 19, 2^255) is accepted and reduces modulo 2^255 - 19. The slice must hold at least 32 bytes.

Returns the element whose limbs are l0 (least significant) to l4.
