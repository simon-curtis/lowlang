import std/yaml

YAML 1.2.2: events, a node tree, an encoder, and serde binding.

Imports std/base64, std/serde, std/simd, std/text.

Types

Error

pub enum Error {
    /// The text is not valid YAML 1.2, at `line` and `column`, counted from `1`; `message` says why. It covers every problem the scanner, parser and composer find, for example a bad indentation, an undefined alias or tag handle, a duplicate mapping key, an invalid escape, a scalar that does not match its tag or an integer that does not fit an `i64`.
    Syntax(i64, i64, str)
    /// Expanding aliases would create more nodes than `Options.max_nodes` allows, at the `line` and `column` of the alias or node that crossed the limit, counted from `1`. Each use of an alias counts as the size of the node it refers to.
    TooManyNodes(i64, i64)
}

The error returned when reading YAML fails.

Event

pub struct Event {
    /// What the event is.
    pub kind: EventKind
    /// The anchor name without the `&`, or the empty string when the node has none. For an `Alias` event it is the name being referred to.
    pub anchor: str
    /// The node's tag, resolved against the `%TAG` directives of the document, or the empty string when it has none. `!!str` is `tag:yaml.org,2002:str`, a local tag `!x` is `!x`, a verbatim tag `!<uri>` is `uri` and the non-specific tag `!` is `!`.
    pub tag: str
    /// The decoded text of a `Scalar`, with quotes, escapes and block scalar folding already applied. It is empty for every other kind.
    pub value: str
    /// How a `Scalar` was written, or whether a collection is `Block` or `Flow`. `Plain` for the other kinds.
    pub style: Style
    /// Whether a `DocumentStart` came from a `---` marker or a `DocumentEnd` from a `...` marker. `false` for every other kind.
    pub explicit: bool
    /// The line of the event in the source, counting from `1`.
    pub line: i64
    /// The column of the event in the source, counting from `1`.
    pub column: i64
}

One event of the YAML parse stream, as returned by events.

Events are in document order. Every sequence and mapping has a start and an end event, and the nodes between them are its entries; a mapping alternates keys and values.

EventKind

pub enum EventKind {
    /// The start of the stream. It is the first event.
    StreamStart
    /// The end of the stream. It is the last event.
    StreamEnd
    /// The start of a document. `Event.explicit` says whether a `---` marker was written.
    DocumentStart
    /// The end of a document. `Event.explicit` says whether a `...` marker was written.
    DocumentEnd
    /// The start of a sequence. `Event.style` is `Block` or `Flow`.
    SequenceStart
    /// The end of a sequence.
    SequenceEnd
    /// The start of a mapping. `Event.style` is `Block` or `Flow`.
    MappingStart
    /// The end of a mapping.
    MappingEnd
    /// A scalar, whose decoded text is in `Event.value`. A node with no content, such as a key with no value, is a `Plain` scalar with an empty value.
    Scalar
    /// An alias to an anchored node. `Event.anchor` is the anchor name.
    Alias
}

The kind of an Event.

encode

pub fn encode(n: *Node) -> str

Returns the node n as YAML text in block style, ending in a newline.

A sequence is written as - item lines and a mapping as key: value lines, indented by two spaces per level; an empty sequence is [] and an empty mapping {}. The Style of a node is ignored. A node reachable more than once through the same *Node is written once with an anchor and then as *alias: the anchor is the node's anchor when that is a valid name no other node uses and a1, a2 and so on otherwise. A string is plain when it would read back as the same string, which rules out text that resolves to a null, boolean or number, the YAML 1.1 words such as yes and off, and text that starts or ends with a space or has indicators in a position that matters. Otherwise it is single quoted, or double quoted with escapes when it holds control or other non-printable characters. A string with a line break is a literal | block when that can carry it exactly. A float is written with a . or an exponent, as .nan, .inf or -.inf when not finite. A Binary is written as !!binary and base64. A tag is written unless it is one that the value already implies, such as tag:yaml.org,2002:str. A key that is a collection, contains a line break or is longer than 1000 bytes is written with the ? form. The output is meant to read back to the same value through parse.

float

pub fn float(n: *Node) -> f64?

Returns the number n holds as a float, or none when n is neither a Float nor an Int. An Int is converted.

from_node

pub fn from_node[T](n: *Node) -> T ! serde.Error

Converts the node n into a T through std/serde.

A struct is read from a mapping by key: unknown keys are skipped, a missing key takes the field's default or none for an optional, and any other missing key fails with Missing. Mapping keys that are scalars are matched as their text, so 1, true and null match the names "1", "true" and "null". Integers are read from Int, floats from Float or Int, text from Str and a []u8 from a Binary node, which a !!binary scalar gives. An enum variant is a string, or a mapping with one key that names the variant. Fails with serde.Error.Mismatch when a node has another type, with Range for a negative integer read as unsigned, and with UnknownVariant and Missing as serde.read describes. In errors, at is the source line of the node.

Style

pub enum Style {
    /// A plain scalar, written without quotes.
    Plain
    /// A scalar in single quotes.
    SingleQuoted
    /// A scalar in double quotes.
    DoubleQuoted
    /// A block scalar introduced by `|`.
    Literal
    /// A block scalar introduced by `>`.
    Folded
    /// A sequence or mapping written in block style, with indentation.
    Block
    /// A sequence or mapping written in flow style, with `[]` or `{}`.
    Flow
}

How a node was written in the source, as recorded in Node.style and Event.style.

A scalar is Plain, SingleQuoted, DoubleQuoted, Literal or Folded, and a sequence or mapping is Block or Flow. encode does not use it.

Value

pub enum Value {
    /// A null: `~`, `null`, `Null`, `NULL` or an empty plain scalar, or a scalar tagged `!!null`.
    Null
    /// A boolean: `true`, `True`, `TRUE`, `false`, `False` or `FALSE`, or a scalar tagged `!!bool`.
    Bool(bool)
    /// An integer: decimal with an optional sign, `0x` hexadecimal or `0o` octal. It must fit an `i64`.
    Int(i64)
    /// A floating point number: decimal with a fraction or exponent, `.inf` with an optional sign, or `.nan`, each also as `.Inf`, `.INF`, `.NaN` or `.NAN`. A scalar tagged `!!float` that is an integer is read as a float.
    Float(f64)
    /// A string: any other plain scalar, any quoted or block scalar, and any scalar tagged `!!str` or `!`.
    Str(str)
    /// Bytes, from a scalar tagged `!!binary`, decoded from base64 with whitespace ignored.
    Binary([]u8)
    /// A sequence of nodes.
    Seq([]*Node)
    /// A mapping, as pairs in the order they were written.
    Map([]Pair)
}

A YAML value after the composer has resolved its tag, using the YAML 1.2 core schema.

events_with

pub fn events_with(source: str, options: Options) -> []Event ! Error

Returns the stream of events for the YAML text source, using options.

The events run from StreamStart to StreamEnd and follow the YAML 1.2 grammar, resolving tag handles and %TAG directives but not scalar types: a scalar is always text, whatever it looks like. Aliases are not expanded, and anchors are not checked, so an undefined alias is found only by parse. Fails with Syntax for text that is not valid YAML, and when sequences and mappings nest deeper than options.max_depth. It never fails with TooManyNodes.

parse_all_with

pub fn parse_all_with(source: str, options: Options) -> []*Node ! Error

Parses the YAML 1.2 text source into one root node per document, using options.

An empty stream gives no documents and an empty document is a Null node. Anchors belong to the document they appear in; an alias cannot refer to an anchor of an earlier document. Otherwise it follows parse_with, and fails with the same errors except for the one about more than one document.

parse_with

pub fn parse_with(source: str, options: Options) -> *Node ! Error

Parses the YAML 1.2 text source that holds one document, using options.

Scalars are resolved with the core schema, so an unquoted 1, true, 1.5 or ~ is not a string. Quoted and block scalars are always strings, and the tags !!str, !!null, !!bool, !!int, !!float and !!binary convert a scalar or fail. An alias gives the same Node as its anchor, not a copy. Merge keys (<<) are not special. An empty stream is a Null node. Fails with Syntax for invalid YAML, for a duplicate scalar key in one mapping, for a tag that does not suit its node, for an alias to an undefined anchor, and when the stream has more than one document; and with TooManyNodes when options.max_nodes is exceeded.

serialize

to_node

pub fn to_node[T](v: T) -> *Node ! serde.Error

Converts v into a node tree through std/serde.

A struct and a map become a mapping with string keys, a slice a sequence, an enum variant without fields a string and a variant with fields a mapping with one key, the variant's name. A []u8 becomes a Binary node and an optional that is none a Null node. The nodes have no tags or anchors, Plain style and no position. Fails with serde.Error.Range when a u64 is above 9223372036854775807.
