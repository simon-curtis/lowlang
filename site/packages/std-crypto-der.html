std/crypto/der

#crypto

import std/crypto/der

A DER cursor and the ASN.1 values the other crypto modules share. Reading: reader, read, peek, done, expect, enter, finish, whole, with unsigned, small_int, boolean, bits, named_bits, oid and time for the primitive types; it rejects indefinite and non-minimal lengths. Writing: encode, integer and sequence; trim_zeros drops the leading zero bytes of a big-endian magnitude. prime256v1 and secp384r1 return the named-curve OIDs that std/crypto/ecdsa and std/crypto/x509 share. std/crypto/x509, std/crypto/rsa and std/crypto/ecdsa build on it.

Imports std/io, std/time/date.

A cursor over DER encoded bytes. Made by reader.

done

pub fn done(d: *Der) -> bool

Returns whether d has read all of its bytes.

enter

pub fn enter(d: *Der, tag: u8) -> *Der ! io.Error

Reads the next element, which must have the given tag, and returns a cursor over its content.

Fails as expect does. Call finish on the result to require that the content was fully consumed.

expect

pub fn expect(d: *Der, tag: u8) -> Element ! io.Error

Reads the next element and fails with Malformed when its tag is not tag.

finish

pub fn finish(d: *Der) ! io.Error

Fails with Malformed unless d has read all of its bytes.

peek

pub fn peek(d: *Der) -> i64

Returns the tag of the next element without consuming it, or -1 at the end of the data.

read

pub fn read(d: *Der) -> Element ! io.Error

Reads the next element and advances past it.

Fails with Malformed when the data is truncated, the length is indefinite, longer than 4 octets or not minimally encoded, or the content runs past the end, and with Unsupported for a multi-octet tag.

unsigned

pub fn unsigned(d: *Der) -> []u8 ! io.Error

Reads the next element, which must be an INTEGER holding a non-negative value in minimal form, and returns its magnitude without the sign octet.

The value zero returns an empty slice. The result is a slice of the input. Fails with Malformed when the tag is not 0x02, the content is empty or negative, or a leading zero octet is not needed to keep it positive.

One DER element: a tag, its content and its complete encoding.

time

pub fn time(e: Element) -> i64 ! io.Error

Returns the Unix time in seconds of a UTCTime or GeneralizedTime element.

Only the forms RFC 5280 section 4.1.2.5 allows are accepted: YYMMDDHHMMSSZ with two-digit years 50 to 99 meaning 1950 to 1999 and 00 to 49 meaning 2000 to 2049, and YYYYMMDDHHMMSSZ. Fails with Malformed for any other form or an invalid date or time.

Functions

bits

pub fn bits(content: []u8) -> []u8 ! io.Error

Returns the bytes of a BIT STRING whose last octet has no unused bits.

Fails with Malformed when the content is empty or its unused-bits count is not 0.

boolean

pub fn boolean(content: []u8) -> bool ! io.Error

Returns the value of a DER BOOLEAN.

Fails with Malformed unless the content is a single octet that is 0x00 or 0xFF.

encode

pub fn encode(tag: u8, content: []u8) -> []u8

Returns the DER encoding of an element with the given tag and content.

The length is written in the short form below 128 and otherwise in the long form with as few octets as it needs.

integer

pub fn integer(magnitude: []u8) -> []u8

Returns the DER INTEGER for the non-negative big-endian number magnitude.

Leading zero octets are dropped, a zero octet is added when the top bit would otherwise mark the value negative, and an empty magnitude encodes zero.

named_bits

pub fn named_bits(content: []u8) -> i64 ! io.Error

Returns the set bits of a BIT STRING as an integer, where bit n of the string, counting from the most significant bit of the first octet, is bit n of the result.

Fails with Malformed for empty content, an unused-bits count above 7, more than 8 octets of bits, or an unused bit that is set.

oid

pub fn oid(content: []u8) -> str ! io.Error

Returns an OBJECT IDENTIFIER as dotted decimal text such as 2.5.4.3.

Fails with Malformed for empty content, an unterminated arc or an arc with a padding octet, and with Unsupported for an arc that does not fit in 48 bits.

reader

pub fn reader(data: []u8) -> *Der

Returns a cursor positioned at the start of data.

sequence

pub fn sequence(parts: [][]u8) -> []u8

Returns a DER SEQUENCE whose content is parts joined in order.

Each part is already encoded, for example by integer or encode.

small_int

pub fn small_int(content: []u8) -> i64 ! io.Error

Returns the value of a non-negative DER INTEGER with at most 7 content octets.

Fails with Malformed for an empty or longer content, a negative value or a non-minimal encoding.

trim_zeros

pub fn trim_zeros(magnitude: []u8) -> []u8

Returns the big-endian number magnitude without its leading zero bytes.

Returns an empty slice when magnitude is empty or all zero. The result shares the memory of magnitude.

whole

pub fn whole(data: []u8, tag: u8) -> Element ! io.Error

Returns the single element with the given tag that makes up all of data.

Fails with Malformed when the tag differs or bytes follow the element.
