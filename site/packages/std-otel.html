std/otel

#observability

import std/otel

OpenTelemetry traces, metrics and logs with W3C propagation, OTLP/HTTP protobuf and JSON, OTLP/gRPC and console exporters, and the instrumentation used by std/http, std/web, std/sql/postgres, std/sql/sqlserver and std/orm.

Imports std/base64, std/compress/deflate, std/crypto, std/file, std/http, std/io, std/json, std/os, std/protobuf, std/rand, std/sql, std/text, std/time.

Call

pub struct Call {
    ...
}

An instrumented operation in progress, returned by server_span and db_span and ended with end_server or end_with. A call made while no SDK is active does nothing. A call made inside an operation of the same kind joins that operation and does not end it.

end_server

pub fn end_server(c: Call, route: str, status: i64)

Finishes the server call c for a response with status. A non-empty route renames the span to the method and route and sets http.route. http.response.status_code is set, and a status of 500 or more also sets error.type and a failed status. A call that owns the span then ends it, restores the context that was current when the call began and records the http.server.request.duration histogram, in seconds, with the method, route, status code, protocol version and error type.

end_with

pub fn end_with(c: Call, error_type: str)

Finishes the database call c. A non-empty error_type sets error.type and a failed status carrying the same text. A call that owns the span then ends it, restores the context that was current when the call began and records the db.client.operation.duration histogram, in seconds, with the system, namespace, operation, collection, response code, server address, port and error type that were set.

recording

pub fn recording(c: Call) -> bool

Reports whether the call is tied to a span, which is false when no SDK was active when it began.

tag

pub fn tag(c: Call, key: str, value: str)

Sets the string attribute key on the call's span. The attribute is also kept for use as a metric attribute when the call ends. Nothing happens when the call is not recording.

tag_int

pub fn tag_int(c: Call, key: str, value: i64)

Sets the integer attribute key on the call's span, and keeps it for the metric as tag does.

The settings install builds an SDK from. With no span processors no spans are recorded, with no metric readers no metric instruments record and with no log processors no log records are emitted.

install

pub fn install(config: Config) -> Sdk

Builds an SDK from config, installs it for the calling green thread and returns the Sdk that owns it. Green threads spawned afterwards inherit it. Periodic metric readers start collecting in the background. Dropping the result shuts the SDK down, so a program keeps it for its lifetime, usually in main.

install_handle

pub fn install_handle(config: Config) -> *SdkHandle

Builds an SDK from config and installs it for the calling green thread, like install, but returns the bare handle. The caller shuts it down with shutdown_on.

Context

pub struct Context {The active span, which is not recording when none was started.    pub span: SpanThe baggage members in effect.    pub baggage: []EntryWhether telemetry is switched off for work done in this context. suppressed sets it.    pub suppressed: bool
    ...
}

The telemetry state of a green thread: the active span, the baggage, a flag that suppresses telemetry and the installed SDK. A Context is never modified; the with_ functions return an updated copy. A green thread holds one in its context slot, and spawn copies the slot to the new green thread.

attach

pub fn attach(c: *Context) -> *Context

Makes c the calling green thread's context and returns the context it replaces. Pass the result to detach to restore it.

baggage_value

pub fn baggage_value(c: *Context, key: str) -> str?

Returns the value of the baggage member key in c, or none when there is none.

detach

pub fn detach(outer: *Context)

Restores outer, a context returned by attach, as the calling green thread's context.

extract_into

pub fn extract_into(c: *Context, headers: []http.Header) -> *Context

Returns a context with the span and baggage found in headers. A valid traceparent header becomes the active span, a remote one with the joined tracestate headers as its state, and a non-empty baggage with at least one valid member replaces the baggage. Repeated headers are joined with commas. Each part is read only when its propagator is on. Returns c itself when nothing was found.

in_context

pub fn in_context[T](c: *Context, body: fn() -> T) -> T

Runs body with c as the calling green thread's context and returns its result. The previous context is restored when body returns.

inject

pub fn inject(c: *Context, mut headers: []http.Header)

Writes the trace and baggage headers for c into headers, replacing any of the same name. traceparent is written when the SDK's trace-context propagator is on and c has a valid span, and tracestate with it when the state is not empty. baggage is written when the baggage propagator is on and the member list formats to something. Both propagators are on when c has no SDK.

set_baggage

pub fn set_baggage(c: *Context, key: str, value: str) -> *Context

Returns a copy of c whose baggage has key set to value and an empty metadata. An existing member with the same key is replaced, and the new member is placed last.

suppressed

pub fn suppressed(c: *Context) -> *Context

Returns a copy of c in which telemetry is suppressed: no spans, metrics or log records are produced and the HTTP hooks stay idle. The OTLP exporters send under a suppressed context so that exporting is not itself traced.

with_baggage

pub fn with_baggage(c: *Context, entries: []Entry) -> *Context

Returns a copy of c carrying entries as its baggage in place of the existing members.

with_span

pub fn with_span(c: *Context, s: Span) -> *Context

Returns a copy of c whose active span is s.

Measure

pub struct Measure[T: Number] {
    ...
}

A handle to an instrument that records values of type T. Copies refer to the same instrument. An instrument made when no SDK with a metric reader is installed is inert: its calls do nothing and enabled_measure returns false. An integer T makes the metric integer valued and a floating-point T makes it floating-point.

add

pub fn add[T: Number](i: Measure[T], value: T, attributes: []Attribute)

Adds value to a counter or an up-down counter for the series identified by attributes. A counter ignores a negative value and any other kind of instrument ignores the call. Once the instrument holds 1999 series, a new attribute set is folded into one series with the attribute otel.metric.overflow set to true. A repeated key in attributes keeps its last value.

enabled_measure

pub fn enabled_measure[T: Number](i: Measure[T]) -> bool

Reports whether the instrument records, which is false when it was made without an SDK or without a metric reader. Use it to skip work that only builds a measurement.

record

pub fn record[T: Number](i: Measure[T], value: T, attributes: []Attribute)

Records value on a histogram or a gauge for the series identified by attributes. A histogram ignores a negative value and any other kind of instrument ignores the call. The series limit and attribute handling are those of add.

Meter

pub struct Meter {The scope recorded on every instrument the meter creates.    pub scope: Scope
}

A source of metric instruments for one instrumentation scope.

counter

pub fn counter[T: Number](m: Meter, name: str, unit: str, description: str) -> Measure[T]

Creates a counter named name, a sum that only increases; add adds to it and ignores negative values. unit and description are free text. A second instrument with the same scope and name returns the first one unchanged.

gauge

pub fn gauge[T: Number](m: Meter, name: str, unit: str, description: str) -> Measure[T]

Creates a gauge named name that keeps the last value record was given for each attribute set. A second instrument with the same scope and name returns the first one unchanged.

histogram

pub fn histogram[T: Number](m: Meter, name: str, unit: str, description: str, bounds: []f64) -> Measure[T]

Creates a histogram named name that record adds values to. bounds are the increasing upper bounds of the buckets; an empty list uses default_bounds. record ignores negative values. A second instrument with the same scope and name returns the first one unchanged.

observable_counter

pub fn observable_counter[T: Number](m: Meter, name: str, unit: str, description: str, callback: fn() -> []Observation[T])

Registers an observable counter named name whose total callback returns on every collection. The callback runs each time the reader collects; it returns the current cumulative value for each attribute set and a repeated attribute set keeps the first. With delta temporality the reported value is the change since the previous collection.

observable_gauge

pub fn observable_gauge[T: Number](m: Meter, name: str, unit: str, description: str, callback: fn() -> []Observation[T])

Registers an observable gauge named name whose current value callback returns on every collection. See observable_counter for how the callback is used. A gauge always reports its latest observation.

observable_up_down_counter

pub fn observable_up_down_counter[T: Number](m: Meter, name: str, unit: str, description: str, callback: fn() -> []Observation[T])

Registers an observable up-down counter named name whose current value callback returns on every collection. See observable_counter for how the callback is used.

up_down_counter

pub fn up_down_counter[T: Number](m: Meter, name: str, unit: str, description: str) -> Measure[T]

Creates an up-down counter named name, a sum that add can both increase and decrease. A second instrument with the same scope and name returns the first one unchanged.

otlp_span_exporter

pub fn otlp_span_exporter(o: OtlpOptions) -> SpanExporter

Returns an exporter that sends spans to the collector. export returns true once the collector accepts a batch and false when it rejects it or every attempt fails; an empty batch returns true without a request, and after shutdown every call returns false. HTTP statuses 429, 502, 503 and 504, and a failed connection, are retried after the backoff or the server's Retry-After. Over gRPC, the status codes CANCELLED, DEADLINE_EXCEEDED, ABORTED, OUT_OF_RANGE, UNAVAILABLE and DATA_LOSS are retried and RESOURCE_EXHAUSTED is retried when the response carries a RetryInfo delay. Requests are sent with telemetry suppressed. shutdown closes idle connections.

in_span

pub fn in_span[T](t: Tracer, name: str, body: fn(Span) -> T) -> T

Runs body inside a new span named name and returns its result. The span is the calling green thread's current span while body runs, so spans started in body become its children. start_with

pub fn start_with(t: Tracer, name: str, o: StartOptions) -> Span

Starts a span named name under the parent chosen by o and returns it. The span is not made the calling green thread's current span; in_span does that. The span is not recording and carries its parent's context when there is no SDK, the parent context is suppressed, the SDK has no span processors or it has been shut down. Otherwise the span gets a new span id and inherits the parent's trace id and tracestate, or starts a new trace when the parent is not valid. The sampler then decides: a rejected span has the sampled flag clear and is not recorded, but its context can still be propagated. A recorded span has the sampled flag set, attributes and links trimmed to the SDK limits, and every span processor's on_start called with it. The caller ends the span with end.

config_from_env

pub fn config_from_env(env: [str: str]) -> Config

Returns an SDK configuration read from the standard OTEL_* variables in env. The span, metric and log exporters come from OTEL_TRACES_EXPORTER, OTEL_METRICS_EXPORTER and OTEL_LOGS_EXPORTER, each a comma-separated list that defaults to otlp. otlp is an OTLP exporter built by otlp_options_from_env and console writes to standard error; any other name, including none, adds nothing.
