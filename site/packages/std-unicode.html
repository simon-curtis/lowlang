std/unicode

#encoding #text

import std/unicode

Normalization (Unicode 16.0.0): nfd, nfkd, nfc and nfkc; combining_class; full case folding with casefold; search_key, which case-folds, applies NFKD and drops combining marks in one pass. Properties: category, is_letter, is_upper, is_lower, is_digit, is_space, is_punct, is_identifier_start and the other predicates; east_asian_width, display_width and text_width; script. Case mapping: to_upper, to_lower and to_title, and upper and lower with SpecialCasing but without final-sigma or locale rules. Segmentation: UAX #29 graphemes, grapheme_count and grapheme_end. UTF-8 helpers: decode_rune, encode_rune, utf8_valid, utf8_to_valid. Category, width and identifier data are Unicode 16.0.0; script, grapheme break and case data come from 17.0.0 restricted to characters assigned in 16.0.0. The tables are generated by cmd/tablegen and linked only when a function that reads them is reachable.

Imports std/text.

Functions

casefold

pub fn casefold(s: str) -> str

Returns the Unicode full case folding of s, for caseless comparison. Folded strings of two texts are equal when the texts match without regard to case, and one code point may fold to several, so ß becomes ss. An ASCII string is lowercased. Combining marks are kept, so apply nfc or nfd to both sides when canonically equivalent forms must match.

category

pub fn category(c: u32) -> Category

Returns the general category of the code point c. Unassigned code points and values above 0x10FFFF give Unassigned.

combining_class

pub fn combining_class(c: u32) -> u8

Returns the Unicode canonical combining class of c, from 0 to 254. 0 marks a starter, and is also the value for an unassigned code point and for one above 0x10FFFF.

decode_rune

pub fn decode_rune(s: str, at: i64) -> Rune

Decodes the code point that starts at byte index at of s. Overlong forms, surrogates and values above 0x10FFFF are invalid. An invalid byte gives 0xFFFD with size 1, and an index outside s gives 0xFFFD with size 0.

display_width

pub fn display_width(c: u32) -> i64

Returns the number of terminal columns c takes: 0, 1 or 2. Nonspacing and enclosing marks, control codes, format characters and the Hangul medial and final jamo (U+1160 to U+11FF and U+D7B0 to U+D7FF) take none. U+00AD takes one. Characters with the Wide or Fullwidth East Asian Width take two, and all others take one.

east_asian_width

pub fn east_asian_width(c: u32) -> Width

Returns the East Asian Width property of c.

encode_rune

pub fn encode_rune(c: u32) -> str

Returns the UTF-8 encoding of c as a string, using U+FFFD when c is not a valid code point.

grapheme_count

pub fn grapheme_count(s: str) -> i64

Returns the number of extended grapheme clusters in s.

grapheme_end

pub fn grapheme_end(s: str, at: i64) -> i64

Returns the byte index where the extended grapheme cluster that starts at at in s ends. Clusters follow Unicode Standard Annex 29: CR LF, combining marks, Hangul syllable sequences, emoji with variation selectors and zero-width-joiner sequences, regional-indicator pairs and Indic conjunct sequences stay together. at must be at the start of a character. The last cluster ends at s.len.

graphemes

pub fn graphemes(s: str) -> []str

Returns the extended grapheme clusters of s as substrings. The pieces are slices of s and joining them gives s back.

pub fn is_alphanumeric(c: u32) -> bool

Returns whether c is a letter or a number. Marks are not included.

Returns whether c has the Unicode XID_Start property, so it can begin an identifier.

Returns whether c is a lowercase letter, category Ll.

pub fn is_number(c: u32) -> bool

Returns whether c is a number: category Nd, Nl or No.

Returns whether c has the Unicode White_Space property. This includes the ASCII whitespace characters, U+0085, U+00A0, U+2028, U+2029 and the Zs spaces.

Returns whether c is a symbol: category Sm, Sc, Sk or So.

is_upper

pub fn is_upper(c: u32) -> bool

Returns whether c is an uppercase letter, category Lu.

lower

pub fn lower(s: str) -> str

Returns s with every letter in its Unicode lowercase form. Full mappings are applied and do not depend on locale or context, so Σ always becomes σ. An ASCII string is handled as text.lower does.

nfc

pub fn nfc(s: str) -> str

Returns s in normalisation form C: canonical decomposition followed by canonical composition. Jamo compose into Hangul syllables. An ASCII string is returned as it is.

nfd

pub fn nfd(s: str) -> str

Returns s in Unicode normalisation form D: canonical decomposition with combining marks in canonical order. Hangul syllables decompose into jamo. An ASCII string is returned as it is.

nfkc

pub fn nfkc(s: str) -> str

Returns s in normalisation form KC: compatibility decomposition followed by canonical composition. An ASCII string is returned as it is.

nfkd

pub fn nfkd(s: str) -> str

Returns s in normalisation form KD: compatibility decomposition with combining marks in canonical order. Compatibility forms such as ﬁ and ² become their plain equivalents. An ASCII string is returned as it is.

rune_len

pub fn rune_len(c: u32) -> i64

Returns the number of bytes c takes in UTF-8, from 1 to 4, or -1 when c is not a valid code point.

script

pub fn script(c: u32) -> Script

Returns the script of c. Code points of a script without a variant give Other, and unassigned ones give Unknown.

search_key

pub fn search_key(s: str) -> str

Returns a key for accent- and case-insensitive searching of s. s is case folded, decomposed with the compatibility mappings and stripped of every code point with a non-zero combining class, so Café and cafe give the same key. An ASCII string is lowercased.

text_width

pub fn text_width(s: str) -> i64

Returns the sum of display_width over the code points of s. Code points are measured one at a time, so a grapheme cluster built from several of them adds their widths together.

to_lower

pub fn to_lower(c: u32) -> u32

Returns the simple lowercase mapping of the code point c, or c when it has none.

to_title

pub fn to_title(c: u32) -> u32

Returns the simple titlecase mapping of the code point c, or c when it has none. For ǆ this is ǅ rather than the uppercase Ǆ.

to_upper

pub fn to_upper(c: u32) -> u32

Returns the simple uppercase mapping of the code point c, or c when it has none. The mapping is always a single code point, so ß is unchanged. Use upper for strings.

upper

pub fn upper(s: str) -> str

Returns s with every letter in its Unicode uppercase form. Full mappings are applied, so one character can become several: ß becomes SS. Mappings do not depend on locale or context. An ASCII string is handled as text.upper does.

utf8_invalid_at

pub fn utf8_invalid_at(s: str) -> i64

Returns the byte index of the first invalid UTF-8 sequence in s, or -1 when s is valid.

utf8_to_valid

pub fn utf8_to_valid(s: str) -> str

Returns s with each invalid byte replaced by U+FFFD. Returns s itself when it is already valid.

utf8_valid

pub fn utf8_valid(s: str) -> bool

Returns whether s is valid UTF-8.

valid_rune

pub fn valid_rune(c: u32) -> bool

Returns whether c is a Unicode scalar value: not a surrogate and not above 0x10FFFF.
