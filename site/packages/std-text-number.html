import std/text/number

Functions

compact

pub fn compact(n: i64) -> str

Returns n abbreviated with a suffix for thousands, such as 999, 1.5K or 12M. The suffixes are K, M, B, T, Qa and Qi, with no space before them. A value below 10 of its unit shows one decimal, dropped when it is 0, and a larger value is rounded to an integer. A negative n has a leading -.

format_bytes

pub fn format_bytes(n: i64, binary: bool) -> str

Returns n as a human-readable byte size such as 1.5 KiB or 999 B. binary selects the units: true uses powers of 1024 named KiB to EiB, false uses powers of 1000 named kB to EB. The unit is the largest that keeps the value at 1 or above. A value below 10 of its unit shows one decimal, dropped when it is 0, and a larger value is rounded to an integer. A negative n has a leading -.

grouped

pub fn grouped(n: i64, sep: str) -> str

Returns n in decimal with sep between each group of three digits, and a leading - when negative.

ordinal

pub fn ordinal(n: i64) -> str

Returns n in decimal followed by its English ordinal suffix, such as 1st, 22nd, 103rd and 11th.

parse_bytes

pub fn parse_bytes(s: str) -> i64 ! NumberError

Parses a byte size such as 1.5 KiB, 10MB or 512 and returns the number of bytes. The text is an optional sign, digits with an optional . and fraction digits, optional whitespace and a unit. Leading and trailing whitespace is ignored. The unit is matched without regard to case and is empty or B for bytes, K, M, G, T, P or E optionally followed by B for powers of 1000, or followed by i or iB for powers of 1024. A fractional result is rounded to the nearest byte.

Fails with Empty for blank input, Malformed at the offset where digits were expected, UnknownUnit for any other unit, TooPrecise when the fraction has more than 18 digits after trailing zeros, and OutOfRange when the result does not fit in an i64.

parse_roman

pub fn parse_roman(s: str) -> i64 ! NumberError

Parses a Roman numeral and returns its value. Letters may be either case. Only the canonical form that roman produces is accepted, so IV parses and IIII and IC do not.

Fails with Empty for an empty string, with Malformed at the index of the first byte that is not a Roman letter or that departs from the canonical form, and with OutOfRange when the value exceeds 3999.

percent

pub fn percent(ratio: f64, digits: i64) -> str

Returns ratio as a percentage with digits digits after the decimal point, so percent(0.256, 1) gives 25.6%. A negative digits is treated as 0. Rounding is that of text.fixed.

percent_of

pub fn percent_of(part: i64, whole: i64, digits: i64) -> str

Returns part as a percentage of whole with digits digits after the decimal point. A whole of 0 gives NaN% or inf%, as the division produces.

roman

pub fn roman(n: i64) -> str ! NumberError

Returns n as an uppercase Roman numeral. Fails with OutOfRange when n is outside 1 to 3999.

si

pub fn si(v: f64, unit: str) -> str

Returns v scaled to an SI prefix with three significant digits, followed by unit. Behaves as si_digits with digits of 3.

si_digits

pub fn si_digits(v: f64, unit: str, digits: i64) -> str

Returns v scaled to an SI prefix with digits significant digits, followed by unit, such as 1.5 kHz or 47 µF. The prefix runs from y (10^-24) to Y (10^24), and a magnitude beyond that range keeps the nearest prefix and shows more integer digits. The number is rounded half to even from the exact value of v and trailing zeros are removed. The integer part is never cut, so a digits below the number of integer digits still shows all of them. A space separates the number from the prefix and unit, and is omitted when both are empty. A zero is shown as 0 with no prefix. NaN, inf and -inf are shown as such.

words

pub fn words(n: i64) -> str

Returns n spelled out in English, such as forty-two or one thousand two hundred. Tens and units are joined by a hyphen, no and is used, a negative n starts with minus, and 0 is zero. Every i64 is supported.
