std/io

#io

import std/io

Error, the error type shared by the I/O, codec and protocol modules. Stream, a copyable struct of read, write and close closures that views a resource. Guard and Lease (guard, enter, retire), the shared state that makes a closed descriptor fail with NotConnected instead of reaching a reused descriptor. A buffered Reader over a stream or, with bytes_reader, over a buffer, with read_line, read_exact, read_up_to, read_some, read_byte, buffered and fill. write_all, read_all, buffer(n), copy, and the fixed-width integer codec in both byte orders: reads (be16, be24, be32, be64 and the le forms as i64, u16_be, u32_be, u64_be and the _le forms as unsigned types, uint_be and uint_le for any width from 1 to 8 bytes as u64, and u16_le_str, u32_le_str and u64_le_str over a str), appends (put_be16 through put_be64, put_le16 through put_le64, and put_be and put_le for any width up to 8 bytes) and in-place stores (set_be16 through set_be64, set_le16 through set_le64).

Imports std/simd.

The error type shared by the I/O, codec and protocol modules.

Operating system error numbers map onto the named variants through errno; numbers without a variant become Os.

Guard

pub struct Guard {
    ...
}

Shared state that tracks the uses of a resource so a closed descriptor fails with NotConnected instead of reaching a reused one.

Made by guard; each use holds a Lease from enter, and retire stops new uses.

enter

pub fn enter(g: *Guard) -> Lease ! Error

Registers a use of the guarded resource and returns the lease that ends it when dropped.

Fails with NotConnected once the guard has been retired, so a closed descriptor is never reached.

retire

pub fn retire(g: *Guard)

Closes the guard to new uses.

Runs wake so that blocked operations return, then runs release immediately if no lease is held, or when the last lease is dropped. Later calls do nothing.

Lease

pub struct Lease {
    ...
}

A scope token returned by enter that keeps a Guard in use.

Dropping the lease releases the use. When the guard has been retired and the last lease is dropped, the guard's release runs.

Reader

pub struct Reader {
    ...
}

A buffered reader over a Stream or a fixed byte slice, created by reader or bytes_reader.

Used through a pointer. Not safe for concurrent use.

buffered

pub fn buffered(r: *Reader) -> i64

Returns the number of bytes buffered in the reader and available without reading the stream.

fill

pub fn fill(r: *Reader) -> i64 ! Error

Reads more bytes from the stream into the reader's buffer and returns the count, or 0 at end of input.

Blocks until the stream returns data. Buffered bytes that are not yet consumed are kept. Fails with TooLarge when the buffer is full of unconsumed bytes, and with any error the stream returns. A reader made by bytes_reader returns 0.

read_byte

pub fn read_byte(r: *Reader) -> u8 ! Error

Reads and returns the next byte.

Blocks until a byte is available. Fails with Eof at end of input.

read_exact

pub fn read_exact(r: *Reader, n: i64) -> []u8 ! Error

Reads exactly n bytes and returns them in a new slice.

Blocks until n bytes have been read. Fails with Eof if the input ends first, in which case the bytes already read are discarded, and with any error the stream returns.

read_line

pub fn read_line(r: *Reader) -> str ! Error

Reads up to the next line feed and returns the line without its terminator.

A \r directly before the \n is removed as well. The returned string is a copy. Blocks until a full line is available.

Fails with Eof when the input ends before a line feed, including when text without a terminator remains; that text stays buffered and can be read with read_some. Fails with TooLarge when a line does not fit in the 16384-byte buffer.

read_some

pub fn read_some(r: *Reader, dst: []u8) -> i64 ! Error

Reads up to dst.len bytes into dst and returns the count, or 0 at end of input.

Returns buffered bytes first. When nothing is buffered it blocks for one read of the stream, and a dst at least as long as the reader's buffer is read into directly, bypassing the buffer. Returns fewer bytes than requested when that is all that is available.

read_up_to

pub fn read_up_to(r: *Reader, dst: []u8) -> i64 ! Error

Reads into dst until it is full or the input ends, and returns the count read.

The count is smaller than dst.len only at end of input. Blocks until dst is full or the input ends. Fails with any error the stream returns, in which case the bytes already read are in dst but not reported.

reader_stream

pub fn reader_stream(r: *Reader) -> Stream

Returns the stream the reader reads from.

Bytes already buffered by the reader are not returned by the stream.

Stream

A copyable view of a readable and writable resource, made of read, write and close closures.

Copies of a Stream refer to the same underlying resource.

read_all

pub fn read_all(s: Stream) -> []u8 ! Error

Reads the stream until end of input and returns everything read.

Blocks until the stream reports end of input. Fails with the first error read returns, discarding the bytes read so far. Does not close the stream.

reader

pub fn reader(s: Stream) -> *Reader

Returns a buffered reader over s with a 16384-byte buffer.

write_all

pub fn write_all(s: Stream, data: []u8) ! Error

Writes all of data to the stream, calling write repeatedly until every byte is accepted.

Fails with the first error write returns; bytes written before the error are not reported.

write_str

pub fn write_str(s: Stream, text: str) ! Error

Writes the bytes of text to the stream in full, as write_all does.

guard

pub fn guard(wake: fn(), release: fn()) -> *Guard

Returns a guard that coordinates use of a resource with its closing.

wake runs once when the guard is retired, to unblock operations that are waiting on the resource. release runs once when the guard is retired and no leases remain, and is where the resource is freed.
