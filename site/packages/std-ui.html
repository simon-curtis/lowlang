std/ui

#ui

import std/ui

Elements and their builders, signals, memos, effects and cached views, the context, the app loop and windows that share its GPU, hit testing, focus, event dispatch, key bindings and actions, text input and the text field, the clipboard, opening URLs, window controls, scrolling, uniform and variable lists, canvases, images, deferred and anchored layers, tooltips, drag and drop, animations, and background tasks and timers.

Imports std/cancel, std/image, std/text, std/time, std/ui/font, std/ui/geometry, std/ui/gpu, std/ui/layout, std/ui/platform, std/ui/scene, std/ui/svg, std/ui/text, std/unicode.

Context

pub struct Context {
    ...
}

The state of one user interface apart from its window: the signals' owner, the text system, and what the pointer and the keyboard are on.

A context is a handle: copies share the state. frame and dispatch drive it without a window or a GPU, as run drives it with them.

active_drag

Returns the value being dragged, or none when no drag is under way.

add_fonts

Adds fonts, such as fonts the application embeds, to those font_family chooses among, ahead of the system's own.

after

pub fn after(cx: Context, ms: i64, f: fn()) -> Task

Runs f on the context's green thread once ms milliseconds have passed, unless the task is cancelled first.

background_task

pub fn background_task[T](cx: Context, work: fn(*cancel.Token) -> T, done: fn(T)) -> Task

Runs work on a green thread of its own, which the scheduler may run on another OS thread, then runs done with its result on the context's green thread before the next frame.

work receives the task's token, to stop early with cancel.check or cancel.pause once the task is cancelled. A cancelled task never runs done.

bind

pub fn bind(cx: Context, keys: str, action: str, context: str) ! BindError

Binds the keystrokes keys to the action action wherever the key context predicate context holds; "" holds everywhere.

keys is one or more keystrokes separated by spaces, such as "ctrl-shift-k" or "g g": any of ctrl, alt, shift and super (also cmd or win), each followed by -, then a character or enter, escape, tab, backspace, delete, left, right, up, down, home, end, pageup, pagedown, space or f1 to f24. The action "" binds nothing and disables the bindings of the same keys it outranks.

bind_field_keys

pub fn bind_field_keys(cx: Context) ! BindError

Binds the keys a text field's actions take by default in the key context TextField: Backspace, Delete, Left, Right, Home and End, with Shift extending the selection and Ctrl acting on words, and Ctrl with A, C, X and V for select all, copy, cut and paste.

bindings_for

pub fn bindings_for(cx: Context, name: str) -> []str

Returns the keystrokes of each binding of the action name whose predicate holds where focus is, the one that wins first.

blur

pub fn blur(cx: Context)

Leaves no element focused.

cached

pub fn cached(cx: Context, key: str, build: fn() -> Element) -> Element

Returns an element that stands for what build returns, built again only when a signal or memo it read during its last build has changed, or the focus, pending keys, drag, a scroll offset, or the window's status or decorations have.

key names the view across frames, and a view that a frame does not lay out is dropped. build reads the state it depends on through signals, memos and the context; a captured value that changes without them leaves the view as it was. The element's builders belong inside build, because the element returned here is replaced by the view's.

field

pub fn field(cx: Context, f: TextField, name: str, size: f32) -> Element

Returns the element that edits f, with the id name, with text size logical pixels high in the font it inherits.

It takes focus when pressed, selects a word on a double click and the whole text on a triple click, takes typed text and compositions through on_input, draws the selection, the composition underlined and, while focused, the caret, which blinks every 500 milliseconds once 500 milliseconds pass without the text or the caret changing, and selects with the pointer. Its actions, in the key context TextField, are field.backspace, field.delete, field.left, field.right, field.select_left, field.select_right, field.home, field.end, field.select_home, field.select_end, field.word_left, field.word_right, field.select_word_left, field.select_word_right, field.backspace_word, field.delete_word, field.select_all, field.copy, field.cut and field.paste; bind_field_keys binds their usual keys.

Returns the key of the focused element, its id or its position in the tree, or "" when none is focused.

frame

pub fn frame(cx: Context, render: fn() -> Element, size: geometry.Size, scale: f32) -> scene.Scene

Builds the tree render returns, lays it out in a window of size logical pixels and paints it into a scene of scale device pixels per logical pixel.

The hitboxes of the painted elements replace those of the last frame, so dispatch finds the elements this frame drew. A frame is due again at once while an animation runs.
