std/big/rat

#math

import std/big/rat

Normalised rationals over big.Int: ratio, parse (a/b, decimals, exponents), the four operations, inv, cmp, to_fixed, to_f64.

Imports std/big, std/big/decimal, std/text.

Examples

recipe

import std/big
import std/big/decimal
import std/big/rat

fn show(label: str, r: rat.Rat) {
    print("{label}: {rat.to_str(r)}")
}

/// Scales a recipe written in fractions from 4 servings to 6 without rounding, adds the results exactly, and sums the first 20 harmonic fractions exactly.
fn main() ! big.Error {
    let flour = rat.parse("3/4")?
    let sugar = rat.parse("1/3")?
    let butter = rat.parse("2.5")?

    let scale = rat.ratio(big.from_i64(6), big.from_i64(4))?
    show("flour for 6", rat.mul(flour, scale))
    show("sugar for 6", rat.mul(sugar, scale))
    show("butter for 6", rat.mul(butter, scale))

    let total = rat.add(rat.add(flour, sugar), butter)
    show("cups at 4 servings", total)
    print("as a decimal: {decimal.to_str(rat.to_decimal(total, -4, HalfEven))}")
    print("to two places: {rat.to_fixed(total, 2)}")
    print("is a whole number: {rat.is_int(total)}")
    print("sugar is less than flour: {rat.cmp(sugar, flour) < 0}")

    var harmonic = rat.from_i64(0)
    for n in 1..21 {
        harmonic = rat.add(harmonic, rat.ratio(big.one(), big.from_i64(n))?)
    }
    show("H(20)", harmonic)
    print("H(20) as f64: {rat.to_f64(harmonic)}")

    let _ = rat.ratio(big.one(), big.zero()) catch {
        DivideByZero => {
            print("a zero denominator is refused")
            return
        }
        _ => return
    }
}

Rat

pub struct Rat {
    ...
}

An exact rational number num / den over big.Int.

A Rat is always in lowest terms and its denominator is positive, so equal values have identical parts.

to_decimal

pub fn to_decimal(r: Rat, exponent: i32, mode: decimal.Rounding) -> decimal.Decimal

Returns r as a decimal with the given exponent, rounded according to mode.

The result is r divided by 10^exponent rounded to an integer coefficient, so an exponent of -2 keeps two fractional digits.

to_f64

pub fn to_f64(r: Rat) -> f64

Returns the f64 nearest to r, rounding ties to even.

Values beyond the f64 range give an infinity of the same sign.

to_fixed

pub fn to_fixed(r: Rat, places: i64) -> str

Returns r as a decimal string with exactly places fractional digits, rounding half to even.

A negative places rounds to a power of ten and writes the zeros out.

to_str

pub fn to_str(r: Rat) -> str

Returns r as "n/d", or as "n" when r is an integer.

parse

pub fn parse(s: str) -> Rat ! big.Error

Parses a rational written as a/b or as a decimal.

In the a/b form both sides are base 10 integers with an optional sign. Otherwise the text is a decimal with an optional sign, fraction and e exponent, as accepted by decimal.parse. Fails with Empty when a part has no digits, with BadDigit carrying the byte offset in s of the first offending character, with DivideByZero when the denominator is zero and with Overflow when a decimal exponent does not fit an i32.

ratio

pub fn ratio(n: big.Int, d: big.Int) -> Rat ! big.Error

Returns the rational n / d reduced to lowest terms with a positive denominator.

Fails with DivideByZero when d is zero.
