std/cbor

#formats

import std/cbor

CBOR (RFC 8949): the Value model, a decoder with depth and length limits, a deterministic encoder, diagnostic notation, and serialize[T] and deserialize[T].

Imports std/io, std/serde, std/slices, std/text.

as_integer

pub fn as_integer(v: Value) -> i64?

Returns the value of an Unsigned or Negative that fits an i64, and none for any other value, including integers outside that range.

diagnostic

pub fn diagnostic(v: Value) -> str

Returns the diagnostic notation of v (RFC 8949, section 8) on one line, for logs and tests.

Maps print as {key: value}, arrays as [...], a tag as number(content), byte strings as h'hex', simple values as simple(n) and the others as true, false, null and undefined. Text is quoted with \" and \\ escaped and every character outside printable ASCII written as \uXXXX, using a surrogate pair above U+FFFF. Floats print as NaN, Infinity, -Infinity or a decimal that always contains a .. Integers print in decimal, including Negative down to -18446744073709551616.

encode

pub fn encode(v: Value) -> []u8

Encodes v as deterministic CBOR (RFC 8949, section 4.2).

Integers, lengths and tag numbers use the shortest head. Strings, arrays and maps have definite lengths. Map entries are sorted by the bytes of their encoded keys, so the same map encodes to the same bytes whatever its order; entries with the same key are not removed. A float is written in the shortest of half, single and double precision that holds its value exactly, and every NaN is written as the half precision quiet NaN 0xF97E00. A Simple value is written with its number as the argument. It cannot fail.

get

pub fn get(v: Value, key: Value) -> Value?

Returns the value of the first entry of the map v whose key equals key, or none when v is not a Map or has no such entry.

Keys are equal when their deterministic encodings are the same bytes, so an Unsigned and a Float with the same number are different keys.

decode_first

pub fn decode_first(data: []u8, options: Options) -> Item ! io.Error

Decodes the data item at the start of data and reports its size, ignoring any bytes after it.

Use it to read a sequence of back-to-back items by advancing data by Item.length. Fails like decode_with except that trailing bytes are not an error.

decode_with

pub fn decode_with(data: []u8, options: Options) -> Value ! io.Error

Decodes data, which must hold exactly one CBOR data item.

Every major type is read, including indefinite-length strings, arrays and maps, which arrive as their definite equivalents, tags, simple values and half, single and double floats. Fails with Malformed for truncated input, additional information 28 to 30, a stray break, an indefinite length on an integer or tag, a chunk of an indefinite-length string that is not a definite string of the same type, a simple value 24 to 31 written in two bytes, text that is not valid UTF-8, a map with a repeated key, and bytes after the item. Fails with TooLarge when nesting is deeper than Options.max_depth or a length is over Options.max_length. Strings and byte strings are copied, so the result does not alias data.

deserialize

pub fn deserialize[T](data: []u8) -> T ! serde.Error

Decodes CBOR data into a T through std/serde.

Decoding uses the default Options. A tag is ignored and its content is read in its place. null and undefined both read as an absent optional. A float is read from a float or an integer, and an integer from Unsigned or Negative when it fits, failing with serde.Error.Range when it does not. Map keys may be text, integers or booleans, the latter two read as text. A decoding failure becomes serde.Error.Syntax with position 0, except that TooLarge becomes serde.Error.TooDeep. Fails with Mismatch when a value has another type and with Missing and UnknownVariant as serde.read describes. In errors, at counts the values consumed so far.

pub fn integer(n: i64) -> Value

serialize

pub fn serialize[T](v: T) -> []u8

Encodes v as CBOR bytes through std/serde.

Structs and maps become maps with text keys, slices become arrays, []u8 becomes a byte string, optionals become null or the value, floats become floats of the shortest exact precision, and integers become Unsigned or Negative. An enum variant without fields becomes text and a variant with fields a one-entry map from its name to a map of its labelled fields or an array of its positional ones. The output is deterministic, as encode makes it.
