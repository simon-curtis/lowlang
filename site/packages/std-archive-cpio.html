std/archive/cpio

#compression

import std/archive/cpio

newc, CRC and odc archives, detected per entry on read: a Reader, a Writer (add_file, add_dir, add_symlink, add_links, finish), and extract and create over the filesystem with the safe extraction of std/archive. Hard links store their data with the last link in newc and CRC. The binary format fails with Unsupported.

Imports std/archive, std/file, std/io, std/text.

A cpio archive member: its name and metadata, and for a symbolic link its target.

The defaults describe an empty regular file with mode 0o644 owned by id 0. When an entry is written, a value that does not fit its header field fails with TooLarge: 8 hexadecimal digits in Newc and Crc, and 6 or 11 octal digits in Odc.

Reader

pub struct Reader {
    ...
}

A streaming cpio reader made by reader, reader_with or bytes_reader.

Call next for each entry and read its data with read_body or read_entry before calling next again.

extract_from

pub fn extract_from(r: *Reader, dir: str) ! io.Error

Extracts the entries of r below dir, creating dir and its missing parents.

Each name goes through archive.resolve, so an absolute name, a .. segment, a NUL byte or a path through a symbolic link below dir fails with Denied. Files are created exclusively and without following links, and an existing file or link at the target is replaced. Permission bits are masked to 0o777, so setuid, setgid and sticky bits are dropped, and the process umask applies. Modification times are applied to files as they are written and to directories once all entries are placed. Symbolic links are created with their stored target, which is not validated. Character, block, fifo and socket entries are skipped.

Hard links are recreated: files that share dev_major, dev_minor and ino with an nlink above 1 are linked to the one entry that carries data. A group with no data becomes an empty file with the other names linked to it.

Fails with the errors of next and of the filesystem.

next

pub fn next(r: *Reader) -> Entry? ! io.Error

Returns the next entry, or none at the TRAILER!!! entry. Every later call returns none.

Data of the previous entry that was not read is read and discarded, which still checks the checksum of a Crc entry. The target of a symbolic link is read into link and its size is 0.

Fails with Eof when the input ends before the trailer, with Malformed for an unknown magic number, a non-digit in a header field, an empty or unterminated name or an unknown file type, with Unsupported for the binary cpio format, and with TooLarge when a limit is exceeded.

read_body

pub fn read_body(r: *Reader, dst: []u8) -> i64 ! io.Error

Reads up to dst.len bytes of the current entry's data into dst and returns the count, or 0 once the data is exhausted.

Fails with Eof when the source ends first. For a regular file in the Crc format the byte sum is checked when the last byte is read, and a mismatch fails with Malformed. A directory has no data and a symbolic link's data was already read by next, so both return 0.

read_entry

pub fn read_entry(r: *Reader) -> []u8 ! io.Error

Returns the rest of the current entry's data in a new slice.

Errors are those of read_body. The slice is empty for a directory and a symbolic link.

Writer

    ...
}

A cpio writer made by writer or stream_writer.

Add entries in order and call finish to write the trailer.

add

pub fn add(w: *Writer, e: Entry, data: []u8) ! io.Error

Writes the entry e with data as its contents.

data is used for a File only; a Symlink stores e.link and every other kind stores nothing. e.size is ignored. A negative e.ino is replaced by the next unused inode number. A Crc entry carries the byte sum of its data.

Fails with Invalid after finish, for an empty name, for TRAILER!!! and for a name or link with a NUL byte, with TooLarge when a value does not fit its header field, and with the error of the sink.

add_dir

pub fn add_dir(w: *Writer, name: str, mode: i64) ! io.Error

Writes a directory name with the permission bits mode, owned by id 0 with a modification time of 0.

add_file

pub fn add_file(w: *Writer, name: str, data: []u8, mode: i64) ! io.Error

Writes a regular file name with data and the permission bits mode, owned by id 0 with a modification time of 0.

add_links

pub fn add_links(w: *Writer, e: Entry, names: []str, data: []u8) ! io.Error

Writes names as hard links to one file whose metadata is e.

Every name gets e with name replaced and an nlink of names.len, and all share one inode number. In Newc and Crc only the last name carries data; in Odc every name does. e.name and e.nlink are ignored.

Fails with Invalid when names is empty or e.kind is not File, and otherwise as add.

add_symlink

pub fn add_symlink(w: *Writer, name: str, target: str) ! io.Error

Writes a symbolic link name that points to target, with mode 0o777, owned by id 0 with a modification time of 0.

finish

pub fn finish(w: *Writer) ! io.Error

Writes the TRAILER!!! entry and pads the output with zero bytes to a multiple of 512.

A second call does nothing. After finish, add fails with Invalid.

output

pub fn output(w: *Writer) -> []u8

Returns the bytes collected by a Writer made with writer.

Call it after finish for a complete archive. It is empty for a stream writer.

create

pub fn create(dir: str, format: Format) -> []u8 ! io.Error

Returns an archive of the tree below dir in format.

Names are relative to dir, which is not an entry itself, and come in sorted depth-first order. Directories, symbolic links, which are not followed, and regular files are archived with the mode, owner and modification time that lstat reports. Other objects are skipped. Regular files that share a device and inode are written with add_links. The archive is built in memory and ends with the trailer.

Fails with the error of the filesystem call that failed.
