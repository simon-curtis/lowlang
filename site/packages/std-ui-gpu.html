Gpu

pub struct Gpu {
    ...
}

A Vulkan 1.3 instance and device with the pipelines, glyph atlas texture and frame resources that draw a scene.Scene.

Releasing a Gpu waits for the device to go idle and destroys everything it created. Every Target made from it must be released first, which using does when the targets are bound after the Gpu.

present

pub fn present(g: Gpu, s: scene.Scene, mut atlas: scene.Atlas) ! Error

Draws s into the next image of the window's swapchain and presents it, and uploads the rows of atlas that changed since the last call.

The swapchain is made on the first call, at the size of s in device pixels, and is made again when the size of s changes or when presentation reports that it is out of date or suboptimal. A scene of no pixels presents nothing. The call returns once the frame is queued for presentation. The Gpu keeps one atlas texture that mirrors the atlas it was last given. After the call atlas is marked clean.

Fails with NoSurface on a Gpu that open made.

read

pub fn read(g: Gpu, t: Target) -> []u8 ! Error

Waits for every submitted frame and returns the pixels of t as rows from the top of four bytes each, red, green, blue and alpha, width * height * 4 bytes in all.

The bytes are unspecified until render has drawn into t.

render

pub fn render(g: Gpu, t: Target, s: scene.Scene, mut atlas: scene.Atlas) ! Error

Draws s into t, clearing it to the scene's background first, and uploads the rows of atlas that changed since the last call.

Positions in s are device pixels of t; the scene's own width and height are not read. The call returns once the work is submitted, and read waits for it. The Gpu keeps one atlas texture that mirrors the atlas it was last given, so a Gpu draws with one Atlas. After the call atlas is marked clean.

target

pub fn target(g: Gpu, width: i64, height: i64) -> Target ! Error

Makes a target of width by height pixels on g.

Fails with InvalidSize when either is below one.

The window a Gpu presents to, as the handles the windowing system gave it.

On Linux display is the wl_display and window the wl_surface. On Windows display is the HINSTANCE and window the HWND.

open_for

pub fn open_for(s: Surface) -> Gpu ! Error

Opens the first Vulkan 1.3 device that offers dynamic rendering, synchronization2 and the swapchain extension, and has a graphics queue that can present to s, for drawing into the window with present.

The Gpu owns the Vulkan surface it makes from s and destroys it on release, so the window must outlive the Gpu. Offscreen targets work on it as on one from open. Fails with NoDevice when no device qualifies, and with Vulkan when a call fails, including VK_ERROR_EXTENSION_NOT_PRESENT when the instance lacks the windowing extension.

An offscreen image that scenes are drawn into and read back from, R8G8B8A8_UNORM with width by height pixels.

A Target must be released before the Gpu it was made from. Releasing it waits for the device to go idle.
