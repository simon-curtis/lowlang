std/atomic

#concurrency

import std/atomic

Int, Bool and Flag built on compare-and-swap, with load_int, store_int, add_int, swap_int, compare_and_swap_int and update_int, and the same forms for Bool. Every load is a locked operation, so a loop cannot hoist it. Value[T] swaps a heap pointer under a lock: load_value, store_value, swap_value, update_value, snapshot_value and compare_and_swap_value (compares pointer identity).

A 64-bit integer cell that is read and updated atomically.

Copies of an Int refer to the same cell. No operation parks the green thread.

update_int

pub fn update_int(i: Int, f: fn(i64) -> i64) -> i64

Replaces the value of i with f applied to it, and returns the stored result.

If another green thread changes i while f runs, f runs again on the new value, so f can run more than once and should not have side effects.

Value

pub struct Value[T] {
    ...
}

An atomic cell holding a value of any type T.

Each store_value and swap_value allocates a copy of the new value and replaces a pointer to it, so a pointer from snapshot_value stays valid and unchanged while the cell moves on. Copies of a Value refer to the same cell. An internal lock is held only for the pointer exchange, so no operation parks the green thread.

compare_and_swap_value

pub fn compare_and_swap_value[T](v: Value[T], seen: *T, next: T) -> bool

Replaces the value of v with next if it still holds the version seen, and returns whether it did.

seen is a pointer from snapshot_value. The comparison is by pointer identity, not by equality of the values, so a cell that was stored with an equal value since the snapshot does not match.

load_value

pub fn load_value[T](v: Value[T]) -> T

Returns a copy of the value currently stored in v.

snapshot_value

pub fn snapshot_value[T](v: Value[T]) -> *T

Returns a pointer to the value currently stored in v, without copying it.

The pointed-to value is never modified; later stores make the cell point elsewhere. The pointer identifies a version of the cell for compare_and_swap_value.

swap_value

update_value

pub fn update_value[T](v: Value[T], f: fn(T) -> T) -> T

Replaces the value of v with f applied to it, and returns the stored result.

If another green thread stores to v while f runs, f runs again on the new value, so f can run more than once and should not have side effects.
