std/atomic

#concurrency

import std/atomic

Int, Bool and Flag built on compare-and-swap, with load_int, store_int, add_int, swap_int, compare_and_swap_int and update_int, and the same forms for Bool. Every load is a locked operation, so a loop cannot hoist it. Value[T] swaps a heap pointer under a lock: load_value, store_value, swap_value, update_value, snapshot_value and compare_and_swap_value (compares pointer identity).
