std/sync

#concurrency

import std/sync

Mutex with lock, try_lock, unlock and locked. WaitGroup with add, done and wait. Once with run. RwLock, first in first out and writer-fair, with read_lock, read_unlock, write_lock, write_unlock, try_read_lock, try_write_lock, reading and writing. Semaphore with acquire, try_acquire, release and available. Cond with wait_cond, signal and broadcast. Barrier with wait_barrier. OnceValue[T]. ErrorGroup[E], whose go blocks while limit tasks run and whose join returns the first error. All are built on channels, so a waiting green thread parks instead of spinning.

Types

Barrier

pub struct Barrier {
    ...
}

A rendezvous point where a fixed number of green threads wait for each other.

The barrier is reusable: once the last party arrives it resets for the next round. Copies of a Barrier share its state.

wait_barrier

pub fn wait_barrier(b: Barrier) -> bool

Parks the green thread until parties green threads have called wait_barrier on b.

Returns true to the call that completed the round, which releases the others, and false to the rest.

Cond

pub struct Cond {
    ...
}

A condition variable tied to a Mutex.

Green threads park in wait_cond until another calls signal or broadcast. Copies of a Cond share the same waiters.

broadcast

pub fn broadcast(c: Cond)

Wakes every green thread parked in wait_cond.

signal

pub fn signal(c: Cond)

Wakes the longest-waiting green thread parked in wait_cond, and does nothing if there is none.

A call that happens before the waiter has parked is not remembered.

wait_cond

pub fn wait_cond(c: Cond)

Unlocks the owner of c, parks the green thread until signal or broadcast wakes it, and locks the owner again before returning.

The caller must hold the owner. A wakeup does not guarantee the awaited condition still holds, so check it in a loop.

ErrorGroup

pub struct ErrorGroup[E] {
    ...
}

A set of tasks that run concurrently on green threads, with a limit on how many run at once and a record of the first error.

Copies of an ErrorGroup share its state.

go

pub fn go[E](g: ErrorGroup[E], f: fn() -> E?)

Runs f on a new green thread as a task of g.

Parks the green thread while limit tasks are already running. When f returns some(e), e is recorded unless an earlier task has already recorded an error; the other tasks are not stopped.

join

pub fn join[E](g: ErrorGroup[E]) -> E?

Parks the green thread until every task started with go has finished, and returns the first recorded error, or none if no task failed.

Mutex

pub struct Mutex {
    ...
}

A mutual exclusion lock shared by its copies.

A mutex is not reentrant: locking it again from the green thread that holds it parks forever. Waiting for a lock parks the green thread rather than blocking the OS thread.

cond

pub fn cond(owner: Mutex) -> Cond

Returns a Cond that is used with the lock owner.

lock

pub fn lock(m: Mutex)

Locks m, parking the green thread until it is available.

locked

pub fn locked[T](m: Mutex, f: fn() -> T) -> T

Locks m, runs f, unlocks m and returns the result of f.

try_lock

pub fn try_lock(m: Mutex) -> bool

Locks m if it is free and returns whether it did, without parking.

unlock

pub fn unlock(m: Mutex)

Unlocks m.

m must be locked. Unlocking an unlocked mutex is a bug and parks the green thread until another green thread locks the mutex, then releases that lock.

Once

pub struct Once {
    ...
}

A guard that lets a function run a single time.

Copies of a Once share its state.

run

pub fn run(o: Once, f: fn())

Runs f if no call to run on o has run a function before, and does nothing otherwise.

Calls from other green threads that arrive while f runs park until it finishes, so when run returns, f has completed.

OnceValue

pub struct OnceValue[T] {
    ...
}

A value computed by a function the first time it is requested and then reused.

Copies of an OnceValue share the cached value.

get_once

pub fn get_once[T](o: OnceValue[T]) -> T

Returns the value of o, calling its function if this is the first request.

Callers that arrive while the function runs park until it finishes, so the function runs once and every caller receives the same result.

RwLock

pub struct RwLock {
    ...
}

A lock that admits many readers or one writer.

Requests are granted in arrival order: a reader that arrives while a writer is waiting queues behind it, so writers are not starved. Waiting parks the green thread. The lock is not reentrant, and copies of an RwLock refer to the same lock.

read_lock

pub fn read_lock(l: RwLock)

Takes a shared lock, parking the green thread while a writer holds the lock or any request is queued.

read_unlock

pub fn read_unlock(l: RwLock)

Releases a shared lock taken with read_lock or try_read_lock.

Panics with sync: read_unlock of an unlocked RwLock if no shared lock is held.

reading

pub fn reading[T](l: RwLock, f: fn() -> T) -> T

Takes a shared lock, runs f, releases the lock and returns the result of f.

try_read_lock

pub fn try_read_lock(l: RwLock) -> bool

Takes a shared lock if one is available immediately and returns whether it did, without parking.

try_write_lock

pub fn try_write_lock(l: RwLock) -> bool

Takes the exclusive lock if it is available immediately and returns whether it did, without parking.

write_lock

pub fn write_lock(l: RwLock)

Takes the exclusive lock, parking the green thread while any reader or writer holds the lock or any request is queued.

write_unlock

pub fn write_unlock(l: RwLock)

Releases the exclusive lock.

Panics with sync: write_unlock of an unlocked RwLock if the lock is not held for writing.

writing

pub fn writing[T](l: RwLock, f: fn() -> T) -> T

Takes the exclusive lock, runs f, releases the lock and returns the result of f.

Semaphore

pub struct Semaphore {
    ...
}

A counting semaphore that limits how many green threads use a resource at once.

Waiters are served in arrival order. Copies of a Semaphore share the count.

acquire

pub fn acquire(s: Semaphore)

Takes a permit, parking the green thread until one is available.

available

pub fn available(s: Semaphore) -> i64

Returns the number of permits that can be taken without waiting.

release

pub fn release(s: Semaphore)

Returns a permit.

Hands it to the longest-waiting acquire if there is one, and otherwise increases the available count. The count has no upper bound, so releasing more than was acquired grows the capacity.

try_acquire

pub fn try_acquire(s: Semaphore) -> bool

Takes a permit if one is available and returns whether it did, without parking.

WaitGroup

pub struct WaitGroup {
    ...
}

A counter of outstanding tasks that wait parks on until it reaches zero.

Copies of a WaitGroup share the counter.

add

pub fn add(w: WaitGroup, n: i64)

Adds n to the count of w, which can be negative.

Wakes every green thread parked in wait when the count reaches zero. Panics with sync: negative wait group count if the count would go below zero.

done

pub fn done(w: WaitGroup)

Subtracts one from the count of w.

Panics if the count is already zero.

wait

pub fn wait(w: WaitGroup)

Parks the green thread until the count of w is zero, and returns at once if it already is.
