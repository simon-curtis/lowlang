Imports std/bits, std/compress/codec, std/hash, std/io, std/math.

Examples

stream

import std/compress/zstd
import std/hash
import std/io
import std/text

/// Compresses log lines as they arrive, then decodes the frame in chunks while counting bytes and a checksum, without holding the decoded text.
fn main() ! io.Error {
    var frame: []u8 = []
    let enc = zstd.encoder(3, fn(chunk) {
        io.append(mut frame, chunk)
    })
    var expected = hash.crc32_new()
    var total = 0
    for i in 0..2000 {
        let line = "2026-01-05 12:00:{text.pad_left("{i % 60}", 2, '0')} GET /api/items/{i % 17} 200\n"
        enc.encode(bytes(line))?
        hash.crc32_update(expected, bytes(line))
        total += line.len
    }
    enc.finish()?
    print("frame smaller than input: {frame.len < total / 10}")

    var seen = hash.crc32_new()
    var decoded = 0
    zstd.decode(io.bytes_reader(frame), fn(chunk) {
        hash.crc32_update(seen, chunk)
        decoded += chunk.len
    }, 1 << 20)?
    print("decoded {decoded} of {total} bytes")
    print("checksums match: {hash.crc32_sum(seen) == hash.crc32_sum(expected)}")

    let small = zstd.decompress(frame, 1000) catch {
        TooLarge => {
            print("limit of 1000 bytes rejected the frame")
            return
        }
        _ => return
    }
    print("unexpected {small.len}")
}

Output

frame smaller than input: true
decoded 82820 of 82820 bytes
checksums match: true
limit of 1000 bytes rejected the frame

Types

Encoder

pub struct Encoder {
    ...
}

A streaming Zstandard encoder made by encoder.

encode takes input in any chunking, flush writes the buffered input as blocks, and finish writes the last block and the content checksum. After finish, encode, flush and finish fail with Invalid. The frame carries no content size. A chunk is valid only during the call to sink.

encode

pub fn encode(e: *Encoder, data: []u8) ! io.Error

Compresses data and passes each completed block to the encoder's sink.

Input is buffered until a block is full, so a call can produce no output. Fails with Invalid after finish, and with any error sink returns.

finish

pub fn finish(e: *Encoder) ! io.Error

Writes the buffered input as the last block, followed by the low 32 bits of the XXH64 content checksum.

Fails with Invalid when the stream is already finished, and with any error sink returns.

flush

pub fn flush(e: *Encoder) ! io.Error

Writes the buffered input as blocks, so a decoder can read everything encoded so far.

Fails with Invalid after finish, and with any error sink returns.

Functions

compress

pub fn compress(data: []u8, level: i64) -> []u8

Returns data compressed as one Zstandard frame.

level is clamped to 1..22. The frame header records the content size and the window is reduced for small inputs.

decode

pub fn decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes Zstandard frames from r and passes the decoded bytes to sink in chunks until the input ends.

Concatenated frames are decoded in turn and skippable frames are ignored. A frame's content checksum is verified when present. Input with no frame is Malformed; frames that need a dictionary or a window above 2 GiB are Unsupported. A frame whose declared content size exceeds limit fails with TooLarge before any of it is decoded. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

decompress

pub fn decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from Zstandard frames in data.

Concatenated frames are decoded in turn and skippable frames are ignored. Input with no frame is Malformed; frames that need a dictionary or a window above 2 GiB are Unsupported. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.

encoder

pub fn encoder(level: i64, sink: fn([]u8) ! io.Error) -> *Encoder

Returns an encoder that writes one Zstandard frame to sink.

level is clamped to 1..22; the window is at most 8 MiB and higher levels search more candidates.
