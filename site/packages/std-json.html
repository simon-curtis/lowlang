std/json

#formats

import std/json

A reader and writer over UTF-8 bytes, the Value document model with member builders (text_member, int_member, bool_member, base64url_member, object_member, array_member) and typed getters (field, field_text, field_int, text_of, int_of), equal (compares numbers numerically and objects without regard to member order), and serialize[T] and deserialize[T] with naming policies.

Imports std/base64, std/bits, std/math, std/serde, std/simd, std/text, std/unicode, std/unicode/utf16.

How struct field names and enum variant names are spelled in JSON.

Low field names are conventionally snake_case and variant names PascalCase. serialize_with converts them to this spelling, and deserialize_with converts JSON names back: struct field names to snake_case, and variant names to PascalCase unless the naming is Unchanged.

Reader

pub struct Reader {
    ...
}

A pull tokenizer over one JSON text, made by reader.

read advances to the next token and the get_ functions read the value of the current one. The reader checks the whole of RFC 8259 syntax, the validity of UTF-8 and the order of commas, colons and brackets, so a successful token sequence is a well-formed document. Strings, names and numbers are views of the input until a get_ function converts them.

depth

pub fn depth(r: *Reader) -> i64

Returns the number of containers that are open at the current token.

After a StartObject or StartArray it counts that container, and after the matching end token it does not. It is 0 at the top level.

get_bool

pub fn get_bool(r: *Reader) -> bool ! serde.Error

Returns the value of the current True or False token.

Fails with serde.Error.Mismatch when the token is neither.

get_f64

pub fn get_f64(r: *Reader) -> f64 ! serde.Error

Returns the current Number token as an f64.

Fails with serde.Error.Mismatch when the token is not a number.

get_i64

pub fn get_i64(r: *Reader) -> i64 ! serde.Error

Returns the current Number token as an i64.

Fails with serde.Error.Mismatch when the token is not a number, or the number has a fraction or exponent, and with Range when it does not fit an i64.

get_string

pub fn get_string(r: *Reader) -> str ! serde.Error

Returns the string of the current String or PropertyName token with its escapes decoded.

A \u surrogate pair becomes one character and a lone surrogate becomes U+FFFD. Fails with serde.Error.Mismatch when the token is neither. The string views the input when it has no escapes.

get_u64

pub fn get_u64(r: *Reader) -> u64 ! serde.Error

Returns the current Number token as a u64.

Fails with serde.Error.Mismatch when the token is not a number, or the number is negative or has a fraction or exponent, and with Range when it does not fit a u64.

position

pub fn position(r: *Reader) -> i64

Returns the byte offset in the input that the reader has reached, just past the current token, or past the colon for a PropertyName. Errors report it.

read

pub fn read(r: *Reader) -> bool ! serde.Error

Advances to the next token and returns true, or returns false once the top-level value has been read completely and only whitespace remains, leaving the token as None.

An object member is two tokens, PropertyName and then the value. Fails with serde.Error.Syntax at the byte offset of malformed input, for example an unexpected character, a trailing comma, a bad escape, a control character or invalid UTF-8 in a string, an unterminated string, a number with a leading zero, an unexpected end of data or data after the top-level value, and with TooDeep when containers nest deeper than the reader allows.

skip

pub fn skip(r: *Reader) ! serde.Error

Skips the current value.

When the token is a PropertyName it skips the member's value; when the value is an object or array it reads through to the matching end token, and the end token becomes current. For other tokens it does nothing. Fails like read.

token

pub fn token(r: *Reader) -> Token

Returns the kind of the current token, or None before the first read and at the end of the document.

pub fn value_bytes(r: *Reader) -> []u8

Returns the raw bytes of the current token as a view of the input: the text of a number or literal, the bracket of a container token, and, for a string or name, the characters between the quotes with any escapes still undecoded.

equal

pub fn equal(a: Value, b: Value) -> bool

Returns whether a and b are equal as JSON values.

An Int equals a Float of the same numeric value. Objects are equal when they have the same members regardless of order, and arrays when they have equal elements in the same order. Values of different kinds are not equal, so Null equals only Null. A Float NaN equals nothing.

stringify

Returns v as JSON text.

indent is the number of spaces per nesting level; 0 writes compact text with no whitespace, and a positive value puts each member and element on its own line. A non-finite Float is written as null, since JSON has no representation for it. See Writer for the escaping of strings.

Writer

pub struct Writer {
    ...
}

A JSON text builder that appends to an internal buffer, made by writer.

Call start_object, property, the value functions and end_object in document order, then read the text with written_text or written_bytes. Commas, colons and indentation are added automatically. Strings are escaped: " and \ with a backslash, newline, carriage return and tab as \n, \r and \t, and the other control characters below 0x20 as \u00XX. Everything else, including non-ASCII text and /, is written as it is; the text is not checked for UTF-8. The writer does not check that calls form a valid document.

events

pub fn events(w: *Writer, naming: Naming) -> serde.Writer

Returns a serde.Writer that writes derived values as JSON through the Writer w, with field and variant names spelled as naming says.

[]u8 is written as a base64 string. A none is written as null. Maps are written as objects with their keys as they are. An enum variant without fields is its name as a string, and one with fields an object with a single member named by the variant. Use it to write a value with serde.write into a writer that already holds other output.

deserialize_with

pub fn deserialize_with[T](data: []u8, options: Options) -> T ! serde.Error

Decodes the JSON text data into a T, as options says.

The text must be one complete JSON value; data after it fails with serde.Error.Syntax. A struct is read from an object: unknown members are skipped, a missing member takes the field's default or none for an optional, and any other missing member fails with Missing. null reads as none. Integers must be written without a fraction or exponent, and a []u8 is read from a base64 string. An enum variant is read from a string or an object with one member. Failures are serde.Error: Syntax for malformed JSON, Mismatch for a value of the wrong type, Range for a number that does not fit, TooDeep and UnknownVariant.

parse

pub fn parse(data: []u8) -> Value ! serde.Error

Parses data as one JSON text into a Value.

The input is UTF-8 and follows RFC 8259 strictly: no comments, no trailing commas, no leading zeros, no control characters in strings, and invalid UTF-8 is rejected. A leading byte order mark and whitespace around the value are accepted. A number without a fraction or exponent that fits an i64 becomes Int, any other number Float. A lone surrogate escape in a string becomes U+FFFD. Duplicate member names are kept. Nesting deeper than 64 fails with serde.Error.TooDeep. Other failures, including empty input and data after the value, are serde.Error.Syntax at the byte offset of the problem.

reader

pub fn reader(data: []u8) -> *Reader

Returns a reader over data, which is not copied.

serialize_with

pub fn serialize_with[T](v: T, options: Options) -> str

Returns v as JSON text, as options says.

A struct becomes an object of its fields, a map an object, a slice an array, an optional null or its value, and []u8 a base64 string. An enum variant without fields becomes a string, and a variant with fields an object with one member named by the variant, holding an object of its labelled fields or an array of its positional ones. Non-finite floats become null.

Names are matched as they are, the nesting limit is 64, and data after the first value is not checked. Failures are reported as serde.Errors.
