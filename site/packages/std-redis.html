std/redis

#database #net

import std/redis

RESP2 and RESP3 over TCP or TLS: a droppable Client with a ClientHandle, connect with AUTH, SELECT and HELLO 3, command, typed helpers for strings, hashes, lists, sets, sorted sets and publish, pipelining, transaction, pub/sub through a channel usable in select, command timeouts, and limits on bulk size and nesting.

Imports std/io, std/net, std/sync, std/text, std/tls.

Types

Client

pub struct Client {The shared state of the connection, for the _on functions.    pub handle: *ClientHandle
    ...
}

An owned connection to a Redis server, from connect, connect_tls or connect_stream.

Dropping a Client closes the connection, unless detach released it first.

close_client

pub fn close_client(c: Client)

Closes the connection.

Closing twice is harmless. Later commands fail with Closed, and the messages channel of a running subscription is closed.

command

pub fn command(c: Client, args: []str) -> Reply ! Error

Sends one command and returns its reply.

args[0] is the command name and the rest are its arguments, sent as binary-safe bulk strings. Every reply type is returned as is, including an error reply as Failure, which is not raised. RESP3 Push frames that arrive before the reply are skipped. Concurrent calls on one connection are serialised.

Fails with Closed after the client is closed and Subscribed while a subscription runs. A transport failure fails with Timeout, Closed, TooLarge or Protocol and closes the client.

del

pub fn del(c: Client, keys: []str) -> i64 ! Error

Deletes keys and returns how many existed.

An empty keys fails with Server.

detach

pub fn detach(mut c: Client) -> *ClientHandle

Releases the client's ownership of its connection and returns the ClientHandle.

Dropping c afterwards does not close the connection; close it with close_client_on or take it back with adopt. Use it to share the connection between green threads.

discard

pub fn discard(c: Client) ! Error

Drops the commands queued since multi and ends the transaction. Fails with Server when no transaction is open.

exec

pub fn exec(c: Client) -> []Reply ! Error

Runs the commands queued since multi and returns the result of each in order.

Fails with Aborted when the server returns nil because a watched key changed, Server on an error reply such as EXECABORT or EXEC without MULTI, and Type on any other reply.

exists

pub fn exists(c: Client, keys: []str) -> i64 ! Error

Returns how many of keys exist.

An empty keys fails with Server.

expire

pub fn expire(c: Client, key: str, seconds: i64) -> bool ! Error

Sets a time to live of seconds on key. Returns true when it was set and false when the key does not exist.

get

pub fn get(c: Client, key: str) -> str? ! Error

Returns the value of key, or none when the key does not exist.

Fails with Server on an error reply such as a key holding a different type.

hget

pub fn hget(c: Client, key: str, field: str) -> str? ! Error

Returns the value of field in the hash at key, or none when the field or the key does not exist.

hgetall

pub fn hgetall(c: Client, key: str) -> []Field ! Error

Returns every field and value of the hash at key. A missing key gives an empty list.

Reads the RESP3 map form and the RESP2 flat list; a flat list of odd length fails with Protocol.

hset

pub fn hset(c: Client, key: str, fields: []Field) -> i64 ! Error

Sets each of fields in the hash at key and returns how many were new.

Fields that already existed are updated and not counted. An empty fields fails with Server.

incr

pub fn incr(c: Client, key: str) -> i64 ! Error

Adds one to the integer at key and returns the new value.

A missing key counts as 0. Fails with Server when the value is not an integer.

incrby

pub fn incrby(c: Client, key: str, n: i64) -> i64 ! Error

Adds n to the integer at key and returns the new value.

A missing key counts as 0. Fails with Server when the value is not an integer.

lpop

pub fn lpop(c: Client, key: str) -> str? ! Error

Removes and returns the first element of the list at key, or none when the list is empty or missing.

lpush

pub fn lpush(c: Client, key: str, values: []str) -> i64 ! Error

Pushes values onto the head of the list at key one after another, so the last value ends up first, and returns the new length.

An empty values fails with Server.

lrange

pub fn lrange(c: Client, key: str, start: i64, stop: i64) -> []str ! Error

Returns the elements of the list at key from index start to stop, both inclusive.

Negative indexes count from the end, so -1 is the last element. A missing key or an out of range slice gives an empty list.

multi

pub fn multi(c: Client) ! Error

Starts a transaction with MULTI.

Commands sent with command are then queued by the server and answer Status("QUEUED"); the typed commands such as get fail with Type meanwhile. End it with exec or discard. Fails with Server on an error reply.

ping

pub fn ping(c: Client) ! Error

Sends PING and returns when the server answers.

Fails with Type on any reply other than PONG or a bulk string, so it also checks that the connection is alive.

psubscribe

pub fn psubscribe(c: Client, patterns: []str) -> Subscription ! Error

Subscribes to the glob-style patterns and returns the running Subscription.

Each Message carries the matching pattern in pattern. Fails as subscribe does.

publish

pub fn publish(c: Client, channel: str, message: str) -> i64 ! Error

Sends message to channel and returns how many subscribers received it.

rpop

pub fn rpop(c: Client, key: str) -> str? ! Error

Removes and returns the last element of the list at key, or none when the list is empty or missing.

rpush

pub fn rpush(c: Client, key: str, values: []str) -> i64 ! Error

Appends values to the tail of the list at key in order and returns the new length.

An empty values fails with Server.

run_pipeline

pub fn run_pipeline(c: Client, commands: [][]str) -> []Reply ! Error

Sends commands in one write and returns the replies in the same order.

Each entry is a command name followed by its arguments. An empty list returns an empty list without using the connection. An error reply appears as a Failure element and does not stop the rest. Fails as command does, and a transport failure closes the client.

sadd

Adds members to the set at key and returns how many were new.

An empty members fails with Server.

set

pub fn set(c: Client, key: str, value: str) ! Error

Stores value at key, replacing any existing value and clearing its time to live. Fails with Server on an error reply.

set_timeout

pub fn set_timeout(c: Client, millis: i64)

Sets the read and write time limit in milliseconds for later operations, replacing Options.timeout. 0 waits indefinitely.

A running subscription reads without a limit; the value applies again once it ends.

set_with

pub fn set_with(c: Client, key: str, value: str, o: SetOptions) -> bool ! Error

Stores value at key subject to o.

Returns true when the value was stored and false when the nx or xx condition stopped it. Fails with Server on an error reply.

smembers

pub fn smembers(c: Client, key: str) -> []str ! Error

Returns every member of the set at key in the order the server sends them, which is unspecified. A missing key gives an empty list.

subscribe

pub fn subscribe(c: Client, channels: []str) -> Subscription ! Error

Subscribes to channels and returns the running Subscription.

Returns once the server has confirmed every channel. The connection is dedicated to the subscription until it ends; other commands fail with Subscribed. Fails with Protocol when channels is empty, Server when the server rejects the subscription, Subscribed when one is already running, and Closed when the connection ends before the confirmation.

transaction

pub fn transaction(c: Client, commands: [][]str) -> []Reply ! Error

Runs commands atomically between MULTI and EXEC, sent in one write, and returns the result of each in order.

Fails with Server when the server rejects a command or MULTI while queueing, and with Aborted when EXEC returns nil because a key given to watch changed. A command that fails while EXEC runs appears as a Failure element.

ttl

pub fn ttl(c: Client, key: str) -> i64 ! Error

Returns the remaining time to live of key in seconds: -1 when it has none and -2 when the key does not exist.

unwatch

pub fn unwatch(c: Client) ! Error

Forgets every key watched with watch.

watch

pub fn watch(c: Client, keys: []str) ! Error

Watches keys so that the next exec returns Aborted if any of them changes first.

The watch ends with exec, discard or unwatch. Fails with Server on an error reply, including an empty keys.

zadd

pub fn zadd(c: Client, key: str, members: []Scored) -> i64 ! Error

Adds members to the sorted set at key, updating the score of any that exist, and returns how many were new.

An empty members fails with Server.

zrange

pub fn zrange(c: Client, key: str, start: i64, stop: i64) -> []str ! Error

Returns the members of the sorted set at key ranked start to stop, both inclusive, by ascending score.

Negative indexes count from the end. A missing key gives an empty list.

zrange_scores

pub fn zrange_scores(c: Client, key: str, start: i64, stop: i64) -> []Scored ! Error

Returns the members of the sorted set at key ranked start to stop, both inclusive, each with its score.

Reads the RESP3 list of pairs and the RESP2 flat list. Ranking and negative indexes are as for zrange.

ClientHandle

    ...

A copyable reference to the state of one server connection.

Copies refer to the same connection. Commands on it are serialised by an internal lock, so green threads may share it. detach returns one from a Client, adopt turns it back into a Client, and the _on functions take it directly.

connect

pub fn connect(o: Options) -> Client ! Error

Opens a TCP connection to o.host and o.port and performs the handshake.

The handshake sends HELLO 3 when o.protocol is 3, otherwise AUTH when o.password is set, then SELECT when o.database is not 0. Fails with Connect when the server cannot be reached, Timeout when o.connect_timeout expires, Auth when the credentials are rejected, Unsupported when HELLO 3 is rejected and no password is set, Server when SELECT is rejected, or with a transport Error from the exchange. The connection is closed when the handshake fails.

connect_tls

pub fn connect_tls(o: Options, config: tls.Config) -> Client ! Error

Opens a TCP connection and performs the handshake over TLS configured by config.

When config.server_name is empty, o.host is used. Behaves as connect, and a failed TLS handshake fails with Connect, or Timeout when it times out.

A decoded RESP reply.

RESP2 produces Nil, Status, Failure, Integer, Bulk and Array. RESP3 adds the remaining variants.

format

pub fn format(reply: Reply) -> str

Returns a single-line text form of reply for logs and tests.

Nil is (nil), Status is +text, Failure is -text, Integer is :n, and Bulk is the quoted text. Arrays are [a, b], maps {k: v}, sets ~[a, b] and pushes >[a, b], with elements formatted recursively.

Subscription

pub struct Subscription {Receives the messages in the order the server sent them. It is closed when the subscription ends.    pub messages: chan[Message]
    ...
}

A running subscription to channels or patterns, from subscribe or psubscribe.

While it runs the connection is dedicated to it: commands on the client fail with Subscribed, and no read time limit applies. A green thread reads the connection and sends each message to messages.

messages is closed when the subscription ends, which happens after unsubscribe is confirmed or when the connection fails or is closed. An unsubscribe leaves the client usable for commands; a failure closes it.

unsubscribe

pub fn unsubscribe(s: Subscription) ! Error

Asks the server to end the subscription.

Drops every channel, or every pattern for a psubscribe subscription, and returns once the request is sent. Messages already in flight may still arrive; s.messages is closed when the server confirms and the client can then run commands again. Fails with Closed when the connection is closed.

Functions

connect_stream

pub fn connect_stream(s: io.Stream, o: Options) -> Client ! Error

Performs the handshake over an existing io.Stream instead of dialling.

o.host, o.port, o.timeout and o.connect_timeout are not used, and set_timeout has no effect because the stream carries no time limits. Closing the client closes the stream. Fails as connect does from the handshake onwards.

decode

pub fn decode(data: []u8) -> Reply ! Error

Decodes the first reply in data using the default Limits.

Bytes after the first reply are ignored. Fails with Protocol when data is malformed or ends before the reply is complete.

decode_with

pub fn decode_with(data: []u8, limits: Limits) -> Reply ! Error

Decodes the first reply in data using limits. Fails as decode does, and with TooLarge when a bound is exceeded.

encode

pub fn encode(args: []str) -> []u8

Returns the RESP encoding of a command as an array of bulk strings.

args[0] is the command name and the rest are its arguments. Arguments are length-prefixed, so any bytes are allowed.

encode_into

pub fn encode_into(mut out: []u8, args: []str)

Appends the RESP encoding of a command to out, for batching several commands into one buffer. See encode.

read_reply

pub fn read_reply(r: *io.Reader, limits: Limits) -> Reply ! Error

Reads one reply from r, blocking until it is complete.

RESP3 attribute frames before the reply are read and discarded. Fails with Closed at end of input or on a read failure, Timeout when the read times out, Protocol when the bytes are not valid RESP, and TooLarge when a bound in limits is exceeded.
