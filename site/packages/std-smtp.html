std/smtp

#net

import std/smtp

An SMTP client: connect, connect_starttls and connect_tls, EHLO extensions, AUTH PLAIN, LOGIN, XOAUTH2 and CRAM-MD5 (plaintext authentication is refused unless insecure_auth), send with per-recipient results, dot-stuffing, pipelining when advertised, and errors separating 4xx from 5xx.

Imports std/base64, std/crypto/hash, std/crypto/md5, std/io, std/mail, std/net, std/slices, std/sync, std/text, std/tls.

Examples

send_mail

import std/io
import std/mail
import std/net
import std/smtp
import std/text
import std/time/offset
import std/time/timestamp
import std/time/zone
import std/time/zoned

fn reply(c: net.Conn, line: str) ! io.Error {
    net.write_all(c, bytes("{line}\r\n"))?
}

fn serve_session(c: net.Conn, delivered: chan[str]) ! io.Error {
    let r = io.reader(net.stream(c))
    reply(c, "220 mail.example.com ready")?
    for {
        let line = io.read_line(r)?
        if text.starts_with(line, "EHLO") {
            reply(c, "250 mail.example.com")?
        } else if text.starts_with(line, "RCPT TO:<nobody@") {
            reply(c, "550 no such mailbox")?
        } else if line == "DATA" {
            reply(c, "354 go ahead")?
            var lines: []str = []
            for {
                let l = io.read_line(r)?
                if l == "." {
                    break
                }
                push(mut lines, l)
            }
            delivered <- text.join(lines, "\n")
            reply(c, "250 queued as Q1")?
        } else if line == "QUIT" {
            reply(c, "221 bye")?
            return
        } else {
            reply(c, "250 ok")?
        }
    }
}

fn serve(l: net.ListenerHandle, delivered: chan[str]) {
    let h = net.accept_handle(l) or return
    using c = net.adopt(h)
    serve_session(c, delivered) or {}
}

fn sent_at() -> zoned.Zoned? {
    let ts = timestamp.from_unix(1762851000) or return none
    let shift = offset.hours(0) or return none
    zoned.of(ts, zone.fixed(shift)) or none
}

/// Sends one message to a stub SMTP server on loopback, where one of the two recipients is refused.
fn main() ! io.Error {
    using l = net.listen("127.0.0.1", 0)?
    let delivered = chan[str](1)
    spawn serve(l.handle, delivered)

    let options = smtp.Options { port: l.handle.addr.port, hello: "client.example.org", timeout: 5000 }
    using client = smtp.connect(options) or {
        print("connect failed")
        return
    }
    let message = mail.Message {
        from: mail.named("Ada", "ada@example.org")
        to: [mail.address("bob@example.com"), mail.address("nobody@example.com")]
        subject: "Lunch"
        date: sent_at()
        message_id: "lunch-1@example.org"
        text: "Noon at the usual place.\n"
    }
    let receipt = smtp.send(client, message) or {
        print("send failed")
        return
    }
    print("{receipt.code} {receipt.message}")
    print("accepted: {text.join(receipt.accepted, ", ")}")
    for r in receipt.refused {
        print("refused: {r.address} {r.code} {r.message}")
    }
    smtp.quit(client)

    let data = (<-delivered) ?? ""
    print(data)
    net.close_listener(l)
}

authenticate_on

pub fn authenticate_on(h: *ClientHandle, username: str, password: str, mechanism: Mechanism) ! Error

Authenticates with username and password using mechanism.

Auto picks the first of the mechanisms the server advertises that choose prefers. Fails with Unsupported when the server advertises no usable mechanism or not the requested one, Insecure when a password mechanism would run over an unencrypted connection without insecure_auth, Auth(message) when the server rejects the credentials, Transient for a 4xx reply and Protocol for an unexpected reply. Waits for any command in progress.

close_client_on

pub fn close_client_on(h: *ClientHandle)

Closes the connection without sending QUIT. Later commands fail with Closed.

Safe to call more than once and from several tasks. Use quit_on for an orderly close.

noop_on

pub fn noop_on(h: *ClientHandle) ! Error

Sends NOOP and waits for the reply. Fails with Closed when the client is closed, Transient or Permanent when the server refuses, and with a transport error that also closes the connection.

quit_on

pub fn quit_on(h: *ClientHandle)

Sends QUIT and closes the connection.

Errors while sending are ignored, and the connection is closed in every case. Safe to call more than once.

reset_on

pub fn reset_on(h: *ClientHandle) ! Error

Sends RSET, which abandons any mail transaction in progress, and waits for the reply. Fails like noop_on.

send_on

pub fn send_on(h: *ClientHandle, m: mail.Message) -> Receipt ! Error

Renders m with mail.render and sends it to the recipients from mail.recipients, which include bcc.

The envelope sender is m.from.email, and 8BITMIME and SMTPUTF8 are requested when mail.needs_8bit and mail.needs_utf8 report that the message needs them. Fails with Invalid when the message cannot be rendered or has no valid recipients, and with the errors of send_raw_on.

send_raw_on

pub fn send_raw_on(h: *ClientHandle, e: Envelope, data: []u8) -> Receipt ! Error

Sends data, a complete RFC 5322 message, with the given envelope.

The data is dot stuffed and terminated here. The transaction is MAIL FROM, one RCPT TO per recipient and DATA; when the server advertises PIPELINING the first two are sent together. SIZE is declared when the server announces a limit. A recipient the server refuses is listed in Receipt.refused and does not fail the call. The call fails with Transient or Permanent when the sender, every recipient, the DATA command or the final reply is refused; RSET is sent when every recipient or the DATA command is refused. It fails with Invalid for an invalid address or no recipients, Unsupported when the envelope needs 8BITMIME or SMTPUTF8 and the server lacks it, MessageTooLarge when the data exceeds the announced size, and Closed, Timeout or Protocol on transport failures, which close the connection. Waits for any command in progress.

set_timeout_on

pub fn set_timeout_on(h: *ClientHandle, millis: i64)

Sets how many milliseconds each read and write on the connection may take before failing with Timeout. 0 removes the limit.

Applies to later operations.

start_tls_on

pub fn start_tls_on(h: *ClientHandle, config: tls.Config) ! Error

Sends STARTTLS, performs the TLS handshake and repeats EHLO over the encrypted channel, refreshing extensions.

Does nothing when the connection is already encrypted. Fails with Unsupported("STARTTLS") when the server does not advertise it, Closed when the client is closed, Transient or Permanent when the server refuses, and Connect, Timeout or Protocol when the handshake fails or the server sent data before it, which closes the connection. config.server_name defaults to the host of the connection. Waits for any command in progress.

connect

pub fn connect(o: Options) -> Client ! Error

Connects to the server in plain text, reads the greeting, sends EHLO and authenticates when o.username is set.

If the server rejects EHLO with a 5xx code, HELO is tried. Fails with Connect or Timeout while connecting, Transient or Permanent when the server refuses the greeting or the hello, and with the errors of authenticate, which includes Insecure for password mechanisms unless o.insecure_auth is set. A failure after the connection is made closes it.

connect_starttls

pub fn connect_starttls(o: Options, config: tls.Config) -> Client ! Error

Connects like connect but upgrades to TLS with STARTTLS after the first EHLO, repeats EHLO over the encrypted channel and then authenticates.

Fails with Unsupported("STARTTLS") when the server does not offer it, and with the errors of connect otherwise. config.server_name defaults to o.host.

connect_tls

pub fn connect_tls(o: Options, config: tls.Config) -> Client ! Error

Connects with TLS from the first byte, as on port 465, then reads the greeting, sends EHLO and authenticates when o.username is set.

Fails with Connect or Timeout when the connection or handshake fails, and with the errors of connect after that. config.server_name defaults to o.host.

Functions

choose

pub fn choose(advertised: []str, encrypted: bool) -> Mechanism?

Returns the preferred mechanism the server advertises, or none when it advertises none of them.

On an encrypted connection the order is Plain, Login, CramMd5. On an unencrypted one CramMd5 comes first, because it does not send the password. XOAuth2 and Auto are never returned.

connect_stream

pub fn connect_stream(s: io.Stream, o: Options) -> Client ! Error

Runs the SMTP session over an already open stream instead of dialling.

The stream is treated as unencrypted, so password mechanisms need o.insecure_auth. o.timeout and set_timeout have no effect, because the client holds no socket of its own to apply them to. Fails like connect, and closes the stream on failure.

dot_stuff

pub fn dot_stuff(data: []u8) -> []u8

Returns data framed for the SMTP DATA command.

Every line break (\r\n, \n or a lone \r) becomes \r\n, a . at the start of a line is doubled, a missing final line break is added, and the terminator .\r\n is appended. Empty input gives only the terminator.

login_response

Returns the base64 encoding of value, the response to each LOGIN prompt. Use it once for the user name and once for the password.

parse_reply_with

pub fn parse_reply_with(data: []u8, limits: Limits) -> Reply ! Error

Parses the first reply in data, which may span several lines such as 250-first and 250 last. Data after the reply is ignored.

Fails with Protocol when a code is not three digits from 100 to 599, the codes of the lines differ, a separator is not a space or -, or the data ends before the last line, and with TooLarge when the reply has more than limits.lines lines.

plain_response

pub fn plain_response(user: str, password: str) -> str

Returns the base64 initial response of PLAIN: an empty authorization identity, user and password, each preceded by a NUL byte.

read_reply

pub fn read_reply(r: *io.Reader, limits: Limits) -> Reply ! Error

Reads one reply from r, which may span several lines.

Blocks until the last line arrives. Fails with Protocol for a malformed or inconsistent reply, TooLarge when it has more than limits.lines lines or a line over the reader's limit, Timeout when the stream times out, and Closed when the stream ends or fails first.

Maps an I/O error onto the SMTP error type: TimedOut becomes Timeout, TooLarge stays TooLarge, Malformed becomes Protocol and everything else becomes Closed.
