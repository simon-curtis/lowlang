std/charset

#encoding #text

import std/charset

decode, decode_lossy, encode, encode_replace, canonical (WHATWG labels) and detect_bom for UTF-8, UTF-16, UTF-32, ISO-8859-1, -2 and -15, windows-1250, -1251 and -1252, KOI8-R, IBM437 and IBM850. The CJK encodings are not provided.

Imports std/text, std/unicode, std/unicode/utf16, std/unicode/utf32.

Functions

canonical

pub fn canonical(label: str) -> str?

Returns the canonical encoding name for label, or none when the label is unknown. The label is trimmed and compared case-insensitively. Aliases such as latin1, ascii, cp1252 and utf8 resolve to a canonical name; the supported names are UTF-8, UTF-16LE, UTF-16BE, UTF-32LE, UTF-32BE, ISO-8859-1, ISO-8859-2, ISO-8859-15, windows-1250, windows-1251, windows-1252, KOI8-R, IBM437 and IBM850. The labels utf-16 and utf-32 mean the little-endian forms, and ascii and us-ascii mean windows-1252.

decode

pub fn decode(label: str, data: []u8) -> str ! Error

Decodes data written in the encoding named by label into a UTF-8 string. A leading UTF-8 byte order mark is dropped. For UTF-16 and UTF-32 a leading byte order mark selects the byte order over the one the label names and is dropped. Single-byte encodings accept every byte: values below 0x80 map to themselves and the rest through the encoding's table.

Fails with UnknownEncoding when label is not recognised and with Malformed at the byte offset of the first invalid UTF-8 sequence, lone UTF-16 surrogate or invalid UTF-32 code point. An odd trailing byte in UTF-16, or one to three trailing bytes in UTF-32, fails at the start of the incomplete unit.

decode_lossy

pub fn decode_lossy(label: str, data: []u8) -> str ! Error

Decodes data written in the encoding named by label into a UTF-8 string, replacing invalid input with U+FFFD. Byte order marks are handled as in decode. Fails only with UnknownEncoding.

detect_bom

pub fn detect_bom(data: []u8) -> Bom?

Returns the byte order mark at the start of data, or none when there is none. FF FE 00 00 is reported as UTF-32LE before FF FE is considered as UTF-16LE.

encode

pub fn encode(label: str, s: str) -> []u8 ! Error

Encodes s in the encoding named by label. UTF-16 and UTF-32 are written without a byte order mark. Invalid UTF-8 in s is written as U+FFFD. Fails with UnknownEncoding when label is not recognised and with Unmappable for the first character a single-byte encoding cannot represent.

encode_replace

pub fn encode_replace(label: str, s: str, replacement: str) -> []u8 ! Error

Encodes s in the encoding named by label, writing replacement for each character a single-byte encoding cannot represent. The UTF-8 bytes of replacement are written unchanged. Fails only with UnknownEncoding.
