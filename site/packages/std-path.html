std/path

#os

import std/path

Slash-separated path manipulation: clean (lexical, resolving . and ..), join, base, dir, ext, stem and is_absolute. matches matches shell globs with *, ?, [...] classes (ranges, ! or ^ negation) and \ escapes; no wildcard crosses a /.

Imports std/text.

Functions

base

pub fn base(p: str) -> str

Returns the last segment of p after trailing slashes are removed.

Returns "." for the empty string and "/" when p consists only of slashes.

clean

pub fn clean(p: str) -> str

Returns the shortest equivalent of p by lexical processing alone, without touching the file system.

Repeated slashes and . segments are dropped and a .. removes the segment before it. A leading .. is kept in a relative path and dropped in an absolute one. A trailing slash is removed. An empty result is "." for a relative path and "/" for an absolute one.

dir

pub fn dir(p: str) -> str

Returns p without its last segment, cleaned.

Returns "." when p contains no slash, and "/" for a path directly under the root.

ext

pub fn ext(p: str) -> str

Returns the extension of the last segment of p, including the leading dot, or the empty string when it has none.

The extension starts at the last . in the final segment, so "a.tar.gz" gives ".gz" and a name that starts with a dot such as ".profile" gives the whole name. A path that ends in a slash has no extension.

is_absolute

pub fn is_absolute(p: str) -> bool

Returns true when p starts with /.

The empty string is not absolute.

join

pub fn join(parts: []str) -> str

Joins the non-empty parts with / and returns the cleaned result.

Empty parts are skipped. Returns the empty string, not ".", when no part is non-empty. Later absolute parts do not replace earlier ones: join(["a", "/b"]) is "a/b".

matches

pub fn matches(pattern: str, name: str) -> bool

Returns true when name matches the glob pattern in full.

  • * matches any run of characters, including none.
  • ? matches one character.
  • [abc] and [a-z] match one character of the set; a leading ! or ^ negates it, and a ] right after the opening bracket is a member of the set.
  • \ makes the next pattern character literal.

*, ? and sets never match /; a / in the pattern matches only a / in the name. An unterminated [ matches nothing. The match is bytewise and does not treat a leading dot specially.

stem

pub fn stem(p: str) -> str

Returns the last segment of p without its extension.

The segment is taken as base returns it and the suffix as ext returns it from that segment.
