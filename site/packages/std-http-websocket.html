std/http/websocket

#net #web

import std/http/websocket

accept and dial over ws and wss return a droppable Socket that sends a normal close when released. Operations: receive, send_text, send_binary, ping and close, with _on forms, and adopt and detach on the *SocketHandle.

Imports std/base64, std/crypto, std/http, std/io, std/text.

Socket

pub struct Socket {
    /// The shared connection state, for use with the `_on` functions.
    pub handle: *SocketHandle
    ...
}

An open WebSocket connection that closes itself.

Dropping a Socket sends a close frame with code 1000 and waits for the peer's close, unless it was detached. Use detach to keep the connection open past the end of the scope.

close

pub fn close(ws: Socket, code: i64) ! io.Error

Closes the connection with the status code.

Sends a close frame with code unless one has been exchanged already, then reads and discards messages until the peer's close frame or an error, and releases the connection; a client side closes its stream. Blocks until then. Normal closure is 1000. Fails with the write error when the close frame cannot be sent, and the connection is still released.

detach

pub fn detach(mut s: Socket) -> *SocketHandle

Stops s closing its connection on drop and returns its handle.

The caller becomes responsible for calling close_on.

ping

pub fn ping(ws: Socket, data: []u8) ! io.Error

Sends a ping frame carrying data, which the protocol limits to 125 bytes.

The peer's pong is skipped by receive. Fails with NotConnected once the socket is closed, or with the write error.

receive

pub fn receive(ws: Socket) -> Message ! io.Error

Blocks until a complete message arrives and returns it.

Fragments are joined into one Message of at most 16 MiB. Ping frames are answered with a pong and pong frames are skipped, so neither is returned. When the peer sends a close frame the close is echoed and the call fails with Eof.

A protocol violation, such as a bad frame, a text message that is not UTF-8 or a message over the size limit, sends a close frame with code 1002, 1007 or 1009 and fails with Malformed. A connection that ends fails with Eof, and any other read failure with Reset. Fails with NotConnected once the socket is closed.

The state of one WebSocket connection: the reader over the connection, which side it is, and whether it has been closed.

A *SocketHandle can be shared between tasks and passed to the _on functions, which exist so a connection can be used without an owning Socket.

Functions

accept

pub fn accept(req: http.Request) -> Socket ! io.Error

Completes the server side of the WebSocket handshake for req and returns the open connection.

req must be a GET that has upgrade: websocket, a connection header with the upgrade token, sec-websocket-version: 13 and a sec-websocket-key that decodes to 16 bytes. The 101 Switching Protocols response is written to the connection directly. The origin header, subprotocols and extensions are not examined.

Fails with Unsupported when req has no connection to take over, as on HTTP/2, and with Malformed when a handshake requirement is not met. Write failures are returned as they occur. After using the socket, return upgraded() from the handler.

import std/http
import ws = std/http/websocket

fn echo(req: http.Request) -> http.Response {
    using s = ws.accept(req) catch {
        _ => return http.response(400, "bad handshake")
    }
    for {
        let m = ws.receive(s) catch {
            _ => break
        }
        ws.send_text(s, str(m.data)) catch {
            _ => break
        }
    }
    http.upgraded()
}

dial

pub fn dial(url: str) -> Socket ! io.Error

Connects to a ws or wss URL, performs the client handshake and returns the open connection.

Messages the client sends are masked as the protocol requires. Fails with Unsupported for any other scheme, with the error from parse_url for a bad URL, with the connection or TLS error when connecting fails, and with Refused when the handshake cannot be completed or the server does not answer 101 with the expected sec-websocket-accept.
