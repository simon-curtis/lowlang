std/header

#net #web

import std/header

The header primitives below std/http, std/multipart and std/mail: Header, get, values, has, add, set, remove, token, token_byte, valid_value, valid, quote, and parse_value with param, which resolve RFC 2231 and 5987 parameters.

Imports std/charset, std/text, std/uri.

get

pub fn get(headers: []Header, name: str) -> str?

Returns the value of the first header in headers whose name equals name, ignoring case, or none when there is none.

has

pub fn has(headers: []Header, name: str) -> bool

Returns true when headers has a header named name, ignoring case.

parse_value

pub fn parse_value(s: str) -> Value

Parses a header value into its main part and parameters.

A parameter value may be a quoted string, in which \" and \\ are unescaped. Parameters in the RFC 2231 forms are resolved: name*=charset'language'text is percent-decoded, and the pieces name*0, name*1 and so on are joined in order. A value in ISO-8859-1, latin1 or US-ASCII is converted to UTF-8, and any other charset is taken as UTF-8. The extended form wins over the plain one, and when a name is repeated the first occurrence wins.

quote

pub fn quote(value: str) -> str

Returns value as a quoted string for a header parameter.

" and \ are escaped with a backslash, and a carriage return, line feed or zero byte becomes %0D, %0A or %00, so the result always passes valid_value.

remove

pub fn remove(headers: []Header, name: str) -> []Header

Returns the headers of headers whose name differs from name, ignoring case, in a new slice.

set

pub fn set(mut headers: []Header, name: str, value: str)

Replaces the value of the first header in headers named name, ignoring case, using the spelling of name given here, or appends the header when there is none. Further headers of the same name are left alone.

token

pub fn token(s: str) -> bool

Returns true when s is not empty and every byte is a token byte.

token_byte

pub fn token_byte(c: u8) -> bool

Returns true when c may appear in an RFC 9110 token: a letter, a digit, the grave accent or one of !#$%&'*+-.^_|~.

valid_value

pub fn valid_value(value: str) -> bool

Returns true when value has no \r, \n or zero byte.

values

pub fn values(headers: []Header, name: str) -> []str

Returns the values of every header in headers whose name equals name, ignoring case, in order. The slice is empty when there are none.
