std/archive/zip

#compression

import std/archive/zip

Zip archives read through the central directory, with zip64, stored and deflate entries, CRC-32 checks and limits on entries, sizes and compression ratio. Written with add_file, add_dir, add_symlink and finish, which emits zip64 records when a count or size needs them. extract works over the filesystem. Encrypted entries and other methods fail with Unsupported.

Imports std/archive, std/compress/deflate, std/hash, std/io, std/slices, std/text, std/time/date, std/time/datetime.

extract_archive

pub fn extract_archive(a: Archive, dir: str) ! io.Error

Extracts every entry of a below dir, creating dir and its missing parents.

Every name is checked with archive.clean_name before anything is written, so an unsafe name fails with Denied or Malformed and leaves the filesystem unchanged. Then each entry goes through archive.resolve, which also rejects a path through a symbolic link below dir. Directories are created with their mode. Files are created exclusively and without following links, replacing an existing file or link, with permission bits masked to 0o777 and the modification time applied; the process umask applies. A symbolic link is created with its entry data as the target, which is not validated. Directory modification times are not applied.

Fails with the errors of read and of the filesystem.

find

pub fn find(a: Archive, name: str) -> Entry?

Returns the first entry whose name equals name, or none.

read

pub fn read(a: Archive, e: Entry) -> []u8 ! io.Error

Returns the uncompressed data of the entry e of a in a new slice.

Fails with Unsupported for an encrypted entry or a method other than stored or deflate, with TooLarge when e.size exceeds Limits.entry, and with Malformed when the local header is missing or out of range, the stored sizes disagree, the deflate data is invalid, or the length or CRC-32 of the result does not match the entry.

read_entry

pub fn read_entry(a: Archive, name: str) -> []u8 ! io.Error

Returns the uncompressed data of the entry named name.

Fails with NotFound when there is no such entry, and otherwise as read does.

Writer

pub struct Writer {
    ...
}

A zip writer made by writer or stream_writer.

Each entry is written as add is called, compressed in memory, and finish writes the central directory. Entries are written without data descriptors.

add

pub fn add(w: *Writer, e: Entry, data: []u8) ! io.Error

Writes the entry e with data as its contents.

A File is compressed per e.method. A Symlink stores data as the link target. A Dir stores no data and gets a trailing / when it lacks one. The type and the low 12 bits of e.mode are recorded as Unix attributes, e.mtime as an MS-DOS timestamp and as an extended timestamp when it is between 0 and 0xFFFFFFFF, and a non-ASCII name sets the UTF-8 flag. Sizes or offsets of 0xFFFFFFFF or more are written as zip64 extra fields.

Fails with Invalid after finish, for an empty name, a name longer than 65535 bytes and a name with a NUL byte, and with the error of the sink.

add_dir

pub fn add_dir(w: *Writer, name: str) ! io.Error

Writes a directory name with mode 0o755 and a modification time of 0.

add_file

pub fn add_file(w: *Writer, name: str, data: []u8, method: Method) ! io.Error

Writes a regular file name with data compressed with method, with mode 0o644 and a modification time of 0.

add_symlink

pub fn add_symlink(w: *Writer, name: str, target: str) ! io.Error

Writes a symbolic link name that points to target, with mode 0o777 and a modification time of 0.

finish

pub fn finish(w: *Writer) ! io.Error

Writes the central directory and the end of central directory record.

zip64 end records are added when the writer is forced, when the entry count reaches 0xFFFF or when the directory size or offset reaches 0xFFFFFFFF. A second call does nothing. After finish, add fails with Invalid.

force_zip64

pub fn force_zip64(w: *Writer)

Makes the writer use zip64 records for every entry added after the call and for the end of the archive, even when no size or count needs them.

output

pub fn output(w: *Writer) -> []u8

Returns the bytes collected by a Writer made with writer.

Call it after finish for a complete archive. It is empty for a stream writer.

open_with

pub fn open_with(data: []u8, limits: Limits) -> Archive ! io.Error

Opens the zip archive in data by reading its central directory, applying limits.

zip64 archives are supported. Entry data is neither decompressed nor checked until it is read.

Fails with Malformed when no end of central directory record is found in the last 64 KiB or the records are inconsistent, with Unsupported for an archive split over several disks, and with TooLarge when the entry count, an entry size, the total size or the compression ratio exceeds a limit.

stream_writer

pub fn stream_writer(sink: io.Stream) -> *Writer

Returns a Writer that writes the archive to sink.

The writer does not close sink, and output stays empty.
