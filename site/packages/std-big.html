std/big

#math

import std/big

Int over 32-bit limbs. Parsing and printing in bases 2 to 36 (printing divides the limbs, packed into 64-bit words, by the largest power of the base below 2^64 with a precomputed reciprocal). add, sub, mul (Karatsuba), divmod, divmod_floor, divmod_euclid, pow, modpow (Montgomery for odd moduli), mod_inverse, gcd, lcm, isqrt. Shifts and bitwise operators with two's complement semantics. is_probable_prime, next_prime, random_below, to_f64, from_bytes and to_bytes. Division by zero is an error. Not constant time.

Imports std/bits, std/crypto, std/text.

Int

pub struct Int {

An arbitrary-precision signed integer.

Stored as a sign and a magnitude of 32-bit limbs. Zero is never negative. An Int is a value: every operation returns a new Int and leaves its arguments unchanged. Operations are not constant time.

is_probable_prime

pub fn is_probable_prime(n: Int, rounds: i64) -> bool

Returns true when n is probably prime.

Negative numbers, zero and one are not prime. Trial division by the primes below 1000 comes first, then Miller-Rabin. The test is deterministic for n below 2^81. Above that it uses base 2 plus rounds random bases drawn from the operating system's random source.

modpow

pub fn modpow(base: Int, exp: Int, modulus: Int) -> Int ! Error

Returns base raised to exp modulo |modulus|, as a value in 0..|modulus|.

Uses Montgomery multiplication with a sliding window for an odd modulus and plain square-and-multiply for an even one. A negative exp raises the modular inverse of base to -exp. A modulus of 1 or -1 gives zero. Fails with DivideByZero when modulus is zero and with NoInverse when exp is negative and base has no inverse. Not constant time.

to_f64_scaled

pub fn to_f64_scaled(a: Int, exp2: i64, sticky: bool) -> f64

Returns (a + e) * 2^exp2 as an f64 rounded to nearest, ties to even, where e is a fraction below one unit of a that is non-zero exactly when sticky is true.

sticky lets a caller that has already discarded low bits of an exact quotient keep rounding correct. Results below the normal range round to subnormals or to zero, and results beyond the f64 range are infinite.

parse

pub fn parse(s: str, base: i64) -> Int ! Error

Parses an integer written in base.

The text may start with + or -, and digits may be separated by single _ characters. Letters are accepted in either case. With base 0 the base is taken from a 0x, 0b or 0o prefix after the sign and is 10 without one; with any other base a prefix is not recognised. Fails with Empty when there are no digits, with BadBase when base is not 0 or in 2 to 36, and with BadDigit carrying the byte offset of a character that is not a digit of the base or of a _ that does not follow a digit.
