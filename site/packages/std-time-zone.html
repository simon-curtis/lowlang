std/time/zone

#time

import std/time/zone

IANA zones. Zone is a shared value decoded once, from named (the host database, honouring ZONEINFO), load_from (any fn(str) -> []u8?), local (TZ, /etc/localtime, /etc/timezone, then UTC), from_posix, decode, utc or fixed. fixed_offset returns the offset of a zone fixed made. Queries: info_at, candidates (One, Overlap, Gap for a civil time), next_transition, previous_transition and transitions.

Imports std/file, std/io, std/math, std/os, std/text, std/time/calendar, std/time/fault, std/time/offset, std/time/scan, std/time/timestamp.

Examples

transitions

import std/time/datetime
import std/time/fault
import std/time/offset
import std/time/timestamp
import std/time/tzdata
import std/time/zone

fn describe(info: zone.Info) -> str {
    "{info.abbreviation} {offset.to_string(info.offset)}{if info.dst { " (daylight saving)" } else { "" }}"
}

fn local_seconds(text: str) -> i64 ! fault.Fault {
    datetime.civil_seconds(datetime.parse(text)?)
}

fn classify(z: zone.Zone, text: str) -> str ! fault.Fault {
    match zone.candidates(z, local_seconds(text)?) {
        One(only) => "{text} happens once at {offset.to_string(only)}"
        Overlap(earlier, later) => "{text} happens twice, at {offset.to_string(earlier)} then {offset.to_string(later)}"
        Gap(before, after) => "{text} never happens, the clock jumps from {offset.to_string(before)} to {offset.to_string(after)}"
    }
}

/// Reads rules from the embedded database and lists a year of daylight saving changes for two zones.
fn main() ! fault.Fault {
    let london = zone.load_from("Europe/London", tzdata.source())?
    let sydney = zone.load_from("Australia/Sydney", tzdata.source())?
    let year_start = timestamp.parse("2026-01-01T00:00:00Z")?
    let year_end = timestamp.parse("2027-01-01T00:00:00Z")?

    for tz in [london, sydney] {
        print("{zone.name(tz)} on New Year's Day: {describe(zone.info_at(tz, year_start))}")
        for change in zone.transitions(tz, year_start, year_end) {
            print("  {timestamp.to_string(change.at)}: {describe(change.before)} -> {describe(change.after)}")
        }
    }

    print(classify(london, "2026-03-29T01:30:00")?)
    print(classify(london, "2026-10-25T01:30:00")?)
    print(classify(london, "2026-11-13T09:00:00")?)

    let summer = timestamp.parse("2026-07-01T12:00:00Z")?
    print("london in july: offset {offset.to_string(zone.offset_at(london, summer))}, daylight saving {zone.is_dst_at(london, summer)}")
    let next = zone.next_transition(london, summer)
    match next {
        some(change) => print("next change {timestamp.to_string(change.at)} to {describe(change.after)}")
        none => print("no further changes")
    }
    let last = zone.previous_transition(london, summer)
    match last {
        some(change) => print("last change {timestamp.to_string(change.at)} to {describe(change.after)}")
        none => print("no earlier changes")
    }

    let rule = zone.from_posix("CET-1CEST,M3.5.0,M10.5.0/3", "Custom/Europe")?
    print("{zone.name(rule)} in july: {describe(zone.info_at(rule, summer))}")
    let plus_nine = zone.fixed(offset.hours(9)?)
    print("fixed zone {zone.name(plus_nine)} fixed {zone.is_fixed(plus_nine)}, offset {offset.to_string(zone.fixed_offset(plus_nine) ?? offset.utc())}")
    print("london fixed {zone.is_fixed(london)}")

    let missing = zone.load_from("Atlantis/Lost", tzdata.source()) catch {
        UnknownZone(name) => {
            print("no zone named {name}")
            zone.utc()
        }
        _ => zone.utc()
    }
    print("fell back to {zone.name(missing)}")
}

Candidates

pub enum Candidates {The local time occurs once, at only.    One(offset.Offset)The local time occurs twice because the clocks go back. earlier is the offset of the first occurrence and later is the offset of the second.    Overlap(offset.Offset, offset.Offset)The local time does not occur because the clocks go forward. before is the offset in force before the change and after is the offset after it.    Gap(offset.Offset, offset.Offset)
}

The offsets a zone allows for one local date and time, which a local time needs because daylight saving changes can repeat it or skip it.

Zone

pub struct Zone {
    ...
}

A time zone: a name and the rules that give the UTC offset at each instant.

Copies of a Zone share the same rules. A zone is made by named, local, load_from, from_posix, fixed or utc.

candidates

pub fn candidates(z: Zone, local_seconds: i64) -> Candidates

Returns the offsets z allows for a local time given as seconds since the Unix epoch counted as if the local clock were UTC.

The result is One for a time that occurs once, Overlap for one that occurs twice and Gap for one that does not occur.

fixed_offset

pub fn fixed_offset(z: Zone) -> offset.Offset?

Returns the offset of z when z is the zone fixed makes for it, and none for every other zone.

A zone from from_posix, decode or a database file is not such a zone, even when its offset never changes, because fixed also decides the name.

info_at

pub fn info_at(z: Zone, ts: timestamp.Timestamp) -> Info

Returns the Info in force in z at ts.

is_dst_at

pub fn is_dst_at(z: Zone, ts: timestamp.Timestamp) -> bool

Returns whether daylight saving time is in effect in z at ts.

is_fixed

pub fn is_fixed(z: Zone) -> bool

Returns whether z has a single offset for all time, with no recorded transitions and no daylight saving rule.

name

pub fn name(z: Zone) -> str

Returns the name of z.

next_transition

pub fn next_transition(z: Zone, ts: timestamp.Timestamp) -> Transition?

Returns the first change of offset, abbreviation or daylight saving flag after ts, or none when the zone has none after it.

A fraction of a second in ts is ignored. A transition outside the supported timestamp years is not returned.

offset_at

pub fn offset_at(z: Zone, ts: timestamp.Timestamp) -> offset.Offset

Returns the UTC offset in force in z at ts.

previous_transition

pub fn previous_transition(z: Zone, ts: timestamp.Timestamp) -> Transition?

Returns the latest change of offset, abbreviation or daylight saving flag before ts, or none when the zone has none before it.

transitions

pub fn transitions(z: Zone, from: timestamp.Timestamp, to: timestamp.Timestamp) -> []Transition

Returns the changes of z from from up to but not including to, in time order.

At most 10000 are returned.

Functions

decode

pub fn decode(name: str, data: []u8) -> Zone ! fault.Fault

Returns the zone name decoded from the TZif data data.

It reads the 64-bit block of a version 2 or later file and its POSIX rule footer, which continues the zone past the last stored transition, and reads the 32-bit block of a version 1 file. Fails with Malformed when the header, a transition type, an offset, an abbreviation or the footer is not valid.

fixed

pub fn fixed(o: offset.Offset) -> Zone

Returns a zone that always has the offset o.

It is named UTC for a zero offset and otherwise by the offset text, such as +05:30, and that is also its abbreviation.

from_posix

pub fn from_posix(rule: str, name: str) -> Zone ! fault.Fault

Returns a zone described by the POSIX TZ rule rule, named name.

A rule such as CET-1CEST,M3.5.0,M10.5.0/3 has standard and daylight names, offsets and the dates the daylight period starts and ends. A rule without daylight saving gives a fixed zone. Fails with Syntax at the offset of the first byte of the rule that does not fit.

load_from

pub fn load_from(name: str, source: fn(str) -> []u8?) -> Zone ! fault.Fault

Returns the zone with the name name, with its TZif data supplied by source.

source returns the data for a name, or none when it has none. Use tzdata.source() to read the embedded database. Fails with Invalid for a bad name as named does, with UnknownZone when source returns none, and with Malformed when the data is not valid.

local

pub fn local() -> Zone ! fault.Fault

Returns the system's local time zone.

The TZ environment variable is used when it is set. A leading : is dropped, an empty value is UTC, a value starting with / is a zone file, and other values are tried as a zone name and then as a POSIX rule. Failing all of those gives UnknownZone. Without TZ the zone comes from /etc/localtime, named from the link target after zoneinfo/ or Local, then from the name in /etc/timezone, and falls back to UTC.

named

pub fn named(name: str) -> Zone ! fault.Fault

Returns the zone with the IANA name name, such as Europe/Paris.

The name is read from the directory in the ZONEINFO environment variable when it is set and has the file, and then from /usr/share/zoneinfo. Fails with Invalid when the name is empty, starts with /, or contains .., a backslash or a NUL byte. Fails with UnknownZone when no file has the name, except that UTC then returns utc(). Fails with Malformed when the file is unreadable or is not valid TZif data.

utc

pub fn utc() -> Zone

Returns the zone with a zero offset, named UTC.
