std/webauthn

#crypto #web

import std/webauthn

A WebAuthn relying party: registration and authentication options as JSON, registration and authentication verification for ES256, EdDSA and RS256 credentials, and COSE key parsing.

Imports std/base64, std/cbor, std/crypto, std/crypto/ecdsa, std/crypto/ed25519, std/crypto/hash, std/crypto/rsa, std/json.

Error

pub enum Error {
    /// A member of the credential JSON is missing, has the wrong type or is not valid Base64url. `field` names it.
    MalformedCredential(str)
    /// The credential `id` is not the Base64url of `rawId`.
    IdMismatch
    /// The credential `type` is not `public-key`. `found` is the type received.
    WrongCredentialType(str)
    /// `clientDataJSON` is not a JSON object with string `type`, `challenge` and `origin` members, or its challenge is not Base64url.
    MalformedClientData
    /// The client data `type` is not `webauthn.create` for a registration or `webauthn.get` for an authentication. `found` is the type received.
    WrongClientDataType(str)
    /// The client data challenge differs from `Expected.challenge`.
    ChallengeMismatch
    /// The client data origin differs from `Expected.origin`. `found` is the origin received.
    OriginMismatch(str)
    /// The attestation object is not a CBOR map with a text `fmt` and a byte string `authData`.
    MalformedAttestationObject
    /// The attestation format is not `none`. `format` is the format received.
    UnsupportedAttestation(str)
    /// The attestation statement is not an empty map, as the `none` format requires.
    UnexpectedAttestationStatement
    /// The authenticator data is shorter than 37 bytes, has invalid attested credential data or extensions, or has trailing bytes.
    MalformedAuthenticatorData
    /// The authenticator data does not start with the SHA-256 of `Expected.rp_id`.
    RpIdHashMismatch
    /// The user present (`UP`) flag is not set.
    UserNotPresent
    /// `Expected.require_user_verification` is set and the user verified (`UV`) flag is not.
    UserNotVerified
    /// A registration response has no attested credential data or an empty credential id.
    MissingCredentialData
    /// The backup state (`BS`) flag is set while backup eligibility (`BE`) is not.
    InconsistentBackupFlags
    /// The credential public key is not a valid COSE_Key for a supported algorithm.
    MalformedPublicKey
    /// The credential public key uses a COSE algorithm other than `-7`, `-8` and `-257`. `alg` is the identifier received.
    UnsupportedAlgorithm(i64)
    /// The assertion signature does not verify under the stored public key.
    BadSignature
    /// The signature counter did not increase, which can indicate a cloned authenticator. `received` is the counter in the response and `stored` the one the caller holds.
    SignCountRegression(i64, i64)
}

PublicKey

pub enum PublicKey {
    /// A P-256 ECDSA key as the 65-byte uncompressed SEC 1 point: `0x04` followed by the 32-byte `x` and `y` coordinates.
    Es256([]u8)
    /// An Ed25519 key as its 32-byte public key (RFC 8032).
    EdDsa([]u8)
    /// An RSA key for RSASSA-PKCS1-v1_5 with SHA-256 (RFC 8017), with the modulus and exponent stripped of leading zero bytes.
    Rs256(rsa.PublicKey)
}

A credential public key decoded from a COSE_Key (RFC 9052).

The supported algorithms are ES256 (COSE -7), EdDSA with Ed25519 (-8) and RS256 (-257).

verify_signature

pub fn verify_signature(key: PublicKey, data: []u8, signature: []u8) -> bool

Returns whether signature is a valid signature of data under key.

ES256 verifies a DER encoded ECDSA signature over the SHA-256 of data, RS256 a PKCS#1 v1.5 signature over the SHA-256 of data and EdDSA a signature over data itself. Returns false, not an error, for a signature that does not verify.

registration_options turns it into the JSON for navigator.credentials.create. The defaults for user_id and challenge are evaluated each time a value is built, so every request gets fresh random values.

registration_options

pub fn registration_options(o: RegistrationOptions) -> json.Value

Returns the JSON object for PublicKeyCredentialCreationOptions described by o.

Binary values (user.id, challenge and credential ids) are Base64url without padding, as the JSON form of the WebAuthn API expects. attestation is always none, matching verify_registration, which accepts only that format. authenticatorSelection is present only when o.selection is set.

Functions

parse_public_key

pub fn parse_public_key(cose_key: []u8) -> PublicKey ! Error

Decodes a CBOR encoded COSE_Key into a PublicKey.

The alg label (3) selects the type and must agree with the other labels: ES256 needs key type 2 (EC2), curve 1 (P-256) and 32-byte x and y; EdDSA needs key type 1 (OKP), curve 6 (Ed25519) and a 32-byte x; RS256 needs key type 3 (RSA) and a non-empty modulus n and exponent e. Fails with MalformedPublicKey when the CBOR is invalid, is not a map or a label is missing, has the wrong type or the wrong value, and with UnsupportedAlgorithm carrying the alg for any other algorithm.

verify_authentication

pub fn verify_authentication(credential_json: json.Value, expected: Expected, public_key: []u8, sign_count: i64) -> Authentication ! Error

Verifies the JSON of a navigator.credentials.get response against the stored credential and returns the result.

credential_json is the JSON form of a PublicKeyCredential whose response has clientDataJSON, authenticatorData and signature, Base64url encoded. public_key and sign_count are the values saved from Registration or the last Authentication; the caller finds them from the credential id before calling. The checks are those of verify_registration with the client data type webauthn.get, then the signature counter, then the signature over the authenticator data followed by the SHA-256 of the client data.

The counter is checked only when either value is nonzero, and must then be strictly greater than sign_count, otherwise SignCountRegression is returned. Fails with BadSignature when the signature does not verify and otherwise with the Error variant of the first check that fails.

verify_registration

pub fn verify_registration(credential_json: json.Value, expected: Expected) -> Registration ! Error

Verifies the JSON of a navigator.credentials.create response and returns the credential to store.

credential_json is the JSON form of a PublicKeyCredential (id, rawId, type and a response with clientDataJSON and attestationObject, Base64url encoded). The checks follow WebAuthn registration verification: the credential id and type, the client data type webauthn.create, challenge and origin, the rpIdHash, the UP flag (and UV when required), the attested credential data and its COSE public key, and the backup flags. Only the none attestation format with an empty statement is accepted; no attestation signature or certificate chain is verified.

Fails with the Error variant of the first check that fails.
