std/crypto/md5

#crypto

import std/crypto/md5

MD5 as a hash.Algorithm, so HMAC, HKDF and PBKDF2 work over it, and sum. For interop and checksums, not security.

Imports std/bits, std/crypto/hash, std/io.

Functions

md5

pub fn md5() -> hash.Algorithm

Returns the hash.Algorithm for MD5 (RFC 1321).

The name is md5, the digest is 16 bytes and the block size is 64 bytes. MD5 is not collision resistant; use it only where a protocol requires it.
