std/crypto/md5

#crypto

import std/crypto/md5

MD5 as a hash.Algorithm, so HMAC, HKDF and PBKDF2 work over it, and sum. For interop and checksums, not security.

Imports std/bits, std/crypto/hash, std/io.

Examples

manifest

import std/base64
import std/crypto/md5
import std/text

struct Entry {
    name: str
    body: str
    listed: str
}

/// Checks each payload against the MD5 checksum its manifest lists, then builds a Content-MD5 header value.
fn main() {
    let entries = [
        Entry { name: "empty.txt", body: "", listed: "d41d8cd98f00b204e9800998ecf8427e" },
        Entry { name: "greeting.txt", body: "The quick brown fox jumps over the lazy dog", listed: "9e107d9d372bb6826bd81d3542a419d6" },
        Entry { name: "tampered.txt", body: "The quick brown fox jumps over the lazy cog", listed: "9e107d9d372bb6826bd81d3542a419d6" },
    ]
    for entry in entries {
        let actual = text.encode_hex(md5.sum(bytes(entry.body)))
        let verdict = if actual == entry.listed { "ok" } else { "MISMATCH" }
        print("{entry.name} {verdict}")
    }

    let streaming = md5.md5().digest()
    for part in ["The quick brown fox ", "jumps over ", "the lazy dog"] {
        streaming.update(bytes(part))
    }
    print("streamed {text.encode_hex(streaming.finish())}")
    print("Content-MD5: {base64.encode(md5.sum(bytes("The quick brown fox jumps over the lazy dog")))}")
}

Output

greeting.txt ok
tampered.txt MISMATCH
streamed 9e107d9d372bb6826bd81d3542a419d6

md5

pub fn md5() -> hash.Algorithm

Returns the hash.Algorithm for MD5 (RFC 1321).

The name is md5, the digest is 16 bytes and the block size is 64 bytes. MD5 is not collision resistant; use it only where a protocol requires it.
