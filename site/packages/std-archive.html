std/archive

#compression

import std/archive

The filesystem layer shared by std/archive/tar and std/archive/zip. Names are cleaned and rejected when absolute, containing .. or NUL, or passing through a symbolic link below the destination. Files are created exclusively without following links.

Imports std/io, std/path, std/text.
