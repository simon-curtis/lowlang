std/archive

#compression

import std/archive

The filesystem layer shared by std/archive/tar, std/archive/cpio and std/archive/zip, built on std/file and std/sys. Names are cleaned and rejected when absolute, containing .. or NUL, or passing through a symbolic link below the destination. Files are created exclusively without following links.

Imports std/file, std/io, std/path, std/sys, std/text.

Output

pub struct Output {

A file opened exclusively for writing by create.

Dropping it closes the file descriptor.

put

pub fn put(o: Output, data: []u8) ! io.Error

Writes all of data to o.

Partial and interrupted writes are repeated until every byte is written. Fails with the error of the first write that fails.

Functions

clean_name

pub fn clean_name(name: str) -> str ! io.Error

Returns name normalised with path.clean, or fails when an archive entry of that name is not safe to extract.

Fails with Malformed for an empty name, and with Denied for an absolute name, a name containing a NUL byte or a name with a .. segment.

create

pub fn create(target: str, mode: i64) -> Output ! io.Error

Creates target exclusively for writing and returns the open Output.

An existing file or symbolic link at target is removed first and an existing directory fails with IsDir. The file is created with O_EXCL and O_NOFOLLOW, so a link that appears in between is never followed. mode is masked to 0o777, which drops the setuid, setgid and sticky bits, and the process umask applies. An interrupted open is retried.

hardlink

pub fn hardlink(target: str, source: str) ! io.Error

Creates target as a hard link to the existing file source.

An existing file or symbolic link at target is removed first and an existing directory fails with IsDir.

make_dir

pub fn make_dir(target: str, mode: i64) ! io.Error

Creates the directory target with the permission bits mode.

An existing directory is kept and its mode is not changed. Any other existing object, including a symbolic link, is removed first. mode is masked to 0o777 and always includes 0o700 so extraction can write into the directory; the process umask applies.

make_root

pub fn make_root(root: str) ! io.Error

Prepares root as the destination of an extraction.

A missing root is created together with its missing parents, each by make_dir with mode 0o755. An existing directory or symbolic link is accepted as it is. Any other existing object fails with NotDir.

resolve

pub fn resolve(root: str, name: str) -> str ! io.Error

Returns the filesystem path of the archive entry name below root.

name is checked with clean_name, and a name that cleans to . resolves to root. Each missing parent directory below root is created with mode 0o755, filtered by the process umask. A parent that is a symbolic link fails with Denied and one that is any other non-directory fails with NotDir, so a path never passes through a link below root. The final component is neither created nor checked.

set_mtime

pub fn set_mtime(target: str, seconds: i64) ! io.Error

Sets the modification time of target to seconds since the Unix epoch and leaves the access time unchanged.

A final symbolic link is not followed; the link itself is stamped.

symlink

pub fn symlink(target: str, to: str) ! io.Error

Creates a symbolic link at target that points to to.

An existing file or symbolic link at target is removed first and an existing directory fails with IsDir. to is stored as given and is not validated.

write_file
