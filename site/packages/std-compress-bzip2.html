std/compress/bzip2

#compression

import std/compress/bzip2

compress(data, level), decompress(data, limit), a streaming decode and an Encoder. The decoder reads multiple streams and blocks and checks both CRCs. Randomised blocks fail with Unsupported.

Imports std/bits, std/compress/codec, std/io, std/math, std/slices.

Encoder

A streaming bzip2 encoder made by encoder.

encode takes input in any chunking and finish ends the stream. After finish, encode and finish fail with Invalid. Each block holds up to level * 100000 bytes of run-length encoded input. A chunk is valid only during the call to sink.

encode

pub fn encode(e: *Encoder, data: []u8) ! io.Error

Adds data to the current block and passes each completed block to the encoder's sink.

Input is buffered until a block is full, so a call can produce no output. Fails with Invalid after finish, and with any error sink returns.

finish

pub fn finish(e: *Encoder) ! io.Error

Writes the final block and the stream trailer with the combined checksum.

Fails with Invalid when the stream is already finished, and with any error sink returns.

Returns data compressed as a bzip2 stream.

level is clamped to 1..9 and sets the block size to level * 100000 bytes.

decode

pub fn decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes bzip2 from r and passes the decoded bytes to sink in chunks until the input ends.

Concatenated streams are decoded in turn. Input with no stream is Malformed, and a randomised block (a bzip2 0.9.0 feature) is Unsupported. Block and stream checksums are verified. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

decompress

pub fn decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from bzip2 in data.

Concatenated streams are decoded in turn; input with no stream is Malformed. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.
