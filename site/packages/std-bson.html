std/bson

#formats

import std/bson

BSON documents as []Field with ObjectId, datetime, binary, regex, int32, int64, double and Decimal128 (as bytes): decode, encode, get, diagnostic, new_object_id and parse_object_id.

Imports std/crypto, std/text.

Types

Error

pub enum Error {
    /// The input ends before a value is complete. `at` is the offset where the missing bytes were expected; for a top-level document whose declared size exceeds the input it is the input length.
    Truncated(i64)
    /// A document, string or binary length is impossible, or a document does not end where its length says. `at` is the offset of the length.
    BadLength(i64)
    /// The element type byte `kind` is not supported. `at` is the offset of the type byte.
    ///
    /// Supported types are the ones in `Value`; the deprecated types `undefined`, `DBPointer`, `JavaScript`, `Symbol` and `JavaScript with scope` are rejected.
    BadType(i64, u8)
    /// A string or field name is not valid UTF-8. `at` is the offset of the string, which for a string value is its length prefix.
    BadUtf8(i64)
    /// A string's last byte is not the NUL terminator. `at` is the offset of its length.
    BadString(i64)
    /// A boolean byte is neither `0` nor `1`. `at` is its offset.
    BadBool(i64)
    /// Documents nest deeper than `Options.max_depth`. `at` is the offset of the offending document.
    TooDeep(i64)
    /// A document declares a size over `Options.max_length`. `at` is the offset of the document.
    TooLong(i64)
    /// Bytes remain after the document. `at` is the offset where they start, which is the length of the document.
    Trailing(i64)
    /// A field name, regular expression pattern or options string contains a NUL byte, which `encode` cannot represent.
    BadName
    /// An `ObjectId` does not hold 12 bytes, or `parse_object_id` was given something other than 24 hex digits.
    BadObjectId
    /// A `Decimal128` does not hold 16 bytes.
    BadDecimal
}

The error returned when decoding or encoding BSON fails.

Decoding errors carry the byte offset from the start of the input; offset reads it back and message formats it.

message

pub fn message(e: Error) -> str

Returns a one-line description of the error, including the byte offset when it has one.

offset

pub fn offset(e: Error) -> i64

Returns the byte offset a decoding error refers to, or -1 for BadName, BadObjectId and BadDecimal, which are not tied to a position.

Value

pub enum Value {
    /// A 64-bit IEEE 754 binary floating point number (type `0x01`).
    Double(f64)
    /// A UTF-8 string (type `0x02`). It may contain NUL bytes.
    Str(str)
    /// An embedded document (type `0x03`): an ordered list of named fields. Names may repeat.
    Document([]Field)
    /// An array (type `0x04`). It is stored as a document whose field names are the decimal indexes `0`, `1`, and so on; decoding ignores the names and keeps the values in order.
    Array([]Value)
    /// Binary data (type `0x05`) with a `subtype` byte that says how to interpret `data`.
    Binary(u8, []u8)
    /// A 12-byte ObjectId (type `0x07`), made of a 4-byte big-endian timestamp in seconds followed by 8 bytes that identify the value. `bytes` must hold exactly 12 bytes to be encoded.
    ObjectId([]u8)
    /// A boolean (type `0x08`).
    Bool(bool)
    /// A UTC datetime (type `0x09`) as signed milliseconds since the Unix epoch.
    DateTime(i64)
    /// The null value (type `0x0A`).
    Null
    /// A regular expression (type `0x0B`) with its `pattern` and `options`. Neither string may contain a NUL byte, and neither is validated or reordered.
    Regex(str, str)
    /// A signed 32-bit integer (type `0x10`).
    Int32(i32)
    /// An internal MongoDB timestamp (type `0x11`): the increment in the low 32 bits and the seconds in the high 32 bits.
    Timestamp(u64)
    /// A signed 64-bit integer (type `0x12`).
    Int64(i64)
    /// A 128-bit IEEE 754-2008 decimal (type `0x13`), held as its 16 little-endian bytes without interpretation. `bytes` must hold exactly 16 bytes to be encoded.
    Decimal128([]u8)
    /// The key that sorts before every other value (type `0xFF`).
    MinKey
    /// The key that sorts after every other value (type `0x7F`).
    MaxKey
}

A BSON element value (bsonspec.org, version 1.1).

Functions

decode

pub fn decode(data: []u8) -> []Field ! Error

Decodes data, which must hold exactly one BSON document, into its fields, with default Options.

Fails with Trailing when bytes follow the document. See decode_with.

decode_first

pub fn decode_first(data: []u8, options: Options) -> Item ! Error

Decodes the document at the start of data and reports its size, ignoring any bytes after it.

Use it to read a stream of back-to-back documents by advancing data by Item.length. Fails like decode_with except that it never returns Trailing.

decode_with

pub fn decode_with(data: []u8, options: Options) -> []Field ! Error

Decodes data, which must hold exactly one BSON document, into its fields.

The document's declared size must match data exactly: a longer input fails with Trailing, and a shorter one with Truncated. Fails with BadLength, BadType, BadUtf8, BadString, BadBool, TooDeep or TooLong for malformed or over-limit input. Strings, binary data and ids are copied, so the result does not alias data.

diagnostic

pub fn diagnostic(fields: []Field) -> str

Returns a one-line text description of a document, in a notation like JSON with type markers, for logs and tests.

Fields print as "name": value in braces, arrays in brackets. Strings are quoted with \" and \\, and every character outside printable ASCII is written as \uXXXX, using a surrogate pair above U+FFFF. Doubles print as NaN, Infinity, -Infinity or a decimal that always contains a ., such as 1.0. An Int32 prints plainly and an Int64 with an L suffix. Other values print as bin(subtype, h'hex'), oid("hex"), date(millis), /pattern/options, timestamp(n), decimal128(h'hex'), true, false, null, minkey and maxkey.

encode

pub fn encode(fields: []Field) -> []u8 ! Error

Encodes fields as one BSON document.

Returns the bytes with the 4-byte little-endian size prefix and the trailing NUL. Arrays are written with the field names "0", "1", and so on. Fields keep their order and repeated names are kept. Fails with BadName when a field name, regex pattern or regex option contains a NUL byte, BadObjectId when an ObjectId does not hold 12 bytes, and BadDecimal when a Decimal128 does not hold 16 bytes.

get

pub fn get(fields: []Field, name: str) -> Value?

Returns the value of the first field called name, or none when there is none.

Only the given level is searched; nested documents are not.

new_object_id

pub fn new_object_id() -> Value

Returns a new ObjectId value.

The first four bytes are the current time in seconds since the Unix epoch, big-endian, and the other eight come from std/crypto's random bytes.

object_id_hex

pub fn object_id_hex(id: []u8) -> str

Returns the lowercase hex text of the bytes of id, two digits per byte.

object_id_seconds

pub fn object_id_seconds(id: []u8) -> i64

Returns the creation time in seconds since the Unix epoch stored in the first four bytes of id, read big-endian.

id must hold at least 4 bytes.

parse_object_id

pub fn parse_object_id(hex: str) -> Value ! Error

Returns the ObjectId for 24 hex digits, in either case.

Fails with BadObjectId when hex is not exactly 24 hex digits.
