std/cdp

#net

import std/cdp

The Chrome DevTools Protocol. launch starts a headless Chromium with a disposable profile, connects to it and returns a droppable Browser that shuts it down when released. Its handle is the shared *BrowserHandle; launch_handle, adopt, shutdown_on and open_page_on take it. call sends a command to the browser or a session, and events delivers everything else. open_page opens a page in its own browser context whose every request, including those of cross-site frames and workers, passes through Handlers. Also navigate and shutdown.

Imports std/file, std/http/websocket, std/io, std/json, std/process, std/text.

A shared reference to a running browser, for use from several tasks.

Owns the browser process and its temporary profile directory. shutdown_on stops the process and removes the directory.

Wraps a handle in a Browser that shuts the browser down when dropped.

open_page_on

pub fn open_page_on(b: *BrowserHandle, handlers: Handlers) -> Page ! Error

Creates an isolated browser context with downloads denied, opens a blank page in it and starts routing its network activity to handlers.

Fails with Timeout when the page does not attach within 10000 milliseconds, and with the error of the first failing command otherwise. Further pages that the page itself opens, such as popups, are closed as soon as they attach.

shutdown_on

pub fn shutdown_on(h: *BrowserHandle)

Closes the DevTools connection, kills the browser process, waits for it to exit and removes the profile directory.

Safe to call more than once and from several tasks; only the first call has an effect. Errors while stopping the process or removing files are ignored.

Connection

pub struct Connection {
    ...
}

A WebSocket connection to the DevTools endpoint of a browser.

A background task reads every message, delivers command replies to the waiting call and queues events for events. When the socket closes, pending calls fail with Closed and the event channel is closed.

call

pub fn call(c: *Connection, session: str, method: str, params: []json.Member) -> json.Value ! Error

Sends the command method with params and waits for the reply, returning its result.

An empty session addresses the browser itself; otherwise the command goes to that session. A reply without a result gives Null. Fails with Closed when the connection is closed before or while the command is sent or while waiting, Protocol(message) when the browser reports an error, and Timeout when there is no reply within 30000 milliseconds. Blocks the calling task until then. Safe to call from several tasks.

events

pub fn events(c: *Connection) -> chan[Event]

Returns the channel that receives the events of every session on the connection.

The channel holds up to 1024 queued events; while it is full, reading of further replies and events waits. It is closed when the connection closes. Each event is received once, by whichever task reads it.

launch

pub fn launch(o: Options) -> Browser ! Error

Starts a headless browser and connects to it.

Returns once the browser has announced its DevTools endpoint and the connection is open. Fails with Launch(NotFound) when no executable is found, Launch(TimedOut) when the endpoint is not announced within Options.startup, or as soon as the browser exits without announcing it, and Launch(error) for any other failure to create the profile directory, start the process or connect. A failed launch kills the process and removes the profile directory.

launch_handle

pub fn launch_handle(o: Options) -> *BrowserHandle ! Error

Starts a headless browser like launch and returns its handle.

The caller is responsible for calling shutdown_on. Fails with the same errors as launch.

A page in its own isolated browser context.

navigate

pub fn navigate(p: Page, url: str, referrer: str) ! Error

Starts navigating the page to url.

A non-empty referrer is sent as the referrer. Returns once the browser accepts the navigation, without waiting for the page to load. Fails with Protocol(text) when the browser rejects the navigation, for example because the host cannot be resolved, and with the errors of call otherwise.
