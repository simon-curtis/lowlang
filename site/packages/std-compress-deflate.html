import std/compress/deflate

DEFLATE, zlib and gzip.

Imports std/compress/codec, std/hash, std/io, std/math.

Examples

containers

import std/compress/deflate
import std/io
import std/slices
import std/text

fn header(packed: []u8) -> str {
    "{packed[0]:x2} {packed[1]:x2}"
}

/// Compresses one body as raw deflate, zlib and gzip, shows the leading bytes that tell the containers apart, and decodes each with the matching function.
fn main() ! io.Error {
    let body = bytes(text.repeat("<li>deflate keeps the longest repeated runs short</li>\n", 40))

    let raw = deflate.compress(body, 6)
    let zlib = deflate.zlib_compress(body, 6)
    let gzip = deflate.gzip_compress(body, 6)
    print("raw shrinks the body: {raw.len < body.len / 4}")
    print("zlib overhead: {zlib.len - raw.len}, header {header(zlib)}")
    print("gzip overhead: {gzip.len - raw.len}, header {header(gzip)}")

    print("raw round trip: {slices.equal(deflate.decompress(raw, 1 << 20)?, body)}")
    print("zlib round trip: {slices.equal(deflate.zlib_decompress(zlib, 1 << 20)?, body)}")
    print("gzip round trip: {slices.equal(deflate.gzip_decompress(gzip, 1 << 20)?, body)}")

    let _ = deflate.gzip_decompress(zlib, 1 << 20) catch {
        Malformed => {
            print("zlib data is not gzip")
            return
        }
        _ => return
    }
}

Types

Encoder

pub struct Encoder {
    ...
}

A streaming DEFLATE encoder made by encoder, producing a raw, zlib or gzip stream.

encode takes input in any chunking, flush ends the data written so far on a byte boundary, and finish writes the end of the stream and any trailer. After finish, encode, flush and finish fail with Invalid. A chunk is valid only during the call to sink.

encode

pub fn encode(e: *Encoder, data: []u8) ! io.Error

Compresses data and passes the compressed bytes that are ready to the encoder's sink, updating the checksum for the zlib and gzip formats.

Input is buffered, so a call can produce no output. Fails with Invalid after finish, and with any error sink returns.

finish

pub fn finish(e: *Encoder) ! io.Error

Writes the buffered input, the final block and, for zlib and gzip, the checksum trailer.

Fails with Invalid when the stream is already finished, and with any error sink returns.

flush

pub fn flush(e: *Encoder) ! io.Error

Writes the buffered input and an empty stored block that pads the output to a byte boundary, so a decoder can read everything encoded so far.

Fails with Invalid after finish, and with any error sink returns.

Format

pub enum Format {A bare DEFLATE stream (RFC 1951) with no header or checksum.    RawA zlib stream (RFC 1950): a two byte header, the DEFLATE stream and an Adler-32 checksum.    ZlibA gzip member (RFC 1952): a ten byte header, the DEFLATE stream and a CRC-32 and size trailer.    Gzip
}

The container around a DEFLATE stream.

encoder

pub fn encoder(format: Format, level: i64, sink: fn([]u8) ! io.Error) -> *Encoder

Returns an encoder that writes a stream in format to sink; a zlib or gzip header is written immediately.

level is clamped to 0..9, with a negative value meaning 6; 0 stores the data without compression.

Functions

compress

pub fn compress(data: []u8, level: i64) -> []u8

Returns data compressed as a raw DEFLATE stream.

level is clamped to 0..9, with a negative value meaning 6; 0 stores the data without compression.

decode

pub fn decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes a raw DEFLATE stream from r and passes the decoded bytes to sink in chunks until the input ends.

Decoding stops after the final block. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

decompress

pub fn decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from a raw DEFLATE stream in data.

Bytes after the final block are ignored. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.

gzip_compress

pub fn gzip_compress(data: []u8, level: i64) -> []u8

Returns data compressed as a single gzip member.

level is clamped to 0..9, with a negative value meaning 6; 0 stores the data without compression. The header carries no name, comment or modification time and marks the operating system as unknown.

gzip_decode

pub fn gzip_decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes gzip from r and passes the decoded bytes to sink in chunks until the input ends.

Concatenated members are decoded in turn. The header checksum, the CRC-32 and the size in each trailer are verified. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

gzip_decompress

pub fn gzip_decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from gzip in data.

Concatenated members are decoded in turn. The header checksum, the CRC-32 and the size in each trailer are verified. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.

zlib_decode

pub fn zlib_decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes a zlib stream from r and passes the decoded bytes to sink in chunks until the input ends.

The header and the Adler-32 checksum are verified. A stream that needs a preset dictionary is Unsupported. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

Returns the bytes decoded from a zlib stream in data.

The header and the Adler-32 checksum are verified, and bytes after the stream are ignored. A stream that needs a preset dictionary is Unsupported. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.
