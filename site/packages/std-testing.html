std/testing

#testing

import std/testing

T, passed to a test fn(*T), with log, error, fatal, skip, require and sub. Assertions equal, not_equal, equal_slice, is_true, is_false, is_some, is_none, contains, contains_item, close_to, unexpected, must and expect_error render values of any type. table and table_of. run and run_with run each test on its own green thread with a timeout, filter with -run, print with -v and exit with status 1 on failure. bench, bench_for and blackhole. golden rewrites its file when UPDATE_GOLDEN is set. check_property, check_shrunk and check_ints print the seed and shrink integers.

Imports std/file, std/flag, std/os, std/path, std/rand, std/serde, std/slices, std/text, std/time.
