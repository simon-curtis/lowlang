std/testing

#testing

import std/testing

T, passed to a test fn(*T), with log, error, fatal, skip, require and sub. Assertions equal, not_equal, equal_slice, is_true, is_false, is_some, is_none, contains, contains_item, close_to, unexpected, must and expect_error render values of any type. table and table_of. run and run_with run each test on its own green thread with a timeout, filter with -run, print with -v and exit with status 1 on failure. bench, bench_for and blackhole. golden rewrites its file when Settings.update_golden is set, which -update does. check_property, check_shrunk and check_ints print the seed and shrink integers.

Imports std/file, std/flag, std/math, std/os, std/path, std/rand, std/slices, std/text, std/time.

The state of one running test or subtest, passed to its body as a *T.

Records, assertions and subtests all go through it. The recording functions are safe to call from several green threads at once.

check_ints

pub fn check_ints(t: *T, runs: i64, seed: u64, low: i64, high: i64, prop: fn(i64) -> bool) -> bool

Checks that prop holds for runs integers drawn uniformly from low through high, both inclusive.

Seeding and the error are those of check_shrunk. Failing inputs are shrunk with shrink_int, keeping only candidates within the range.

check_property

pub fn check_property[V](t: *T, runs: i64, seed: u64, gen: fn(mut rand.Rng) -> V, prop: fn(V) -> bool) -> bool

Checks that prop holds for runs inputs made by gen.

gen draws each input from the random generator. A seed of 0 picks one from the clock. The first failing input stops the check: the error records the run number, the seed, which reproduces the failure, and the input. Returns true when every run passes. The input is not shrunk; see check_shrunk.

check_shrunk

pub fn check_shrunk[V](t: *T, runs: i64, seed: u64, gen: fn(mut rand.Rng) -> V, prop: fn(V) -> bool, shrink: fn(V) -> []V) -> bool

Checks that prop holds for runs inputs made by gen, and shrinks a failing input.

Behaves like check_property, and the error also shows the smallest failing input found. After a failure, shrink lists simpler candidates for the current input; the first candidate that still fails replaces it, and this repeats until no candidate fails or 10000 rounds have passed.

close_to

pub fn close_to(t: *T, got: f64, want: f64, tolerance: f64) -> bool

Checks that got is within tolerance of want.

Passes when the absolute difference is at most tolerance. A got or want that is not a number never passes.

contains

pub fn contains(t: *T, whole: str, part: str) -> bool

Checks that the text part occurs in whole.

An empty part is always found.

contains_item

pub fn contains_item[V: Eq](t: *T, items: []V, item: V) -> bool

equal

pub fn equal[V: Eq](t: *T, got: V, want: V) -> bool

Checks that got equals want.

Returns true when they are equal. Otherwise records an error that shows both values rendered with format and returns false; the test keeps running. Every assertion in this module reports the same way.

equal_slice

pub fn equal_slice[V: Eq](t: *T, got: []V, want: []V) -> bool

Checks that the slices got and want have the same length and equal elements.

Returns true when they do. Otherwise records an error that shows both slices and either the index of the first differing element or the two lengths, and returns false.

error

pub fn error(t: *T, message: str)

Records message on t and marks the test failed.

The test body keeps running, so later checks still report.

error_if

pub fn error_if(t: *T, condition: bool, message: str) -> bool

Calls error with message when condition is true.

Returns condition, so the result is true when a failure was recorded.

expect_error

pub fn expect_error[E: Eq, V](t: *T, e: E, want: E, fallback: V) -> V

Checks that the error e equals want and returns fallback.

Meant for the handler of a catch around a call that is expected to fail. Records an error that shows both when they differ. The test keeps running.

failed

pub fn failed(t: *T) -> bool

Returns true when t has recorded a failure.

A failed subtest also fails its parent, and a timeout counts as a failure.

fatal

pub fn fatal(t: *T, message: str)

Records message on t, marks the test failed and ends it.

The calling green thread never continues after this call.

fatal_if

pub fn fatal_if(t: *T, condition: bool, message: str)

Calls fatal with message when condition is true.

golden

pub fn golden(t: *T, name: str, actual: str) -> bool

Checks actual against the golden file name in the directory Settings.golden_dir of t.

The file is name with .golden appended. See golden_in; the files are rewritten when Settings.update_golden is true, which the -update flag sets.

golden_in

pub fn golden_in(t: *T, dir: str, name: str, actual: str, update: bool) -> bool

Checks actual against the file dir/name.golden, or rewrites that file when update is true.

When updating, creates the directory if needed, writes actual and returns true; an error creating or writing is recorded on t and gives false. Otherwise returns true when the file's text equals actual. A file that cannot be read, such as a missing one, and a difference are both recorded as errors that name -update, and the difference shows the first line that differs, or the two line counts.

log

pub fn log(t: *T, message: str)

Records message on t without failing the test.

The run prints the notes of a test that fails, or of every test with -v.

must

pub fn must[E, V](t: *T, e: E, fallback: V) -> V

Records e as an unexpected error, ends the test and never returns fallback.

Meant for the handler of a catch like unexpected, but stops the test as fatal does.

not_equal

pub fn not_equal[V: Eq](t: *T, got: V, other: V) -> bool

Checks that got and other differ.

Returns true when they are not equal, and otherwise records an error that shows the value and returns false.

require

pub fn require(t: *T, ok: bool)

Ends the test when ok is false, without recording a failure.

The calling green thread never continues in that case. Use it to stop after a check that already reported through error or an assertion, when the rest of the test cannot run.

skip

pub fn skip(t: *T, reason: str)

Records reason on t, marks the test skipped and ends it.

The calling green thread never continues after this call. A skipped test is reported as SKIP with -v and is counted apart from passes and failures, unless it also recorded a failure.

sub

pub fn sub(t: *T, name: str, body: fn(*T)) -> bool

Runs body as a subtest of t named name, and waits for it to finish.

The subtest's full name is t.name and name joined with /. It has its own green thread and timeout. It is not run when the run's filter does not select its full name, which counts as a pass. A subtest that fails also fails t. Returns true when the subtest recorded no failure.

table

pub fn table[C](t: *T, cases: [str: C], body: fn(*T, C)) -> bool

Runs body as a subtest of t for each entry of cases, named by its key.

Cases run in the map's insertion order. Returns true when every subtest passed. See sub.

table_of

pub fn table_of[C](t: *T, cases: []C, name: fn(C) -> str, body: fn(*T, C)) -> bool

Runs body as a subtest of t for each element of cases, named by name applied to the element.

Cases run in order. Returns true when every subtest passed. See sub.

unexpected

pub fn unexpected[E, V](t: *T, e: E, fallback: V) -> V

Records e as an unexpected error and returns fallback.

Meant for the handler of a catch, where the expression still needs a value of the right type: parse(text) catch { e => testing.unexpected(t, e, 0) }. The test keeps running.

Functions

bench

pub fn bench(name: str, body: fn(i64)) -> Bench

Benchmarks body for about one second, prints the result line and returns it.

This is bench_for with a target of 1000 milliseconds followed by printing describe of the result.

bench_for

pub fn bench_for(name: str, body: fn(i64), target_ms: i64) -> Bench

Benchmarks body until one run takes at least target_ms milliseconds, and returns that run.

body(n) must do the measured work n times. It is first called with 1, then with a larger n estimated from the previous run, growing at most 100 times per step, until a run reaches the target or n reaches one billion. Only the last run is reported. Nothing is printed.

blackhole

pub fn blackhole[V: Number](value: V)

Consumes value so a benchmarked computation is not optimised away.

It does nothing observable, apart from printing a fixed word when value converts to one specific unlikely integer.

blackhole_str

pub fn blackhole_str(value: str)

Consumes value so a benchmarked computation is not optimised away.

It uses the length of value and its last byte.

format

pub fn format[V](v: V) -> str

Returns a readable rendering of v for test messages, for a value of any type.

Structs print as Name{field: value}, slices as [a, b], maps as {key: value}, a variant with positional fields as Name(a, b), one with labelled fields as Name{label: value} and one without fields as its name. Text, including map keys and a top-level str, is quoted with ", \, newline and tab escaped, and []u8 is 0x and hex digits. An absent optional is none and a present one is its value. A pointer renders its target, and a pointer reached again while it is being rendered is <cycle>. Integers and floats use their default text. The rules are those of print for a value nested in a composite.

run

pub fn run(tests: []Test) -> i64

Runs tests using the flags in the process arguments and returns the number of failed tests.

Reads the flags with settings_from after the program name. A bad flag prints the usage and exits with status 2. Otherwise it runs the tests as run_with does and exits with status 1 when any test failed; it returns only when none did.

run_with

pub fn run_with(tests: []Test, settings: Settings) -> i64

Runs each test of tests selected by settings.filter and returns the number of failed tests.

Each test runs on its own green thread and is failed when it exceeds settings.timeout_ms. It prints a report for each failed test, or each test with settings.verbose, then a final line with the verdict and the counts of failed, passed and skipped tests. It does not exit the process.

selected

pub fn selected(filter: str, name: str) -> bool

Returns true when the test name is selected by filter.

An empty filter selects every name. Otherwise the filter and the name are split at /, and each level of the name must contain the filter's text at the same level. Levels of the name beyond the filter's depth match anything, and so does a name with fewer levels than the filter, so a top-level test is selected while its first level matches and its subtests are then filtered by the remaining levels.

settings_from

pub fn settings_from(args: []str) -> Settings ! flag.Error

Builds Settings from command-line flag arguments.

Reads -run for the filter, -v for verbose output, -notime to leave timings out, -update to rewrite golden files and -timeout for the milliseconds a test may take. Fails with the flag.Error for an unknown flag, a flag without its value, or a -timeout that is not an integer.

shrink_int

pub fn shrink_int(n: i64) -> []i64

Returns candidate smaller values for shrinking the integer n.

Zero has none. Any other value yields 0, and for a negative n also its absolute value, then n / 2 and n + 1; for a positive n it yields n / 2 and n - 1.
