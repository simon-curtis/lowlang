std/time

#time

import std/time

now (Unix seconds), now_millis and now_nanos (the wall clock at finer resolution), monotonic (nanoseconds), sleep_for (rounds up to whole milliseconds), after, Timer and Ticker (their channels work in select), and Stopwatch. Calendar and zone types live in the submodules below, one module per type, so d.plus(span.days(3)) resolves to date.plus.

Imports std/atomic, std/time/duration.

Types

Stopwatch

pub struct Stopwatch {
    ...
}

A starting point on the monotonic clock, made by start, from which elapsed measures.

Copies of a Stopwatch share the same starting point.

elapsed

pub fn elapsed(w: Stopwatch) -> duration.Duration

Returns the time since w was started.

Each call measures from the original start, so repeated calls keep growing and the stopwatch is never stopped.

Ticker

pub struct Ticker {
    /// The channel that receives `true` on each tick.
    ///
    /// It holds one value, so a tick that finds the channel full is dropped and a slow receiver sees fewer ticks rather than a backlog. It is never closed and can be used in `select`.
    pub ticks: chan[bool]
    ...
}

A repeating timer made by ticker that sends on its ticks channel once per period until stop_ticker is called.

Copies of a Ticker refer to the same ticker.

stop_ticker

pub fn stop_ticker(t: Ticker)

Stops the ticker.

Its green thread exits the next time it wakes, so a tick already in ticks stays readable and the channel is not closed.

Timer

pub struct Timer {
    /// The channel that receives `true` when the timer fires.
    ///
    /// It holds one value, so a firing that finds the channel full is dropped. It is never closed and can be used in `select`.
    pub fired: chan[bool]
    ...
}

A one-shot timer made by timer that sends on its fired channel when its duration has passed.

Copies of a Timer refer to the same timer. stop_timer cancels a pending firing and reset_timer arms it again.

reset_timer

pub fn reset_timer(t: Timer, d: duration.Duration)

Stops the timer, discards any value waiting in fired and arms it again to fire after d.

stop_timer

pub fn stop_timer(t: Timer) -> bool

Cancels a pending firing and returns true, or returns false if the timer already fired or was already stopped.

A value already sent to fired stays in the channel.

Functions

after

pub fn after(d: duration.Duration) -> chan[bool]

Returns the channel of a new timer that fires once after d.

The timer cannot be stopped or reset. Use timer when it must be.

monotonic

pub fn monotonic() -> i64

Returns a reading of the monotonic clock in nanoseconds.

The origin is unspecified, so only the difference between two readings is meaningful. The reading never goes backwards when the wall clock is adjusted.

now

pub fn now() -> i64

Returns the wall clock as whole seconds since the Unix epoch.

The fractional second is dropped. Use now_millis or now_nanos for finer resolution.

now_millis

pub fn now_millis() -> i64

Returns the wall clock as whole milliseconds since the Unix epoch.

now_nanos

pub fn now_nanos() -> i64

Returns the wall clock as nanoseconds since the Unix epoch.

sleep_for

pub fn sleep_for(d: duration.Duration)

Pauses the calling green thread for at least d.

The duration is rounded up to whole milliseconds. A zero or negative duration returns immediately, and a duration beyond the range of i64 nanoseconds sleeps for that maximum.

start

pub fn start() -> Stopwatch

Returns a Stopwatch that begins at the current monotonic reading.

ticker

pub fn ticker(d: duration.Duration) -> Ticker

Returns a Ticker that ticks every d.

The first tick comes one period after the call. A period under one millisecond is raised to one millisecond. Ticks stay on the original schedule: a late tick does not delay the next one, and periods missed while the thread was late are skipped.

timer

pub fn timer(d: duration.Duration) -> Timer

Returns a Timer that fires once after d.

The duration is rounded up to whole milliseconds. A zero or negative duration fires as soon as the timer's green thread runs. The timer sleeps on its own green thread and does not block the caller.
