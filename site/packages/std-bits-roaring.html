Imports std/bits, std/io, std/math.

Examples

postings

import std/bits/roaring
import std/io

/// Builds posting lists for three search terms over a million documents, answers boolean queries with set algebra, then saves and reloads one list.
fn main() ! io.Error {
    let error = roaring.roaring()
    roaring.add_range(error, 100_000, 100_050)
    roaring.add(error, 7)
    roaring.add(error, 900_001)

    let timeout = roaring.roaring()
    roaring.add_range(timeout, 100_040, 100_100)
    roaring.add(timeout, 900_001)

    let all_docs = roaring.roaring()
    roaring.add_range(all_docs, 0, 1_000_000)

    print("error: {roaring.cardinality(error)} documents")
    print("error AND timeout: {roaring.members(roaring.intersect(error, timeout))}")
    print("error OR timeout: {roaring.cardinality(roaring.union(error, timeout))} documents")
    print("error AND NOT timeout: {roaring.cardinality(roaring.difference(error, timeout))} documents")
    print("first and last error: {roaring.min(error) ?? 0}, {roaring.max(error) ?? 0}")
    print("errors up to document 100000: {roaring.rank(error, 100_000)}")
    print("tenth error: {roaring.select_at(error, 9) ?? 0}")

    roaring.run_optimize(all_docs)
    let saved = roaring.serialize(all_docs)
    print("a million consecutive documents serialize in under 1 KiB: {saved.len < 1024}")

    let restored = roaring.deserialize(saved)?
    print("restored equals original: {roaring.equal(restored, all_docs)}")
}

Roaring

pub struct Roaring {
    ...
}

A compressed bitmap of u32 values in the Roaring format.

Values are grouped by their high 16 bits into containers, each stored as a sorted array of up to 4096 values, a bitmap of 65536 bits or a list of runs. Create one with roaring. A Roaring is used through a pointer. Locating a container costs a binary search over the container keys, so single-value operations take time logarithmic in the number of containers plus the cost inside one container.

add

pub fn add(r: *Roaring, x: u32)

Adds x to r.

Adding a value that is present changes nothing.

add_range

pub fn add_range(r: *Roaring, lo: i64, hi: i64)

Adds every value in the half-open range lo to hi, excluding hi, to r.

The range is clamped to 0 through 2^32. Does nothing when the clamped range is empty. Whole containers inside the range are made from a single run, so the cost depends on the number of containers touched, not on the number of values.

run_optimize

pub fn run_optimize(r: *Roaring)

Converts every container of r to the representation that takes the least space, which can be a list of runs.

The values do not change. Runs shrink long consecutive ranges, and serialize writes the runs it finds.

select_at

pub fn select_at(r: *Roaring, k: i64) -> u32?

Returns the value of r at zero-based position k in increasing order, or none when k is negative or at least cardinality(r).

This is the inverse of rank.

serialize

pub fn serialize(r: *Roaring) -> []u8

Returns r in the portable Roaring serialization format.

The format starts with a cookie that says whether run containers are present, then the container keys and counts, then each container: sorted u16 values for up to 4096 values, a 1024-word bitmap above that, or a list of runs. All integers are little-endian. Call run_optimize first to get run containers.

deserialize

pub fn deserialize(data: []u8) -> *Roaring ! io.Error

Reads a bitmap in the portable Roaring serialization format.

Fails with Malformed when the data is truncated, the cookie is unknown, the container keys are not increasing, an offset does not match the container's position, or a container's values are unsorted, overlapping or disagree with its stated count. Bytes after the last container are ignored.
