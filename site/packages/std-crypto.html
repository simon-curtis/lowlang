random

pub fn random(n: i64) -> []u8

Returns n bytes from the operating system's cryptographically secure random generator.

Reads through the getrandom system call with no flags, so the call blocks until the kernel pool is initialised. A short or interrupted read is retried until n bytes are filled. An n of 0 returns an empty slice.

sha1

pub fn sha1(data: []u8) -> []u8

Computes the SHA-1 digest of data as specified by FIPS 180-4.

Returns 20 bytes. SHA-1 is not collision resistant; use it only where a protocol requires it.
