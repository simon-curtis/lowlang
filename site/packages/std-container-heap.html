A binary heap that yields its smallest item first, as decided by a less function. /// /// Create one with heap. Mutating functions take the heap as mut.

insert

pub fn insert[T](mut h: Heap[T], item: T)

Adds item to h. /// /// Sifts the item up with O(log n) calls to less.

peek

pub fn peek[T](h: Heap[T]) -> T?

Returns the item that pop would return, or none when h is empty. /// /// Takes constant time.

pop

pub fn pop[T](mut h: Heap[T]) -> T?

Removes and returns the item that less ranks first, or none when h is empty. /// /// Items that compare equal leave in no defined order. Sifting down takes O(log n) calls to less, but the call also copies the remaining items into a new slice, so its time is linear in size(h).

size

pub fn size[T](h: Heap[T]) -> i64

Returns the number of items in h.

heap

pub fn heap[T](less: fn(T, T) -> bool) -> Heap[T]

Returns an empty heap ordered by less. /// /// less(a, b) returns true when a must leave the heap before b. It must be a strict weak ordering. For a max-heap, pass a function that compares in the opposite direction.
