std/compress/brotli

#compression

import std/compress/brotli

Brotli (RFC 7932).

Imports std/bits, std/compress/codec, std/io, std/math.

Examples

bomb

import std/compress/brotli
import std/io
import std/slices

/// Decodes untrusted input with a cap on the output: a payload that expands to 4 MiB is refused at a 64 KiB limit and accepted at 8 MiB.
fn main() ! io.Error {
    let zeros = slices.repeat([u8(0)], 4 << 20)
    let payload = brotli.compress(zeros, 5)
    print("payload is under 1% of the output: {payload.len < zeros.len / 100}")

    let full = brotli.decompress(payload, 8 << 20)?
    print("decoded {full.len} bytes under the large limit")

    let capped = brotli.decompress(payload, 64 << 10) catch {
        TooLarge => {
            print("refused at 64 KiB")
            return
        }
        _ => return
    }
    print("decoded {capped.len} bytes under the small limit")
}

Types

Encoder

pub struct Encoder {
    ...
}

A streaming Brotli encoder made by encoder.

encode takes input in any chunking, flush ends the data written so far on a byte boundary, and finish ends the stream. After finish, encode, flush and finish fail with Invalid. A chunk is valid only during the call to sink.

encode

pub fn encode(e: *Encoder, data: []u8) ! io.Error

Compresses data and passes the compressed bytes that are ready to the encoder's sink.

Input is buffered and written in meta-blocks of up to 256 KiB, so a call can produce no output. Fails with Invalid after finish, and with any error sink returns.

finish

pub fn finish(e: *Encoder) ! io.Error

Writes the buffered input and the last meta-block, ending the stream.

Fails with Invalid when the stream is already finished, and with any error sink returns.

flush

pub fn flush(e: *Encoder) ! io.Error

Writes the buffered input and an empty metadata meta-block that pads the output to a byte boundary, so a decoder can read everything encoded so far.

Fails with Invalid after finish, and with any error sink returns.

Functions

compress

pub fn compress(data: []u8, level: i64) -> []u8

Returns data compressed as a Brotli stream.

level is clamped to 0..11; 0 stores the data in uncompressed meta-blocks. The window is sized from data.len, up to 22 bits.

decode

pub fn decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes a Brotli stream from r and passes the decoded bytes to sink in chunks until the input ends.

Decoding stops at the end of the stream. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

decompress

pub fn decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from a Brotli stream in data.

Bytes after the end of the stream are Malformed. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.

encoder

pub fn encoder(level: i64, sink: fn([]u8) ! io.Error) -> *Encoder

Returns an encoder that writes a Brotli stream with a 22-bit window to sink.

level is clamped to 0..11; 0 stores the data in uncompressed meta-blocks.
