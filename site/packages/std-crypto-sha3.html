Types

Shake

pub struct Shake {
    ...
}

A SHAKE extendable-output sponge (FIPS 202).

Input is absorbed with absorb; the first squeeze ends absorption and returns output of any length.

absorb

pub fn absorb(s: *Shake, data: []u8)

Feeds data into the sponge. A call after the first squeeze has no effect.

squeeze

pub fn squeeze(s: *Shake, n: i64) -> []u8

Returns the next n bytes of output.

The first call ends absorption. Successive calls continue the same output stream. An n of 0 or less returns an empty slice.

Returns the hash.Algorithm for SHA3-256 (FIPS 202). The name is sha3-256, the digest is 32 bytes and the block size is the 136-byte rate.
