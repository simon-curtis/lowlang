std/ui/platform

#ui

import std/ui/platform

Windows, input events and the waiting loop: Wayland, xkbcommon and the generated Wayland bindings on Linux, user32 and kernel32 on Windows.

Imports std/io, std/sys, std/time.

Window

pub struct Window {
    ...
}

An open window. Releasing it destroys the window and closes the connection to the windowing system.

A window belongs to the green thread that opened it: next must be called from that green thread.

native

pub fn native(w: Window) -> Native

Returns the handles a renderer needs to draw into w.

next

pub fn next(w: Window, timeout_ms: i64) -> []Event ! Error

Returns the events that arrived for w, waiting until at least one arrives, a Waker fires or timeout_ms milliseconds pass. A negative timeout waits without limit.
