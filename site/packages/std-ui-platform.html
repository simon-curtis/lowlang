std/ui/platform

#ui

import std/ui/platform

Windows, input events and the waiting loop: Wayland, xkbcommon and the generated Wayland bindings on Linux, user32, kernel32 and imm32 on Windows.

Imports std/io, std/os/signal, std/process, std/sys, std/time.

Functions

is_url

pub fn is_url(s: str) -> bool

Returns whether s starts with a URL scheme of at least two characters, a letter then letters, digits, +, - or ., followed by a colon, as open_url requires.

open_url

pub fn open_url(url: str) ! Error

Opens url in the application the desktop registers for its scheme, such as the web browser for https, without waiting for it.

url must pass is_url, so a path or an option is refused; any scheme passes, file among them, so a URL from an untrusted source needs its scheme checked first. Runs xdg-open on Linux and ShellExecuteW on Windows. Fails with Unsupported for a string without a scheme or when xdg-open is not installed, or Failed with the code the system returned.
