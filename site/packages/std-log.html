std/log

#observability

import std/log

Leveled line logging (debug, info, warn, error) to a descriptor (stderr by default) as level prefix: message, without timestamps so journald and other collectors add their own. with_prefix nests a prefix. A Logger also carries attributes (str_attr, int_attr, float_attr, bool_attr, with_attrs, and the _with level forms), a Format of Text (key=value, quoting what needs it) or Json (one object per line), a Sink (a descriptor, an io.Stream, a line closure or a Record handler), optional RFC 3339 timestamps, and a level from parse_level or the LOG_LEVEL variable. Each record is one write, so lines from green threads do not interleave.

Imports std/io, std/json, std/os, std/text, std/time, std/time/datetime, std/time/timestamp.

with_handler

with_level

Returns a copy of the logger with its minimum level set to level.

with_lines

pub fn with_lines(l: Logger, f: fn(str)) -> Logger

Returns a copy of the logger that passes each formatted line, without a newline, to f, replacing any other sink.

with_prefix

pub fn with_prefix(l: Logger, prefix: str) -> Logger

Returns a copy of the logger that shows prefix before each message. When the logger already has a prefix, the result is the old prefix, . and prefix.

with_stream

pub fn with_stream(l: Logger, s: io.Stream) -> Logger

Returns a copy of the logger that writes lines to the stream s, replacing any other sink.

with_timestamps

pub fn with_timestamps(l: Logger, on: bool) -> Logger

Returns a copy of the logger that stamps records with the time when on is true, and omits it when false. Timestamps are UTC, RFC 3339 with millisecond precision, taken from the logger's clock.
