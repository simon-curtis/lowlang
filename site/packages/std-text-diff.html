std/text/diff

#text

import std/text/diff

Myers line diff: diff, lines, stats, distance, similarity, GNU-compatible unified and hunks, patch and patch_within over a unified diff, and word and character level inline, inline_chars and inline_markup.

Imports std/text, std/unicode.

hunk_header

pub fn hunk_header(h: Hunk) -> str

Returns the @@ -a,b +c,d @@ header line of h, without a newline. Line numbers count from 1. A range of one line omits the count, and a range of no lines is written with the line before it and a count of 0.

Functions

diff

pub fn diff[T: Eq](before: []T, after: []T) -> []Edit

Returns the edit script that turns before into after, with elements compared by ==. The script has the properties described for diff_by.

diff_by

pub fn diff_by[T](before: []T, after: []T, same: fn(T, T) -> bool) -> []Edit

Returns the edit script that turns before into after, with elements compared by same. The script is minimal in the number of insertions and deletions, found by Myers' algorithm in linear space. It walks both sequences in order and has one Equal, Insert or Delete for every element, with the deletions of a changed region before its insertions. Two empty sequences give an empty script.

diff_lines

pub fn diff_lines(before: str, after: str) -> []Edit

Returns the line-level edit script that turns before into after. Lines are split with lines, so a line that differs only in its missing final newline counts as changed.

diff_rows

pub fn diff_rows(before: []str, after: []str) -> []Edit

Returns the edit script that turns the rows before into the rows after. Rows are compared as whole strings.

distance

pub fn distance(edits: []Edit) -> i64

Returns the number of insertions and deletions in edits.

hunks

pub fn hunks(edits: []Edit, context: i64) -> []Hunk

Groups edits into hunks with context unchanged edits around each change. Changes closer than twice context edits share one hunk. A negative context counts as 0. A script with no changes gives no hunks.

inline

pub fn inline(before: str, after: str) -> []Span

Returns a word-level diff of before and after as a list of spans. Neighbouring tokens with the same operation, as split by words, are merged into one span. Unchanged and deleted text comes from before and inserted text from after.

inline_chars

pub fn inline_chars(before: str, after: str) -> []Span

Returns a diff of before and after over grapheme clusters as a list of spans. Spans are merged as for inline.

inline_markup

pub fn inline_markup(spans: []Span) -> str

Renders spans with deleted text as [-deleted-] and inserted text as {+inserted+}.

inline_with

pub fn inline_with(spans: []Span, delete_open: str, delete_close: str, insert_open: str, insert_close: str) -> str

Renders spans as a single string, wrapping each deleted span in delete_open and delete_close and each inserted span in insert_open and insert_close. Unchanged text is copied as it is.

lines

pub fn lines(s: str) -> []str

Splits s into lines that keep their \n terminators. The last line has no terminator when s does not end in a newline, and an empty s gives no lines. Joining the lines gives s back.

patch

pub fn patch(before: str, patch_text: str) -> str ! PatchError

Applies a unified diff to before and returns the result. Behaves as patch_within with a window of 1000 lines.

patch_within

pub fn patch_within(before: str, patch_text: str, window: i64) -> str ! PatchError

Applies a unified diff to before and returns the result, searching up to window lines from where each hunk is expected. Lines before the first @@ header, such as --- and +++, are ignored. A hunk is expected where the previous hunk's shift leaves its stated start and is searched for outward in both directions, never before the end of the previous hunk, and its context and removed lines must match exactly. \ No newline at end of file markers are honoured.

Fails with Malformed when a header or hunk line cannot be read or a hunk has fewer lines than it declares, and with Mismatch when a hunk is not found within window lines.

render

pub fn render(before: []str, after: []str, edits: []Edit, context: i64, before_name: str, after_name: str) -> str

Renders edits as a unified diff, with --- and +++ lines naming before_name and after_name. before and after are the line lists the edits were computed from, as lines returns them, and context is the number of unchanged lines kept around each change. A line without a newline is followed by \ No newline at end of file. Returns an empty string when there are no changes.

similarity

pub fn similarity(before: str, after: str) -> f64

Returns how alike before and after are by lines, from 0.0 to 1.0. The value is twice the number of unchanged lines divided by the total number of lines in both texts. Two empty texts give 1.0.

stats

pub fn stats(before: str, after: str) -> Stats

Returns the line-level Stats of changing before into after.

stats_of

pub fn stats_of(edits: []Edit) -> Stats

Returns the number of Insert, Delete and Equal edits in edits.

unified

pub fn unified(before: str, after: str, context: i64, before_name: str, after_name: str) -> str

Returns the unified diff that turns before into after. Both texts are split into lines, diffed and rendered as render does, so an empty string means no difference.

words

pub fn words(s: str) -> []str

Splits s into the tokens that inline compares. A token is a run of letters, digits, marks and _, a run of whitespace, or a single other character. Joining the tokens gives s back.
