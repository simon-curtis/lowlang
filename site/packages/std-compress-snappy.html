Raw blocks (compress_block, decompress_block, decoded_length) and the framing format with masked CRC-32C (compress, decompress, decode, Encoder).

Imports std/hash, std/io.

Types

Encoder

pub struct Encoder {
    ...
}

A streaming encoder for the Snappy framing format made by encoder.

encode takes input in any chunking and writes it as chunks of up to 64 KiB, storing a chunk uncompressed when compression saves less than an eighth. The stream identifier is written with the first call. A chunk is valid only during the call to sink.

encode

pub fn encode(e: *Encoder, data: []u8) ! io.Error

Compresses data and passes each completed 64 KiB chunk to the encoder's sink.

Input is buffered until a chunk is full, so a call can produce no output beyond the stream identifier. Fails with any error sink returns.

finish

pub fn finish(e: *Encoder) ! io.Error

Writes the buffered input as a chunk. The format has no trailer, so this equals flush.

Fails with any error sink returns.

flush

pub fn flush(e: *Encoder) ! io.Error

Writes the buffered input as a chunk, so a decoder can read everything encoded so far.

Fails with any error sink returns.

compress_block

pub fn compress_block(data: []u8) -> []u8

Returns data compressed as one Snappy block, which is the raw block format with no framing.

The block holds the whole of data. compress and encoder write the framing format, which splits input into 64 KiB chunks.

decode

pub fn decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes the Snappy framing format from r and passes the decoded bytes to sink in chunks until the input ends.

Chunk checksums are verified. Skippable chunks are ignored; a reserved unskippable chunk type is Unsupported, and input without the leading stream identifier is Malformed. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

decoded_length

pub fn decoded_length(data: []u8) -> i64 ! io.Error

Returns the decoded length stored in the header of the Snappy block data.

Reads only the leading varint. Fails with Malformed when it is truncated, longer than five bytes or above 0xFFFFFFFF.

decompress

pub fn decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from the Snappy framing format in data.

Chunk checksums are verified. Input without the leading stream identifier is Malformed. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.

decompress_block

pub fn decompress_block(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from the Snappy block data, which is the raw block format with no framing.

Fails with TooLarge when the decoded length in the header exceeds limit and with Malformed when the header is invalid, claims more than 22 times the compressed size or the block does not decode to exactly that length.

encoder

pub fn encoder(sink: fn([]u8) ! io.Error) -> *Encoder

Returns an encoder that writes the Snappy framing format to sink.
