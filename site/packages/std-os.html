std/os

#os

import std/os

Process state: args and environment (from the argument and environment vectors the program started with), env as str?, umask (sets the creation mask and returns the previous one), pid and exit. Queries: getcwd, chdir, hostname, uid, gid, euid, egid, ppid, executable, uptime, cpu_count, and lookup_user and user_name from /etc/passwd. set_env and unset_env are seen by env, environment, process.find and the environment process.run passes on. Directories: home_dir, cache_dir, config_dir, data_dir and state_dir (XDG variables when absolute, otherwise under $HOME), and temp_dir_path.

Imports std/io, std/sys, std/text.

args

pub fn args() -> []str

Returns the command-line arguments the program started with, the program name first.

cache_dir

pub fn cache_dir() -> str?

Returns the per-user cache directory, or none if it cannot be found.

Uses XDG_CACHE_HOME when it is an absolute path, and otherwise .cache under home_dir. On Windows uses LOCALAPPDATA.

chdir

pub fn chdir(path: str) ! io.Error

Changes the working directory of the whole process to path.

Fails with NotFound, NotDir or Denied as the operating system reports. The change affects every green thread and relative paths used afterwards.

config_dir

pub fn config_dir() -> str?

Returns the per-user configuration directory, or none if it cannot be found.

Uses XDG_CONFIG_HOME when it is an absolute path, and otherwise .config under home_dir. On Windows uses APPDATA.

cpu_count

pub fn cpu_count() -> i64

Returns the number of CPUs the process may run on, according to its affinity mask.

Returns 1 if the mask cannot be read.

data_dir

pub fn data_dir() -> str?

Returns the per-user data directory, or none if it cannot be found.

Uses XDG_DATA_HOME when it is an absolute path, and otherwise .local/share under home_dir. On Windows uses APPDATA.

egid

pub fn egid() -> i64

Returns the effective group id.

env

pub fn env(name: str) -> str?

Returns the value of the environment variable name, or none if it is not set.

A variable that is set to an empty string returns some(""). Changes made by set_env and unset_env take precedence over the starting environment.

environment

pub fn environment() -> [str: str]

Returns every environment variable as a map from name to value.

Starts from the environment the program was started with and applies the changes made by set_env and unset_env.

euid

pub fn euid() -> i64

Returns the effective user id.

executable

pub fn executable() -> str ! io.Error

Returns the path of the running executable.

Reads /proc/self/exe on Linux, and fails with the system error of reading the link, such as NotFound when /proc is not mounted. Blocks the OS thread for the call.

exit

pub fn exit(code: i64)

Ends the process immediately with the status code.

Does not run pending defer blocks or drops and does not wait for other green threads. Does not return.

getcwd

pub fn getcwd() -> str ! io.Error

Returns the absolute path of the current working directory.

Fails with NotFound if the directory has been removed and with TooLarge if the path exceeds 1 MiB.

gid

pub fn gid() -> i64

Returns the real group id.

home_dir

pub fn home_dir() -> str?

Returns the home directory of the current user, or none if it cannot be found.

Uses HOME when it is set and not empty, and otherwise the home field of the effective user's /etc/passwd entry. On Windows uses USERPROFILE.

hostname

pub fn hostname() -> str ! io.Error

Returns the host name of the machine.

lookup_user

pub fn lookup_user(id: i64) -> User?

Returns the /etc/passwd entry whose user id is id, or none.

Returns none as well when the file cannot be read, and always on Windows, which has no numeric user ids. Lines with fewer than seven fields or a non-numeric id are skipped. Reads the file on every call and blocks the OS thread while doing so.

pid

pub fn pid() -> i64

Returns the process id.

ppid

pub fn ppid() -> i64

Returns the process id of the parent.

set_env

pub fn set_env(name: str, value: str) ! io.Error

Sets the environment variable name to value for this program.

The change is seen by env, environment, std/process's find and the environment std/process passes to children that do not set their own. It is kept in a shared memory region, not in the operating system's environment block, so code outside Low that reads that block does not see it. Fails with Invalid if name is empty or contains = or NUL, or value contains NUL; with NoSpace when the region (1 MiB) is full; and with Unsupported if the region cannot be set up.

state_dir

pub fn state_dir() -> str?

Returns the per-user state directory, or none if it cannot be found.

Uses XDG_STATE_HOME when it is an absolute path, and otherwise .local/state under home_dir. On Windows uses LOCALAPPDATA.

temp_dir_path

pub fn temp_dir_path() -> str

Returns the directory for temporary files: TMPDIR when it is set and not empty, and /tmp otherwise.

On Windows the first of TMP, TEMP and USERPROFILE that is set and not empty, and C:\Windows\Temp otherwise.

uid

pub fn uid() -> i64

Returns the real user id.

umask

pub fn umask(mask: i64) -> i64

Sets the file creation mask to mask & 0o777 and returns the previous mask.

The mask is process-wide.

unset_env

pub fn unset_env(name: str) ! io.Error

Removes the environment variable name from this program's view of the environment.

Afterwards env returns none and environment omits the name, even when the program started with it. Fails with Invalid if name is empty or contains = or NUL, and with NoSpace or Unsupported as set_env does.

uptime

pub fn uptime() -> i64 ! io.Error

Returns the number of seconds the machine has been running.

user_name

pub fn user_name() -> str?

Returns the login name of the effective user, or none if it cannot be found.

Reads the effective user's /etc/passwd entry on Linux and USERNAME on Windows.
