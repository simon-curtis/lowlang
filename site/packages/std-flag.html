Functions

parse

pub fn parse(specs: []Spec, args: []str) -> Parsed ! Error

Parses args against specs.

args does not include the program name. A flag is written --name or -name, with the value either joined as --name=value or as the next argument; a switch takes no next argument. An argument that does not start with -, and a lone -, is positional. -- ends flag parsing and every later argument is positional. Flags and positional arguments can be interleaved, and a flag given more than once keeps its last value. Fails with Unknown, Missing or Invalid for the first problem found.

usage

pub fn usage(specs: []Spec) -> str

Returns help text for specs, one line per flag in the order given.

Each line has the form --name value help (default fallback): switches omit value, the help part is omitted when empty, and the default part appears only for non-switch flags with a non-empty fallback.
