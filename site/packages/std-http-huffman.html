std/http/huffman

#net #web

import std/http/huffman

The static Huffman code of RFC 7541 appendix B that HPACK and QPACK share: decode, encode and encoded_size. decode fails Malformed on the EOS symbol and on padding that is longer than 7 bits or not all ones, and never panics on any input.

Imports std/io.

Examples

header_strings

import std/http/huffman
import std/io
import std/text

/// Codes header strings with the HPACK Huffman table and decodes them again.
fn main() ! io.Error {
    for value in ["www.example.com", "no-cache", "custom-value", "/index.html?q=low"] {
        var coded: []u8 = []
        huffman.encode(mut coded, value)
        let back = huffman.decode(coded)?
        print("{value}: {value.len} -> {huffman.encoded_size(value)} bytes {text.encode_hex(coded)} {back == value}")
    }
    let corrupt = huffman.decode([0xF1, 0xE3, 0x00]) catch {
        Malformed => "rejected malformed input"
        e => "{e}"
    }
    print(corrupt)
}

decode

pub fn decode(raw: []u8) -> str ! io.Error

Decodes raw, a string coded with the static Huffman code of RFC 7541 appendix B, which HPACK and QPACK share, and returns the bytes it spells as a str.

The result is not checked for UTF-8. Fails Malformed when a code in raw is the EOS symbol, when the final byte pads with more than 7 bits, or when the padding is not all ones. An empty raw decodes to an empty string.

encode

pub fn encode(mut out: []u8, s: str)

Appends the Huffman code of the bytes of s to out, padding the last byte with the high bits of the EOS symbol.

An empty s appends nothing. The number of bytes appended is encoded_size(s).

encoded_size

pub fn encoded_size(s: str) -> i64

Returns the number of bytes encode appends for s.
