std/sql

#database

import std/sql

The driver contract: Connection, the droppable owner that closes the driver connection when released; ConnectionHandle, the copyable view of closures that std/orm and closures use (handle makes it from an owner, adopt the other way); Value, Rows, Error, Options and dialect helpers.

An owned database connection that closes the underlying connection when dropped.

Its fields are the same closures as ConnectionHandle; handle returns the copyable view and adopt builds a Connection from one.

handle

pub fn handle(c: Connection) -> ConnectionHandle

Returns the copyable view of a connection.

The Connection still owns the connection and closes it when dropped, so the view must not outlive it.

A second call has no effect.    pub close: fn()

A copyable view of a database connection, made of closures.

Copies refer to the same connection and none of them owns it: close closes the connection for all of them. std/orm and std/sql/pool work in terms of this view. handle makes one from a Connection.

adopt

pub fn adopt(h: ConnectionHandle) -> Connection

Returns a Connection that owns the connection behind the handle, so that dropping it calls the handle's close.

placeholder

pub fn placeholder(d: Dialect, index: i64) -> str

Returns the placeholder for the parameter at the zero-based index: $1 for PostgreSQL, @p1 for SQL Server and ?1 for SQLite when index is 0.

quote_identifier

pub fn quote_identifier(d: Dialect, name: str) -> str

Returns the identifier quoted for the dialect: wrapped in [ and ] for SQL Server and in double quotes otherwise, with each closing quote character in the name doubled.

A database value, used both as a statement parameter and as a cell in a result row.

Which variants a driver returns depends on the database: SQLite only produces Null, Int, Float, Text and Bytes, and stores the other variants as integers, text or blobs when they are bound. A driver fails with Error.Conversion when it cannot represent a parameter.
