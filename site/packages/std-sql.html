std/sql

#database

import std/sql

The driver contract: Connection, the droppable owner that closes the driver connection when released; ConnectionHandle, the copyable view of closures that std/orm and std/sql/pool use, held in the owner's public handle field (adopt makes an owner from one); Value, Rows, Error, Options and Dialect. A Dialect is a record that owns everything that differs between databases: the OpenTelemetry system name, default port, placeholder prefix, identifier quotes, generated-key and paging syntax, column types, the conditional CREATE TABLE, the session lock statements and the write-transaction statement. postgres(), sqlserver() and sqlite() build the three; std/orm and std/sql/migrate read the one a connection carries. rolled_back rolls a transaction back after an error and reports the rollback's own error when it fails.

Connection

pub struct Connection {The copyable view of the connection.    pub handle: ConnectionHandle

An owned database connection that closes the underlying connection when dropped.

Its handle is the copyable view that std/orm and std/sql/pool work in terms of; adopt builds a Connection from one.

ConnectionHandle

A second call has no effect.    pub close: fn()

A copyable view of a database connection, made of closures.

Copies refer to the same connection and none of them owns it: close closes the connection for all of them. std/orm and std/sql/pool work in terms of this view. The handle field of a Connection is one.

adopt

pub fn adopt(h: ConnectionHandle) -> Connection

Returns a Connection that owns the connection behind the handle, so that dropping it calls the handle's close.

rolled_back

pub fn rolled_back(h: ConnectionHandle, cause: Error) -> Error

Rolls back the current transaction of h after cause and returns the error to report.

That is cause when the rollback succeeds and the rollback's own error when it fails, because the transaction may then still be open.

Everything that differs between the databases the drivers speak to: placeholders, identifier quotes, column types, generated keys, paging, DDL, locks, the OpenTelemetry system name and the default port.

postgres, sqlserver and sqlite build the three dialects. Every connection carries its own, and std/orm and std/sql/migrate read it.

create_table_if_missing

pub fn create_table_if_missing(d: Dialect, name: str, columns: str) -> str

Returns the statement that creates the table name with columns unless it exists. columns is the text between the parentheses, and name is quoted for the dialect.

placeholder

pub fn placeholder(d: Dialect, index: i64) -> str

Returns the placeholder for the parameter at the zero-based index: $1 for PostgreSQL, @p1 for SQL Server and ?1 for SQLite when index is 0.

quote_identifier

pub fn quote_identifier(d: Dialect, name: str) -> str

Returns the identifier quoted for the dialect, with each closing quote character in the name doubled.

A database value, used both as a statement parameter and as a cell in a result row.

Which variants a driver returns depends on the database: SQLite only produces Null, Int, Float, Text and Bytes, and stores the other variants as integers, text or blobs when they are bound. A driver fails with Error.Conversion when it cannot represent a parameter.
