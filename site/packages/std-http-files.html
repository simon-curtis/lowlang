std/http/files

#net #web

import std/http/files

serve_file and serve_file_with answer a request from a file. Content type comes from the extension, then sniffing. Weak ETag and Last-Modified work with If-None-Match and If-Modified-Since. A single Range is answered as 206 or 416, with If-Range. HEAD is supported and the body is streamed.

Imports std/cancel, std/file, std/header, std/http, std/io, std/mime, std/path, std/text, std/time/timestamp.

serve_file_with

pub fn serve_file_with(req: http.Request, target: str, o: FileOptions) -> http.Response

Returns the response that serves the regular file at the filesystem path target for req.

target is used as given, so a caller that builds it from a request path must first reject or confine anything that escapes its root.

The status is 404 when the path does not exist or is not a regular file, 403 when it is not accessible, and 500 for other failures. The response carries last-modified, a weak etag made from the size and modification time, and accept-ranges: bytes. It is 304 when if-none-match lists the entity tag or is *, or, if that header is absent, when if-modified-since is not older than the file.

The content type is o.content_type, else the type for the extension of o.name or the path, else a guess from the first 512 bytes, else application/octet-stream.

A single bytes= range in range is answered with 206 and content-range: first-last, first- and -suffix forms are accepted, and the end is clamped to the file size. A range starting past the end of the file, or a zero-length suffix, gets 416 with content-range: bytes */size. A range that is malformed, lists several ranges or is not in bytes is ignored and the whole file is sent. An if-range header that is not the date the file was last modified also sends the whole file.

The body is read in 64 KiB chunks on a separate task and delivered through Response.stream, and reading stops when req.token is cancelled. A HEAD request and an empty file get the headers and content-length and no stream.
