std/crypto/password

#crypto

import std/crypto/password

Password hashes in PHC strings: Argon2id, scrypt (RFC 7914, with a memory limit checked before allocating) and PBKDF2. bcrypt ($2b$; passwords over 72 bytes are rejected). verify handles all of them and $2a$ and $2y$ bcrypt strings. BLAKE2b.

Imports std/base64, std/crypto, std/crypto/hash, std/io, std/text.

argon2id

pub fn argon2id(password: []u8, salt: []u8, t: i64, m: i64, p: i64, length: i64) -> []u8

Computes Argon2id version 0x13 (RFC 9106) of password with salt and returns length bytes.

Equivalent to argon2id_keyed with an empty secret and no associated data, including its parameter limits and the empty slice returned for invalid parameters.

argon2id_keyed

pub fn argon2id_keyed(password: []u8, salt: []u8, secret: []u8, associated: []u8, t: i64, m: i64, p: i64, length: i64) -> []u8

Computes Argon2id version 0x13 (RFC 9106) with an optional secret value and associated data, and returns length bytes.

t is the number of passes, m the memory in KiB and p the number of lanes. salt must be at least 8 bytes. secret and associated may be empty. The memory used is m rounded down to a multiple of 4 * p KiB.

Returns an empty slice when p is outside [1, 16777215], t is below 1, m is below 8 * p or above 4294967295, length is below 4, or salt is shorter than 8 bytes. Allocates about m KiB, with no limit applied here.

bcrypt

pub fn bcrypt(password: []u8, salt: []u8, cost: i64) -> []u8 ! Error

Computes the bcrypt hash of password and returns the 23 raw digest bytes.

salt must be exactly 16 bytes and cost is the base-2 logarithm of the number of rounds, from 4 to 31. The password is used with a trailing NUL byte, as in $2b$. The digest is not encoded and carries no cost or salt; see hash_bcrypt for the string form.

Fails with InvalidCost for a cost outside [4, 31], with InvalidSalt for a salt that is not 16 bytes, and with PasswordTooLong for a password over 72 bytes.

blake2b

pub fn blake2b(data: []u8, length: i64, key: []u8) -> []u8

Computes BLAKE2b (RFC 7693) of data and returns length bytes.

length is the digest size, from 1 to 64. key is an optional MAC key of at most 64 bytes; an empty key gives the unkeyed hash. Returns an empty slice when length is outside [1, 64] or key is longer than 64 bytes. The whole input is processed in one call.

hash

pub fn hash(password: str) -> str

Hashes password with Argon2id and returns a PHC string.

The parameters are fixed at 19456 KiB of memory, 2 passes, 1 lane, a random 16-byte salt from crypto.random and a 32-byte tag. The result has the form $argon2id$v=19$m=19456,t=2,p=1$<salt>$<tag>, with salt and tag in unpadded standard base64.

hash_bcrypt

pub fn hash_bcrypt(password: str, cost: i64) -> str ! Error

Hashes password with bcrypt and returns a $2b$ string.

The salt is 16 random bytes from crypto.random. The result has the form $2b$<cost, two digits>$<salt, 22 characters><digest, 31 characters>, using the bcrypt base64 alphabet. Fails with the errors of bcrypt: InvalidCost, or PasswordTooLong for a password over 72 bytes.

hash_pbkdf2

pub fn hash_pbkdf2(password: str, iterations: i64) -> str

Hashes password with PBKDF2-HMAC-SHA-256 (RFC 8018) and returns a PHC string.

iterations is clamped to [1, 10000000]. The salt is 16 random bytes from crypto.random and the tag is 32 bytes. The result has the form $pbkdf2-sha256$i=<iterations>$<salt>$<tag>, with salt and tag in unpadded standard base64.

hash_scrypt

pub fn hash_scrypt(password: str, log_n: i64, r: i64, p: i64) -> str ! Error

Hashes password with scrypt and returns a PHC string.

The cost is N = 2^log_n with log_n in [1, 32]. r and p follow the limits of scrypt, with a memory limit of 512 MiB. The salt is 16 random bytes from crypto.random and the tag is 32 bytes. The result has the form $scrypt$ln=<log_n>,r=<r>,p=<p>$<salt>$<tag>, with salt and tag in unpadded standard base64.

Fails with InvalidParameters for log_n outside [1, 32] or invalid r or p, and with MemoryLimit when the memory needed exceeds 512 MiB.

pbkdf2

pub fn pbkdf2(algorithm: hash.Algorithm, password: []u8, salt: []u8, iterations: i64, length: i64) -> []u8

Derives length bytes from password and salt with PBKDF2 (RFC 8018) using HMAC over algorithm.

iterations is the iteration count; a value below 1 runs one iteration. Output longer than the digest size of algorithm is built from successive blocks, so length is not limited to one digest. A length of 0 returns an empty slice. The password may be any length; one longer than the block size of algorithm is hashed first, as HMAC specifies. No parameter limits are enforced.

scrypt

pub fn scrypt(password: []u8, salt: []u8, n: i64, r: i64, p: i64, length: i64, max_memory: i64) -> []u8 ! Error

Derives length bytes from password and salt with scrypt (RFC 7914).

n is the CPU and memory cost, a power of two from 2 to 2^32, r the block size and p the parallelism, both at least 1 with r * p below 2^30. length is from 1 to 137438953440 ((2^32 - 1) * 32). max_memory is the memory limit in bytes and is checked, with scrypt_memory, before anything is allocated.

Fails with InvalidParameters when a parameter is outside those ranges, and with MemoryLimit when scrypt_memory(n, r, p) exceeds max_memory.

scrypt_memory

pub fn scrypt_memory(n: i64, r: i64, p: i64) -> i64

Returns the bytes of memory scrypt allocates for the cost parameters n, r and p, computed as 128 * r * (n + p + 1).

The result is not range-checked.

verify

pub fn verify(password: str, encoded: str) -> bool

Reports whether password matches the hash string encoded.

Accepts $argon2id$v=19$..., $pbkdf2-sha256$..., $scrypt$... and bcrypt $2a$, $2b$ and $2y$ strings. The recomputed tag is compared without an early exit. Returns false, never an error, for an unrecognised format, malformed fields, parameters outside the limits below, a bcrypt password over 72 bytes, or a mismatch.

Argon2id requires p in [1, 255], t in [1, 100], m in [8 * p, 1048576] KiB, a salt of 8 to 256 bytes and a tag of 4 to 256 bytes. PBKDF2 requires i in [1, 10000000], a salt of 1 to 256 bytes and a tag of 4 to 64 bytes. scrypt requires ln in [1, 32], a salt of 8 to 256 bytes, a tag of 4 to 256 bytes and at most 512 MiB of memory.
