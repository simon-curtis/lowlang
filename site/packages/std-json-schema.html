std/json/schema

#formats

import std/json/schema

JSON Schema 2020-12. compile and compile_with check the schema, resolve $ref, $anchor, $dynamicRef and registered resources, and precompile patterns. validate returns Violations with the instance pointer, the keyword pointer and a message. unevaluatedProperties and unevaluatedItems use annotations from the branches that passed. format annotates or asserts.

Imports std/json, std/json/pointer, std/regex, std/slices, std/text.

A compiled JSON Schema (draft 2020-12), made by compile or compile_with.

A Schema can validate any number of instances.

is_valid

pub fn is_valid(s: Schema, instance: json.Value) -> bool

Returns whether instance is valid against s; equivalent to validate(s, instance).len == 0.

validate

pub fn validate(s: Schema, instance: json.Value) -> []Violation

Returns every way in which instance fails s; the result is empty when it is valid.

Annotations from the branches of allOf, anyOf, oneOf, if and the other applicators that passed decide what unevaluatedProperties and unevaluatedItems cover. Validation does not stop at the first failure.

compile_with

pub fn compile_with(schema: json.Value, options: Options) -> Schema ! Error

Compiles the JSON Schema 2020-12 document schema.

It checks the schema, resolves $ref, $anchor, $dynamicRef and the schemas in options.resources by their $id, and precompiles every pattern and patternProperties expression. A schema is an object or a boolean. Fails with Malformed for an invalid schema and Unresolved for a reference that resolves to nothing.
