decode

pub fn decode(cs: []u32) -> str ! Error

Decodes code points into a string. Fails with InvalidCodePoint at the index of the first surrogate or value above 0x10FFFF.

decode_bytes

pub fn decode_bytes(data: []u8, order: unicode.Order) -> str ! Error

Decodes UTF-32 bytes into a string. A leading byte order mark is removed, and it selects its own byte order over order. Without one, order applies. Fails with BadLength when the bytes after the mark are not a multiple of 4 and with InvalidCodePoint for a surrogate or a value above 0x10FFFF.

decode_bytes_lossy

pub fn decode_bytes_lossy(data: []u8, order: unicode.Order) -> str

Decodes UTF-32 bytes into a string, replacing invalid input with U+FFFD. The byte order mark is handled as in decode_bytes. Each invalid value and a trailing partial code point become one U+FFFD.

decode_lossy

pub fn decode_lossy(cs: []u32) -> str

Decodes code points into a string, replacing each invalid value with U+FFFD.

encode

pub fn encode(s: str) -> []u32

Returns the code points of s as a slice of u32. Each byte of s that is not valid UTF-8 becomes 0xFFFD.

encode_bytes

pub fn encode_bytes(s: str, order: unicode.Order, bom: bool) -> []u8

Returns s encoded as UTF-32 bytes in the given byte order, preceded by a byte order mark when bom is true. Each byte of s that is not valid UTF-8 becomes U+FFFD.

from_bytes

pub fn from_bytes(data: []u8, order: unicode.Order) -> []u32 ! Error

Reads code points from data in the given byte order. A byte order mark is not interpreted and values are not validated. Fails with BadLength when data.len is not a multiple of 4.

to_bytes

pub fn to_bytes(cs: []u32, order: unicode.Order) -> []u8

Returns the bytes of cs in the given byte order, four bytes per code point and without a byte order mark.
