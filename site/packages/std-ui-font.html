std/ui/font

#ui

import std/ui/font

TrueType and OpenType CFF parsing, font collections, font descriptions, system font discovery, glyph outlines, the rasteriser and the embedded fallback font.

Imports std/builder, std/file, std/io, std/os, std/path, std/slices, std/text, std/ui/geometry, std/unicode/utf16.

Contour

pub struct Contour {The points in file order.    pub points: []Point
}

A closed loop of points: lines between consecutive on-curve points, and a quadratic curve through each run of off-curve points.

Between two consecutive off-curve points the curve passes through their midpoint, which the list leaves out. A cubic curve of an OpenType CFF glyph is stored as one to eight quadratic curves that stay within a tenth of a font unit of it, each ending on an on-curve point.

kern

pub fn kern(f: Font, left: i64, right: i64) -> i64

Returns the font units to add to the pen position between the glyphs left and right, negative to bring them closer, or 0 when the font has no pair adjustment for them.

A font whose GPOS table has a kern feature for its latn script, else DFLT, else its first script, in the default language system, is kerned by the pair adjustments (format 1 or 2, directly or through extension lookups) of that feature's lookups, in lookup order, summing the x advance of the first glyph's value record. In a lookup the first subtable that covers the pair decides it. Any other font is kerned by its kern table.

mark_offset

pub fn mark_offset(f: Font, base: i64, mark: i64) -> Offset?

Returns where the origin of the glyph mark sits relative to the origin of base, in font units, or none when the font does not attach it.

When base is a mark, the offset comes from the mark-to-mark lookups of the mkmk feature; otherwise it comes from the mark-to-base lookups of the mark feature. The features are chosen as kern is. A lookup's subtables are tried in order and the first that covers both glyphs decides, with the anchor of base for the mark's class minus the mark's own anchor. Anchor formats 1, 2 and 3 are read as their x and y. A malformed offset gives none.

outline

pub fn outline(f: Font, glyph: i64) -> Outline

Returns the outline of glyph, with each component of a composite glyph placed by its offset and scale.

A component placed by matching points instead of an offset is supported; SCALED_COMPONENT_OFFSET is not, so offsets are never scaled. A composite nests at most 6 deep and holds at most 64 components in all.

A CFF glyph is drawn from its Type 2 charstring, with subroutines up to 10 deep and at most 200000 operators. The deprecated arithmetic and storage operators and the accented form of endchar are not supported.

A space, a glyph the font does not have and a glyph whose data is truncated or inconsistent give an outline with no contours.

rasterize

pub fn rasterize(f: Font, glyph: i64, pixel_size: f32) -> Bitmap

Returns the coverage of glyph with the em square pixel_size pixels tall, the pen at the origin of an integer pixel grid.

The outline is flattened into lines, each of which adds its signed area and cover to the pixels it crosses; a running sum along each row then gives the winding coverage, clamped to full.

A glyph with no outline, a pixel_size that is not positive and a glyph more than 2048 pixels wide or tall give an empty bitmap.

scale

pub fn scale(f: Font, pixel_size: f32) -> f32

Returns the number of pixels one font unit covers when the em square is pixel_size pixels.

substitute

pub fn substitute(f: Font, glyphs: []i64) -> []Substituted

Applies the glyph substitutions of the font's GSUB table to glyphs, which are adjacent glyphs of one run, and returns the glyphs left, each with the range of input glyphs it replaces. The ranges are in order, adjacent and cover every input glyph.

The features are chosen as for kern: the latn script, else DFLT, else the first, in its default language system. The lookups of ccmp run first, in lookup order, then those of rlig, liga and clig together in lookup order. Each lookup runs over the whole sequence, left to right, and replaces what it matches before the next lookup runs. Single substitutions (type 1), ligature substitutions (type 4) and extension lookups (type 7) holding either are applied; the other types and the lookup flags are ignored, so a ligature forms only from glyphs that are next to each other. A ligature or substitute outside the font's glyphs, and a subtable with a malformed offset, are skipped. A font with no such lookups returns each glyph unchanged.

discover

pub fn discover() -> []Face

Returns every font in .ttf, .otf, .ttc and .otc files under font_directories(), ordered by path and index within each directory and without repeats.

Only each file's table directory and its name, OS/2 and head tables are read. A file that cannot be read, is not a font, or names no family is left out. A symbolic link to a font file or to a directory is followed, and a file reached by several paths is listed once, under the first.

parse

pub fn parse(data: str) -> Font ! Error

Reads the TrueType or OpenType font in data. A font collection fails with Unsupported("ttcf"); parse_collection reads one of its fonts.

The head, hhea, maxp, cmap and hmtx tables are required, with loca and glyf for TrueType outlines or CFF for OpenType ones, and GPOS, GSUB, GDEF and kern are optional. A font with only a CFF2 table fails with Unsupported("CFF2"). A cmap subtable of format 12 or 4 is used, preferring a Unicode one that covers every plane. Kerning comes from the GPOS pair adjustments of the kern feature when the font has any, else from the first horizontal kern subtable of format 0.

Every table in the directory, and the loca offsets, are checked here. Glyph data and lookup tables are read when used, and a malformed one gives glyph 0, an empty outline or a zero metric instead of an error.

parse_collection

pub fn parse_collection(data: str, index: i64) -> Font ! Error

Reads font index of the TrueType or OpenType collection in data, counting from 0. The result holds the whole file, and reads its tables as parse does.

Data that is not a collection, or whose header or list of font offsets runs past the end, fails with Malformed("header"), and an index outside the collection with Malformed("collection").
