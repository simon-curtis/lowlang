glyphs

import std/ui/font

fn draw(f: font.Font, c: u32, pixel_size: f32) {
    let glyph = font.glyph_index(f, c)
    let bitmap = font.rasterize(f, glyph, pixel_size)
    print("glyph {glyph} at {pixel_size}px: {bitmap.width}x{bitmap.height}, left {bitmap.left}, top {bitmap.top}")
    for row in 0..bitmap.height {
        var line = ""
        for col in 0..bitmap.width {
            let v = bitmap.coverage[row * bitmap.width + col]
            line = "{line}{if v > 191 { "#" } else if v > 96 { "+" } else if v > 24 { "-" } else { "." }}"
        }
        print(line)
    }
}

/// Reads the metrics of the embedded font, looks up glyphs and draws glyphs as coverage text.
fn main() {
    let f = font.fallback()
    let scale = font.scale(f, 16.0)
    print("units per em {f.units_per_em}, ascent {f.ascent}, descent {f.descent}, {f.glyph_count} glyphs")
    print("ascent at 16px: {f32(f.ascent) * scale}")

    let a = font.glyph_index(f, 'A')
    print("advance of A: {font.advance(f, a)} units")
    print("missing glyph for U+1F600: {font.glyph_index(f, 0x1F600)}")

    draw(f, 'R', 14.0)
    draw(f, 'g', 14.0)

    let broken = font.parse("not a font") catch {
        Malformed(table) => {
            print("malformed {table}")
            f
        }
        Unsupported(table) => {
            print("unsupported {table}")
            f
        }
    }
}

Contour

pub struct Contour {The points in file order.    pub points: []Point
}

A closed loop of points: lines between consecutive on-curve points, and a quadratic curve through each run of off-curve points.

Between two consecutive off-curve points the curve passes through their midpoint, which the list leaves out.

A TrueType font with glyf outlines, held as the bytes it was parsed from.

Metrics are in font units, units_per_em to the em square, with y up.

advance

pub fn advance(f: Font, glyph: i64) -> i64

Returns the distance in font units from the pen position of glyph to the next one, or 0 for a glyph the font does not have.

glyph_index

pub fn glyph_index(f: Font, code_point: u32) -> i64

Returns the glyph that draws code_point, or 0 when the font has none.

kern

pub fn kern(f: Font, left: i64, right: i64) -> i64

Returns the font units to add to the pen position between the glyphs left and right, negative to bring them closer, or 0 when the font has no kern pair for them.

outline

pub fn outline(f: Font, glyph: i64) -> Outline

Returns the outline of glyph, with each component of a composite glyph placed by its offset and scale.

A component placed by matching points instead of an offset is supported; SCALED_COMPONENT_OFFSET is not, so offsets are never scaled. A composite nests at most 6 deep and holds at most 64 components in all.

A space, a glyph the font does not have and a glyph whose data is truncated or inconsistent give an outline with no contours.

rasterize

pub fn rasterize(f: Font, glyph: i64, pixel_size: f32) -> Bitmap

Returns the coverage of glyph with the em square pixel_size pixels tall, the pen at the origin of an integer pixel grid.

The outline is flattened into lines, each of which adds its signed area and cover to the pixels it crosses; a running sum along each row then gives the winding coverage, clamped to full.

A glyph with no outline, a pixel_size that is not positive and a glyph more than 2048 pixels wide or tall give an empty bitmap.

scale

pub fn scale(f: Font, pixel_size: f32) -> f32

Returns the number of pixels one font unit covers when the em square is pixel_size pixels.

parse

pub fn parse(data: str) -> Font ! Error

Reads the TrueType font in data.

The head, hhea, maxp, cmap, hmtx, loca and glyf tables are required and kern is optional. A cmap subtable of format 12 or 4 is used, preferring a Unicode one that covers every plane. Only the first horizontal kern subtable of format 0 is read.

Every table in the directory, and the loca offsets, are checked here. Glyph data and lookup tables are read when used, and a malformed one gives glyph 0, an empty outline or a zero metric instead of an error.
