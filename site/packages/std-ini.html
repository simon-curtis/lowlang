std/ini

#formats

import std/ini

INI files with sections, = or :, ; and # comments, quoted values, continuations and duplicate keys (last wins, or all with collect): parse, get, get_all, sections, set, format.

Imports std/text.

Document

An ordered list of sections.

The first section is the unnamed one for entries before any header; it is always present. Sections are shared pointers, so a Section found with find reflects later changes to the document.

add

pub fn add(mut d: Document, section: str, key: str, value: str)

Appends the entry key and value to section, even when the key is already present.

The section is created at the end of the document when it does not exist. The entry's line is 0.

find

pub fn find(d: Document, name: str) -> *Section?

Returns the section called name, or none when the document has no such section.

The empty name finds the unnamed section.

format

pub fn format(d: Document) -> str

Formats the document as INI text.

The unnamed section is written first without a header and is skipped when it is empty; each named section follows as [name], with a blank line between sections. An entry is written as key = value, or key = for an empty value. A value is quoted, with \", \\, \n, \r, \t and \uXXXX escapes, when it starts with a space, tab or ", ends with a space, tab or \, or holds a control character; other values are written as they are. Keys and section names are not escaped. Every line ends with \n.

get

pub fn get(d: Document, section: str, key: str) -> str?

Returns the value of key in section, or none when the section or the key does not exist.

When the key occurs more than once the last value is returned.

get_all

Returns an empty slice when the section or the key does not exist. A document parsed without collect holds at most one value per key.

set

parse_with

pub fn parse_with(source: str, options: Options) -> Document ! Error

Parses INI text into a Document.

A leading UTF-8 byte order mark is dropped. Lines are split at \n; a \r before it is trimmed away. A line whose first non-blank character is ; or # is a comment, and blank lines are skipped. [name] starts a section, and a header may be followed by a comment; repeating a name continues the same section. Entries before the first header belong to the unnamed section. An entry is split at the first = or :, and key and value are trimmed. An unquoted value is taken as it is, so ; and # inside it are part of the value. A value starting with " is quoted: it understands \n, \t, \r, \0, \\, \", \', \;, \#, \=, \: and \uXXXX (not a surrogate), and may be followed by a comment. A line whose last non-blank character is an odd number of backslashes continues on the next line; the backslash is removed and the next line is trimmed before it is joined.

Fails with Syntax, which carries the line, for malformed input.
