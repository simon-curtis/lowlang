std/tls

#crypto #net

import std/tls

TLS 1.2 and 1.3 clients and servers. client, server and dial return a droppable Session that sends close_notify and closes the stream beneath it when released. Its handle is the shared *SessionHandle holding protocol, version, group, suite, cipher_suite and peer_certificates. client_handle and server_handle return the view alone, and read_on, write_on, close_on and stream_on operate on it. quic_client and quic_server run the TLS 1.3 handshake of RFC 9001 through a QuicTransport of callbacks that send and receive handshake bytes per Level and install each QuicSecret, and return a QuicResult. suite_hash, key_size, cipher and expand_label derive keys for a Suite.

Imports std/crypto, std/crypto/aead, std/crypto/ecdsa, std/crypto/hash, std/crypto/mlkem, std/crypto/x25519, std/crypto/x509, std/io, std/net, std/slices, std/text, std/time.

fn reply(h: net.ConnHandle, config: tls.Config) {
    using c = net.adopt(h)
    using session = tls.server(net.stream(c), config) or return
    let r = io.reader(tls.stream(session))
    let line = io.read_line(r) or return
    tls.write(session, bytes("echo: {line}")) or return
}

fn accept_loop(l: net.ListenerHandle, config: tls.Config) {
    for {
        let h = net.accept_handle(l) or return
        spawn reply(h, config)
    }
}

fn ask(l: net.Listener, config: tls.Config, message: str) ! io.Error {
    using c = net.connect(l.handle.addr)?
    using session = tls.client(net.stream(c), config)?
    let h = session.handle
    print("version {text.hex(h.version)}, suite {text.hex(h.cipher_suite)}, group {text.hex(h.group)}, alpn {h.protocol}")
    print("server certificate {h.peer_certificates[0].common_name}")
    tls.write(session, bytes("{message}\n"))?
    let answer = io.read_all(tls.stream(session))?
    print(str(answer))
}

fn attempt(label: str, l: net.Listener, config: tls.Config) {
    print("{label}")
    ask(l, config, label) catch {
        Invalid => print("  handshake refused: the certificate is not trusted for this name")
        e => print("  failed: {e}")
    }
}

fn run() ! io.Error {
    let roots = [x509.parse(x509.pem_certificates(root_pem())[0])?]
    let server = tls.Config {
        certificates: x509.pem_certificates(leaf_pem())
        key: x509.pem_private_key(leaf_key())?
        alpn: ["h2", "http/1.1"]
    }

    using l = net.listen("127.0.0.1", 0)?
    spawn accept_loop(l.handle, server)

    let trusting = tls.Config { server_name: "localhost", roots, alpn: ["http/1.1"] }
    attempt("tls 1.3", l, trusting)

    let older = tls.Config { server_name: "localhost", roots, max_version: tls.tls12 }
    attempt("tls 1.2", l, older)

    let unknown = tls.Config { server_name: "localhost" }
    attempt("system roots only", l, unknown)

    let misnamed = tls.Config { server_name: "www.example.test", roots }
    attempt("wrong name", l, misnamed)

    let unchecked = tls.Config { server_name: "www.example.test", verify: false }
    attempt("verification off", l, unchecked)
    net.close_listener(l)
}

/// Starts a TLS server on a loopback port with a certificate from a private root, then connects clients that trust the root, force TLS 1.2, rely on the system roots, check the wrong name or skip verification.
fn main() {
    run() catch {
        e => print("failed: {e}")
    }
}

quic_client

pub fn quic_client(t: QuicTransport, config: Config) -> QuicResult ! io.Error

Performs the client side of a QUIC TLS 1.3 handshake (RFC 9001) through t and returns the outcome.

Only TLS 1.3 is used, whatever config.min_version says, and only the TLS 1.3 suites of config.cipher_suites are offered. The ClientHello carries an empty legacy_session_id, the ALPN list config.alpn and t.parameters as extension 0x39. The server certificate is verified as client does. Handshake messages go out through t.send, come in through t.receive and the traffic secrets go to t.install: Handshake read, Handshake write, Application write and Application read, in that order. Returns after the client Finished has been sent and reads no post-handshake messages.

Fails with Invalid when config.max_version is below TLS 1.3, when t.parameters is longer than 16384 bytes, when config.alpn is empty, when no usable suite or group remains or when verification fails, with Unsupported when the server selects nothing the client offered or no application protocol, with TooLarge for a handshake message longer than 65536 bytes (alert 22) and with Malformed for other protocol violations: an EncryptedExtensions without transport parameters (alert 109) or with more than 16384 bytes of them (alert 47), handshake data received at a level other than the current one and bytes left in the handshake buffer when a key changes (alert 10), and messages that do not parse (alert 50). A fatal failure is reported once through t.alert. Errors of t.send, t.receive and t.install are returned unchanged.

quic_server

pub fn quic_server(t: QuicTransport, config: Config) -> QuicResult ! io.Error

Performs the server side of a QUIC TLS 1.3 handshake (RFC 9001) through t and returns the outcome.

Requires config.certificates and config.key. Only TLS 1.3 is used, whatever config.min_version says, and only the TLS 1.3 suites of config.cipher_suites are chosen. Suite, group and signature scheme are chosen as server does, with a HelloRetryRequest when the client sent no share for the chosen group. The first protocol in config.alpn that the client also offers is selected and t.parameters goes out as extension 0x39 of the EncryptedExtensions. Handshake messages go out through t.send, come in through t.receive and the traffic secrets go to t.install: Handshake write, Handshake read, then after the client Finished, Application write and Application read. Returns after the client Finished has been verified and reads no post-handshake messages.

Fails with Invalid for missing certificates or key, when config.max_version is below TLS 1.3 or when t.parameters is longer than 16384 bytes, with Unsupported when no version, suite, group, scheme or application protocol is shared (alert 120, no_application_protocol, for the last), with TooLarge for a handshake message longer than 65536 bytes (alert 22) and with Malformed for other protocol violations: a ClientHello with a non-empty legacy_session_id (alert 47), without transport parameters (alert 109) or with more than 16384 bytes of them (alert 47), handshake data received at a level other than the current one and bytes left in the handshake buffer when a key changes (alert 10), and messages that do not parse (alert 50). A fatal failure is reported once through t.alert. Errors of t.send, t.receive and t.install are returned unchanged.

Session

pub struct Session {The copyable view of this connection.    pub handle: *SessionHandle
}

An established TLS connection that closes itself when dropped.

Dropping it sends a close_notify alert and closes the underlying stream. handle is the copyable view used by read_on, write_on, close_on and stream_on.

close

pub fn close(t: Session)

Sends a close_notify alert and closes the underlying stream.

Closing an already closed session does nothing. The alert is best effort and its failure is ignored. Later reads and writes fail with NotConnected.

read

pub fn read(t: Session, buf: []u8) -> i64 ! io.Error

Reads up to buf.len decrypted bytes into buf and returns the count, or 0 when the peer has sent close_notify.

Blocks the green thread until application data arrives. Handshake messages that arrive in between are handled: a TLS 1.3 key update is applied, session tickets are ignored, and a TLS 1.2 renegotiation request is refused with a no_renegotiation alert. Fails with NotConnected after close, with Refused when the peer sends a fatal alert and with Malformed for an unexpected record.

stream

pub fn stream(t: Session) -> io.Stream

Returns an io.Stream over t whose read, write and close are read, write and close.

update_keys

pub fn update_keys(t: Session, request_peer: bool) ! io.Error

Rotates the sending keys with a TLS 1.3 KeyUpdate (RFC 8446 section 4.6.3).

With request_peer set, the peer is asked to rotate its sending keys too. Fails with Unsupported on a TLS 1.2 connection and with NotConnected after close.

write

pub fn write(t: Session, data: []u8) -> i64 ! io.Error

Encrypts and writes all of data and returns data.len.

Data is sent in records of at most 16384 bytes. Blocks the green thread until the bytes are handed to the underlying stream. Fails with NotConnected after close, with Aborted after a fatal error on the connection and otherwise with the stream's error.

pub const x25519_mlkem768 = 0x11EC

The TLS named group code 0x11EC, the X25519MLKEM768 hybrid of X25519 and ML-KEM-768.

The client share is the 1184-byte ML-KEM-768 encapsulation key followed by the 32-byte X25519 public key, and the server share is the 1088-byte ML-KEM ciphertext followed by the 32-byte X25519 public key. Functions

client

pub fn client(s: io.Stream, config: Config) -> Session ! io.Error

Performs a TLS client handshake over s and returns the established session.

Offers the versions, cipher suites and groups of config (TLS 1.3, RFC 8446, and TLS 1.2, RFC 5246 with ECDHE key exchange and AEAD suites) and blocks the green thread until the handshake completes. Unless config.verify is false, the server certificate chain is verified with x509.verify_chain against config.roots, or the system roots when that list is empty, for the host config.server_name. A certificate failure sends a bad_certificate alert and fails with Invalid. A client certificate is never sent; a certificate request is answered with an empty certificate list.

Fails with Invalid for an unusable config (a version range outside TLS 1.2 to 1.3, no usable cipher suite or group) or a failed verification, with Unsupported when the server selects nothing the client offered, with Malformed for protocol violations and with Eof, Refused or the stream's error when the connection ends. A failed handshake does not close s. When it succeeds, closing or dropping the Session also closes s.

client_handle

pub fn client_handle(s: io.Stream, config: Config) -> *SessionHandle ! io.Error

Performs a TLS client handshake over s and returns the copyable SessionHandle.

Behaves as client, but the result is not dropped automatically: the caller closes it with close_on. Use it to move a session between green threads.

dial

pub fn dial(host: str, port: i64, config: Config) -> Session ! io.Error

Connects to host and port over TCP and performs a TLS client handshake.

config.server_name defaults to host when empty, which sets both the SNI sent and the name the certificate is checked against. The TCP connection is closed if the handshake fails. Fails as client does for a failed handshake, and with the error of net.dial when the connection cannot be made. Blocks the green thread.

expand_label

pub fn expand_label(h: hash.Algorithm, secret: []u8, label: str, context: []u8, length: i64) -> []u8

Returns length bytes of HKDF-Expand-Label (RFC 8446 section 7.1) over secret with label, which gets the tls13 prefix, and context.

QUIC derives its packet protection keys with it (RFC 9001 section 5.1).

server

pub fn server(s: io.Stream, config: Config) -> Session ! io.Error

Performs a TLS server handshake over s and returns the established session.

Requires config.certificates and config.key. Accepts TLS 1.3 and TLS 1.2 within the version range of config. The cipher suite is the first in config.cipher_suites that the client also offers and that suits the key; the group is the first in config.groups the client supports, with a HelloRetryRequest when the client sent no share for it; the signature scheme must be one the client offers and the key allows (RSA keys sign with PSS in TLS 1.3). The first protocol in config.alpn that the client also offers is selected. Client certificates are not requested.

Blocks the green thread until the handshake completes. Fails with Invalid when the key or certificates are missing or the version range is unusable, with Unsupported when no version, suite, group or scheme is shared and with Malformed or Invalid for protocol violations. A failed handshake does not close s. When it succeeds, closing or dropping the Session also closes s.
