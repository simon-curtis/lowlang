std/tls

#crypto #net

import std/tls

TLS 1.2 and 1.3 clients and servers. client, server and dial return a droppable Session that sends close_notify and closes the stream beneath it when released. Its handle is the shared *SessionHandle holding protocol, version, group, suite, cipher_suite and peer_certificates. client_handle and server_handle return the view alone, and read_on, write_on, close_on and stream_on operate on it.

Imports std/crypto, std/crypto/aead, std/crypto/ecdsa, std/crypto/hash, std/crypto/mlkem, std/crypto/x25519, std/crypto/x509, std/io, std/net, std/time.

Types

Config

pub struct Config {
    /// The host name the client sends as the SNI (RFC 6066) and verifies the certificate against. An IP address is not sent as SNI. The empty string, the default, sends no name and, with `verify` on, accepts any certificate name.
    pub server_name: str
    /// The application protocols for ALPN (RFC 7301), such as `["h2", "http/1.1"]`. A client offers them and fails with `Malformed` when the server selects one not listed. A server selects the first of its own that the client offers, or none. Empty by default.
    pub alpn: []str
    /// The trust anchors a client verifies the server chain against. When empty, the default, the system roots from `x509.system_roots` are used.
    pub roots: []x509.Certificate
    /// Whether a client verifies the server certificate chain and name. Defaults to `true`; `false` accepts any certificate and removes the protection against an active attacker.
    pub verify: bool
    /// The named group codes for key exchange in order of preference, from `x25519_mlkem768`, `group_x25519`, `group_p256` and `group_p384`. The default is all four in that order. A client sends a key share for the first one, and also for X25519 when the first is the hybrid.
    pub groups: []i64
    /// The cipher suite codes in order of preference. The default is `0x1301`, `0x1303` and `0x1302` for TLS 1.3 and for TLS 1.2 the ECDHE suites with AES-128-GCM, ChaCha20-Poly1305 and AES-256-GCM, for ECDSA (`0xC02B`, `0xCCA9`, `0xC02C`) and RSA (`0xC02F`, `0xCCA8`, `0xC030`) certificates.
    pub cipher_suites: []i64
    /// The lowest protocol version accepted, as `tls12()` or `tls13()`. Defaults to TLS 1.2. A range outside TLS 1.2 to 1.3 makes the handshake fail with `Invalid`.
    pub min_version: i64
    /// The highest protocol version accepted, as `tls12()` or `tls13()`. Defaults to TLS 1.3.
    pub max_version: i64
    /// For a server, the DER encoded certificate chain it presents, leaf first; see `load_certificates`. Unused by a client.
    pub certificates: [][]u8
    /// For a server, the private key of the leaf certificate; see `load_key`. Unused by a client.
    pub key: x509.PrivateKey?
}

The settings of a TLS client or server, shared by client, server and dial.

The defaults give a verifying client for TLS 1.2 and 1.3. A server also needs certificates and key.

Session

pub struct Session {
    /// The copyable view of this connection.
    pub handle: *SessionHandle
}

An established TLS connection that closes itself when dropped.

Dropping it sends a close_notify alert and closes the underlying stream. handle is the copyable view used by read_on, write_on, close_on and stream_on.

close

pub fn close(t: Session)

Sends a close_notify alert and closes the underlying stream.

Closing an already closed session does nothing. The alert is best effort and its failure is ignored. Later reads and writes fail with NotConnected.

read

pub fn read(t: Session, buf: []u8) -> i64 ! io.Error

Reads up to buf.len decrypted bytes into buf and returns the count, or 0 when the peer has sent close_notify.

Blocks the green thread until application data arrives. Handshake messages that arrive in between are handled: a TLS 1.3 key update is applied, session tickets are ignored, and a TLS 1.2 renegotiation request is refused with a no_renegotiation alert. Fails with NotConnected after close, with Refused when the peer sends a fatal alert and with Malformed for an unexpected record.

stream

pub fn stream(t: Session) -> io.Stream

Returns an io.Stream over t whose read, write and close are read, write and close.

update_keys

pub fn update_keys(t: Session, request_peer: bool) ! io.Error

Rotates the sending keys with a TLS 1.3 KeyUpdate (RFC 8446 section 4.6.3).

With request_peer set, the peer is asked to rotate its sending keys too. Fails with Unsupported on a TLS 1.2 connection and with NotConnected after close.

write

pub fn write(t: Session, data: []u8) -> i64 ! io.Error

Encrypts and writes all of data and returns data.len.

Data is sent in records of at most 16384 bytes. Blocks the green thread until the bytes are handed to the underlying stream. Fails with NotConnected after close, with Aborted after a fatal error on the connection and otherwise with the stream's error.

A copyable view of an established TLS connection.

Copies refer to the same connection. Closing through any copy closes it for all of them.

close_on

Sends a close_notify alert and closes the underlying stream through the view t. See close.

read_on

Returns an io.Stream over the view t.

Streams made from the same view share the connection, and closing one closes it for all.

Suite

pub enum Suite {
    /// AES-128-GCM with a 16-byte key, `TLS_AES_128_GCM_SHA256` in TLS 1.3.
    Aes128Gcm
    /// AES-256-GCM with a 32-byte key, `TLS_AES_256_GCM_SHA384` in TLS 1.3.
    Aes256Gcm
    /// ChaCha20-Poly1305 (RFC 8439) with a 32-byte key, `TLS_CHACHA20_POLY1305_SHA256` in TLS 1.3.
    ChaCha20Poly1305
}

The authenticated cipher of a negotiated cipher suite.

The TLS 1.3 key schedule uses SHA-384 with Aes256Gcm and SHA-256 with the others. The TLS 1.2 suites map onto the same values by their cipher.

suite_code

pub fn suite_code(s: Suite) -> i64

Returns the TLS 1.3 cipher suite code of s: 0x1301, 0x1302 or 0x1303 for Aes128Gcm, Aes256Gcm and ChaCha20Poly1305.

Functions

client

pub fn client(s: io.Stream, config: Config) -> Session ! io.Error

Performs a TLS client handshake over s and returns the established session.

Offers the versions, cipher suites and groups of config (TLS 1.3, RFC 8446, and TLS 1.2, RFC 5246 with ECDHE key exchange and AEAD suites) and blocks the green thread until the handshake completes. Unless config.verify is false, the server certificate chain is verified with x509.verify_chain against config.roots, or the system roots when that list is empty, for the host config.server_name. A certificate failure sends a bad_certificate alert and fails with Invalid. A client certificate is never sent; a certificate request is answered with an empty certificate list.

Fails with Invalid for an unusable config (a version range outside TLS 1.2 to 1.3, no usable cipher suite or group) or a failed verification, with Unsupported when the server selects nothing the client offered, with Malformed for protocol violations and with Eof, Refused or the stream's error when the connection ends. A failed handshake does not close s. When it succeeds, closing or dropping the Session also closes s.

client_handle

pub fn client_handle(s: io.Stream, config: Config) -> *SessionHandle ! io.Error

Performs a TLS client handshake over s and returns the copyable SessionHandle.

Behaves as client, but the result is not dropped automatically: the caller closes it with close_on. Use it to move a session between green threads.

dial

pub fn dial(host: str, port: i64, config: Config) -> Session ! io.Error

Connects to host and port over TCP and performs a TLS client handshake.

config.server_name defaults to host when empty, which sets both the SNI sent and the name the certificate is checked against. The TCP connection is closed if the handshake fails. Fails with Unsupported, Malformed, Eof or Refused as client does, with Invalid for any other handshake failure including certificate verification, and with the error of net.dial when the connection cannot be made. Blocks the green thread.

load_certificates

pub fn load_certificates(pem: str) -> [][]u8

Returns the DER encodings of every CERTIFICATE block in pem, in order, for Config.certificates.

The leaf certificate must come first, followed by its intermediates. Blocks that are not valid Base64 are skipped.

load_key

pub fn load_key(pem: str) -> x509.PrivateKey ! io.Error

Returns the private key in the first PEM block of pem labelled PRIVATE KEY, EC PRIVATE KEY or RSA PRIVATE KEY, tried in that order.

The block is parsed with x509.parse_private_key, so PKCS#8, SEC 1 and PKCS#1 are accepted whatever the label. Fails with Invalid when pem has none of these blocks and with the parse error otherwise.

server

pub fn server(s: io.Stream, config: Config) -> Session ! io.Error

Performs a TLS server handshake over s and returns the established session.

Requires config.certificates and config.key. Accepts TLS 1.3 and TLS 1.2 within the version range of config. The cipher suite is the first in config.cipher_suites that the client also offers and that suits the key; the group is the first in config.groups the client supports, with a HelloRetryRequest when the client sent no share for it; the signature scheme must be one the client offers and the key allows (RSA keys sign with PSS in TLS 1.3). The first protocol in config.alpn that the client also offers is selected. Client certificates are not requested.

Blocks the green thread until the handshake completes. Fails with Invalid when the key or certificates are missing or the version range is unusable, with Unsupported when no version, suite, group or scheme is shared and with Malformed or Invalid for protocol violations. A failed handshake does not close s. When it succeeds, closing or dropping the Session also closes s.

server_handle

pub fn server_handle(s: io.Stream, config: Config) -> *SessionHandle ! io.Error

Performs a TLS server handshake over s and returns the copyable SessionHandle.

Behaves as server, but the result is not dropped automatically: the caller closes it with close_on. Use it to hand a session to a green thread.

x25519_mlkem768

pub fn x25519_mlkem768() -> i64

Returns the TLS named group code 0x11EC, the X25519MLKEM768 hybrid of X25519 and ML-KEM-768.

The client share is the 1184-byte ML-KEM-768 encapsulation key followed by the 32-byte X25519 public key, and the server share is the 1088-byte ML-KEM ciphertext followed by the 32-byte X25519 public key. The shared secret is the 32-byte ML-KEM secret followed by the 32-byte X25519 secret. It is offered with TLS 1.3 only.
