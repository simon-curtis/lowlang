std/container/lru

#data

import std/container/lru

A least-recently-used Cache[K, V] of fixed capacity: get (refreshes the entry), put (returns the evicted key), contains, size and keys from most to least recent. All run in constant time over index-linked entries.

Imports std/maps.

Examples

lookup_cache

import std/container/lru

struct Lookups {
    cache: lru.Cache[str, str]
    hits: i64
    misses: i64
}

fn resolve(host: str) -> str {
    "10.0.0.{host.len}"
}

fn lookup(mut l: Lookups, host: str) -> str {
    match l.cache.get(host) {
        some(address) => {
            l.hits += 1
            return address
        }
        none => {}
    }
    l.misses += 1
    let address = resolve(host)
    let evicted = l.cache.put(host, address)
    if evicted != none {
        print("evicted {evicted ?? ""}")
    }
    address
}

/// Keeps the three most recently used host lookups and reports which entry each new host pushes out.
fn main() {
    var l = Lookups { cache: lru.cache[str, str](3), hits: 0, misses: 0 }
    for host in ["db", "cache", "queue", "db", "search", "cache", "db"] {
        let address = lookup(mut l, host)
        print("{host} = {address}")
    }
    print("hits {l.hits}, misses {l.misses}, entries {l.cache.size()}")
    print("most recent first: {l.cache.keys()}")
    print("queue cached: {l.cache.contains("queue")}, db cached: {l.cache.contains("db")}")
}

Types

Cache

pub struct Cache[K: Hash, V] {
    ...
}

A least-recently-used cache with a fixed capacity.

Create one with cache. When a new key is added to a full cache the least recently used entry is evicted. get and put count as a use; contains and keys do not. Lookup, insertion and eviction take constant time on average. Mutating functions take the cache as mut.

contains

pub fn contains[K: Hash, V](c: Cache[K, V], key: K) -> bool

Returns true when key is in c.

Does not change the order of use.

get

pub fn get[K: Hash, V](mut c: Cache[K, V], key: K) -> V?

Returns the value stored under key, or none when it is absent.

Makes the entry the most recently used.

keys

pub fn keys[K: Hash, V](c: Cache[K, V]) -> []K

Returns the keys of c from the most recently used to the least recently used.

Does not change the order of use.

put

pub fn put[K: Hash, V](mut c: Cache[K, V], key: K, value: V) -> K?

Stores value under key and makes the entry the most recently used.

Returns none when key was already present, in which case its value is replaced, or when the cache had room. Returns the evicted key when a full cache dropped its least recently used entry to make room.

size

pub fn size[K: Hash, V](c: Cache[K, V]) -> i64

Returns the number of entries in c.

Functions

cache

pub fn cache[K: Hash, V](capacity: i64) -> Cache[K, V]

Returns an empty cache that holds at most capacity entries.

Panics when capacity is less than 1.
