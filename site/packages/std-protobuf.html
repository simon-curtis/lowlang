#formats

import std/protobuf

The protobuf wire format: an encoder with nested messages and packed fields, and a field decoder.

Imports std/io.

    ...

A cursor over an encoded message that yields its fields in order.

Made by decoder or as_message; next advances it.

done

pub fn done(d: *Decoder) -> bool

Returns whether the decoder has consumed all of its input.

next

pub fn next(d: *Decoder) -> Field? ! io.Error

Reads the next field of the message, or returns none at the end of the input.

Fails with Malformed when a field is truncated, the field number is 0 or above 536870911, a length runs past the end of the input or the wire type is 6 or 7, and with Unsupported for the group wire types 3 and 4. When it fails the decoder does not advance. Unknown fields are returned like known ones, so a caller skips one by ignoring it.

Encoder

pub struct Encoder {
    ...
}

A growable buffer that fields are appended to in the protobuf wire format.

Made by encoder or encoder_with. The buffer grows as needed. encoded returns the bytes written so far.

begin_message

pub fn begin_message(e: *Encoder, field: i64) -> i64

Starts an embedded message in field field and returns a mark to pass to end_message.

The tag is written now and the message's fields follow, written with the other write_ functions. The length prefix is inserted by end_message, which moves the message's bytes. Messages can nest.

encoded

pub fn encoded(e: *Encoder) -> []u8

Returns the bytes written so far.

The slice views the encoder's own buffer, so a later write or reset can change it. Copy it to keep it past the next write.

end_message

pub fn end_message(e: *Encoder, mark: i64)

Ends the embedded message that begin_message started, which returned mark.

It inserts the varint length of everything written since the mark.

Field

pub struct Field {The field number, from 1 to 536870911.    pub number: i64The wire type the field was encoded with.    pub wire: WireThe raw value for Varint, Fixed64 and Fixed32 fields, as unsigned bits with no sign extension, and the payload length in bytes for a Bytes field.    pub value: u64The payload of a Bytes field, as a slice of the decoded input; empty for the other wire types.    pub data: []u8
}

One field read from an encoded message by Decoder.next: its number, wire type and raw value.

The as_ functions interpret it as a protobuf type, and the unpack_ functions read repeated fields.

unpack_doubles

pub fn unpack_doubles(f: Field) -> []f64 ! io.Error

Returns the values of a repeated double field.

Accepts a single Fixed64 field, which gives one value, or a packed Bytes field, which gives every eight-byte value in it. Fails with Malformed for another wire type or a packed length that is not a multiple of eight.

unpack_fixed32

pub fn unpack_fixed32(f: Field) -> []u32 ! io.Error

Returns the values of a repeated fixed32 or sfixed32 field, as unsigned bits.

Accepts a single Fixed32 field, which gives one value, or a packed Bytes field, which gives every four-byte value in it. Fails with Malformed for another wire type or a packed length that is not a multiple of four.

unpack_fixed64

pub fn unpack_fixed64(f: Field) -> []u64 ! io.Error

Returns the values of a repeated fixed64 or sfixed64 field, as unsigned bits.

Accepts a single Fixed64 field, which gives one value, or a packed Bytes field, which gives every eight-byte value in it. Fails with Malformed for another wire type or a packed length that is not a multiple of eight.

unpack_varints

pub fn unpack_varints(f: Field) -> []u64 ! io.Error

Returns the values of a repeated varint field.

Accepts both encodings of a repeated field: a single Varint field gives one value, and a packed Bytes field gives every varint in it. Call it once per occurrence and concatenate the results. Fails with Malformed for another wire type or a truncated varint.

Wire

pub enum Wire {Wire type 0: a base-128 varint of one to ten bytes. Used by int32, int64, uint32, uint64, sint32, sint64, bool and enums.    VarintWire type 1: eight little-endian bytes. Used by fixed64, sfixed64 and double.    Fixed64Wire type 2: a varint length followed by that many bytes. Used by string, bytes, embedded messages and packed repeated fields.    BytesWire type 5: four little-endian bytes. Used by fixed32, sfixed32 and float.    Fixed32
}

A protobuf wire type, which says how the value of a field is laid out.

Groups (wire types 3 and 4) are not supported.

read_varint

pub fn read_varint(data: []u8, mut at: i64) -> u64 ! io.Error

Reads the varint that starts at data[at] and advances at past it.

Fails with Malformed when the input ends inside the varint or the value does not fit in 64 bits. Varints longer than necessary are accepted, up to ten bytes. When it fails, at may already have advanced.

pub fn zigzag(v: i64) -> u64

Returns the ZigZag encoding of v, which maps small magnitudes of either sign to small unsigned numbers: 0, -1, 1 and -2 become 0, 1, 2 and 3.

This is the encoding of sint32 and sint64.
