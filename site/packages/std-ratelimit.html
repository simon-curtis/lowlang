std/ratelimit

#concurrency

import std/ratelimit

Bucket (token bucket in exact nanosecond units) with allow, allow_n, reserve, wait and set_rate. Window, a sliding log. Keyed, a bounded per-key set of buckets with idle eviction. All take a clock.Clock.

Imports std/cancel, std/sync, std/time/clock, std/time/duration.

Examples

gateway

import std/ratelimit
import std/time/clock
import std/time/duration
import std/time/timestamp

fn describe(wait: duration.Duration?) -> str {
    match wait {
        some(d) => duration.to_string(d)
        none => "never"
    }
}

/// Limits an API with a token bucket, a per-client limiter and a sliding window, all driven by a manual clock.
fn main() {
    let time = clock.manual(timestamp.epoch())

    let bucket = ratelimit.bucket(5, 10, time.clock())
    var admitted = 0
    for i in 0..14 {
        if bucket.allow() {
            admitted += 1
        }
    }
    print("burst of 14 requests: {admitted} admitted, {bucket.available()} tokens left")
    print("a 15th request would wait {describe(bucket.delay(1))}")
    time.advance(duration.seconds(1))
    print("after 1 s: {bucket.available()} tokens, a batch of 6 allowed: {bucket.allow_n(6)}, a batch of 5 allowed: {bucket.allow_n(5)}")
    let debt = bucket.reserve(3)
    print("reserved 3 tokens in debt, use them after {describe(debt)}")
    bucket.refund(3)
    print("refunded, available {bucket.available()}")

    let clients = ratelimit.keyed[str](1, 2, 2, duration.seconds(60), time.clock())
    for client in ["alice", "alice", "alice", "bob", "carol"] {
        print("{client}: {clients.allow_key(client)}, tracking {clients.tracked()} clients")
    }
    time.advance(duration.seconds(90))
    clients.sweep()
    print("after 90 idle seconds tracking {clients.tracked()} clients")

    let window = ratelimit.window(3, duration.seconds(10), time.clock())
    for second in 0..6 {
        let ok = window.admit()
        print("t={second * 2}s admit {ok}, in window {window.in_window()}, retry in {duration.to_string(window.retry_in())}")
        time.advance(duration.seconds(2))
    }
}

Types

Bucket

pub struct Bucket {
    ...
}

A token bucket that refills continuously and holds at most burst tokens. Accounting is in exact nanosecond units, so fractional tokens accrue without drift. A new bucket starts full.

A Bucket is a handle: copies share one state, and every operation is safe to call from several green threads.

allow

pub fn allow(b: Bucket) -> bool

Takes one token if available and returns true, or returns false without blocking.

allow_n

pub fn allow_n(b: Bucket, n: i64) -> bool

Takes n tokens if they are available now and returns true, or takes nothing and returns false.

Never blocks. Returns false when n is negative or larger than the burst, or when fewer than n tokens have accrued. n of 0 returns true unless the bucket is in debt from reserve.

available

pub fn available(b: Bucket) -> i64

Returns the number of whole tokens available now.

Returns 0 while the bucket is in debt.

burst

pub fn burst(b: Bucket) -> i64

Returns the bucket's capacity in tokens.

delay

pub fn delay(b: Bucket, n: i64) -> duration.Duration?

Returns how long until n tokens are available, without taking any.

Returns a zero duration when they are available now and none when n is negative or larger than the burst.

refund

pub fn refund(b: Bucket, n: i64)

Gives back n tokens, for a reservation that went unused.

The count is capped at the burst and the balance at a full bucket. A count of zero or less does nothing.

reserve

pub fn reserve(b: Bucket, n: i64) -> duration.Duration?

Takes n tokens unconditionally and returns how long the caller must wait before using them.

The returned delay is zero when the tokens were available. Otherwise the bucket goes into debt and later requests queue behind this one. Returns none and takes nothing when n is negative or larger than the burst, or when the debt would grow beyond the bucket's internal limit. Never blocks; pass an unwanted reservation back with refund.

set_burst

pub fn set_burst(b: Bucket, burst: i64)

Changes the bucket's capacity to burst tokens.

A balance above the new capacity is cut down to it; a larger capacity does not add tokens. Panics if burst is not positive or if burst times the refill interval overflows the bucket's internal limit.

set_rate

pub fn set_rate(b: Bucket, rate_per_second: i64)

Changes the refill rate to rate_per_second tokens each second.

Panics under the same conditions as set_rate_per.

set_rate_per

pub fn set_rate_per(b: Bucket, tokens: i64, per: duration.Duration)

Changes the refill rate to tokens tokens every per.

Tokens already accrued are kept, valued in whole tokens when the interval changes. Panics if tokens or per is not positive or if the burst times per overflows the bucket's internal limit.

wait

pub fn wait(b: Bucket, t: *cancel.Token) ! Error

Reserves one token and waits until it is available.

Fails with Cancelled if t is cancelled before or during the wait.

wait_n

pub fn wait_n(b: Bucket, n: i64, t: *cancel.Token) ! Error

Reserves n tokens and waits until they are available.

Blocks the calling green thread for the reserved delay. Fails with Cancelled if t is already cancelled or is cancelled during the wait, in which case the reservation is refunded. Fails with TooLarge if n is negative, exceeds the burst or the debt limit.

Error

}

The error returned by the waiting operations of Bucket and Keyed, and by admit_wait on a Window.

Keyed

pub struct Keyed[K: Hash] {
    ...
}

A set of per-key Buckets that share one rate and burst, bounded in size.

At most capacity keys are tracked. Looking up a new key at capacity evicts the least recently used one, and keys idle for the idle duration are dropped on the next lookup or sweep. An evicted key starts again with a full bucket. A Keyed is a handle: copies share one state, and every operation is safe to call from several green threads.

allow_key

pub fn allow_key[K: Hash](k: Keyed[K], key: K) -> bool

Takes one token from the bucket for key if available and returns true, or returns false without blocking.

allow_key_n

pub fn allow_key_n[K: Hash](k: Keyed[K], key: K, n: i64) -> bool

Takes n tokens from the bucket for key if available and returns true, or returns false without blocking.

See allow_n for the edge cases.

bucket_for

pub fn bucket_for[K: Hash](k: Keyed[K], key: K) -> Bucket

Returns the bucket for key, creating it full if the key is not tracked.

Marks the key as most recently used and evicts idle keys, and the least recently used key if a new key would exceed the capacity. The returned bucket stays usable after eviction but is no longer tracked.

forget_key

pub fn forget_key[K: Hash](k: Keyed[K], key: K)

Stops tracking key, so its next use starts with a full bucket.

Does nothing if the key is not tracked.

reserve_key

pub fn reserve_key[K: Hash](k: Keyed[K], key: K, n: i64) -> duration.Duration?

Reserves n tokens from the bucket for key and returns the delay before they may be used.

Returns none under the conditions listed on reserve.

sweep

pub fn sweep[K: Hash](k: Keyed[K])

Evicts every key that has been idle for the idle duration.

Eviction otherwise happens only on lookup, so call this to release memory while the limiter is unused. Does nothing when idle eviction is disabled.

tracked

pub fn tracked[K: Hash](k: Keyed[K]) -> i64

Returns the number of keys currently tracked, including idle keys not yet evicted.

wait_key

pub fn wait_key[K: Hash](k: Keyed[K], key: K, t: *cancel.Token) ! Error

Reserves one token from the bucket for key and waits until it is available.

Blocks the calling green thread. Fails with Cancelled if t is cancelled before or during the wait.

Window

pub struct Window {
    ...
}

A sliding-window limiter that admits at most limit events in any interval of per.

It records the time of each admitted event and forgets one once per has passed, so unlike Bucket it allows no bursts across window edges. A Window is a handle: copies share one state, and every operation is safe to call from several green threads.

admit

pub fn admit(w: Window) -> bool

Records an event and returns true if fewer than limit events fall in the last per, or returns false without recording it.

Never blocks.

admit_wait

pub fn admit_wait(w: Window, t: *cancel.Token) ! Error

Waits until an event is admitted and records it.

Blocks the calling green thread, pausing for retry_in between attempts. Fails with Cancelled if t is cancelled before an attempt or during a pause.

in_window

pub fn in_window(w: Window) -> i64

Returns the number of admitted events still inside the window.

retry_in

pub fn retry_in(w: Window) -> duration.Duration

Returns how long until admit would succeed.

Returns a zero duration when the window has room now.

Functions

bucket

pub fn bucket(rate_per_second: i64, burst: i64, c: clock.Clock) -> Bucket

Returns a bucket that refills rate_per_second tokens each second and holds at most burst, reading time from c.

The bucket starts full. Panics under the same conditions as bucket_per.

bucket_per

pub fn bucket_per(tokens: i64, per: duration.Duration, burst: i64, c: clock.Clock) -> Bucket

Returns a bucket that refills tokens tokens every per and holds at most burst, reading time from c.

The bucket starts full. Panics if tokens, per (in nanoseconds) or burst is not positive, or if burst times per overflows the bucket's internal limit.

keyed

pub fn keyed[K: Hash](rate_per_second: i64, burst: i64, capacity: i64, idle: duration.Duration, c: clock.Clock) -> Keyed[K]

Returns a keyed limiter whose buckets refill rate_per_second tokens each second and hold burst, tracking at most capacity keys.

A key unused for idle is evicted; an idle of zero or less disables idle eviction. Time comes from c. Panics if capacity is less than 1 or if rate_per_second or burst is not positive or does not fit.

window

pub fn window(limit: i64, per: duration.Duration, c: clock.Clock) -> Window

Returns a window that admits limit events per per, reading time from c.

Panics if limit or per is not positive.
