Functions

decode

pub fn decode(units: []u16) -> str ! Error

Decodes UTF-16 code units into a string. Fails with LoneSurrogate at the index of the first surrogate that has no partner.

decode_bytes

pub fn decode_bytes(data: []u8, order: unicode.Order) -> str ! Error

Decodes UTF-16 bytes into a string. A leading byte order mark is removed, and it selects its own byte order over order: FF FE for little-endian and FE FF for big-endian. Without one, order applies. Fails with OddLength when the bytes after the mark are an odd number and with LoneSurrogate when a surrogate has no partner.

decode_bytes_lossy

pub fn decode_bytes_lossy(data: []u8, order: unicode.Order) -> str

Decodes UTF-16 bytes into a string, replacing invalid input with U+FFFD. The byte order mark is handled as in decode_bytes. Each lone surrogate and a trailing odd byte become one U+FFFD.

decode_escape

pub fn decode_escape(s: str, at: i64) -> Escape ! text.ParseError

Decodes the \uXXXX escape whose four hexadecimal digits start at index at of s, just after its \u. A high surrogate followed by a \uXXXX low surrogate is joined into one code point. The result reports a lone surrogate and leaves the policy to the caller.

Fails with BadDigit at the index of the first byte of the first escape that is not a hexadecimal digit, or at s.len when it runs past the end.

decode_lossy

pub fn decode_lossy(units: []u16) -> str

Decodes UTF-16 code units into a string, replacing each lone surrogate with U+FFFD.

decode_rune

pub fn decode_rune(units: []u16, at: i64) -> Unit

Decodes the code point that starts at index at of units. A surrogate pair gives a supplementary code point with size 2. A surrogate with no partner gives 0xFFFD with size 1, and an index outside units gives 0xFFFD with size 0.

encode

pub fn encode(s: str) -> []u16

Returns the UTF-16 code units of s. Each byte of s that is not valid UTF-8 becomes 0xFFFD.

encode_bytes

pub fn encode_bytes(s: str, order: unicode.Order, bom: bool) -> []u8

Returns s encoded as UTF-16 bytes in the given byte order, preceded by a byte order mark when bom is true. Each byte of s that is not valid UTF-8 becomes U+FFFD.

encode_rune

pub fn encode_rune(mut out: []u16, c: u32)

Appends the UTF-16 encoding of the code point c to out. A supplementary code point becomes a surrogate pair. A surrogate or a value above 0x10FFFF is written as 0xFFFD.

from_bytes

pub fn from_bytes(data: []u8, order: unicode.Order) -> []u16 ! Error

Reads UTF-16 code units from data in the given byte order. A byte order mark is not interpreted. Fails with OddLength when data.len is odd.

is_high_surrogate

pub fn is_high_surrogate(u: u16) -> bool

Returns whether u is a high (leading) surrogate, in 0xD800 to 0xDBFF.

is_low_surrogate

pub fn is_low_surrogate(u: u16) -> bool

Returns whether u is a low (trailing) surrogate, in 0xDC00 to 0xDFFF.

is_surrogate

pub fn is_surrogate(u: u16) -> bool

Returns whether u is a surrogate code unit, in 0xD800 to 0xDFFF.

join

pub fn join(high: u16, low: u16) -> u32

Returns the code point that the surrogate pair high and low encodes. high must be a high surrogate and low a low surrogate; other values give a meaningless result.

to_bytes

pub fn to_bytes(units: []u16, order: unicode.Order) -> []u8

Returns the bytes of units in the given byte order, two bytes per unit and without a byte order mark.

units

pub fn units(data: []u8, order: unicode.Order) -> []u16

Reads UTF-16 code units from data in the given byte order, ignoring a trailing odd byte. A byte order mark is not interpreted.
