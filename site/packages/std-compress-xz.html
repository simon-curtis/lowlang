xz with LZMA2, and .lzma.

Types

Encoder

pub struct Encoder {
    ...
}

A streaming xz encoder made by encoder.

encode takes input in any chunking and finish writes the end of the stream. The file holds at most one block of LZMA2 chunks with a CRC-64 integrity check. After finish, encode and finish fail with Invalid. A chunk is valid only during the call to sink.

encode

pub fn encode(e: *Encoder, data: []u8) ! io.Error

Compresses data and passes the compressed bytes that are ready to the encoder's sink.

Input is buffered, so a call can produce no output. Fails with Invalid after finish, and with any error sink returns.

finish

pub fn finish(e: *Encoder) ! io.Error

Writes the buffered input, the block padding and check, the index and the stream footer.

Fails with Invalid when the stream is already finished, and with any error sink returns.

compress

pub fn compress(data: []u8, level: i64) -> []u8

Returns data compressed as an xz file.

level is clamped to 0..9; the dictionary is reduced for inputs smaller than it.

decode

pub fn decode(r: *io.Reader, sink: fn([]u8) ! io.Error, limit: i64) ! io.Error

Decodes an xz file from r and passes the decoded bytes to sink in chunks until the input ends.

Concatenated streams are decoded in turn, with zero padding in multiples of four bytes allowed between them. The CRC-32 of each header and the index and the integrity check of each block (none, CRC-32, CRC-64 or SHA-256) are verified. Filters other than LZMA2 and delta, and other check types, are Unsupported. Fails with TooLarge when the output would exceed limit bytes, Malformed when the input is invalid or truncated, and with any error r or sink returns. A chunk is valid only during the call to sink.

decompress

pub fn decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from an xz file in data.

Streams are handled as in decode. Fails with TooLarge when the output would exceed limit bytes and with Malformed when the input is invalid or truncated.

encoder

pub fn encoder(level: i64, sink: fn([]u8) ! io.Error) -> *Encoder

Returns an encoder that writes an xz file to sink.

level is clamped to 0..9 and selects the dictionary size, from 256 KiB at 0 to 64 MiB at 9, and the match search effort.

lzma_compress

pub fn lzma_compress(data: []u8, level: i64) -> []u8

Returns data compressed in the .lzma format: a 13 byte header of properties, dictionary size and uncompressed size, then an LZMA stream.

level is clamped to 0..9. The header records the size of data.

lzma_decompress

pub fn lzma_decompress(data: []u8, limit: i64) -> []u8 ! io.Error

Returns the bytes decoded from data in the .lzma format: a 13 byte header of properties, dictionary size and uncompressed size, then an LZMA stream.

The uncompressed size can be unknown, in which case the stream ends with an end marker. Fails with TooLarge when the declared size or the output exceeds limit and with Malformed when the header is invalid or the data does not decode to the declared size.
