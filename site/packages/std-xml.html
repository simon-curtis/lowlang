std/xml

#formats

import std/xml

XML 1.0 with namespaces: a pull reader, a tree, a writer, and serde binding.

Imports std/base64, std/bits, std/charset, std/math, std/serde, std/simd, std/text, std/unicode.

An attribute of a start tag.

Namespace declarations (xmlns and xmlns:prefix) are returned as attributes too, in the namespace http://www.w3.org/2000/xmlns/.

An element of a parsed document.

Made by parse. Every string is an owned copy, independent of the input.

attribute

pub fn attribute(e: *Element, local: str) -> str?

Returns the value of the first attribute of e whose local name is local, or none when there is none.

The namespace is ignored, and namespace declarations are not attributes here.

child

pub fn child(e: *Element, local: str) -> *Element?

Returns the first child element of e whose local name is local, or none when there is none.

The namespace is ignored.

children

pub fn children(e: *Element, local: str) -> []*Element

Returns every child element of e whose local name is local, in document order.

The name * matches every child element. The namespace is ignored.

find

pub fn find(e: *Element, path: str) -> *Element?

Returns the element at path below e, or none when a step finds nothing.

path is steps separated by /, for example a/b. Each step selects the first child element with that local name, and * selects the first child element of any name. Empty steps are skipped, so an empty path returns e itself.

serialize

pub fn serialize(e: *Element, indent: bool) -> str

Returns e and its descendants as XML text.

indent selects indented output as writer does. Names are written as qualified gives them, and attributes, text, CDATA, comments and instructions are written as the write_ functions do. The namespace declarations kept in e.attributes are written as attributes. No declaration is written.

text

pub fn text(e: *Element) -> str

Returns the text of e: the Text and CData content of e and of all its descendant elements, in document order.

Comments and processing instructions are left out. An element whose only child is a text or CDATA node returns it without copying.

Reader

pub struct Reader {
    ...
}

A pull parser over one XML document, made by reader.

It follows XML 1.0 (fifth edition) with Namespaces in XML 1.0, enforces well-formedness and the namespace constraints, and parses the internal DTD subset. General entities declared there expand, including markup, with recursion detection; external entities are never fetched and parameter entities are not expanded. Names are resolved and interned per reader. next returns tokens and position says where the last one began.

next

pub fn next(r: *Reader) -> Token ! Error

Returns the next token of the document.

The XML declaration is read and checked first and is not returned. Comments, processing instructions and the document type declaration are returned in document order, including those before and after the root element. Returns End after the root element and everything following it. Fails with Malformed for anything that is not well-formed, including an unclosed element, a missing root element, content after the root element, mismatched tags, duplicate attributes and undeclared prefixes; with Limit when a limit is exceeded; and with Unsupported for an unsupported encoding.

position

pub fn position(r: *Reader) -> Position

Returns the line and column where the token that next returned last began.

Before the first token it is line 1, column 1.

One unit of an XML document, returned by next.

A Text token carries character data, and every other markup construct has a token of its own. The strings view the reader's input unless a reference or normalisation forced a copy, so copy a value to keep it after the input changes.

Writer

pub struct Writer {
    ...
}

A writer that builds an XML document in memory, made by writer.

Call start_element, write_attribute, write_text and the other write_ functions in document order and finish to take the text. Text and attribute values are escaped. An element with no content is written as <a/>. With indentation on, an element that contains only elements, comments and instructions has each child on its own line, indented two spaces per level, and an element with text or CDATA is written without added whitespace.

end_element

pub fn end_element(w: *Writer)

Closes the innermost open element, as </name>, or as /> when it has no content.

Does nothing when no element is open.

finish

pub fn finish(w: *Writer) -> str

Closes every element that is still open and returns the document text.

The returned string views the writer's buffer, so do not write to the writer afterwards.

start_element

pub fn start_element(w: *Writer, name: str)

Opens the element name, ending the previous start tag if it is still open.

name is written as given, so a prefix goes in it. It is not checked. Follow it with write_attribute and write_namespace calls, then the content, then end_element.

write_attribute

pub fn write_attribute(w: *Writer, name: str, value: str)

Writes the attribute name with value in the start tag that start_element just opened.

The value is escaped for an attribute: &, <, ", carriage return, newline and tab become references. Does nothing once the start tag has ended, that is after any content or a nested element is written.

write_cdata

pub fn write_cdata(w: *Writer, s: str)

Writes s as a CDATA section.

A ]]> inside s is split across two sections, so the output stays well-formed. Text inside an element turns off indentation for that element.

write_comment

pub fn write_comment(w: *Writer, s: str)

Writes a comment.

A -- inside s, and a - at its end, get a space inserted so the output stays well-formed.

write_declaration

pub fn write_declaration(w: *Writer)

Writes the declaration <?xml version="1.0" encoding="UTF-8"?>.

Call it before the root element.

write_instruction

pub fn write_instruction(w: *Writer, target: str, data: str)

Writes the processing instruction target with data.

When data is empty nothing follows the target. A ?> inside data gets a space inserted between the characters. target is not checked.

write_namespace

pub fn write_namespace(w: *Writer, prefix: str, uri: str)

Writes a namespace declaration in the open start tag: xmlns for an empty prefix and xmlns:prefix otherwise, with the value uri.

Does nothing once the start tag has ended.

write_text

pub fn write_text(w: *Writer, s: str)

Writes the text s as character data, escaping &, <, > and carriage return.

Text inside an element turns off indentation for that element.

Functions

deserialize

pub fn deserialize[T](data: []u8) -> T ! serde.Error

Decodes the XML document data into a T through std/serde.

The root element is the value. A struct, map or enum is read from the attributes and child elements of an element, matched to fields by local name, ignoring the namespace; attributes in the xmlns and xsi namespaces are skipped. A slice field is read from all child elements with the field's name, or from a whitespace separated attribute value; a root slice is read from the children of the root element. An element with xsi:nil of true or 1 reads as none, and a missing optional field is none. Scalars are read from the text of the element or attribute, trimmed. A boolean is true, false, 1 or 0; a float may be INF, -INF or NaN; a []u8 is base64. An enum variant is the element's text for a variant without fields and the first child element for one with fields, named by that element. Fails with serde.Error.Syntax, carrying the line, for malformed XML, with Mismatch and Range when a value does not fit its type, and with Missing and UnknownVariant as serde.read describes. In errors other than Syntax, at is 0.

parse

pub fn parse(data: []u8) -> *Element ! Error

Parses the XML document data into a tree and returns its root element.

Reads with reader, so the same encodings, entity handling and limits apply, and fails with the reader's Error. Comments and processing instructions outside the root element and the document type declaration are dropped.

reader

pub fn reader(data: []u8) -> *Reader

Returns a reader over the document data.

The input may be UTF-8, UTF-16 with a byte order mark, ISO-8859-1 or US-ASCII, as the byte order mark or the encoding of the XML declaration says; it is converted to UTF-8, and \r\n and lone \r become \n, before reading. An input in another encoding, a UTF-16 label without a byte order mark, or invalid UTF-16 makes the first call to next fail.

serialize_value

pub fn serialize_value[T](root: str, v: T) -> str

Returns v as an XML document with the root element root, written without indentation or declaration.

Every struct field, map entry and slice element becomes a child element named by the field, the key or item; scalars are written as element text, booleans as true and false, floats as NaN, INF or -INF when not finite, and []u8 as base64. A slice that is a field becomes repeated elements with the field's name, and a top-level slice becomes item elements inside the root. A none optional writes nothing. An enum variant without fields is its name as text, and a variant with fields is an element named by the variant that holds the fields. Nothing is written as an attribute. A value that writes no element gives <root/>.

writer

pub fn writer(indent: bool) -> *Writer

Returns an empty writer. When indent is true, element-only content is indented with two spaces per level and a newline starts each line after the first.
