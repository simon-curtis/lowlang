std/file/watch

#io #os

import std/file/watch

inotify. watch and watch_with take paths and Options (recursive, access) and return a droppable Watcher with a copyable WatcherHandle. On a watcher: add, remove, next, events and stop. next parks the green thread until an Event (watched, name, path, kind, dir, cookie) arrives. events is a chan[Event] fed by a forwarding green thread. Kind is Created, Modified, Deleted, MovedFrom, MovedTo, Attrib, Closed, ClosedUnmodified, Opened, Accessed, SelfDeleted, SelfMoved or Overflow.

Imports std/file, std/io, std/sys, std/text.

Watcher

pub struct Watcher {The copyable view of the watcher.    pub handle: WatcherHandle
    ...
}

Watches files and directories for changes through inotify.

Dropping a watcher stops it, unless detach was called.

add

pub fn add(w: Watcher, path: str) ! io.Error

Starts watching path.

With Options.recursive and a directory, every existing subdirectory is watched too. Fails with NotFound when path does not exist.

detach

pub fn detach(mut w: Watcher) -> WatcherHandle

Returns the handle of w and releases w, so that dropping w no longer stops the watcher.

The caller stops it with stop_on or by adopting the handle.

events

pub fn events(w: Watcher) -> chan[Event]

Returns a channel that receives the watcher's events.

A green thread forwards events into a channel with capacity 64. The channel closes when the watcher stops or reading fails. Competing with next or another channel for events splits them between the readers.

next

pub fn next(w: Watcher) -> Event ! io.Error

Returns the next event, waiting for one when none is queued.

The green thread parks while it waits. Events come in the order the kernel reports them. A change to a path that is no longer watched is dropped, and SelfDeleted and SelfMoved are reported only for paths given to add. Fails with NotConnected once the watcher is stopped.

remove

pub fn remove(w: Watcher, path: str) ! io.Error

Stops watching path and every watched path below it.

Fails with NotFound when path is not watched.

stop

pub fn stop(w: Watcher)

Stops the watcher.

A next call that is waiting fails with NotConnected, as do later calls, and a channel from events closes. Stopping twice does nothing.

A copyable view of a Watcher, made of its inotify descriptor and the state shared with the watcher.

Once the watcher is stopped, operations on the handle fail with NotConnected.
