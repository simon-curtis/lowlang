std/socks

#net

import std/socks

SOCKS5 (RFC 1928, with RFC 1929 username and password) and SOCKS4a clients: dial, dial4a, tunnel and tunnel4a over an existing connection, and dialer and dialer4a, which return a net.Dialer. The proxy resolves the target name.

Imports std/io, std/net, std/text.

Examples

through_proxy

import std/io
import std/net
import std/socks

fn read_exact(c: net.Conn, n: i64) -> []u8 ! io.Error {
    let out = io.buffer(n)
    var got = 0
    for got < n {
        let r = net.read(c, out[got..])?
        if r == 0 {
            fail Eof
        }
        got += r
    }
    out
}

fn handshake(c: net.Conn, requests: chan[str]) ! io.Error {
    let count = read_exact(c, 2)?
    read_exact(c, i64(count[1]))?
    net.write_all(c, [5, 2])?

    let head = read_exact(c, 2)?
    let user = read_exact(c, i64(head[1]))?
    let length = read_exact(c, 1)?
    read_exact(c, i64(length[0]))?
    net.write_all(c, [1, 0])?

    let request = read_exact(c, 5)?
    let host = str(read_exact(c, i64(request[4]))?)
    let port = io.be16(read_exact(c, 2)?, 0)
    requests <- "{str(user)} asks for {host}:{port}"
    if host == "blocked.test" {
        net.write_all(c, [5, 2, 0, 1, 0, 0, 0, 0, 0, 0])?
        return
    }
    net.write_all(c, [5, 0, 0, 1, 0, 0, 0, 0, 0, 0])?
    let buf = io.buffer(64)
    let n = net.read(c, buf)?
    net.write_all(c, bytes("echo: {str(buf[..n])}"))?
}

fn serve_proxy(l: net.ListenerHandle, requests: chan[str]) {
    for {
        let h = net.accept_handle(l) or return
        spawn fn() {
            using c = net.adopt(h)
            handshake(c, requests) or {}
        }()
    }
}

fn try_dial(proxy: net.Addr, host: str, auth: socks.Auth) -> str {
    using c = socks.dial(proxy, host, 443, auth) catch {
        Denied => return "proxy denied {host}"
        e => return "failed: {e}"
    }
    "tunnel to {host} open"
}

/// Opens tunnels to named hosts through a stub SOCKS5 proxy on loopback and reports what the proxy was asked.
fn main() ! io.Error {
    using l = net.listen("127.0.0.1", 0)?
    let requests = chan[str](4)
    spawn serve_proxy(l.handle, requests)

    let auth = socks.Auth { user: "ada", password: "secret" }
    using c = socks.dial(l.handle.addr, "app.internal", 8080, auth)?
    net.write_all(c, bytes("hello"))?
    let buf = io.buffer(64)
    let n = net.read(c, buf)?
    print(str(buf[..n]))
    print((<-requests) ?? "")

    print(try_dial(l.handle.addr, "blocked.test", auth))
    print((<-requests) ?? "")
    net.close_listener(l)
}

Output

echo: hello
ada asks for app.internal:8080
proxy denied blocked.test
ada asks for blocked.test:443

A username and password for a SOCKS5 proxy (RFC 1929).

Functions

dial

pub fn dial(proxy: net.Addr, host: str, port: i64, auth: Auth?) -> net.Conn ! io.Error

Connects to the SOCKS5 proxy at proxy and asks it to connect to host and port.

Returns the connection to the proxy, which then carries the traffic to the target. Parks the green thread while connecting and negotiating. The connection is closed if the proxy refuses. Fails as net.connect and tunnel do.

dial4a

pub fn dial4a(proxy: net.Addr, host: str, port: i64, user: str) -> net.Conn ! io.Error

Connects to the SOCKS4a proxy at proxy and asks it to connect to host and port, identifying the caller as user.

Returns the connection to the proxy, which then carries the traffic to the target. Parks the green thread while connecting and negotiating. The connection is closed if the proxy refuses. Fails as net.connect and tunnel4a do.

pub fn dial4a_handle(proxy: net.Addr, host: str, port: i64, user: str) -> net.ConnHandle ! io.Error

The caller owns the connection and must close it with net.close_on.

dialer

pub fn dialer(proxy: net.Addr, auth: Auth?) -> net.Dialer

Returns a net.Dialer that reaches every target through the SOCKS5 proxy at proxy using auth.

Each call of the dialer connects to the proxy and passes the host name to it unresolved, so the proxy resolves it.

tunnel4a_on

pub fn tunnel4a_on(h: net.ConnHandle, host: str, port: i64, user: str) ! io.Error

Asks the SOCKS4a proxy at the other end of the connection h to connect to host and port, identifying the caller as user, so that h then carries the traffic to the target.

host is an IPv4 literal or a name of up to 255 bytes that the proxy resolves. Parks the green thread during the exchange and is limited by the connection's timeouts. Fails with Invalid for a port outside 1 to 65535, with Unsupported for an IPv6 literal or an unusable host, with Refused if the proxy rejects the request, with Denied for any other failure reply and with Malformed for a reply that does not follow the protocol.

tunnel_on

pub fn tunnel_on(h: net.ConnHandle, host: str, port: i64, auth: Auth?) ! io.Error

Asks the SOCKS5 proxy at the other end of the connection h to connect to host and port, so that h then carries the traffic to the target.

host is an IP literal, optionally in square brackets, or a name of up to 255 bytes that the proxy resolves. With auth set, offers no authentication and username and password; with none, only no authentication. Parks the green thread during the exchange and is limited by the connection's timeouts. Fails with Invalid for a port outside 1 to 65535, an unusable host or credentials, and with Denied if the proxy refuses every method or the credentials, or requires authentication and auth is none. A proxy reply code of 2 gives Denied, 3 and 4 Unreachable, 5 Refused, 6 TimedOut, 7 and 8 Unsupported, and another code Os(code). A reply that does not follow the protocol gives Malformed, and a proxy that closes early gives Eof.
