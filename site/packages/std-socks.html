std/socks

#net

import std/socks

SOCKS5 (RFC 1928, with RFC 1929 username and password) and SOCKS4a clients: dial, dial4a, tunnel and tunnel4a over an existing connection, and dialer and dialer4a, which return a net.Dialer. The proxy resolves the target name.

Imports std/io, std/net.
