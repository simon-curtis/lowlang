std/csv

#formats

import std/csv

RFC 4180 records with quoted fields, doubled quotes, embedded newlines and CRLF or LF line ends. parse and parse_with a separator fail with the line of an unterminated or bare quote. format, format_with and append_record quote only fields that need it.

Imports std/text.

Functions

append_record

pub fn append_record(mut out: []u8, fields: []str, separator: u8)

Appends one record to out, with fields joined by separator and a \r\n line end.

A field is quoted when it contains the separator, ", \r or \n, or starts or ends with a space; inside quotes each " is doubled. Other fields are written as they are. An empty fields slice appends only the line end.

format

pub fn format(records: [][]str) -> str

Formats records as comma separated CSV text.

Equivalent to format_with(records, ',').

format_with

pub fn format_with(records: [][]str, separator: u8) -> str

Formats records as CSV text with fields separated by separator.

Each record is written by append_record, so every record, including the last, ends with \r\n. Empty records gives an empty string.

parse_with

pub fn parse_with(src: str, separator: u8) -> [][]str ! Error

Parses src into records of fields split on separator.

Records end at \n, \r\n or a lone \r; the final line end is optional. Empty lines are skipped, so they produce no record, while a line holding only spaces is a record with one field. Fields are not trimmed. A field that starts with " is quoted: it may hold the separator and line ends, and "" stands for one ". Records may have different numbers of fields, and a trailing separator yields a final empty field. Empty input gives no records.

Fails with UnterminatedQuote or BareQuote, each carrying a line number.
