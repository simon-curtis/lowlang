import std/container/ordered

An AVL Tree[K, V] for ordered keys: tree, put, get, remove, contains, size, height, is_valid, first, last, floor_entry, ceiling_entry, each, each_range, keys, values, entries and the half-open range(lo, hi).

Imports std/math.

Examples

price_tiers

import std/container/ordered

/// Looks up the unit price for an order size in a tree keyed by the smallest quantity of each tier.
fn main() {
    var tiers = ordered.tree[i64, i64]()
    tiers.put(1, 500)
    tiers.put(50, 450)
    tiers.put(500, 400)
    tiers.put(10, 480)
    tiers.put(5000, 350)
    print("{tiers.size()} tiers, valid: {tiers.is_valid()}")

    for quantity in [1, 9, 10, 49, 600, 20000] {
        let tier = tiers.floor_entry(quantity) ?? continue
        let upgrade = tiers.ceiling_entry(quantity + 1)
        match upgrade {
            some(next) => print("{quantity} units: {tier.value} each, {next.key - quantity} more for {next.value}")
            none => print("{quantity} units: {tier.value} each, best price")
        }
    }

    print("quantity 0 has a tier: {tiers.floor_entry(0) != none}")

    tiers.put(50, 440)
    tiers.remove(5000)
    print("tiers 10 to 500:")
    tiers.each_range(10, 500, fn(from, price) print("  from {from}: {price}"))
    let last = tiers.last() ?? return
    print("largest tier starts at {last.key}")
    print("starting quantities {tiers.keys()}")
}

Tree

pub struct Tree[K: Ord, V] {
    ...
}

A map from keys to values kept in ascending key order, implemented as an AVL tree.

Create one with tree. Lookup, insertion, removal and the nearest-key queries take O(log n) time. Keys are compared with < and >. Nodes are shared between copies of a Tree, so keep a single copy and mutate it through mut.

each_range

pub fn each_range[K: Ord, V](t: Tree[K, V], lo: K, hi: K, visit: fn(K, V))

Calls visit in ascending key order with each key and value whose key is at least lo and less than hi.

Skips subtrees outside the range, so it takes O(log n + m) time for m visited entries.

is_valid

pub fn is_valid[K: Ord, V](t: Tree[K, V]) -> bool

Returns true when t satisfies the AVL invariants.

Checks that keys are ordered, that subtree heights differ by at most one and are recorded correctly, and that the stored size matches the number of nodes. Visits every node.

range

pub fn range[K: Ord, V](t: Tree[K, V], lo: K, hi: K) -> []Entry[K, V]

Returns the entries whose key is at least lo and less than hi, in ascending key order.

The range is half-open: hi is excluded. The result is empty when lo is not less than hi.
