std/crypto/jose

#crypto

import std/crypto/jose

JSON Web Tokens: compact JWS with HS256/384/512, RS256/384/512, PS256/384/512, ES256, ES384 and EdDSA, JWK sets, and claim checks. asymmetric_algorithms lists the public key algorithms and token_kid reads the key id from a token header.

Imports std/base64, std/crypto/ecdsa, std/crypto/ed25519, std/crypto/hash, std/crypto/rsa, std/io, std/json, std/text, std/time.

tokens

import std/crypto/ecdsa
import std/crypto/hash
import std/crypto/jose
import std/io
import std/json
import std/text

fn payload(subject: str, expires: i64) -> json.Value {
    json.object_value([
        json.text_member("iss", "https://login.example.test"),
        json.text_member("sub", subject),
        json.member("aud", json.Value.Array([json.Value.Str("billing"), json.Value.Str("reports")])),
        json.int_member("exp", expires),
    ])
}

fn judge(label: str, token: str, keys: []jose.Jwk, options: jose.Options) {
    let claims = jose.verify(token, keys, options) catch {
        Invalid => {
            print("{label}: rejected")
            return
        }
        _ => {
            print("{label}: malformed")
            return
        }
    }
    print("{label}: accepted for {claims.sub ?? "nobody"}")
}

fn run() ! io.Error {
    let now = 1900000000
    let shared = jose.Jwk { kid: "k1", key: jose.Key.Hmac(bytes("0123456789abcdef0123456789abcdef")) }
    let token = jose.sign("HS256", "k1", shared.key, payload("ada", now + 300))?
    print("token {token}")
    print("kid {jose.token_kid(token)}")

    let options = jose.Options { algorithms: ["HS256"], issuer: "https://login.example.test", audience: "billing", now }
    judge("fresh token", token, [shared], options)
    judge("six minutes later", token, [shared], jose.Options { algorithms: ["HS256"], now: now + 360 })
    judge("wrong audience", token, [shared], jose.Options { algorithms: ["HS256"], audience: "payroll", now })
    judge("only RS256 allowed", token, [shared], jose.Options { algorithms: ["RS256"], now })
    let other = jose.Jwk { kid: "k1", key: jose.Key.Hmac(bytes("fedcba9876543210fedcba9876543210")) }
    judge("another secret", token, [other], options)

    let private = hash.sum(hash.sha256(), bytes("issuer signing key"))
    let public = ecdsa.public_key(ecdsa.Curve.P256, private)?
    let signing = jose.Jwk { kid: "2026-11", key: jose.Key.Ec(ecdsa.Curve.P256, public, private), alg: "ES256" }
    let signed = jose.sign("ES256", signing.kid, signing.key, payload("grace", now + 300))?
    print("kid {jose.token_kid(signed)}, {text.split(signed, '.').len} parts")

    let published = jose.jwks_json([shared, signing])
    print("published {published.len} bytes, mentions private scalar: {text.contains(published, "\"d\"")}")
    let fetched = jose.parse_jwks(bytes(published))?
    print("fetched {fetched.len} key, kid {fetched[0].kid}")
    judge("es256 against the published set", signed, fetched, jose.Options { algorithms: jose.asymmetric_algorithms(), now })
    judge("hmac token against the published set", token, fetched, options)
}

/// Issues an HS256 token and checks it under several policies, then signs with ES256, publishes the public JWK Set and verifies against what a client would fetch.
fn main() {
    run() catch {
        e => print("failed: {e}")
    }
}

jwk_json

pub fn jwk_json(k: Jwk) -> str

Returns the JSON text of the public part of k.

Private members (d and the RSA primes) are never written. An HMAC key writes its secret k; use jwks_json to publish a set without symmetric keys. The use member is always sig, and kid and alg are written when not empty.

asymmetric_algorithms

pub fn asymmetric_algorithms() -> []str

Returns the names of the public key signature algorithms that sign and verify_jws support:RS256, RS384, RS512, PS256, PS384, PS512, ES256, ES384 and EdDSA.

jwks_json

pub fn jwks_json(keys: []Jwk) -> str

Returns the JSON text of a JWK Set holding the public parts of keys.

HMAC keys are left out so a shared secret is never published. Private members are never written.

parse_jwks

pub fn parse_jwks(data: []u8) -> []Jwk ! io.Error

Parses a JWK Set (RFC 7517 section 5) or a single JWK from JSON text.

A top-level object with a keys member is read as a set; any other object is read as one key. Keys that cannot be used are skipped, not reported: an unsupported kty or curve, a use other than sig, a missing member, malformed Base64url or a coordinate of the wrong length. Leading zero bytes of RSA integers are stripped.

Fails with Malformed when the text is not JSON, is not an object, or has a keys member that is not an array.

sign

pub fn sign(alg: str, kid: str, key: Key, payload: json.Value) -> str ! io.Error

Returns the compact JWS (RFC 7515) of payload signed with key under the algorithm alg.

The result is header.payload.signature, each part Base64url without padding. The header holds alg, typ of JWT and, when kid is not empty, kid. The payload is the compact JSON of payload.

Supported algorithms are HS256, HS384, HS512, RS256, RS384, RS512, PS256, PS384, PS512, ES256, ES384 and EdDSA (RFC 7518, RFC 8037). ECDSA signatures are the fixed-width r and s concatenation, not DER. Fails with Invalid when alg is not supported, the key type does not suit it, the key has no private part, an HMAC secret is shorter than the hash output or an Ed25519 seed is not 32 bytes.

token_kid

pub fn token_kid(token: str) -> str

Returns the kid in the header of the compact JWS token.

Returns the empty string when the header has no kid or token has no header that verify_jws could read. The signature is not checked.

verify

pub fn verify(token: str, keys: []Jwk, options: Options) -> Claims ! io.Error

Verifies a signed JWT and returns its claims.

The signature is checked with verify_jws. The payload must be a JSON object without repeated members. The token is rejected when exp is present and the time, less leeway, has reached it; when nbf is present and the time, plus leeway, is before it; when options.issuer is set and iss differs; or when options.audience is set and aud does not contain it. A token with no exp does not expire. iat is parsed but not checked.

Fails with Malformed when the token, payload or a registered claim has the wrong shape, and with Invalid when the signature or any check fails.

verify_jws

pub fn verify_jws(token: str, keys: []Jwk, algorithms: []str) -> []u8 ! io.Error

Verifies the compact JWS token against keys and returns its decoded payload.

Only an alg named in algorithms is accepted, so the caller, not the token, chooses the algorithms. A key is tried when its kid matches the header's (or either has none) and its alg is empty or equal to the header's, and its type suits the algorithm. The first key whose signature verifies wins. HMAC comparison is constant-time.

Fails with Malformed when the token does not have three Base64url parts, the header is not a JSON object or repeats a member, or alg or kid is not a string. Fails with Invalid when the header has a crit member, the algorithm is not allowed or supported, or no key verifies the signature. The payload is not parsed.
