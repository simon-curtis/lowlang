std/crypto/blake3

#crypto

import std/crypto/blake3

BLAKE3: sum, xof, keyed_hash, derive_key, an incremental Hasher with finalize and seekable finalize_at, and algorithm(), a hash.Algorithm for HMAC.

Imports std/crypto/hash.

Types

Error

pub enum Error {
    /// The key is not 32 bytes.
    BadKey
}

The failure of a BLAKE3 operation.

Hasher

pub struct Hasher {
    ...
}

An incremental BLAKE3 hash computation.

Created by hasher, keyed_hasher or derive_key_hasher, fed with update and read with finalize or finalize_at.

clone

pub fn clone(h: *Hasher) -> *Hasher

Returns an independent copy of h with the same mode and input so far.

finalize

pub fn finalize(h: *Hasher, length: i64) -> []u8

Returns the first length bytes of the extendable output of h. A length of 32 is the standard BLAKE3 hash. h is not modified.

finalize_at

pub fn finalize_at(h: *Hasher, offset: i64, length: i64) -> []u8

Returns length bytes of the extendable output of h, starting at byte offset.

h is not modified, so the call can be repeated and more input can be added afterwards. offset and length must not be negative.

update

pub fn update(h: *Hasher, data: []u8)

Appends data to the input of h. It can be called any number of times, and empty data has no effect.

Functions

algorithm

pub fn algorithm() -> hash.Algorithm

Returns the hash.Algorithm for BLAKE3.

The name is blake3, the digest is 32 bytes and the block size is 64 bytes.

derive_key

pub fn derive_key(context: str, material: []u8, length: i64) -> []u8

Returns length bytes of key material derived from material under context with BLAKE3 key derivation mode.

derive_key_hasher

pub fn derive_key_hasher(context: str) -> *Hasher

Returns a Hasher in key derivation mode for context.

The key material is fed with update. context should be a fixed string that is unique to the application and purpose.

hasher

pub fn hasher() -> *Hasher

Returns a Hasher in the default hash mode.

keyed_hash

pub fn keyed_hash(key: []u8, data: []u8) -> []u8 ! Error

Returns the 32-byte BLAKE3 keyed hash of data under the 32-byte key. Fails with Error.BadKey when key is not 32 bytes.

keyed_hasher

pub fn keyed_hasher(key: []u8) -> *Hasher ! Error

Returns a Hasher in keyed hash mode with the 32-byte key. Fails with Error.BadKey when key is not 32 bytes.

sum

pub fn sum(data: []u8) -> []u8

Returns the 32-byte BLAKE3 hash of data.

xof

pub fn xof(data: []u8, length: i64) -> []u8

Returns length bytes of the BLAKE3 extendable output for data in the default hash mode.
