std/file

#io #os

import std/file

Opening: open, create, append and update return a droppable File whose handle is a copyable FileHandle. On a File: read, write, write_all, seek, sync, truncate, close, info and stat. On a FileHandle: read_on, write_on, write_all_on, close_on and stream_on. Whole files and directories: exists, read_file, read_text, write_file, write_text, remove, remove_dir, rename, mkdir, mkdir_all, list and stream. read_file sizes its buffer from the file's size; a file that reports no size, such as one under /proc, is read into a 64 KB buffer that doubles when full. Permission bits: create_mode, write_file_mode, write_text_mode, mkdir_mode and mkdir_all_mode take them, the other creators use 0o644 for files and 0o755 for directories, all are filtered by the process umask, and chmod is not. Locks: try_lock and unlock are advisory flock locks that report a held lock as false instead of waiting. remove_all removes a tree without following symbolic links. temp_dir creates a private directory under os.temp_dir_path(), which is TMPDIR when set and /tmp otherwise; temp_file and temp_dir_pattern use it when dir is empty and all three draw the random name suffix from getrandom. child_path joins a directory and an entry name. Info also carries regular, link, accessed, uid, gid, device and inode. Further functions: lstat, is_dir, is_file, is_symlink, symlink, link, readlink, realpath, chown, lchown, set_times, disk_usage and read_dir_info. walk is a sorted depth-first walk that uses lstat, never descends into symbolic links and lets its callback return Continue, Skip or Stop. glob matches each segment with path.matches and supports **. copy and copy_dir keep file modes and recreate symbolic links. temp_file(dir, pattern) creates a uniquely named file with O_EXCL and mode 0600 and returns a droppable TempFile that closes and removes it unless keep is called. temp_dir_pattern makes a 0700 directory the same way.

Imports std/io, std/os, std/path, std/slices, std/sys, std/text.

The kind flags describe the entry itself without following symbolic links. An entry that is none of dir, link and regular is another kind, such as a socket or device.

File

pub struct File {The copyable view of the open file.    pub handle: FileHandle
}

An open file that closes itself when dropped.

handle is the copyable view for passing the file to other green threads, and close or close_on closes it early.

close

pub fn close(f: File)

Closes the file.

Equivalent to close_on(f.handle). Later operations on the file or any copy of its handle fail with NotConnected. The descriptor is released immediately, or when the last operation in flight returns.

info

pub fn info(f: File) -> Info ! io.Error

Returns the metadata of the open file.

Fails with NotConnected when the file has been closed.

read

pub fn read(f: File, buf: []u8) -> i64 ! io.Error

Reads up to buf.len bytes from the current position into buf and returns the count, or 0 at end of file.

Blocks until data is available and can return fewer bytes than requested. The position advances by the count.

seek

pub fn seek(f: File, offset: i64, from: Whence) -> i64 ! io.Error

Moves the position by offset bytes relative to from and returns the new position measured from the start of the file.

offset can be negative. A position past the end is allowed; a later write extends the file with zeros. Fails with Invalid when the resulting position would be negative.

stream

pub fn stream(f: File) -> io.Stream

Returns an io.Stream over the file.

Closing the stream closes the file.

sync

pub fn sync(f: File) ! io.Error

Flushes the file's data and metadata to the storage device and returns once the device has accepted them.

truncate

pub fn truncate(f: File, size: i64) ! io.Error

Sets the file's size to size bytes.

A smaller size discards the tail and a larger one extends the file with zeros. The position does not change. Fails with Invalid when the file was not opened for writing.

try_lock

pub fn try_lock(f: File, exclusive: bool) -> bool ! io.Error

Tries to take an advisory flock lock on the file, exclusive when exclusive is true and shared otherwise.

Returns false without waiting when another descriptor holds a conflicting lock. The lock is released by unlock or when the file is closed.

unlock

pub fn unlock(f: File) ! io.Error

Releases the advisory flock lock that this file holds.

write

pub fn write(f: File, data: []u8) -> i64 ! io.Error

Writes a prefix of data at the current position and returns how many bytes were written, which can be fewer than data.len.

The position advances by the count. Use write_all to write everything.

write_all

pub fn write_all(f: File, data: []u8) ! io.Error

Writes all of data at the current position, repeating write until nothing remains.

Fails with the first error a write returns, after which part of data may have been written.

write_str

pub fn write_str(f: File, text: str) ! io.Error

Writes the bytes of text to the file.

Fails as write_all does.

FileHandle

pub struct FileHandle {The operating system file descriptor.    pub fd: i64
    ...
}

A copyable view of an open file, made of its descriptor and the guard that coordinates its closing.

Copies of a FileHandle refer to the same descriptor. Once any copy is closed, every operation on the handle fails with NotConnected, so a closed descriptor is never reached after the kernel reuses its number.

close_on

pub fn close_on(h: FileHandle)

Closes the file that h views.

Later operations on h or its copies fail with NotConnected. The descriptor is released immediately, or when the last operation in flight returns. Closing twice does nothing.

read_on

pub fn read_on(h: FileHandle, buf: []u8) -> i64 ! io.Error

Reads up to buf.len bytes from the current position of the file that h views into buf and returns the count, or 0 at end of file.

Fails with NotConnected when the file has been closed.

stream_on

pub fn stream_on(h: FileHandle) -> io.Stream

Returns an io.Stream over the file that h views.

Closing the stream closes the file. The stream is safe to copy and use from other green threads.

write_all_on

pub fn write_all_on(h: FileHandle, data: []u8) ! io.Error

Writes all of data to the file that h views, repeating write_on until nothing remains.

Fails with the first error a write returns, after which part of data may have been written.

write_on

pub fn write_on(h: FileHandle, data: []u8) -> i64 ! io.Error

Writes a prefix of data at the current position of the file that h views and returns how many bytes were written, which can be fewer than data.len.

Fails with NotConnected when the file has been closed.

Functions

append

pub fn append(path: str) -> File ! io.Error

Opens the file at path for appending, creating it with mode 0o644 if it does not exist.

Every write goes to the end of the file regardless of seek. The file is write-only and existing content is kept.

child_path

pub fn child_path(dir: str, name: str) -> str

Returns the path of the entry name inside the directory dir, without cleaning either part.

A single / separates them, and none is added when dir already ends with one. An empty dir gives name and an empty name gives dir.

chmod

pub fn chmod(path: str, mode: i64) ! io.Error

Sets the permission bits of the file at path to mode.

Follows symbolic links. Unlike the creating functions, the umask does not filter mode. Fails with NotFound when path does not exist and Denied when the caller does not own the file.

chown

pub fn chown(path: str, uid: i64, gid: i64) ! io.Error

Sets the owner and group of the file at path to uid and gid, following symbolic links.

Fails with Denied when the caller lacks the privilege.

copy

pub fn copy(from: str, to: str) ! io.Error

Copies the contents of the file from to to.

Follows symbolic links on both paths. to is created or truncated and ends with the permission bits of from. Fails with IsDir when from is a directory and Invalid when both paths name the same file. A failure part way leaves a partial to. See copy_dir for directories.

copy_dir

pub fn copy_dir(from: str, to: str) ! io.Error

Copies the directory tree from to to.

Creates to when it does not exist; its parent must exist. Regular files are copied as copy does, symbolic links are recreated as links instead of followed, and directories are copied recursively. Directory and file modes are kept. Fails with NotDir when from is not a directory, Invalid when to is from or inside it, and Unsupported for an entry that is not a file, link or directory.

create

pub fn create(path: str) -> File ! io.Error

Creates the file at path for writing, or truncates it to zero length if it exists.

A new file gets mode 0o644, filtered by the process umask. The file is opened write-only, so read fails. See create_mode to choose the mode.

create_mode

pub fn create_mode(path: str, mode: i64) -> File ! io.Error

Creates the file at path for writing with permission bits mode, or truncates it to zero length if it exists.

mode is filtered by the process umask and applies only when the file is created; an existing file keeps its mode.

disk_usage

pub fn disk_usage(path: str) -> Usage ! io.Error

Returns the capacity figures of the file system that holds path.

Space is in bytes. Fails with NotFound when path does not exist.

exists

pub fn exists(path: str) -> bool

Returns whether path exists.

Follows symbolic links, so a dangling link gives false. Any error, including a denied lookup, gives false.

glob

pub fn glob(pattern: str) -> []str

Returns the paths that match the glob pattern, sorted and without duplicates.

Each /-separated segment is matched against directory entry names with path.matches, so *, ?, [...] and \ work and no segment treats a leading . specially. A segment ** matches any number of nested directories, none included, and as the last segment matches every entry below. Symbolic links are not descended through **.

A relative pattern gives relative paths and an absolute one gives absolute paths. Unreadable directories contribute nothing, so a pattern with no match gives an empty slice, not an error.

is_dir

pub fn is_dir(path: str) -> bool

Returns whether path is a directory, following symbolic links.

Any error, including a missing path, gives false.

is_file

pub fn is_file(path: str) -> bool

Returns whether path is a regular file, following symbolic links.

Any error, including a missing path, gives false.

is_symlink

pub fn is_symlink(path: str) -> bool

Returns whether path is a symbolic link, without following it.

Any error, including a missing path, gives false.

lchown

pub fn lchown(path: str, uid: i64, gid: i64) ! io.Error

Sets the owner and group of path to uid and gid, changing a symbolic link itself instead of its target.

Fails with Denied when the caller lacks the privilege.

link

pub fn link(existing: str, new_path: str) ! io.Error

Creates new_path as a hard link to the file existing.

Both names refer to the same inode. Fails with Exists when new_path exists, Denied when existing is a directory and an Os error when the paths are on different file systems.

list

pub fn list(path: str) -> []str ! io.Error

Returns the names of the entries in the directory path, without . and ...

The names are in the order the file system returns them, not sorted. See read_dir_info for entry kinds and walk for a sorted traversal.

lstat

pub fn lstat(path: str) -> Info ! io.Error

Returns the metadata of path without following a final symbolic link.

For a link, the result describes the link itself and link is true. Fails with NotFound when path does not exist.

mkdir

pub fn mkdir(path: str) ! io.Error

Creates the directory path with mode 0o755, filtered by the process umask.

Fails with Exists when path exists and NotFound when its parent does not.

mkdir_all

pub fn mkdir_all(path: str) ! io.Error

Creates the directory path and every missing parent, with mode 0o755 filtered by the process umask.

mkdir_all_mode

pub fn mkdir_all_mode(path: str, mode: i64) ! io.Error

Creates the directory path and every missing parent, with permission bits mode filtered by the process umask.

Succeeds when a component already exists; the existing entry at path is not checked to be a directory. Fails with NotDir when a parent component is a file.

mkdir_mode

pub fn mkdir_mode(path: str, mode: i64) ! io.Error

Creates the directory path with permission bits mode, filtered by the process umask.

Fails with Exists when path exists and NotFound when its parent does not.

open

pub fn open(path: str) -> File ! io.Error

Opens the file at path for reading.

Fails with NotFound when the file does not exist. Opening a directory succeeds and the first read fails with IsDir. The descriptor is closed when the returned File is dropped or closed.

read_dir_info

pub fn read_dir_info(path: str) -> []Entry ! io.Error

Returns the entries of the directory path, without . and ...

The entries are in the order the file system returns them, not sorted. The kind comes from the directory record, or from lstat when the file system does not provide one. Fails with NotFound when path does not exist and NotDir when it is not a directory.

read_file

pub fn read_file(path: str) -> []u8 ! io.Error

Returns the entire contents of the file at path.

The buffer is sized from the file's size. A file that reports no size, such as one under /proc, is read into a 64 KB buffer that doubles when full. Fails with NotFound when the file does not exist and IsDir when path is a directory.

read_text

pub fn read_text(path: str) -> str ! io.Error

Returns the entire contents of the file at path as text.

The bytes are viewed as a str without validating them as UTF-8. Fails as read_file does.

readlink

pub fn readlink(path: str) -> str ! io.Error

Returns the target text of the symbolic link path.

The text is returned as stored, relative or absolute. Fails with Invalid when path is not a symbolic link and TooLarge when the target is 1 MiB or longer.

realpath

pub fn realpath(path: str) -> str ! io.Error

Returns the absolute path of path with every symbolic link resolved and no . or .. components.

Requires /proc to be mounted. Fails with NotFound when path does not exist.

remove

pub fn remove(path: str) ! io.Error

Removes the file or symbolic link at path.

A symbolic link is removed, not its target. Fails with NotFound when path does not exist and IsDir when it is a directory; see remove_dir and remove_all.

remove_all

pub fn remove_all(path: str) ! io.Error

Removes the file, symbolic link or directory tree at path.

Succeeds when path does not exist. Directory contents are removed recursively and symbolic links are removed without being followed.

remove_dir

pub fn remove_dir(path: str) ! io.Error

Removes the empty directory at path.

Fails with NotEmpty when the directory has entries, NotDir when path is not a directory and NotFound when it does not exist.

rename

pub fn rename(from: str, to: str) ! io.Error

Renames the entry from to to.

An existing to is replaced atomically, except that a directory can only replace an empty directory. Fails with an Os error when the two paths are on different file systems.

set_times

pub fn set_times(path: str, accessed: i64, modified: i64) ! io.Error

Sets the access and modification times of the file at path, in whole seconds since the Unix epoch.

Follows symbolic links. The nanosecond parts are set to zero.

stat

pub fn stat(path: str) -> Info ! io.Error

Returns the metadata of the file at path, following symbolic links.

Fails with NotFound when path does not exist, including when it is a dangling link. See lstat to inspect a link itself.

symlink

pub fn symlink(target: str, link_path: str) ! io.Error

Creates the symbolic link link_path that holds the text target.

target is stored as given and need not exist. Fails with Exists when link_path exists.

temp_dir

pub fn temp_dir(prefix: str) -> str ! io.Error

Creates a private directory under os.temp_dir_path() and returns its path.

The name is prefix followed by ten random characters from 0-9a-z and the mode is 0o700. Fails with Invalid when prefix contains / and Exists after 64 name collisions. The caller removes the directory; see temp_dir_pattern to choose the parent.

temp_dir_pattern

pub fn temp_dir_pattern(dir: str, pattern: str) -> str ! io.Error

Creates a uniquely named temporary directory with mode 0o700 and returns its path.

dir, pattern and the failures are as for temp_file. The caller removes the directory.

temp_file

pub fn temp_file(dir: str, pattern: str) -> TempFile ! io.Error

Creates a uniquely named temporary file and returns it.

The file is created in dir, or in os.temp_dir_path() when dir is empty; dir must already exist. pattern is the file name: its last * is replaced by ten random characters from 0-9a-z, and the characters are appended when there is no *. The file is opened read-write with O_EXCL and mode 0o600.

Fails with Invalid when pattern contains / and Exists after 64 name collisions.

update

pub fn update(path: str) -> File ! io.Error

Opens the file at path for reading and writing, creating it with mode 0o644 if it does not exist.

Existing content is kept and the position starts at the beginning.

walk

pub fn walk(root: str, visit: fn(Visit) -> Step) ! io.Error

Calls visit for root and everything below it, depth first, with the entries of each directory in name order.

visit runs for a directory before its entries and its result decides whether to continue, skip the directory or stop; see Step. Symbolic links are reported and never followed, including a link at root. Fails with the error of lstat on root or of reading a directory.

write_file

pub fn write_file(path: str, data: []u8) ! io.Error

Writes data to the file at path, creating it with mode 0o644 or truncating it first if it exists.

The write is not atomic; a failure part way leaves a partial file.

write_file_mode

pub fn write_file_mode(path: str, data: []u8, mode: i64) ! io.Error

Writes data to the file at path, creating it with permission bits mode or truncating it first if it exists.

mode is filtered by the process umask and applies only when the file is created. The write is not atomic.

write_text

pub fn write_text(path: str, text: str) ! io.Error

Writes the bytes of text to the file at path, creating it with mode 0o644 or truncating it first if it exists.

write_text_mode

pub fn write_text_mode(path: str, text: str, mode: i64) ! io.Error

Writes the bytes of text to the file at path, creating it with permission bits mode or truncating it first if it exists.

mode is filtered by the process umask and applies only when the file is created.
