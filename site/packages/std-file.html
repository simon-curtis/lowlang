std/file

#io #os

import std/file

Opening: open, create, append and update return a droppable File whose handle is a copyable FileHandle. On a File: read, write, write_all, seek, sync, truncate, close, info and stat. On a FileHandle: read_on, write_on, write_all_on, close_on and stream_on. Whole files and directories: exists, read_file, read_text, write_file, write_text, remove, remove_dir, rename, mkdir, mkdir_all, list and stream. read_file sizes its buffer from the file's size; a file that reports no size, such as one under /proc, is read into a 64 KB buffer that doubles when full. Permission bits: create_mode, write_file_mode, write_text_mode, mkdir_mode and mkdir_all_mode take them, the other creators use 0o644 for files and 0o755 for directories, all are filtered by the process umask, and chmod is not. Locks: try_lock and unlock are advisory flock locks that report a held lock as false instead of waiting. remove_all removes a tree without following symbolic links. temp_dir creates a private directory under /tmp. Info also carries regular, link, accessed, uid, gid, device and inode. Further functions: lstat, is_dir, is_file, is_symlink, symlink, link, readlink, realpath, chown, lchown, set_times, disk_usage and read_dir_info. walk is a sorted depth-first walk that uses lstat, never descends into symbolic links and lets its callback return Continue, Skip or Stop. glob matches each segment with path.matches and supports **. copy and copy_dir keep file modes and recreate symbolic links. temp_file(dir, pattern) creates a uniquely named file with O_EXCL and mode 0600 and returns a droppable TempFile that closes and removes it unless keep is called. temp_dir_pattern makes a 0700 directory the same way.

Imports std/io, std/path, std/slices, std/text.
